# van Everdingen Hurst 1949 — преобразование Лапласа для пластовых задач

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**van Everdingen A.F., Hurst W.** The Application of the LaPlace Transformation to Flow Problems in Reservoirs. *Trans. AIME*, 1949, **186**, 305.

## Аннотация

Фундаментальная работа: аналитические решения для радиальной фильтрации жидкости в замкнутом и незамкнутом пластах через преобразование Лапласа. Введены безразмерные переменные $p_D(r_D, t_D)$, ставшие стандартом ГДИС. Решения Al-Hussainy 1966 для реального газа коррелируют с $p_D(t_D)$ van Everdingen–Hurst при использовании функции псевдодавления $m(p)$.

## Потенциал для проекта

Безразмерные решения — эталон для верификации квазианалитических приближений (метод моментов, модели М.3–М.4). Жидкостная аналогия через [[Al-Hussainy 1966 — псевдодавление для реальных газов|$m(p)$]] — мост к многофазному обобщению [[Краснов — многофазное псевдодавление и функции источника|Краснова]].
