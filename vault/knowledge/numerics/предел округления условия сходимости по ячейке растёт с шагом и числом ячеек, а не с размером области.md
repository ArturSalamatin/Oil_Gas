# Предел округления условия сходимости по ячейке растёт с шагом и числом ячеек, а не с размером области

## Условие и его предел

Условие сходимости Ньютона по ячейке ([[BUG-022]], `problem_statement.tex`, `eq:newton_cell_tol`):
$$\max_{c,j} \frac{\Delta t}{V_{p,j}} |F_{c,j}| \le \varepsilon^{cell} = 10^{-8}.$$
Здесь $F$ — невязка прототипа в м³ст/с (газ поделён на $s_g$), $V_p$ — поровый объём на начало шага.

Ниже некоторого предела порог недостижим. При BUG-022 предел оценили как $\varepsilon_{маш}V_{p,\max}/V_{p,\min} \approx \varepsilon_{маш}(R_{ext}/r_w)^2$, не проверив, от чего он зависит. Оценка ушла в шесть документов: постановку, комментарии конфига и прототипа, P8, CHANGELOG, заметку BUG-022. Замер [[DEBT-055]] её опроверг.

## Механизм

Неизвестные $z_k$ ($p$, $S_g$ или $R_s$ ячеек) представимы лишь с шагом $\mathrm{ulp}(z_k) \approx \varepsilon_{маш}|z_k|$. Невязку ячейки нельзя сделать меньше доли изменения, которое даёт сдвиг каждой неизвестной на ulp. Оценка этого изменения сверху (`eq:newton_cell_floor`):
$$m_{окр} = \max_{c,j} \frac{\Delta t}{V_{p,j}}\bigl(|J|\,\mathrm{ulp}(z)\bigr)_{c,j}.$$

97–100 % предела дают столбцы давления: члены потоков через грани $\mathcal T\lambda(p_j - p_{j+1})$. Поэтому
$$m_{окр} \sim \varepsilon_{маш}\,p\,\mathcal T\lambda\,\Delta t/V_{p,j}.$$
У забоя логарифмической сетки $\mathcal T/V_{p,1} \approx k/(\varphi r_w^2 \ln^2 q)$, где $\ln q = \ln(R_{ext}/r_w)/N$. Значит, предел $\propto \Delta t\,N^2/\ln^2(R_{ext}/r_w)$.

## Замеры (`vault/issues/debt-055/probes/`)

Пример 17, состояние после 2 сут добычи, шаг останова 3600 с (`floor_probe.out.txt`):

|---|---|---|---|
| $\Delta t$ (добыча) | 225 → 900 → 3600 → 14400 → 86400 с | ×4.00, ×4.00, ×3.98, ×5.99 | не меняется |
| $N$ | 100 → 200 → 400 | 1.36e-10 → 5.99e-10 → 2.50e-9 | 7.6e-10 → 8.2e-10 → 8.6e-10 |
| $R_{ext}$ | 200 → 1000 → 2000 м | 6.0e-10 → 4.0e-10 → 3.4e-10 | 8.2e-10 → 2.0e-8 → 8.0e-8 |

- Сдвиг $z$ на ±1 ulp меняет меру так же, как предсказывает $|J|\,\mathrm{ulp}(z)$: в пределах 12 %, у 14 строк из 17 — в пределах 3 %.
- Чистый Ньютон из решения доходит до 0.09–0.26 предела.
- Отказы «только по ячейке» встают на 0.23–0.40 предела (`failures_floor_*.out.txt`). Все они — при $N$ = 350 и шаге 1 сут: BUG-018, пример 14, суточный останов.
- Полный расчёт 17 при $R_{ext}$ = 2000 м и пороге 1e-8: отказов 0, якобианов +1 %. Старая оценка обещала ×2.9.
- При $N$ = 800 условие по ячейке расчёт удешевляет: 83 отказа против 140 без него (`cost17_*.out.txt`).

## Следствия

- Предел $\propto \Delta t$, поэтому дробление шага его снимает: срыва расчёта нет, есть лишь лишние подшаги. С DEBT-055 отчёт отказа несёт предел (`cell_floor`), а текст говорит «мера не выше предела округления». С [[DEBT-067]] решение на пределе принимается построчно (`eq:newton_cell_tol_floor`), шаг не дробится.
- У Ньютона два предела округления по разные стороны шага:
  - абсолютный критерий — $\propto 1/\Delta t$ (накопление крупнейшей ячейки; [[BUG-025]], [[на коротком шаге невязка Ньютона стоит на пределе округления запасов — допуск не ниже 4ε·M_max на Δt]]);
  - условие по ячейке — $\propto \Delta t$.

  При мелкой сетке и большой области окно шагов без лишних отказов сужается с обеих сторон.
- Принимать решение на пределе, а не дробить шаг впустую, — [[DEBT-067]] (2026-10-14): строка выше порога проходит при $|F_r| \le (|J|\,\mathrm{ulp}(z))_r$. Изменился только пример 14 (первые сутки одним шагом), 19–21 — побитово. Подробности — [[решение на пределе округления принимается построчно — дробление ради порога точности не добавляет]].

## Урок

- Оценку предела записали без замера зависимости от $\Delta t$ и $N$, и она разошлась по документам.
- Сдвиг неизвестных на ±1 ulp — дешёвая проверка гипотезы о пределе округления, якобиан для неё не нужен.
- Совпадение порядка величины на одном примере (8.2e-10 против замеренных ~1e-10…1e-9 у 17) не подтверждает форму закона. Нужен замер по каждому параметру отдельно.
