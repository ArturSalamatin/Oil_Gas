**Важно:** в статье ε₁ = 0.4 К/МПа > 0. Это значит μ_JT для нефти **положительный**. Нагрев нефти при дросселировании (JT нефти) — корректно для лёгкой нефти при данных условиях.

Знак ε₂ = -4.0 К/МПа < 0 для газа. В нашей конвенции problem_statement.tex используется μ_JT, связь: ε_I = μ_JT (определение одинаковое, eq. 36 из приложенной картинки).

## Начальные и граничные условия

| Параметр | Значение | Из статьи |
|---|---|---|
| p0 (пластовое) | 10 МПа = 1.0e7 Па | P⁰_head = 10 МПа |
| p_wf (на устье) | 7 МПа = 7.0e6 Па | P_head = 7 МПа |
| T0 | 300 К | T_bottom = 300 К |
| pb | 7.24 / 7.60 / 8.61 МПа | P_{b,p} — три варианта |

Примечание: в статье задаётся давление на устье (z_top), не на забое. Для нашей 1D-модели пласта забойное давление — это давление на стенке скважины (r = r_w). Пересчёт: p_wf ≈ p_head + ρ·g·Δz. При ρ ≈ 800 кг/м³, g = 9.81, Δz ≈ 0 (горизонтальный пласт): p_wf ≈ p_head.

## Адаптация для нашей задачи

Наша задача — 1D радиальная (только пласт, без скважины). Параметры из статьи адаптируются:
- R_ext = 50 м (как в статье)
- p_wf задаём на стенке скважины (r = r_w)
- pb выбираем один вариант (7.24 МПа — минимальный)
- dt_integration: 1 с (как в статье) для начала, затем можно увеличить
- Скважинную модель (уравнения 4–10) не реализуем — только пласт
