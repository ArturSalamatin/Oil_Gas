# BUG-019: проверка согласованности PVT — предупреждение при отрицательной сжимаемости, как в ECLIPSE

**Реестр:** [[известные баги и технический долг]] → BUG-019. **Issue:** [#49](https://github.com/ArturSalamatin/Oil_Gas/issues/49). **Ветка:** `fix/bug-019/newton-stall-developed-gas-zone` от `numerical_scheme/implementation` (имя ветки дано при открытии issue, по симптому; не менять — на него ссылаются issue и реестр).

## Цель

Фабрика при сборке модели проверяет согласованность входных данных PVT модели Black Oil — сжимаемости нефти и газа неотрицательны на диапазоне давлений задачи — и при нарушении выводит предупреждение с интервалом давлений, как ECLIPSE («Negative Compressibility Found»). Расчёт продолжается. Решатель, уравнения и все результаты не меняются.

Отказ Ньютона из BUG-019 (прежний пример 20: $R_{s,0} = 500$, $k$ = 10 мД, вторые сутки) **не устраняется**: это следствие некорректной постановки — PVT Стендинга при $R_{s,0} = 500$ даёт отрицательную сжимаемость насыщенной нефти выше 34.55 МПа, и уравнение давления в части пласта становится обратным уравнением теплопроводности. После исправления пользователь узнаёт об этом при сборке модели, а не по отказу шага на вторые сутки.

## 2. Физика и замеры

### 2.1 Причина BUG-019 (установлена опытом)

Подробно — [[сжимаемость насыщенной нефти по Стендингу отрицательна выше 345 бар — при малой S_g шаг вырождается на последовательности Δt]]. Кратко (нефть прежнего примера 20: Стендинг, $\gamma_g = 0.828$, API 45.2, $T_0 = 380$ К, $R_{s,0} = 500$):

- Сжимаемость насыщенной нефти вместе с выделяющимся газом $c_{ot} = (B_g\,dR_s/dp - dB_o/dp)/B_o$ отрицательна при $p > 34.55$ МПа: усадка нефти при снижении давления больше объёма выделившегося газа.
- Полная сжимаемость двухфазной ячейки $c_t = (1 - S_g)c_{ot} + S_g c_g$ ($c_r = 0$) на 1 сут отрицательна в 40 ячейках ($S_g < 0.105$, $p > 395$ бар); знак $\det$ блока накопления модели совпадает со знаком $c_t$ во всех 348 двухфазных ячейках.
- Якобиан шага $J = A/\Delta t + B$ вырожден на последовательности $\Delta t$ (…, 167.6, 211.5, 277.4, 382, …, 24380 с). Отказы ложатся на неё: в пределах 0.1 интервала от вырожденного $\Delta t$ — 0 из 18 шагов сходятся, посередине — 33 из 40. Шаг A-retry 168.75 с — в 0.7 % от 167.6 с. **Не объяснено:** при 10 мД отказывают все 23 шага $\Delta t \ge 10^4$ с, хотя $J$ там не вырожден ($\sigma_{min}/\sigma_{max} \sim 10^{-6}$); предположение (смена знака растущих мод при неявном шаге за последним вырожденным $\Delta t$) не проверено. На план не влияет: исправление — проверка входных данных, а не решатель.
- Якобиан, ОФП, критерий сходимости ни при чём: якобиан согласован с невязкой (поэлементно ≤ 5.8e-5, раскраска побитово), невязка гладкая вдоль направления Ньютона (тест Тейлора: $e \propto \varepsilon$ на 5 декадах).
- Прежний штатный пример 20 (30 мД) был затронут тем же: зона $c_t < 0$ все 30 сут; суточный шаг проходил, мельчение шага отказывало. Теперь пример на $R_{s,0} = 300$ (решение 4): $p_b = 30.29$ МПа < 34.55 МПа.

### 2.2 Условие и коэффициент уравнения давления

В постановке ([`numerical_solver/doc/problem_statement.tex`](../../numerical_solver/doc/problem_statement.tex)) $c_o^{sat} = c_o - \frac{1}{B_o}\frac{\partial B_o}{\partial R_s}\frac{\partial R_s}{\partial p} = -\frac{1}{B_o}\frac{dB_o^{sat}}{dp}$ (`eq:co_sat`, макрос `\csat`) — без газового слагаемого, $\xi_o = S_o/B_o$. Коэффициент при $\partial p/\partial t$ (`eq:Cp`):

$$C_p = \phi\Bigl[S_o(c_r + c_o^{sat})\Bigl(\tfrac{1}{B_g} - \tfrac{R_s}{B_o}\Bigr) + \tfrac{S_o}{B_o}\bigl(R_s' + R_s(c_r + c_o^{sat})\bigr) + \tfrac{S_g}{B_g}(c_g + c_r)\Bigr]
= \frac{\phi}{B_g}\bigl[S_o(c_r + c_o^{sat}) + S_o\tfrac{B_g}{B_o}R_s' + S_g(c_g + c_r)\bigr]
= \frac{\phi}{B_g}\bigl(c_r + S_o\,c_{ot} + S_g\,c_g\bigr),$$

$c_{ot} = c_o^{sat} + \frac{B_g}{B_o}\frac{\partial R_s}{\partial p}$ (слагаемые $\mp S_o R_s(c_r + c_o^{sat})/B_o$ сокращаются; $S_o + S_g = 1$). $C_p$ линеен по $S_g$, поэтому $C_p \ge 0$ при всех $S_g \in [0, 1]$ тогда и только тогда, когда $c_{ot} \ge 0$ ($S_g = 0$) и $c_g \ge 0$ ($S_g = 1$) при $c_r = 0$. Для недонасыщенной (однофазной) нефти то же требуется от $c_o$. Это условия (A2)–(A3) Peszyńska 2006 (§2.3); в постановку их вносит шаг 6 (`eq:c_ot`).

### 2.3 Литература и практика отрасли

- **Peszyńska M.** The Total Compressibility Condition and Resolution of Local Nonlinearities in an Implicit Black-Oil Model with Capillary Effects. *Transport in Porous Media* 63 (2006) 201–222 (`Refs/peszynska2006.pdf`). Допущение (A3) $B_{so}' - B_g R_s' \le 0$ (со ссылкой на Coats 1999); ур. (23): для насыщенной зоны без капиллярного давления (A2)–(A3) необходимы и достаточны для $\bar c_t \ge 0$; при $\bar c_t \ge 0$ уравнение давления (16) вырожденно-параболическое, и условие «можно использовать для проверки внутренней согласованности данных модели».
- **Coats K.H.** A Note on IMPES and Some IMPES-Based Simulation Models. SPE 49774 (1999).
- **ECLIPSE** — предупреждение «Negative Compressibility Found», расчёт продолжается; OPM Flow такой проверки не делает (рассылка OPM, 2020-03-22, <https://opm-project.org/pipermail/opm/2020-March/000603.html>: пользователь продлил PVT на более высокие давления и получил колебания и отказы сходимости — совет: проверить PVT или снизить давление). Руководство ECLIPSE не сверялось.
- **whitson⁺**, руководство, модуль «PVT Table» (<https://manual.whitson.com/modules/bot/>): проверка отрицательной сжимаемости в 30 равноотстоящих точках от наименьшего до наибольшего давления таблицы, интерполяция и численные производные — как в ECLIPSE.
- **Burgoyne M.** Black Oil Tables Behaving Badly: Taming negative compressibility (2020): «30-stage interpolated compressibility checks that Eclipse performs»; проблема обычно у перехода насыщенной нефти в недонасыщенную.
- **SPE 109596** «Consistent Black-Oil PVT Table Modification» (по материалам курса Уитсона — Singh, Fevang, Whitson; авторство не сверено) и **IPTC-20278** (Algdamsi et al., 2020): несогласованные таблицы дают нефизичное поведение, медленный счёт, «numerical instability and premature run termination»; коррекция $B_o$, $B_g$ под положительную сжимаемость.
- **Диапазон данных Стендинга** (1947, 105 точек, 22 нефти Калифорнии): $R_s$ 20–1425 scf/STB, $p_b$ 130–7000 psia, $T$ 100–258 °F, API 16.5–63.8, $\gamma_g$ 0.59–0.95. Нефть конфига BUG-019 вне диапазона только по $R_s$: смена знака $c_{ot}$ — при $R_s$ = 351 м³/м³ = 1972 scf/STB, $R_{s,0}$ = 2807 scf/STB (`standing_range.py`).

### Шаг 2: Модуль проверки

**Цель:** функции сжимаемостей и поиска интервалов $c < 0$.
**Файл:** `numerical_solver/gpn_multiphase_solver/pvt/consistency.py` (новый). Код проверен до реализации (`probes/consistency_draft.py` — тот же, кроме докстринга модуля и комментария у `_REL_STEP`).

```python
"""Согласованность PVT: сжимаемости нефти и газа неотрицательны (BUG-019).

Условия (A2)-(A3) Peszyńska 2006 (Transport in Porous Media 63) со ссылкой на
Coats 1999 (SPE 49774); ур. (eq:c_ot) problem_statement.tex. ECLIPSE проверяет
то же при загрузке PVT и выдаёт предупреждение «Negative Compressibility Found».
"""

import numpy as np

# Число равноотстоящих точек проверки на диапазоне — как в ECLIPSE (30 точек от
# наименьшего до наибольшего давления таблицы; руководство whitson+, «PVT Table»).
N_CHECK = 30

# Относительный шаг центральной разности по давлению. Для формул Стендинга
# разность совпадает с аналитическими производными до 2e-9; на таблицах
# (кусочно-линейная интерполяция) точна внутри отрезка, у узла даёт среднее
# наклонов соседних отрезков.
_REL_STEP = 1e-6

# Делений пополам при уточнении границы интервала: шаг сетки проверки
# (до ~15 бар) / 2^40 — доли паскаля.
_N_BISECT = 40


def _d_dp(f, p):
    """Центральная разность df/dp с шагом _REL_STEP·p."""
    h = _REL_STEP * p
    return (f(p + h) - f(p - h)) / (2.0 * h)


def saturated_oil_compressibility(pvt, p):
    """c_ot = (B_g·dR_s/dp − dB_o/dp)/B_o, 1/Па. Ур. (eq:c_ot) problem_statement.tex."""
    p = np.asarray(p, float)

    def bo_sat(q):
        return pvt.Bo(q, pvt.Rs_eq(q))

    return (pvt.Bg(p) * _d_dp(pvt.Rs_eq, p) - _d_dp(bo_sat, p)) / bo_sat(p)


def undersaturated_oil_compressibility(pvt, p, Rs):
    """c_o = −(1/B_o)·∂B_o/∂p при R_s = const, 1/Па. Ур. (eq:co_cg) problem_statement.tex."""
    p = np.asarray(p, float)

    def bo(q):
        return pvt.Bo(q, np.full_like(q, Rs))

    return -_d_dp(bo, p) / bo(p)


def gas_compressibility(pvt, p):
    """c_g = −(1/B_g)·dB_g/dp, 1/Па. Ур. (eq:co_cg) problem_statement.tex."""
    p = np.asarray(p, float)
    return -_d_dp(pvt.Bg, p) / pvt.Bg(p)


def negative_intervals(c_of_p, p_lo, p_hi, n=N_CHECK):
    """Интервалы [p1, p2], где c_of_p(p) < 0, с минимумом c: n точек, границы — делением пополам."""
    p = np.linspace(p_lo, p_hi, n)
    neg = c_of_p(p) < 0.0
    out = []
    i = 0
    while i < n:
        if not neg[i]:
            i += 1
            continue
        j = i
        while j + 1 < n and neg[j + 1]:
            j += 1
        p1 = p_lo if i == 0 else _boundary(c_of_p, p[i - 1], p[i])
        p2 = p_hi if j == n - 1 else _boundary(c_of_p, p[j + 1], p[j])
        c_min = float(np.min(c_of_p(np.linspace(p1, p2, n))))
        out.append((float(p1), float(p2), c_min))
        i = j + 1
    return out


def _boundary(c_of_p, p_ok, p_neg):
    """Граница между точкой с c >= 0 (p_ok) и точкой с c < 0 (p_neg) — деление пополам."""
    for _ in range(_N_BISECT):
        mid = 0.5 * (p_ok + p_neg)
        if c_of_p(np.array([mid]))[0] < 0.0:
            p_neg = mid
        else:
            p_ok = mid
    return 0.5 * (p_ok + p_neg)
```

Почему строго `< 0`: у таблиц на постоянных участках (ниже первого узла $R_s$, выше последнего узла ветки) $c = 0$ ровно — это вырождение, а не нарушение (Peszyńska: $\bar c_t \ge 0$ допускает ноль).

```python
def _warn_negative_compressibility(config: SimulationConfig, pvt) -> None:
    """Предупредить о c < 0 нефти или газа (BUG-019). Ур. (eq:c_ot) problem_statement.tex."""
    # Условия (A2)-(A3) Peszyńska 2006 (Coats 1999, SPE 49774): при
    # отрицательной сжимаемости коэффициент C_p уравнения давления
    # (eq:Cp, eq:c_ot problem_statement.tex) в части ячеек меньше нуля, и
    # задача некорректна: якобиан шага вырождается на последовательности Δt,
    # шаг не сходится или результат зависит от шага. Как в ECLIPSE («Negative
    # Compressibility Found») — предупреждение, расчёт продолжается.
    # Конфиг BUG-019 (прежний пример 20: Стендинг, R_s0 = 500): c_ot < 0 при
    # p > 34.55 МПа.
    ic = config.initial_conditions
    # Нижняя граница — наименьшее забойное давление истории: при добыче
    # давление в пласте ниже него не опускается. При управлении дебитом
    # p_wf не задано — берём min_bhp (обязателен при control='rate', FEAT-020).
    p_lo = min(h.p_wf if h.control == "pressure" else h.min_bhp
               for h in config.time.history)
    p_b = float(pvt.pb(np.array([ic.Rs0]))[0])
    checks = []
    # Насыщенные состояния (нефть + свободный газ) — только при p <= p_b(Rs0):
    # растворённого газа больше Rs0 в задаче нет (закачки нет). Rs0 = 0 —
    # дегазированная нефть, свободного газа не бывает.
    if ic.Rs0 > 0.0 and p_b > p_lo:
        checks.append((
            "насыщенной нефти с выделяющимся газом c_ot = (B_g·dR_s/dp − dB_o/dp)/B_o",
            lambda p: saturated_oil_compressibility(pvt, p), p_lo, p_b))
        checks.append((
            "газа c_g = −(1/B_g)·dB_g/dp",
            lambda p: gas_compressibility(pvt, p), p_lo, p_b))
    # Недонасыщенная нефть с R_s = Rs0 — от p_b(Rs0) (или p_lo, если оно выше)
    # до p0: при добыче давление выше начального не поднимается.
    p_u = max(p_b, p_lo)
    if ic.p0 > p_u:
        checks.append((
            f"недонасыщенной нефти c_o = −(1/B_o)·∂B_o/∂p при R_s = {ic.Rs0:g}",
            lambda p: undersaturated_oil_compressibility(pvt, p, ic.Rs0), p_u, ic.p0))
    for name, c_of_p, lo, hi in checks:
        for p1, p2, c_min in negative_intervals(c_of_p, lo, hi):
            user_log.warning(
                f"PVT несогласована: отрицательная сжимаемость {name} при p от "
                f"{p1 / 1e6:.4g} до {p2 / 1e6:.4g} МПа (min {c_min:.3g} 1/Па). "
                f"Коэффициент уравнения давления C_p может стать отрицательным "
                f"(problem_statement.tex, eq:c_ot): возможны отказы шага и "
                f"зависимость результата от шага по времени. Расчёт продолжается.")
```

```python
def _c_ot_standing_exact(p):
    """c_ot по аналитическим производным формул standing.py (co_undersaturated = 0)."""
    g_g = RHO_G / RHO_AIR_STD
    g_o = RHO_O / RHO_WATER_STD
    api = 141.5 / g_o - 131.5
    t_f = (T0 - 273.15) * 9.0 / 5.0 + 32.0
    a = 0.00091 * t_f - 0.0125 * api
    y = p / PSI_TO_PA / 18.2 + 1.4                      # standing.py:76
    rs = g_g * y ** (1 / 0.83) * 10.0 ** (-a / 0.83) / SCF_PER_M3
    drs = rs / 0.83 / (18.2 * y) / PSI_TO_PA
    f = rs * SCF_PER_M3 * (g_g / g_o) ** 0.5 + 1.25 * t_f   # standing.py:82-84
    bo = 0.9759 + 1.2e-4 * f ** 1.2
    dbo = 1.2e-4 * 1.2 * f ** 0.2 * SCF_PER_M3 * (g_g / g_o) ** 0.5 * drs
    bg = P_STD * T0 / (T_STD * p)                       # идеальный газ, standing.py:104-106
    return (bg * drs - dbo) / bo

class TestCompressibilityFunctions:

    def test_c_ot_matches_standing_analytic(self, pvt20):

            return saturated_oil_compressibility(pvt20, np.array([q]))[0]
        assert c(30e6) > 0.0 and c(40e6) < 0.0
        assert brentq(c, 30e6, 40e6) == pytest.approx(34.5457e6, abs=1e3)

    def test_c_o_undersaturated_standing(self, co):

def _pvt_warnings(config, caplog):
    """Собрать модель и вернуть предупреждения о несогласованной PVT."""
    # Уровень журнала — из конфига (setup_logging в from_config); у
    # замороженного конфига BUG-019 — ERROR, он скрыл бы предупреждения.
    config.output.log_level = "INFO"
    with caplog.at_level(logging.WARNING, logger="gpn_multiphase_solver"):
        SimulatorFactory.from_config(config)
    return [r.getMessage() for r in caplog.records
            if r.levelno == logging.WARNING and r.getMessage().startswith(WARN_PREFIX)]
```

## 8. Связь формула → код

| формула | где | код |
|---|---|---|
| $c_{ot} = c_o^{sat} + \frac{B_g}{B_o}\frac{\partial R_s^{eq}}{\partial p}$ | `eq:c_ot` (шаг 6) | `pvt/consistency.py::saturated_oil_compressibility` |
| $c_g = -\frac{1}{B_g}\frac{\partial B_g}{\partial p}$ | `eq:co_cg` | `pvt/consistency.py::gas_compressibility` |
| $c_o = -\frac{1}{B_o}\frac{\partial B_o}{\partial p}\big\vert_{R_s}$ | `eq:co_cg` | `pvt/consistency.py::undersaturated_oil_compressibility` |
| $C_p = \phi(c_r + S_o c_{ot} + S_g c_g)/B_g$ | `eq:Cp`, вывод — §2.2 | `factory._warn_negative_compressibility` (знак проверяется на диапазоне давлений задачи) |
