# 21 — $R_{s,0} = 100$, горячий пласт: охлаждение забоя

## Описание

Нефть с газосодержанием $R_{s,0} = 100$ м³ст/м³ст в горячем пласте
($T_0 = 400$ К) с лёгким газом ($\gamma_g = 0.593$) добывается 30 сут при
забойном давлении 3 МПа — глубоко ниже давления насыщения
$p_b = 17.22$ МПа. Забой охлаждается на 2.5 К: теплота выделения газа и
расширение газа сильнее нагрева нефти при дросселировании.

PVT и ОФП заданы корреляциями — внешних файлов нет. Тепловые свойства
согласованы с флюидом (см. «Откуда тепловые параметры»): теплота дегазации
$L = 227$ кДж/кг получена по Клапейрону из той же корреляции Стендинга,
что задаёт $R_s(p)$.

## Почему забой охлаждается

Три эффекта действуют в разные стороны: нефть при дросселировании
**греется** ($\mu_{JT,o} < 0$), газ при расширении **охлаждается**
($\mu_{JT,g} > 0$), выделение газа из нефти **поглощает** теплоту $L$.
Оценка по балансу энтальпии установившегося потока на 1 м³ст нефти
(теплопроводность не учтена, газовый фактор $= R_{s,0}$):

$$
C\,dT = \bigl(m_o c_{p,o}\mu_{JT,o} + m_g c_{p,g}\mu_{JT,g}\bigr)\,dp - L\,dm_g ,
$$

$m_o = \rho_{o,ст} + R_s\rho_{g,ст}$ — масса нефтяной фазы,
$m_g = (R_{s,0} - R_s)\,\rho_{g,ст}$ — масса свободного газа,
$C = m_o c_{p,o} + m_g c_{p,g}$. Интегрирование от $p_0$ до $p_{wf}$ с
$R_s(p)$ Стендинга:

| вклад | К |
|---|---|
| дросселирование нефти | +5.63 |
| расширение газа | −1.44 |
| теплота выделения газа | −6.93 |
| **оценка** | **−2.73** |

Расчёт — −2.48 К на 30 сут, 91 % оценки. Оценка предполагает
установившийся поток с газовым фактором $R_{s,0}$; за 30 сут газ ещё
копится в пласте (GOR = 85.8 < 100), через забой его проходит меньше.

Тот же расчёт с `thermal.L_degas = 0` даёт на забое **+3.24 К**: без
теплоты выделения газа забой грелся бы. Температура линейна по $L$
(гидродинамика от термики не зависит), поэтому вклад теплоты выделения
газа — ровно −5.72 К, и охлаждение целиком создаёт она.

Накопленные члены баланса энергии за 30 сут — интегралы по всему пласту,
а не вклады в $\Delta T$ на забое: в скрытую теплоту входит весь
выделившийся газ, в том числе копящийся в пласте, а член Джоуля–Томсона —
сумма нагрева нефти и охлаждения газа на всём пути:

| член | Дж |
|---|---|
| изменение энергии $\Delta E$ | $-9.4354\cdot10^{10}$ |
| адиабатический | $-5.2283\cdot10^{10}$ |
| конвекция через границы | $+2.6151\cdot10^{10}$ |
| Джоуль–Томсон | $+4.9111\cdot10^{10}$ |
| скрытая теплота | $-1.1734\cdot10^{11}$ |

## Газонасыщенность и газовый фактор

Газ неподвижен, пока $S_g \le S_{gc} = 0.1$, и копится в пласте: газовый
фактор ниже $R_{s,0}$ и растёт (82.0 → 85.8). Газонасыщенность у забоя
(0.41) задаёт форма Кори над порогом: на забойной грани
$k_{rg}/k_{ro}(S_g) = (\mathrm{GOR} - R_s)\,\mu_g B_g/(\mu_o B_o)$.

Стационарная аналитика отключена (`steady_state=False`): замкнутое
решение строится по условию GOR $= R_{s,0}$, а за 30 сут оно ещё не
выполнено. Проверка $R_s = \min(R_s^{eq}(p), R_{s,0})$ и баланс энергии
остаются.

## Откуда тепловые параметры

- $c_{p,o}$ — корреляция Гэмбилла при $T_0$:
  $c_p = (0.388 + 0.00045\,T_{°F})/\sqrt{\gamma_o}$ БТЕ/(фунт·°F).
- $c_{p,g}$ и $\mu_{JT,g}$ — уравнение состояния Пенга–Робинсона для газа
  состава CH₄ 0.94, C₂H₆ 0.04, C₃H₈ 0.02 ($\gamma_g = 0.593$), среднее по
  свободному газу на пути от $p_b$ до $p_{wf}$ при $T_0$.
- $L$ — уравнение Клапейрона для разгазирования:
  $$L = T\,(v_g - \bar v_{go})\left(\frac{\partial p_b}{\partial T}\right)_{R_s}
  = \frac{T}{\rho_{g,ст}}\left(B_g - \frac{\partial B_o}{\partial R_s}\right)\frac{\partial p_b}{\partial T},$$
  производные — из корреляции Стендинга, $B_g$ — реального газа; среднее
  по массе выделившегося газа. $L$ падает с ростом давления, поэтому
  горячий пласт и лёгкий газ дают $L$ выше 200 кДж/кг.
- $\mu_{JT,o} = (\alpha T - 1)/(\rho_o c_{p,o}) \approx -0.4$ К/МПа.
- $(\rho c_p)_s$ — кварц: 2650 кг/м³ × 800 Дж/(кг·К).

## Как модифицировать

| Параметр | Ключ | Эффект |
|---|---|---|
| $L$ | `thermal.L_degas` | $\Delta T(r_w)$ линейно по $L$, гидродинамика не меняется: −0.0252 К на кДж/кг; −10 К на 30 сут — около 525 кДж/кг |
| тепловые скаляры | `thermal` | только $T$ — гидродинамика не меняется (расщепление) |
| $p_{wf}$ | `time.history[].p_wf` | ниже — больше газа и охлаждение |
| $k$, $h$ | `rock`, `geometry` | дебит |
| ОФП | `relperm` | $S_g$ у забоя |
| длительность, частота записи | `time.history` | число интервалов = число записей |
| $N$ | `grid.N` | детальность профилей |

⚠️ **Сходимость первого шага.** При пуске ячейки у забоя получают
газонасыщенность выделения в закрытом объёме
$S_g = d B_g/(B_o + d B_g)$, $d = R_{s,0} - R_s(p_{wf})$ — здесь 0.78
($d = 87.1$), ниже $1 - S_{or} = 0.95$. При $S_{or} > 0.22$ она была бы
выше $1 - S_{or}$, где нефть неподвижна. Из такой начальной точки Ньютон
до решения не доходит, поэтому стартовая $S_g$ ограничивается наибольшим
узлом таблицы ОФП с $k_{ro} > 0$ (Кори передаётся гидродинамическому
решателю таблицей с шагом 0.01 по $S_g$; BUG-018 исправлен).

Шаг интегрирования задаёт только `time.dt_integration`; поля
`numerics.dt_min` и `dt_max` решателем не читаются. `grid.type` и
`output.format` не трогать: объявлены, но не читаются.
