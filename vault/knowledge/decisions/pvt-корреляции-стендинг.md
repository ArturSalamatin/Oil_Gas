# PVT-корреляции для StandingPVT

## Источник

Базовый код: `method_of_moments/src/pvt/correlations.py`. Нужно:
1. Векторизовать (math → numpy)
2. Добавить ветвление p ≷ pb (под/над давлением насыщения)
3. Добавить недостающие производные (dBo/dp, dμ_o/dp, dμ_g/dp)

## Газосодержание Rs_eq(p) — Standing 1947

```
Rs_eq = γ_g · (p_psia/18.2 + 1.4)^{1/0.83} · 10^{-a/0.83}
a = 0.00091·T_F - 0.0125·γ_API
```

Производная (аналитическая):
```
dRs/dp = Rs / (0.83 · Y · 18.2 · Pa_per_psi),   Y = p_psia/18.2 + 1.4
```

Уже реализовано в correlations.py. Нужна векторизация: `math.log(10)` → `np.log(10)`.

## Давление насыщения pb — Standing 1947 (обратная)

```
pb_psia = 18.2 · ((Rs_scf/γ_g)^0.83 · 10^a - 1.4)
```

pb = f(Rs, T). В гидродинамике T = T0 = const, поэтому pb = g(Rs) — функция только Rs. pb(Rs) — массив, вычисляется для каждой ячейки по её Rs. В однофазной зоне Rs = Rs0 = const → pb = pb(Rs0) = скаляр. В двухфазной зоне Rs = Rs_eq(p), pb(Rs) = p — нефть на кривой насыщения.

## Объёмный коэффициент нефти Bo

### p < pb (двухфазная зона, режим 1)

Standing 1947:
```
F = Rs_scf · (γ_g/γ_o)^0.5 + 1.25·T_F
Bo = 0.9759 + 1.2e-4 · F^1.2
```

Bo = f(Rs, T). При фиксированном Rs: **dBo/dp|_{Rs} = 0**.

dBo/dRs — уже реализовано:
```
dBo/dRs = 1.44e-4 · F^0.2 · dF/dRs
dF/dRs = (γ_g/γ_o)^0.5 · SCF_PER_M3
```

### p ≥ pb (однофазная зона, режим 2)

Vasquez-Beggs (упрощённый) — экспоненциальная сжимаемость:
```
Bo(p) = Bo_at_pb · exp(-co_under · (p - pb))
```

co_under — сжимаемость нефти выше pb. Задаётся в JSON как скаляр (порядок 1e-9..1e-10 1/Па).

Bo_at_pb = Bo(pb, Rs0) — вычисляется Standing при Rs = Rs0.

Производные:
```
dBo/dp|_{Rs} = -co_under · Bo(p)     (при p ≥ pb)
dBo/dRs = 0                           (при p ≥ pb, Rs = Rs0 = const)
```

### Реализация ветвления

```python
def Bo(self, p, Rs):
    mask = p < self._pb
    result = np.empty_like(p)

    # p < pb: Standing
    F = self._F_standing(Rs[mask])
    result[mask] = 0.9759 + 1.2e-4 * F**1.2

    # p >= pb: exp-сжимаемость
    result[~mask] = self._Bo_at_pb * np.exp(-self._co_under * (p[~mask] - self._pb))
    return result
```

## Объёмный коэффициент газа Bg — идеальный газ

```
Bg = P_ст · T / (T_ст · p)     (z-фактор = 1)
dBg/dp = -Bg / p
```

Векторизация тривиальна. Для более точной модели — добавить z-фактор (Standing-Katz, Dranchuk-Abou-Kassem). Пока z=1 достаточно.

## Вязкость нефти μ_o

### p < pb: Beggs-Robinson 1975

```
μ_dead = (10^(A·T_F^{-1.163}) - 1) · 1e-3     [Па·с]
A = 10^(3.0324 - 0.02023·γ_API)

μ_o = a · μ_dead^b     [Па·с]
a = 10.715 / (Rs_scf + 100)^0.515
b = 5.44 / (Rs_scf + 150)^0.338
```

μ_o = f(Rs, T). При фиксированном Rs: **dμ_o/dp|_{Rs} = 0** — для насыщенной ветви и при `mu_o_undersaturated = "none"` (по умолчанию).

### p > pb: Бил–Стендинг (FEAT-027, опция `pvt.mu_o_undersaturated = "beal"`)

Бил (1946, Trans. AIME 165), аналитическая форма — Стендинг (1981); μ — сП, p — psia:
```
μ_o = μ_ob + 0.001 · (p - pb) · (0.024 · μ_ob^1.6 + 0.038 · μ_ob^0.56),   p > pb(Rs)
```
μ_ob = μ_ob(Rs) — Беггс–Робинсон при том же Rs, pb = pb(Rs) — Стендинг.

В СИ (код — `StandingFullPVT._beal_slope`, `mu_o`):
```
μ_o = μ_ob + β(μ_ob) · max(p - pb, 0)
β = 1e-3 · (0.024 · μ_ob,сП^1.6 + 0.038 · μ_ob,сП^0.56)  [сП/psi]  · 1e-3 [Па·с/сП] · PA_TO_PSI [psi/Па]   [Па·с/Па]
```

Свойства:
- непрерывна при p = pb (прибавка β·0 = 0);
- линейна по p при фиксированном Rs; излом dμ_o/dp|_{Rs} при pb — тот же тип, что у Bo при co > 0;
- **конечна при любом pb**: у Стендинга pb(Rs) < 0 при Rs < Rs* ≈ 0.6–0.7 м³ст/м³ст (pb(0) = −0.176 МПа), тогда p − pb > 0;
- рост ограничен: при p = 33 МПа не более ×1.40 (Rs = 0, нефть 800 кг/м³, 300 К).

⚠️ Коэффициенты по первоисточникам (Beal 1946, Standing 1981) не сверены — в `Refs/` их нет; форма взята из справочной литературы по PVT (Ahmed, «Reservoir Engineering Handbook»). Диапазон данных Била не сверен.

Опция выключена по умолчанию (`"none"`) и ни в одном примере не включена. При `model = "table"` значение `"beal"` → `ValueError`: недонасыщенные ветви вязкости задаёт таблица.

### Почему не Васкес–Беггс (1980)

```
μ_o = μ_ob · (p/pb)^m,   m = 2.6 · p_psia^{1.187} · exp(-11.513 - 8.98e-5 · p_psia)
```

Зависит от p/pb и расходится при pb → 0⁺; при pb < 0 даёт NaN. Нефть примера 20 (800 / 1.014 / 380 К), p = 33 МПа:

| Rs, м³ст/м³ст | pb, МПа | Бил, μ_o/μ_ob | Васкес–Беггс |
|---|---|---|---|
| 0 | −0.176 | 1.3049 | NaN |
| 0.61 | 0.001 | 1.3037 | **52.4** |
| 5 | 0.843 | 1.2995 | 4.26 |
| 20 | 3.043 | 1.2893 | 2.56 |
| 100 | 12.07 | 1.2277 | 1.49 |
| 300 | 30.29 | 1.0339 | 1.0344 |

Вблизи pb корреляции согласуются (тест `test_beal_close_to_vasquez_beggs_near_pb`); вдали Васкес–Беггс выходит за пределы применимости. Состояния с малым Rs и p ≫ pb возможны: рост p_wf после ухода свободного газа, пробные итерации Ньютона. Числа — проба `vault/issues/feat-027/probes/beal_numbers.py`. Линейная модель `μ_ob(1 + cμ(p − pb))` с параметром из JSON отвергнута: значение cμ нечем обосновать (для нефти примера 20 эквивалент — 1.22e-8 1/Па). Решение пользователя 2026-10-03.

### Производные по p

- p < pb или `"none"`: dμ_o/dp|_{Rs} = 0
- p > pb, `"beal"`: dμ_o/dp|_{Rs} = β(μ_ob) — постоянна по p при фиксированном Rs

Аналитическая производная в коде не нужна: `StandingFullPVT` наследует `FullPVT`, а не `DifferentiableHydroPVT`; якобиан прототипа конечно-разностный.

### Проверка на задаче (VAL-001, `tests/test_val001.py::TestKirchhoffBeal`)

Однофазный приток с c_o = 0: подстановка Кирхгофа ∫dp/μ = ln(μ_e/μ_wf)/β даёт точный дебит. Схема (подвижность против потока) сходится к нему с порядком 1: q/q_точн − 1 = −1.02e-3 (N = 20), −5.2e-4 (40), −2.6e-4 (80), −1.3e-4 (160). Дебит с Билом на 6.8 % ниже, чем с μ_ob.

## Вязкость газа μ_g — Lee-Gonzalez-Eakin 1966

```
K = (9.4 + 0.02·M_g) · T_R^1.5 / (209 + 19·M_g + T_R)
X = 3.5 + 986/T_R + 0.01·M_g
Y = 2.4 - 0.2·X
μ_g = 1e-4 · K · exp(X · ρ_g_gcc^Y)     [Па·с]
```

ρ_g = ρ_g_ст / Bg(p). При z=1: ρ_g = ρ_g_ст · T_ст · p / (P_ст · T).

### Производная dμ_g/dp

Цепное правило:
```
dμ_g/dp = μ_g · X · Y · ρ_g_gcc^{Y-1} · dρ_g_gcc/dp
dρ_g/dp = ρ_g / p     (для идеального газа)
dρ_g_gcc/dp = dρ_g/dp / 1000 = ρ_g / (1000·p)
```

Итого:
```
dμ_g/dp = μ_g · X · Y · ρ_g_gcc^{Y-1} · ρ_g_gcc / p
        = μ_g · X · Y · ρ_g_gcc^Y / p
```

## Параметры в JSON — секция pvt

```json
"pvt": {
    "model": "standing",
    "rho_o_std": 850.0,
    "rho_g_std": 1.2,
    "Rs0": 50.0,
    "co_undersaturated": 1.5e-9,
    "c_mu_o_undersaturated": 5e-9
}
```

Минимальный набор для Standing: rho_o_std, rho_g_std, Rs0. gamma_o и gamma_g вычисляются из плотностей. Температура T0 берётся из initial_conditions.

co_undersaturated и c_mu_o_undersaturated — опциональные; если не заданы, используются нулевые (Bo, μ_o постоянны при p > pb).
