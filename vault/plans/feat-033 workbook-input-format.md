### 0.3. Формат (2026-10-15, первый круг)

8. **Столбец «Ключ»** на листах «параметр–значение»: ключ — путь поля конфига (`rock.permeability`); строка ищется по ключу, подпись и комментарий правятся свободно.
9. **Simulation time удаляется.** Конец расчёта — последняя строка SCHEDULE, ячейки режима в ней пустые. Строка $k$ задаёт режим на $[t_k, t_{k+1}]$.
10. **Параметры шага прототипа заменяются полями решателя:** DTMAX → `time.dt_integration`, DT initial → `time.dt_after_control_change`, DT minimum → `numerics.max_retries` (целое — глубина дробления). Пересчёта значений нет — смысл разный (раздел 2.3).
11. **Теплота дегазации — в кДж/кг, знак конфига:** $L > 0$ — дегазация охлаждает (`thermal.L_degas`, Дж/кг газа; $L < 0$ — предупреждение `_validate`).
12. **Режимы — BHP / OIL_RATE.** Останов — OIL_RATE с $q_o = 0$ и минимальным $p_{wf}$ = 1.01325 бар, как в примерах 16, 17.
13. **Ветвь $R_s = 60$ в демонстрационной таблице PVTO** — подобрать данные (раздел 2.4).
14. **Шаблон генерируется кодом** из таблицы полей: команда `gpn-solver template путь.xlsx`.
15. Конвертер примера 18 (`examples/18_prototype_input/prototype_input.py`) и тесты [[VAL-005]] не трогаем: им пользуются ~8 тестов сверки с CMG IMEX на книгах прототипа T07, T09 (листа THERMAL в них нет).

### 0.4. Формат (2026-10-15, второй круг)

16. **Раскладка листов раздела 2.5 утверждена** (в том числе $\rho_{ст}$, скин и $T_0$ на MODEL).
17. **NUMERICS — все численные поля** конфига, с умолчаниями.
18. **Единицы шагов (`dt_integration`, `dt_after_control_change`) — часы**, перевод в секунды — внутри программы. Следствие: $h_0$ = 0.11 с = $3.0\overline{5}\cdot10^{-5}$ ч; обратный перевод может дать 0.10999999999999999 с — безвредно: $h_0$ округляется вниз до $dt/2^m$ (`TimeSchedule.first_substep_depth`; при $dt$ = 3600 с $m$ = 15, 0.10986 с в обоих случаях).
19. **$L$ демонстрационной книги — из примера 14:** 230 кДж/кг.
20. **`dt_after_control_change` демонстрационной книги — 0.11 с** (как в 16, 17 после [[BUG-026]]).
21. **Шаблон — с примерными (демонстрационными) значениями.**
22. **Черновик руководителя и книга генератора — обе в `numerical_solver/configs/`.**

24. **Подписи параметров — на английском.** Перевод строк THERMAL — от пользователя (2026-10-15):

### 0.10. Планирование (2026-10-17)

61. **SCHEDULE: заполненные ячейки, которые режим строки не использует, молча пропускаются** — как режим последней строки (решение 40). Строка BHP читает только BHP target; строка OIL_RATE — Oil-rate target и Minimum BHP.
62. **Строка «Run» листа COMMENTS (`gpn-solver run my_case.xlsx`) — в [[feat-036 run-from-workbook|FEAT-036]]**, когда команда заработает. Книга FEAT-033 описывает только работающие команды: получить шаблон, заполнить, правила листов.
63. **Демонстрационные числа — с 15 значащими цифрами** (2026-10-17, после аудита 1; предложение пользователя «12–15 цифр», выбрано 15). XlsxWriter пишет число с 16 значащими цифрами (`{:.16G}`), а у таблиц T08c и `INPUT_TEMPLATE.xlsx` их 17 — в книге 79 из 265 чисел сдвигались до 5e-16 (К16). Число с ≤ 16 цифрами запись не меняет; 15 — точность числа, набранного в ячейке Excel. Литералы `DEMO_*` и демо-значения строк округлены один раз в коде (`probes/round15.py`), книга равна им бит в бит; тест-страж — каждое демо-число равно своему округлению до 15 цифр. Отклонение от источников — до 4.6e-15. При переводе книги (FEAT-035) не округляется: в ячейках — то, что хранит Excel, правило «ячейка → CSV побитово» остаётся.

### 2.3. Как модуль гидродинамики получает шаг (вопрос пользователя к решению 10)

Свой выбор шага прототипа (драйвер `radial_blackoil/simulation.py` с DT initial / DT minimum / DTMAX) решатель не использует. Временем управляет `Simulator`:

- интервал истории делится на равные подшаги не длиннее `time.dt_integration` (`TimeSchedule.substeps`);
- после смены управления (кроме первого интервала, [[BUG-028]]) первый подшаг — `time.dt_after_control_change`, округлённый вниз до $dt/2^m$, дальше удвоение ([[FEAT-032]], `TimeSchedule.first_substep_depth`);
- при отказе Ньютона подшаг делится пополам, наименьший — `dt_integration / 2**max_retries` ([[DEBT-015]], `Simulator._advance`);
- на каждый подшаг адаптер вызывает `advance` прототипа один раз; лимиты Ньютона (`newton_max_iter`, `max_active_set_iter`), допуски (`rs_switch_tol`, `sg_switch_tol`, `newton_cell_tol`), `jacobian_mode`, `linear_solver` фабрика передаёт прототипу (`factory._create_prototype_hydro`).

Поэтому значения DT-строк прототипа в наши поля не пересчитываются: DT initial прототипа действует только при $t = 0$ и при смене управления шаг не сбрасывает (поправка плана [[FEAT-032]]), а `dt_after_control_change` — наоборот; DT minimum — секунды, `max_retries` — число делений пополам. Строки книги — сразу поля решателя.

```python
"""Формат книги ввода Excel, версия 1: листы, строки, единицы, допустимые значения (FEAT-033).

Одна таблица на генератор шаблона (io/workbook_template.py) и на перевод книги
в конфиг (FEAT-035). Подписи, единицы и комментарии книги правятся здесь:
правки, сделанные командой в самой книге, переносятся сюда вручную, а
gpn-solver template пишет книгу заново.
"""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np

from ..units import BAR_TO_PA, DAY_TO_S, HOUR_TO_S, MD_TO_M2, PA_S_TO_CP

# Версия формата — ячейка format_version листа MODEL. В книге все строки
# обязательны (умолчаний нет), поэтому новое поле или другая единица — новая
# версия: книга прежней версии получает отказ перевода.
FORMAT_VERSION = 1

# «Выключено» в ячейке Value → null в JSON. Только у строк с none_allowed —
# полей конфига, где null означает «выключено».
NONE_WORD = "none"

# Заголовки листов «параметр–значение», столбцы A…E
PARAM_HEADER = ("Key", "Parameter", "Value", "Unit", "Comment")


@dataclass(frozen=True)
class Limit:
    """Допустимые значения числовой ячейки: границы, целое, больше значения другой строки."""
    lo: float | None = None        # нижняя граница; None — нет
    lo_strict: bool = False        # True: v > lo; False: v >= lo
    hi: float | None = None        # v <= hi; None — нет
    integer: bool = False          # целое; Excel хранит 100 как 100.0 — оно целое
    above_key: str | None = None   # v > значения строки с этим ключом на том же листе

    def accepts(self, v, above: float | None = None) -> bool:
        """Допустимо ли число v; above — значение строки above_key."""
        # bool — подкласс int: логическое значение в числовой ячейке — не число
        if isinstance(v, bool) or not isinstance(v, (int, float)) or not np.isfinite(v):
            return False
        if self.integer and v != np.floor(v):
            return False
        if self.lo is not None and (v <= self.lo if self.lo_strict else v < self.lo):
            return False
        if self.hi is not None and v > self.hi:
            return False
        return self.above_key is None or v > above


# Пределы — как у программы (_validate, _validate_interval в io/config.py;
# пределы столбцов CSV в factory.py): проверка книги не строже JSON (решение 50)
POSITIVE = Limit(lo=0.0, lo_strict=True)              # > 0
NON_NEGATIVE = Limit(lo=0.0)                           # >= 0
ANY = Limit()                                          # любое конечное число
FRACTION = Limit(lo=0.0, hi=1.0)                       # [0, 1]
POROSITY = Limit(lo=0.0, lo_strict=True, hi=1.0)       # (0, 1]
COUNT = Limit(lo=1.0, integer=True)                    # целое >= 1


@dataclass(frozen=True)
class Param:
    """Строка листа «параметр–значение»: ключ, подпись, единица, демонстрационное значение, пределы."""
    key: str                    # путь поля конфига (rock.permeability) или ключ книги (rock.p_ref)
    label: str                  # столбец Parameter: «Название (символ)»
```

```python
def write_template(path) -> None:
    """Записать шаблон книги версии 1 в новый файл path (.xlsx); существующий — FileExistsError."""
    path = Path(path)

def excel_rule(limit: wf.Limit, cell: str, above_cell: str | None = None,
               none_allowed: bool = False) -> str:
    """Формула проверки данных Excel для ячейки cell по пределу limit (решение 50)."""
    parts = [f"ISNUMBER({cell})"]
    if limit.integer:
        parts.append(f"{cell}=INT({cell})")
    if limit.lo is not None:
        parts.append(f"{cell}{'>' if limit.lo_strict else '>='}{limit.lo:g}")
    if limit.hi is not None:
        parts.append(f"{cell}<={limit.hi:g}")
    if limit.above_key is not None:
        parts.append(f"{cell}>{above_cell}")
    rule = f"AND({','.join(parts)})"
    if none_allowed:
        # Excel сравнивает строки без учёта регистра — «None» тоже пройдёт (П10)
        rule = f'OR({cell}="{wf.NONE_WORD}",{rule})'
    return "=" + rule


def limit_text(limit: wf.Limit, above_label: str | None = None,
               none_allowed: bool = False) -> str:
    """Сообщение Excel о недопустимом значении: какое значение ждёт ячейка."""
    what = "an integer" if limit.integer else "a number"
    lo, hi = limit.lo, limit.hi
    if lo is not None and hi is not None:
        rng = (f" equal to {lo:g}" if lo == hi else
               f" in ({lo:g}, {hi:g}]" if limit.lo_strict else f" from {lo:g} to {hi:g}")
    elif lo is not None:
        rng = f" {'>' if limit.lo_strict else '>='} {lo:g}"
    elif limit.above_key is not None:
        rng = f" > {above_label}"
    else:
        rng = ""
    return f"Enter {what}{rng}" + (f" or {wf.NONE_WORD}" if none_allowed else "") + "."
```

```python
"""Чтение книги .xlsx в тестах стандартной библиотекой (FEAT-033).

Значения ячеек, стили, проверки данных и защита листа — то, что пишет генератор
шаблона (io/workbook_template.py). Не разборщик книги для пользователя (FEAT-034).
"""

import xml.etree.ElementTree as ET
import zipfile
from dataclasses import dataclass, field
from pathlib import Path

_M = "{http://schemas.openxmlformats.org/spreadsheetml/2006/main}"
_R = "{http://schemas.openxmlformats.org/officeDocument/2006/relationships}"
_PR = "{http://schemas.openxmlformats.org/package/2006/relationships}"


@dataclass
class Sheet:
    """Лист: значения (адрес → float | str), стили ячеек, проверки данных, защита."""
    values: dict = field(default_factory=dict)
    styles: dict = field(default_factory=dict)       # адрес → индекс стиля cellXfs
    validations: list = field(default_factory=list)  # атрибуты <dataValidation> + formula1
    protection: dict | None = None                   # атрибуты <sheetProtection>; None — нет


@dataclass
class Book:
    """Книга: листы в порядке книги и стили без блокировки."""
    sheets: dict
    unlocked: set

    def locked(self, sheet: str, addr: str) -> bool:
        """Заблокирована ли ячейка; ячейка без стиля — стиль 0, заблокирована (как в Excel)."""
        return self.sheets[sheet].styles.get(addr, 0) not in self.unlocked


def read_book(path: Path) -> Book:
    """Прочитать книгу path: листы, значения, стили, проверки данных, защиту."""
    with zipfile.ZipFile(path) as z:
        shared = []
        if "xl/sharedStrings.xml" in z.namelist():
            for si in ET.fromstring(z.read("xl/sharedStrings.xml")).iter(f"{_M}si"):
                shared.append("".join(t.text or "" for t in si.iter(f"{_M}t")))
        xfs = ET.fromstring(z.read("xl/styles.xml")).find(f"{_M}cellXfs")
        unlocked = set()
        for i, xf in enumerate(xfs):
            prot = xf.find(f"{_M}protection")
            if prot is not None and prot.get("locked") == "0":
                unlocked.add(i)
        rels = {r.get("Id"): r.get("Target") for r in
                ET.fromstring(z.read("xl/_rels/workbook.xml.rels")).iter(f"{_PR}Relationship")}
        sheets = {}
        for s in ET.fromstring(z.read("xl/workbook.xml")).iter(f"{_M}sheet"):
            target = rels[s.get(f"{_R}id")].lstrip("/")
            root = ET.fromstring(z.read(target if target.startswith("xl/") else "xl/" + target))
            sh = Sheet()
            for c in root.iter(f"{_M}c"):
                sh.styles[c.get("r")] = int(c.get("s", "0"))
                v = c.find(f"{_M}v")
                if v is not None:
                    sh.values[c.get("r")] = (shared[int(v.text)] if c.get("t") == "s"
                                             else float(v.text))
            for dv in root.iter(f"{_M}dataValidation"):
                f1 = dv.find(f"{_M}formula1")
                sh.validations.append({**dv.attrib, "formula1": None if f1 is None else f1.text})
            prot = root.find(f"{_M}sheetProtection")
            sh.protection = None if prot is None else dict(prot.attrib)
            sheets[s.get("name")] = sh
    return Book(sheets, unlocked)
```
