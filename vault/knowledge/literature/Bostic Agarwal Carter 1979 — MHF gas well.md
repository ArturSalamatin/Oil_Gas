# Bostic Agarwal Carter 1979 — MHF gas well

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Bostic J.N., Agarwal R.G., Carter R.D.** Combined Analysis of Post-Fracturing Performance and Pressure Buildup Data for Evaluating an MHF Gas Well. *SPE 8280*, 54th Annual Fall Meeting, Las Vegas, Sept. 23–26, 1979.

## Аннотация

Совместный анализ промысловых данных (performance data + buildup) для газовой скважины после массированного ГРП. Статья-компаньон к Agarwal 1979 (SPE 8279), демонстрирующая применение метода псевдовремени $t_a(p)$ на реальных полевых данных.

## Потенциал для проекта

Источник промысловых данных для верификации; пример комбинированной интерпретации drawdown + buildup.
