### Причина установлена опытом (2026-10-02)

Причина отказа — начальное приближение Ньютона. Ячейки, перешедшие в двухфазный режим, получают газонасыщенность «закрытого сосуда» (весь выделившийся газ остаётся в ячейке, перетоки за шаг не учитываются). У забоя она 0.85–0.91 — выше $1 - S_{or} = 0.8$; в решении 0.38–0.45. Из области $S_g > 1 - S_{or}$ Ньютон до решения не доходит.

Опыт: обёртка обрезает $S_g$ в начальном приближении сверху значением cap, остальной алгоритм не меняется (`vault/issues/bug-018/probes/cap_initial_sg.py`, 5 суточных интервалов, $S_{or} = 0.2$):

| cap | $R_{s,0} = 500$, $N = 50$, $p_{wf} = 5$ МПа | $R_{s,0} = 150$, $N = 350$, $p_{wf} = 3$ МПа |
|---|---|---|
| без ограничения | отказ | отказ |
| 0.85 / 0.81 | отказ | — |
| **0.79** | **сходится**, без дробления | — |
| 0.75 / 0.50 | сходится, без дробления | сходится, без дробления |

Порог — ровно $1 - S_{or}$.

**Ограничение не меняет решение.** Уравнения и критерий сходимости те же — меняется только стартовая точка Ньютона. Сверка полей $p$, $S_g$, $R_s$, $T$ за 5 сут (`compare_solutions.py`): в двух случаях, где расчёт сходится и без ограничения, решения с cap = 0.5 и 0.3 совпадают с эталоном до допуска Ньютона ($\max|\Delta p| \le 1.9\cdot10^{-4}$ Па, $\max|\Delta S_g| \le 6.4\cdot10^{-10}$, $\max|\Delta T| \le 1.6\cdot10^{-10}$ К). В отказном случае cap от 0.15 до 0.79 даёт одно и то же решение ($\max|\Delta p| \le 2.9\cdot10^{-5}$ Па). Единственность корня в общем виде не доказана — показана на этих случаях.

Объяснение, почему Ньютон не выходит из этой области (полки ОФП Кори: $k_{ro} = 0$, $k_{rg} = k_{rg}^{max}$, производные по $S_g$ равны нулю; излом $k_{rg}$ на границе), по итерациям не проверено. Зацикливание active set при шаге 169 с — побочная слабость: при исправленном начальном приближении до дробления шага не доходит.

Описание обновлено; рекомендованный вариант — 1 (ограничение начального $S_g$).
