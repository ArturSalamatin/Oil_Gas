## Записи

### FEAT-001: PVT-корреляции Black Oil
- **Описание:** Rs(p,T), Bo(p,T), Bg(p,T), μo(p,T), μg(p,T), cp,o, cp,g по Стендингу
- **Формулы:** two_phase_energy.tex §1.3–1.4 (PVT-допущения)
- **Модуль:** `src/pvt/correlations.py`, `src/pvt/black_oil.py`
- **Тесты:** сравнение с табличными данными из Refs
- **Статус:** 🔴 ОТКРЫТ

### FEAT-002: Относительные фазовые проницаемости (ОФП)
- **Описание:** модель Кори для kro(Sg), krg(Sg)
- **Формулы:** \eqref{eq:mobility}
- **Модуль:** `src/pvt/black_oil.py`
- **Тесты:** граничные значения, монотонность, Sg=0 и Sg=1−Sor
- **Статус:** 🔴 ОТКРЫТ

### FEAT-003: Параметризация профилей p(r), Sg(r), T(r)
- **Описание:** Φ(η), Sg,w·(1−η)^β, Ψ(ζ)·ΔTw
- **Формулы:** moments_method.tex §4 (\eqref{eq:p_outer}–\eqref{eq:T_profile})
- **Модуль:** `src/profiles/`
- **Тесты:** ГУ на забое и на границе, гладкость, согласованность
- **Статус:** 🔴 ОТКРЫТ

### FEAT-004: Аналитические интегралы I_Φ^(n), I_Ψ^(n), I_S^(n)
- **Описание:** замкнутые формулы для интегралов при замороженных PVT
- **Формулы:** moments_method.tex §5.4 (\eqref{eq:I_Phi}–\eqref{eq:I_S})
- **Модуль:** `src/integrals.py`
- **Тесты:** аналитика vs scipy.integrate.quad
- **Статус:** 🔴 ОТКРЫТ

### FEAT-005: Коэффициенты ODE-системы A_ij, F_i
- **Описание:** матрица и правая часть системы (3×3)
- **Формулы:** moments_method.tex §5.1–5.4 (\eqref{eq:ode_system})
- **Модуль:** `src/coefficients.py`
- **Тесты:** невырожденность матрицы, размерности
- **Статус:** 🔴 ОТКРЫТ

### FEAT-006: Начальная асимптотика
- **Описание:** rb(tε), Sg,w^eq, ΔTw=0 при t→0
- **Формулы:** moments_method.tex §6 (\eqref{eq:ic_regularized})
- **Модуль:** `src/initial.py`
- **Тесты:** автомодельная задача диффузии
- **Статус:** 🔴 ОТКРЫТ

### FEAT-007: ODE-решатель
- **Описание:** интеграция системы через scipy.integrate.solve_ivp
- **Формулы:** \eqref{eq:ode_system}, правая часть из coefficients.py
- **Модуль:** `src/ode_system.py`, `src/solver.py`
- **Тесты:** rb(t) растёт, Sg,w ∈ [0,1], ΔTw < 0 (охлаждение)
- **Статус:** 🔴 ОТКРЫТ

### FEAT-008: CLI и визуализация
- **Описание:** запуск из командной строки, вывод графиков rb(t), p(r), Sg(r), T(r)
- **Модуль:** `src/main.py`
- **Статус:** 🔴 ОТКРЫТ
