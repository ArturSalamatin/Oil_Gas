# Fraim Wattenbarger 1988 — decline curve при многофазном потоке

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Fraim M.L., Wattenbarger R.A.** Decline Curve Analysis for Multiphase Flow. *SPE-18274-MS*, 1988.

## Аннотация
Применение модели Muskat 1937 к анализу кривых падения дебита при многофазном потоке. Основной акцент — влияние градиента насыщенности на профиль $q(t)$ при снижении давления ниже $p_b$.

## Потенциал для проекта
Связь между $S(r)$ и $q(t)$ при разгазировании — релевантна для верификации моделей ПЗП, где дебит определяется пространственным распределением подвижности.
