# Запуск решателя

Пользователь указал конфиг или параметры: `$ARGUMENTS`

Если `$ARGUMENTS` пуст — использовать `method_of_moments/configs/baseline.json`.

## Инструкции

### 1. Запусти решатель

```powershell
cd d:\Lessons\Grants\2026\GPN\Oil_Gas\method_of_moments
.venv\Scripts\python src/main.py $ARGUMENTS
```

Если `method_of_moments/src/main.py` не существует или не готов — сообщи, какие FEAT нужно реализовать.

### 2. Проверь результат

- Решение завершилось без ошибок?
- rb(t) — монотонно растёт?
- Sg,w(t) ∈ [0, 1]?
- ΔTw(t) < 0 (охлаждение)?
- Нет NaN / Inf?

### 3. Визуализация

Если `main.py` не выводит графики автоматически, построй:
1. **rb(t)** — радиус зоны разгазирования.
2. **p(r)** при t = [100, 1000, 10000, 86400] с — профиль давления.
3. **Sg(r)** при тех же t — профиль газонасыщенности.
4. **T(r)** при тех же t — профиль температуры.

Сохрани в `method_of_moments/results/`.

### 4. Физическая проверка

- Давление на забое p(rw) → p_wf?
- Давление на контуре p(Rext) → p_0 (при ранних t)?
- Sg(r > rb) = 0?
- T(rw) < T_0 (охлаждение из-за JT и дегазации)?

Если что-то нефизично — сообщи, предложи диагностику.
