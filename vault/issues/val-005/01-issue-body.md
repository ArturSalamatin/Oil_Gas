## Описание

Руководитель группы просит пример расчёта на таблице PVTO и прочих параметрах из папки своего прототипа (2026-10-08). Вход — `numerical_solver/HydroSolverPrototype/Prototype_1.0.3/INPUT_TEMPLATE.xlsx` (решение пользователя).

Сейчас ни один пример решателя не построен на входе прототипа: все табличные PVT примеров 04–21 сгенерированы у нас. Не проверено, что наш путь «конфиг → фабрика → `PrototypeHydroAdapter` → прототип» с нашим управлением шагом по времени воспроизводит расчёт самого прототипа и его сверку с CMG IMEX на тех же данных.

**Что эта проверка доказывает и чего нет.** Гидродинамику в нашем решателе считает Ньютон прототипа, табличное PVT от $T$ не зависит. Согласие с IMEX — не независимая проверка гидродинамики (её авторы прототипа уже сверили с IMEX), а проверка конвертации входа, адаптера и нашего шага по времени. Температура остаётся без внешнего эталона; VAL-003 эта задача не снимает.

## Эталонное решение

1. **Сам прототип** — `run_prototype.py` на той же книге (`OUTPUT/INPUT_TEMPLATE/`: `profiles.csv`, `rates.csv`).
2. **CMG IMEX, кейс T07** (полностью неявная схема). У T07 тот же лист MODEL и те же таблицы OIL_PVT, GAS_PVT, RELPERM, что у шаблона; отличие — в шаблоне добавлены отчёты через 10 с в первую минуту после смены режима. Файлы: `regression/reference_imex_normalized/T07_profiles.csv`, `T07_rates.csv`. Сопоставление ячейка $i$ ↔ ячейка $i$ IMEX ($i$ = 1…100; 101-я ячейка IMEX — буфер постоянного давления, исключается), `CONTEXT_HANDOFF_1.0.3.md` §19.
3. **Температура** — эталона нет. Внутренние проверки: баланс энергии, знаки эффектов.

## Сценарий

Содержимое книги — `vault/issues/val-005/probes/proto_inputs.out.txt` (проба `proto_inputs.py`).

| Параметр | Значение |
|---|---|
| $r_w$, $r_e$, $h$ | 0.1 м, 100 м, 10 м |
| $k$ | 1 мД |
| $\phi$, $c_r$ | 0.2 при $p_{ref}$ = 200 бар; 4.5e-5 1/бар |
| скин, $N$ | 0; 100 |
| $p_0$ = $p_e$ | 200 бар |
| $R_{s0}$ | 50 м³ст/м³ст ($p_b$ = 180 бар) |
| время | 30 сут |
| расписание | BHP 150 бар → 120 бар на 5 сут → 100 бар на 15 сут (как T07) + отчёты через 10 с после смен режима |
| OIL_PVT | PVTO: 6 ветвей $R_s$ = 5…50, по 5 строк (насыщенная точка + недонасыщенные до 300 бар); ветвь $R_s$ = 50 последняя — $R_{s0}$ на краю таблицы |
| GAS_PVT | 13 строк, 10…250 бар |
| RELPERM | 15 строк, $S_{gc}$ ≈ 0.04, $S_g$ ≤ 0.85 |

**Путь входа** (решение пользователя): разовая конвертация скриптом в папке примера: xlsx → `oil_pvt.csv`, `gas_pvt.csv`, `relperm.csv` (СИ) + `config.json`. Нового кода библиотеки нет. Перевод единиц: бар → Па (×1e5), cP → Па·с (×1e-3), мД → м² (×9.869233e-16), 1/бар → 1/Па (×1e-5). Опорное давление породы фабрика берёт равным $p_0$ (`factory.py:357-361`) — у шаблона совпадает с $p_{ref}$ = 200 бар.

**Тепловые параметры и плотности при стандартных условиях** (решение пользователя): в книге прототипа их нет — прототип изотермический. Берутся из наших примеров (как в примере 14): $T_0$ = 350 К, $\rho_{o,ст}$ = 850 кг/м³, $\rho_{g,ст}$ = 0.85 кг/м³, $\mu_{JT,o}$ = −4e-7 К/Па, $\mu_{JT,g}$ = 4e-6 К/Па, $L$ = 2.3e5 Дж/кг, $c_p$, $\lambda$. README примера обязан сказать, что это не данные руководителя.

Отчётные отметки: 1 мин, 1, 2, 4, 5, 6, 14, 15, 16, 30 сут. Величины: $p(r)$, $S_g(r)$, $R_s(r)$, $T(r)$, $q_o$, $q_g$, GOR, $p_{wf}$, $T(r_w)$.

## Зависимости

Блокирующих нет. Вопросы к планированию:

1. **Шаг по времени.** Прототип стартует с 1 мин и растёт до 60 мин, у нас — `dt_integration` на интервал истории. Разница с прототипом — погрешность по времени (VAL-004). Какой `dt_integration` брать и какой допуск против прототипа.
2. **Край таблицы.** На T07 прототип пишет предупреждение «OIL_PVT saturated locus above table»: газ при $p$ до 182.14 бар > $p_b$ = 180 бар, ветвь $R_s$ = 50 зажата. Проверить реакцию наших проверок PVT в фабрике (BUG-019, DEBT-026, `_check_rs0_in_table`, `factory.py:155`).
3. **Имя примера** — свободен номер 18 (`18_…`).
