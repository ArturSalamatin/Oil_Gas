# Hintermüller Ito Kunisch 2003 — метод активного множества как полугладкий Ньютон

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Hintermüller M., Ito K., Kunisch K. The primal-dual active set strategy as a semismooth Newton method. *SIAM Journal on Optimization*, 2003, 13, 865–888.

## Аннотация

В [[Ben Gharbia Jaffré 2014 — полугладкий Ньютон для появления и исчезновения газовой фазы]] цитируется дважды. Во введении, вместе с [16], — как работа о полугладком методе Ньютона (Newton-min) для нелинейных задач дополнительности. В §3.2 — как обоснование того, что Newton-min можно рассматривать как стратегию активного множества. По названию: прямо-двойственная стратегия активного множества трактуется как полугладкий метод Ньютона.

## Потенциал для проекта

Категория A. Общая рамка для двух схем обработки фаз в проекте:
- внешний цикл набора фаз прототипа (фазы переключаются после сходимости Ньютона, [[P3-маппинг-состояния]]);
- переключение на каждой итерации (метод S в [[bug-014 well-shutin-active-set]]).

Вторая схема, по этой работе, — полугладкий Ньютон. Год: в [[Jaffré Sboui 2010 — закон Генри и исчезновение газовой фазы]] ссылка приведена по памяти с годом 2002. В списке литературы статьи 2014 г. стоит 2003, том 13, с. 865–888.
