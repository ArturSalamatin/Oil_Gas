# Ozkan Raghavan Chen 2011 — tri-linear flow для SRV

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Ozkan E., Brown M., Raghavan R., Kazemi H.** Comparison of Fractured-Horizontal-Well Performance in Tight Sand and Shale Reservoirs. *SPE Reservoir Evaluation & Engineering*, 2011, 14(1), pp. 113–127.

## Аннотация
Модель tri-linear flow для стимулированного объёма пласта (SRV): линейный поток из матрицы в естественные трещины, из трещин в ГРП, из ГРП в скважину. Базовая геометрическая схема для аналитических решений давления в нетрадиционных коллекторах. В Al-Rbeawi 2018 используется для определения storativity (Eqs. 39–43) и dimensionless параметров (Appendix A). Совместно с Brown et al. 2011 формирует основу аналитической модели давления.

## Потенциал для проекта
Методология (решение в Лапласе для составной области) переносима на радиальную геометрию с зонами разных свойств, хотя сама геометрия SRV не применима к ПЗП.
