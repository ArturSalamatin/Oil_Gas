### План готов

**План:** `vault/plans/bug-024 stage4-rs-step-limit.md` (база `a26706a`), 7 шагов (0–6), тестов 1677 → 1680.

#### Корневая причина уточнена — условие по ячейке ни при чём

Трасса итераций ступени 4 (`vault/issues/bug-024/probes/stage4_failure.py`): на всех отказавших подшагах Ньютон ни разу не достигает даже глобального порога `||F||_inf <= atol + rtol·||F0||`. Условие по ячейке до проверки не доходит. Гипотеза «не хватает 40 итераций» тоже снята: `_newton_switching` при любом отказе пишет `iterations = max_iter`, поэтому «37.8 в среднем» ничего не доказывало (11 × 40 + 89 = 529) — зарегистрировано как DEBT-061.

Механизм: шаг Ньютона по `R_s` недонасыщенных ячеек в `_newton_switching` не ограничен (`blackoil.py:573`): давление ограничено 0.3·p, `S_g` — 0.2, а `R_s` — нет. Замер: шаги до ±1.7e4 м³ст/м³ст за итерацию, отрицательный `R_s` обрезается до 0 (десятки–сотни раз за решение). Два вида отказа:
- **застой** — ячейка у забоя стоит на `R_s = 0`, Ньютон требует ΔR_s ≈ −45, отсечка возвращает 0, `||F||` не меняется 30 итераций;
- **хаос** — давление итераций до 433 бар, массовые переключения фаз.

BUG-022 лишь сдвинул траекторию. На коде базы исход 20B (1 сут, `max_retries` = 9) скачет без закономерности:

| условие по ячейке | 1e-5 | 1e-6 | 1e-7 | 1e-8 | 1e-9 | выкл. | выкл., atol 5e-12 |
|---|---|---|---|---|---|---|---|
| итог | ✓ | ✗ | ✓ | ✗ | ✗ | ✓ | ✗ |

При 1 сут падают также 19B и 20A.

#### Решение (пользователь, 2026-10-10)

Ограничить шаг: `|ΔR_s| <= 0.2·max(R_s^sat(p), 1)`, `R_s >= 0` — аналог `ds-max` для `S_g`: доля допустимого диапазона `0 <= R_s <= R_s^sat(p)`. В руководстве OPM Flow 2025-10 такого ограничения нет (только `dp-max-rel` = 0.3, `ds-max` = 0.2). Отвергнуты: штатный `max_retries` = 11 и лимит ступени 4 40 → 80 — сценарий проходят, но причину не трогают.

Замер подменой ступени 4:

| сценарий | код базы | с ограничением |
|---|---|---|
| 20B, 1 сут, пороги 1e-6…1e-9, без условия, atol 5e-12 | ✗ на 5 из 6 | ✓ все, 5–25 с |
| 19B / 21B / 20A, 1 сут | ✗ / ✓ 111 с / ✗ | ✓ 8 / 5 / 6 с |
| 20B, 3600 с | ✓ 188 с, 174 отказа ступени 4 | ✓ 33 с, 0 отказов |
| пример 17 | 101 с, 41 отказ шага | 69 с, 0 отказов |

Чувствительность: доля 0.1–0.5 проходит, 1.0 — нет.

Цена:
- **Примеры.** 20 из 22 — побитово; 16 — отличие на уровне допуска Ньютона (1e-10 бар); 17 — часы останова больше не дробятся, история сдвигается на погрешность шага (`T(r_w)` на 16 сут −8.9 мК, на 30 сут 377.3090 → 377.3078 К).
- **Первые сутки сценария BUG-018** (`R_s0` = 500, добыча) — на один отказ и подшаг больше. Так ведут себя все формы правки, даже меняющая только отсечку: на коде базы ступень 4 сходилась там «через» `R_s = 0`.
- **Прототип.** Регрессия побитово: ступень 4 в собственных расчётах прототипа выключена.

Полный прогон с подменой: 1674 passed, 3 к перемеру — `TestShutInStrongCooling::test_wellbore_warms_monotonically`, `TestSwitching::test_switching_meets_cell_tol` (переделка: недостижимый порог 1e-30 вместо сравнения), `test_first_day_with_cell_tol`.
