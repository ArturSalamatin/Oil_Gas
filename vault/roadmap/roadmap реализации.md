```

FEAT-002 (ОФП) ──┘         ↑                                                                      ↑
```

## Фазы

### Фаза 1 — Фундамент: PVT и ОФП

| Задача | Модуль | Критерий готовности |
|---|---|---|
| FEAT-001 | `pvt/correlations.py`, `pvt/black_oil.py` | Rs, Bo, Bg, μo, μg по Стендингу; dRs/dp численно проверены |
| FEAT-002 | `pvt/black_oil.py` | kro, krg по Кори; подвижности λo, λg |

FEAT-001 и FEAT-002 **независимы**, реализуются параллельно.

**Тесты фазы 1:**
- `test_pvt.py`: Rs, Bo, Bg, μo, μg при известных p,T vs табличные данные
- `test_relperm.py`: kro(Sg=0)=kro_max, krg(Sg=0)=0, монотонность, граничные So+Sg=1

### Фаза 2 — Параметризация профилей

| Задача | Модуль | Критерий готовности |
|---|---|---|
| FEAT-003 | `profiles/pressure.py`, `saturation.py`, `temperature.py` | Φ(η), γ(rb), степенной Sg, Ψ(ζ) по §4 moments_method.tex |

**Зависит от:** FEAT-001 (PVT нужны для вычисления γ).

**Тесты фазы 2:**
- ГУ: p(rw)=pwf, p(rb)=pb, dp/dr непрерывен при r=rb
- ГУ: Sg(rw)=Sgw, Sg(rb)=0
- ГУ: T(rw)=T0+ΔTw, T(re)=T0
- Гладкость dp/dr на стыке зон

### Фаза 3 — Интегралы и коэффициенты

| Задача | Модуль | Критерий готовности |
|---|---|---|
| FEAT-004 | `integrals.py` | I_Φ^(n), I_S^(n), J^(m) — формулы §5.4 |
| FEAT-005 | `coefficients.py` | Матрица A (3×3), вектор F (3×1) — §5.1–5.4 |

FEAT-004 → FEAT-005 **последовательно** (коэффициенты строятся из интегралов).

**Тесты фазы 3:**
- Аналитические формулы vs `scipy.integrate.quad`, tolerance < 1e-10
- det(A) ≠ 0 при типичных параметрах (baseline.json)
- Структура матрицы: A₁₂=0, A₃₂=0 (расщепление, §5 moments_method.tex)
- Размерностный анализ коэффициентов

### Фаза 4 — Начальные условия

| Задача | Модуль | Критерий готовности |
|---|---|---|
| FEAT-006 | `initial.py` | rb(tε), Sgw^eq, ΔTw(tε) — формулы §6 |

**Зависит от:** FEAT-001 (PVT для flash-расчёта Sgw^eq).
**Параллельна** с фазой 3.

**Тесты фазы 4:**
- rb(tε) = rw + 2·α*·√(χ₀·tε), сравнение с erfc⁻¹ (\eqref{eq:delta_sqrt})
- Sgw^eq по flash (\eqref{eq:Sgw_equil}) — физичность: Sgw ∈ (0, 1)
- ΔTw(tε) ≈ 0

### Фаза 5 — ODE-решатель

| Задача | Модуль | Критерий готовности |
|---|---|---|
| FEAT-007 | `ode_system.py`, `solver.py` | solve_ivp(Radau), система A·ẋ=F |

**Зависит от:** FEAT-003, FEAT-004, FEAT-005, FEAT-006.

**Тесты фазы 5:**
- rb(t) монотонно растёт
- Sg,w(t) ∈ [0, 1]
- ΔTw(t) ≤ 0 (охлаждение)
- Массовый баланс (интегральный контроль)

### Фаза 6 — CLI, визуализация, валидация

| Задача | Модуль | Критерий готовности |
|---|---|---|
| FEAT-008 | `main.py` | JSON → решение → .csv + .png |
| VAL-001 | — | Sg=0, T=const → q vs Дюпюи, δ < 1% |
| VAL-002 | — | T=const → p(r), Sg(r) vs FD-решение, δ < 5% |
| VAL-003 | — | Полная система vs OPM Flow, δ < 10% |

## Пирамида тестирования

```
         ╱ VAL-001..003 ╲         ← валидация vs эталоны
        ╱  интеграция     ╲       ← solver: физические инварианты
       ╱  согласованность   ╲     ← So+Sg=1, энергобаланс, det(A)≠0
      ╱  граничные случаи     ╲   ← Sg=0, p=pb, γ→0, rb→rw
     ╱  unit-тесты              ╲ ← каждый модуль изолированно
```

**Правило:** тест пишется одновременно с реализацией. Зелёные тесты — условие перехода к следующей фазе.

## Порядок запуска

1. **FEAT-001 + FEAT-002** (параллельно) → зелёные тесты
2. **FEAT-003** → зелёные тесты
3. **FEAT-004 → FEAT-005** (последовательно) + **FEAT-006** (параллельно с 004–005) → зелёные тесты
4. **FEAT-007** → зелёные тесты + физические инварианты
5. **FEAT-008** → smoke-test
6. **VAL-001 → VAL-002 → VAL-003** (последовательно, по возрастанию сложности)
