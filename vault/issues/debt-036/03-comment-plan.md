**Что меняется** (численный метод — нет, всё побитово):

1. `component_inventories` берёт `pvt.bo`, `pvt.bg` без вязкостей.
2. Запасы старого состояния считаются один раз на шаг: кеш одной записи `_old_inventories`, ключ — **байты** $p$, $R_s$, $S_g$. Вариант issue «по ссылке на объект» отклонён: проба показала устаревшие запасы, если состояние изменено на месте. Ключ стоит 1.8 мкс, запасы — 230 мкс.
3. `BlackOilPVT`: интерполяция PVTO массивами — таблица строк ветвей с наклонами `np.interp` и карта «интервал объединённой сетки узлов → строка ветви», один точный `searchsorted`. `_oil_prop` и `_branch_prop_delta` удаляются.
4. `bo_mu_o` — $B_o$ и $\mu_o$ за один проход; на гранях — через `getattr`, адаптер Стендинга не меняется.
