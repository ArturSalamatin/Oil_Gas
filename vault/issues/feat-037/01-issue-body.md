## Описание

Механизм версий решателя `gpn-multiphase-solver`: единый номер `gpn_multiphase_solver.__version__`, журнал изменений `numerical_solver/CHANGELOG.md` и правило повышения номеров. Выделено из FEAT-031 (решение пользователя 2026-10-18): библиотеку получают пользователи с регулярными выпусками, номер и журнал нужны каждому выпуску, а не только поставке 1.0.0.

## Мотивация

Сейчас у решателя нет ни номера, по которому пользователь может узнать, какой код у него установлен, ни описания того, что изменилось между выпусками:

- номер — литерал `version = "0.1.0"` в `numerical_solver/pyproject.toml:7`; в пакете `__version__` нет (`gpn_multiphase_solver/__init__.py` — одна строка докстринга), `importlib.metadata` нигде не читается;
- журнала изменений решателя нет; у прототипа есть — `HydroSolverPrototype/Prototype_1.0.3/CHANGELOG_1.0.3.md`;
- номер `0.1.0` ничего не утверждает о соответствии кода поставке.

Фаза: поставка заказчику. Блокирует FEAT-031 (#114): номер 1.0.0 и раздел журнала поставки ставятся механизмом этой задачи.

## Предлагаемый API

1. **Единый источник номера.** Литерал в `gpn_multiphase_solver/__init__.py`:
   ```python
   __version__ = "1.0.0.dev0"
   ```
   `pyproject.toml`: `version = "0.1.0"` убирается, вместо него
   ```toml
   [project]
   dynamic = ["version"]

   [tool.setuptools.dynamic]
   version = {attr = "gpn_multiphase_solver.__version__"}
   ```
   Так же устроен прототип (`radial_blackoil/__init__.py:7`, `pyproject.toml:11,28`; DEBT-059). Именно литерал, без вычисления: setuptools читает его разбором исходника; иначе он импортирует пакет, а в изолированной сборке numpy нет.
2. **Номер до выпуска — `1.0.0.dev0`** (PEP 440: разработка к 1.0.0). `1.0.0` ставится в момент выпуска (решение пользователя 2026-10-18): пока FEAT-035 (#133) и FEAT-036 открыты, номер не должен утверждать, что код совпадает с поставкой.
3. **Журнал `numerical_solver/CHANGELOG.md`** — для пользователя библиотеки, по-русски. Разделы по выпускам, сверху — «Не выпущено». Изменения, меняющие числа результатов, описываются явно: какие величины и насколько.
4. **Правило номеров** — в начале журнала:
   - MAJOR — несовместимые изменения публичного интерфейса (`tests/test_public_api.py`, README §4), формата конфига или книги Excel;
   - MINOR — новые возможности, прежние конфиги считаются;
   - PATCH — исправления ошибок;
   - номер прототипа: локальная метка `+gpn.N` повышается при выпуске, если код `radial_blackoil/` изменился с прошлого выпуска.

### Варианты источника номера

| Вариант | Суть | Плюсы | Минусы |
|---|---|---|---|
| **А (рекомендуется)** | литерал `__version__` + `dynamic` в `pyproject.toml` | один источник; работает без установки и в изолированной сборке; совпадает с прототипом, проверка по образцу готового теста | номер правится руками при выпуске |
| Б | `__version__ = importlib.metadata.version("gpn-multiphase-solver")`, номер в `pyproject.toml` | номер в одном месте — `pyproject.toml` | при редактируемой установке метаданные записаны в момент `pip install -e` и отстают от `pyproject.toml` до переустановки; venv общий для основного каталога и worktree — тесты worktree увидят номер основного каталога; без установки — `PackageNotFoundError` |
| В | `setuptools-scm`: номер из меток git | номер не правится руками | заказчик получает срез исходного кода без `.git` — сборка из среза не получит номер; новая зависимость сборки |

## Подводные камни

- **Метаданные редактируемой установки.** После смены `__version__` `importlib.metadata.version("gpn-multiphase-solver")` возвращает прежний номер до переустановки (`pip install -e`). Тест сверки метаданных с литералом в рабочем окружении дал бы ложный отказ — проверять нужно `pyproject.toml` и литерал, не метаданные. В чистом окружении номер проверяет приёмка (`vault/issues/debt-059/probes/clean_env_acceptance.py`).
- **Разбор PEP 440.** Пакет `packaging` не объявлен в зависимостях; проверка формата номера — регулярным выражением канонической формы PEP 440 или через `pytest.importorskip("packaging")`.
- `_pyproject()` в `test_packaging.py` пропускает тест на Python 3.10 (нет `tomllib`); рабочее окружение — 3.13.
