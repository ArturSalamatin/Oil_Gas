### План готов

**План:** `vault/plans/bug-020 shutin-phase-switching-newton.md` (2026-10-06). Пробы и выводы — `vault/issues/bug-020/probes/`.

**Причина установлена** (кандидаты из описания issue уточнены):

- **М1, первый шаг останова.** Забойная ячейка 0 ($PV = 2.8\cdot10^{-3}$ м³) после закрытия скважины ни для одной грани не стоит выше по потоку. Её газовый коэффициент запаса $1/B_g - R_s/B_o$ при 51 бар равен 7.4 против 38.9 при 200 бар. Первое направление Ньютона требует $|\Delta S_{g,0}| \approx 0.7\,\Delta t$ [с]: 48 при 60 с, 435 при 600 с.
  - Исходный алгоритм отвергает все пробные точки.
  - Запасной путь уводит $S_{g,0}$ в $-23 \ldots -1137$; там $c_t < 0$ (кандидат К2 — следствие перелёта, а не причина).
  - Третья ступень масштабирует всё приращение на $0.2/|\Delta S_{g,0}|$, и давление стоит.
- **М2, следующие шаги.** В застойной однофазной зоне у забоя на 1–11 гранях на каждой итерации меняется ячейка выше по потоку. Ньютону нужно 26 итераций при лимите 15. Набор фаз и ветка скважины ни при чём.
- **К3** подтверждён только для отчёта в режиме $p_{wf} = p_{ext}$: невязка $10^{-14}$ — от несогласованной ветки «открыта» (DEBT-030). К BUG-021 эти отказы не относятся.
- **Равномерное A-retry.** При `dt_integration` = 1 сут один неудачный подшаг из 512 валит интервал — даже с исправленным Ньютоном.

**Решения пользователя:**

1. Четвёртая ступень `advance` под флагом прототипа `phase_switching_stage` (по умолчанию выключен — эталон регрессии прототипа побитовый); фабрика GPN включает. Устройство ступени:
   - переключение набора фаз после каждой итерации с сохранением отношения газ/нефть;
   - поячеечное ограничение $|\Delta p| \le 0.3p$, $|\Delta S_g| \le 0.2$;
   - без линейного поиска;
   - замораживание ячейки выше по потоку на гранях после двух смен направления, затем доводка без него;
   - лимит 40 итераций.
2. `dt_integration` ≤ 3600 с при останове — документировать в README и в тексте ошибки. Локальное дробление остаётся в DEBT-015 (довод дописан).
3. Пример останова с сильным охлаждением — отдельная FEAT-029.

**Замеры на коде плана:**

| | без ступени 4 | со ступенью 4 |
|---|---|---|
| первый час останова, конфиг 19 | отказ | 1 подшаг |
| первый час, конфиг 21 | отказ | 16 подшагов |
| первый час, конфиг 20 | 256 подшагов | 64 |
| 3 сут останова, `dt_integration` 3600 с, конфиг 19 | отказ | 438 с |
| то же, конфиг 21 | отказ | 196 с |
| то же, конфиг 20 | 512 с | 366 с |

- Где ступени 1–3 сходятся — побитово.
- Тот же корень, что у штатного алгоритма: $|\Delta p| = 3\cdot10^{-9}$ бар.
- Баланс масс шага — $10^{-16}$…$10^{-13}$ запаса.
- Примеры меняются только 13b и 16, по одному шагу: $|\Delta p| \le 0.44$ бар, $|\Delta T| \le 2.7$ мК.

**Шаги (9):** подготовка → замороженные сценарии и тесты-воспроизводители → прототип (отчёт, флаг, потоки, `_switch_phases`, `_newton_switching`, `advance`) → фабрика, текст ошибки, тесты логики → сквозная проба → пересъём чисел 13b и 16 → CHANGELOG и полная регрессия прототипа → полный прогон GPN → vault.

**Зависимость:** начинать после влития DEBT-030 (#62), который правит тот же `advance`.
