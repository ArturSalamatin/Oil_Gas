# Gringarten 2000 — PTA газоконденсата с rate-dependent ОФП

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Gringarten A.C., Al-Lamki A., Daungkaew S. et al. Well Test Analysis in Gas-Condensate Reservoirs. *SPE ATCE*, 2000. SPE 62920.

## Аннотация
Введена четвёртая зона в модель газоконденсатного пласта — непосредственная окрестность скважины, где ОФП зависят от дебита (rate-dependent relative permeability). Четырёхзонная модель расширяет концепцию Fevang–Whitson (1996). Продемонстрированы полевые примеры radial composite сигнатуры при использовании однофазной $m(p)$.

## Потенциал для проекта
Rate-dependent ОФП (coupling/capillary number effect) — явление, специфичное для газоконденсатных систем. В нефтяных системах с разгазированием скоростной эффект менее выражен, но четырёхзонная концепция может быть полезна для классификации зон ПЗП.
