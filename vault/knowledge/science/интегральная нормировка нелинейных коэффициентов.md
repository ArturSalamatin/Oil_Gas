# Интегральная нормировка нелинейных коэффициентов

Общий приём: если коэффициенты PDE зависят от решения (давления, насыщенности, температуры), замена переменной через интеграл от этих коэффициентов «поглощает» нелинейность. В задачах подземной гидромеханики реализуется в нескольких формах.

## Нормировка по давлению — псевдодавление $m(p)$

$$m(p) = 2\int_{p_0}^{p} \frac{p}{\mu(p)\,z(p)}\,dp$$

Введена [[Al-Hussainy 1966 — псевдодавление для реальных газов|Al-Hussainy et al. (1966)]] для однофазного газа. Сводит строго нелинейное PDE к квазилинейной форме $\nabla^2 m = (\phi\mu c_g/k)\,\partial m/\partial t$, где остаточная нелинейность — в диффузивности.

Многофазное обобщение: [[Краснов — многофазное псевдодавление и функции источника|Краснов]] вводит $m^k(p)$ для фазы $k$ с учётом ОФП и PVT Black Oil.

## Нормировка по времени — псевдовремя $t_a(p)$

$$t_a(p) = \int \frac{dt}{\mu(p(t))\,c_t(p(t))}$$

Введена [[Agarwal 1979 — псевдовремя для реального газа|Agarwal (1979)]]. Устраняет зависимость $\mu c_t(p)$ при buildup-анализе. Приближённая функция (в отличие от точной $m(p)$), поскольку опирается на кусочно-линейную аппроксимацию $p(t)$.

## Нормировка по пространству — интегральные моменты

$$M_n(t) = \int_\Omega S(r,t)\,r^n\,dr$$

Метод моментов Баренблатта ([[ref_moments_method]]): свёртка PDE по пространственной координате сводит систему к ODE для интегральных моментов $M_n(t)$. Нелинейные коэффициенты (ОФП, PVT) «поглощаются» интегрированием.

## Общая структура

| Вид нормировки | Переменная | Что поглощается | Источник |
|---|---|---|---|
| По давлению | $m(p)$ | $\mu(p)z(p)$ или $\mu(p) k_r(S)/B(p)$ | Al-Hussainy 1966, Краснов |
| По времени | $t_a(p)$ | $\mu(p)c_t(p)$ | Agarwal 1979 |
| По пространству | $M_n(t)$ | пространственная структура $S(r,t)$ | Баренблатт, [[ref_moments_method]] |
