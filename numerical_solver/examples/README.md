# Примеры использования солвера

Десять готовых сценариев: JSON-конфиг → Factory → расчёт → графики и таблицы.
Каждая подпапка самодостаточна — конфиг, нужные CSV, `main.py` и README
с описанием физики и эталонными числами.

**Главная задача примеров** — показать, как комбинировать конкретные
реализации модулей библиотеки. Возьмите ближайший к вашей задаче пример
и меняйте конфиг.

## С какого начать

| Ваша ситуация | Пример |
|---|---|
| Первое знакомство с библиотекой | **01** — самый простой, однофазный |
| Лабораторных данных нет, есть только параметры пласта | **03** — корреляции PVT + аналитические ОФП |
| Есть полный набор лабораторных данных (PVTO + ОФП по керну) | **04** — всё из CSV |
| PVT по корреляциям, ОФП измерены на керне | **05** |
| PVT из лаборатории, ОФП неизвестны | **06** |
| Нужно оценить вклад отдельного теплового эффекта | **07 → 08 → 09** |
| Интересует сильная депрессия | **10** |

## Все сценарии

### Семейство 1 — однофазные ($R_{s,0} = 0$, нефть несжимаема)

| № | Папка | PVT | ОФП | Что показывает |
|---|---|---|---|---|
| 01 | [01_single_phase_no_jt](01_single_phase_no_jt/) | Standing | Corey | базовый расчёт, только адиабатический эффект |
| 02 | [02_single_phase_jt](02_single_phase_jt/) | Standing | Corey | вклад Джоуля–Томсона в чистом виде |

### Семейство 2 — четыре комбинации модулей ($R_{s,0} > 0$, полная термика)

Одинаковые условия, разные модули. Показывает, что PVT и ОФП комбинируются
независимо.

| № | Папка | PVT | ОФП | Комбинация | Внешние файлы |
|---|---|---|---|---|---|
| 03 | [03_standing_corey](03_standing_corey/) | Standing | Corey | **A** | нет |
| 04 | [04_table_table](04_table_table/) | Table | Table | **B** | oil_pvt, gas_pvt, relperm |
| 05 | [05_standing_table_rp](05_standing_table_rp/) | Standing | Table | **C** | только relperm |
| 06 | [06_table_corey_rp](06_table_corey_rp/) | Table | Corey | **D** | только oil_pvt, gas_pvt |

### Семейство 3 — изоляция тепловых эффектов (Table + Table)

Одна комбинация модулей, варьируется только секция `thermal`.

| № | Папка | $\mu_{JT}$ | $L$ | $p_{wf}$ | $T(r_w)$, К |
|---|---|---|---|---|---|
| 07 | [07_degassing_adiabatic_only](07_degassing_adiabatic_only/) | 0 | 0 | 8 МПа | 352.770 |
| 08 | [08_degassing_jt](08_degassing_jt/) | > 0 | 0 | 8 МПа | 348.558 |
| 09 | [09_degassing_latent_heat](09_degassing_latent_heat/) | 0 | > 0 | 8 МПа | 351.083 |
| 10 | [10_deep_degassing](10_deep_degassing/) | > 0 | > 0 | **6 МПа** | 346.779 |

Полная термика при 8 МПа — это сценарий 04 ($T = 346.871$ К).
Вклады складываются линейно: $(-4.212) + (-1.687) = -5.899$ К.

## Запуск

```powershell
cd numerical_solver
.venv\Scripts\pip install -e .        # один раз

# Один пример
.venv\Scripts\python examples\01_single_phase_no_jt\main.py

# Все десять последовательно
.venv\Scripts\python examples\run_all.py
```

`PYTHONPATH` задавать не нужно: `example_runner.py` сам подключает прототип
`radial_blackoil` через `sys.path`.

`run_all.py` не останавливается на первой ошибке — прогоняет все примеры,
печатает сводку и возвращает ненулевой код, если что-то упало.
Суммарное время всех десяти — около 11 с.

## Три вещи, которые полезно знать заранее

**1. Смена ОФП почти не видна на температуре и дебитах.**
Пары 03↔05 и 04↔06 отличаются только моделью ОФП: насыщенность меняется
на 80 %, а температура — на 0.002 К, дебит — на 0.4–2 %. Разные ОФП
компенсируют разницу насыщенности до одной подвижности газа.
Смотреть надо `saturation_profiles.png`.

**2. Смена PVT меняет всё.** Пара 03↔04: и насыщенность, и температура
(0.65 К), и дебит (46 %), и положение фронта (0.20 против 2.39 м).

**3. Тепловые параметры не влияют на гидродинамику вообще.**
Следствие расщепления (operator splitting): `HydroSolver` не видит секцию
`thermal`, `EnergySolver` работает на замороженных $p$, $S_g$, $R_s$.
У сценариев 07, 08, 09 массивы $S_g$, $p$, $R_s$, $q_o$ совпадают
**побитово**.

## Общие параметры всех сценариев

| Параметр | Значение |
|---|---|
| $r_w$ / $R_e$ / $h$ | 0.1 / 50 / 10 м |
| $\varphi$ / $k$ | 0.2 / $10^{-13}$ м² (≈100 мД) |
| $p_0$ / $T_0$ | 20 МПа / 350 К |
| $N$ | 50 ячеек |
| $\Delta t$ / длительность | 3600 с / 3 суток (73 сохранённых шага) |
| $(\rho c_p)_s$ / $\lambda_s$ | $1.25\times10^6$ Дж/(м³·К) / 1.5 Вт/(м·К) |
| $\rho_{o,ст}$ / $\rho_{g,ст}$ | 850 / 0.85 кг/м³ |

Варьируются между сценариями только: $R_{s,0}$, $p_{wf}$, модели PVT и ОФП,
тепловые скаляры.

## Автоматические тесты

Все десять примеров покрыты smoke-тестами:

```powershell
.venv\Scripts\python -m pytest tests\test_examples.py -v
```

Проверяется: расчёт завершается, нет NaN/Inf, $S_g \in [0,1]$, у двухфазных
сценариев газ действительно выделяется, у однофазных — нет, суперпозиция
тепловых вкладов, побитовое совпадение гидродинамики в семействе 3,
структурная целостность (конфиги валидны, CSV на месте, README содержат
обязательные разделы).
