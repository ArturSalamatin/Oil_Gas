# 04a — Характеристики процесса при высокой газонасыщенности ($S_g = 0.70$)

Табличный PVT, ОФП Кори с $k_{rg}^{max} = 0.0014$, вычисленной
**обратным расчётом** из условия $\text{GOR} = R_{s,0}$.

## Описание

Сильно двухфазный сценарий: газонасыщенность на забое 0.70. Он
показывает, как выглядит режим, когда свободного газа много: подвижности
фаз, дебит, газовый фактор, температурный отклик, протяжённость
двухфазной зоны.

Обратный расчёт $k_{rg}^{max}$ (раздел «Обратный расчёт») — инструмент,
которым режим получен, а не самоцель.

Теплопроводность — 1.5 / 0.14 / 0.04 Вт/(м·К) (скелет / нефть / газ).
Без неё забойная температура за 3 суток была бы выше на 0.002 К; по
области разница доходит до 0.02 К (у забоя, $r \approx 0.11$ м).

## Характеристики режима — ядро примера

| характеристика | значение |
|---|---|
| $S_g$ на забое | **0.7000** |
| $k_{ro}$ на забое | **0.300** |
| $k_{rg}$ на забое | $6.86\cdot10^{-4}$ |
| $R_s$ на забое | **0** — полная дегазация |
| $p_{wf}$ / депрессия $p_0 - p_{wf}$ | 4 / 16 МПа |
| $q_o$, м³ст/с | $4.941\cdot10^{-3}$ |
| $q_g$, м³ст/с | $1.483\cdot10^{-1}$ |
| GOR | 30.006 |
| нагрев забоя за 72 ч | **2.24 К** |
| фронт $r_b$ (расчёт) | **1.51 м** |

### Четыре вывода

1. **Обе фазы малоподвижны**: $k_{ro} = 0.30$, $k_{rg} = 6.9\cdot10^{-4}$.

2. **GOR равен $R_{s,0}$.** Весь свободный газ на забое — газ, вышедший из
   проходящей нефти, а не накопленный. В стационаре разгазирование в ПЗП
   газовый фактор скважины **не повышает**. Остаток 0.006 — незавершённая
   релаксация (см. «Переходный процесс»).

3. **Забой нагревается на 2.24 К** за 3 суток. $T(r_w)$ растёт монотонно с
   первой записи (см. «Переходный процесс») и за 3 суток не
   устанавливается.

4. **Двухфазная зона узкая** — фронт на 1.51 м при депрессии 16 МПа. Фронт
   есть изобара $p = p_b$, и в замкнутом решении её положение задаёт доля
   интеграла подвижности нефти ниже $p_b$:

   $$\frac{\ln(r_b/r_w)}{\ln(R_e/r_w)} = \frac{\int_{p_{wf}}^{p_b}\lambda_o\,dp}{\int_{p_{wf}}^{p_0}\lambda_o\,dp}, \qquad \lambda_o = \frac{k_{ro}(S_g(p))}{\mu_o B_o}.$$

   У забоя $\lambda_o = 95$ 1/(Па·с), доля — 0.43: малая подвижность нефти
   в двухфазной зоне забирает на себя депрессию, и изобара смещается к
   скважине. Насыщенность растёт «в высоту», а не «в ширину».

## Обратный расчёт $k_{rg}^{max}$

Задаём целевое $S_g^{*} = 0.70$ и решаем уравнение замыкания
**относительно параметра ОФП**.

### Уравнение замыкания

В стационаре компонентные потоки не зависят от $r$, а на контуре питания
свободного газа нет ($S_g = 0$) — весь газ приходит растворённым. Значит
газовый фактор закреплён: $\text{GOR} = R_{s,0}$. В отношении $G^g/G^o$
множитель $\mathcal{T}\,\Delta p$ сокращается, и остаётся **алгебраическое**
уравнение на $S_g$:

$$R_s(p) + \frac{k_{rg}(S_g)}{k_{ro}(S_g)}\cdot\frac{\mu_o B_o}{\mu_g B_g} = R_{s,0}.$$

Насыщенность оказывается **локальной функцией давления**: $S_g(r) = S_g(p(r))$,
решать PDE для неё не нужно. Вывод целиком — в докстринге
[diagnostics/closed_form.py](../../gpn_multiphase_solver/diagnostics/closed_form.py).

### Вывод параметра

**Шаг 1.** Берём $p$ в зоне полной дегазации. В `oil_pvt.csv` ветка
$R_s = 0$ начинается при $p = 5$ МПа, значит при $p \le 5$ МПа имеем
$R_s^{sat} = 0$ и дефицит газа максимален: $R_{s,0} - R_s = 30$.

**Шаг 2.** PVT-множитель при $p = 4$ МПа:

$$\frac{\mu_o B_o}{\mu_g B_g} = \frac{0.003 \cdot 1.05}{1.2\cdot10^{-5} \cdot 0.02} = 13125.$$

**Шаг 3.** Требуемое отношение подвижностей:

$$\frac{k_{rg}}{k_{ro}}\bigg|_{S_g = 0.7} = \frac{R_{s,0} - R_s}{(\mu_o B_o)/(\mu_g B_g)} = \frac{30}{13125} = 0.0022857.$$

**Шаг 4.** Для Кори при $S_{or} = 0$, $S_{gc} = 0$, $n_o = 1$, $n_g = 2$,
$k_{ro}^{max} = 1$ имеем $k_{ro} = 1 - S_g$ и $k_{rg} = k_{rg}^{max} S_g^2$,
откуда

$$k_{rg}^{max} = \frac{k_{rg}}{k_{ro}}\cdot\frac{1 - S_g^{*}}{(S_g^{*})^2} = 0.0022857\cdot\frac{0.3}{0.49} = 0.0013994 \approx 0.0014.$$

**Прогон:** $S_g(r_w) = 0.69996$; замыкание при $k_{rg}^{max} = 0.0014$ даёт
0.69993. Отличие от целевых 0.70 ($7\cdot10^{-5}$) — округление
$k_{rg}^{max}$ до 0.0014.

### Контринтуитивный вывод

**Чтобы накопить больше газа, его надо сделать менее подвижным.** ОФП с
отношением $k_{rg}/k_{ro} \sim 10$ при $S_g = 0.7$ — в тысячи раз больше
требуемого 0.0023 — удовлетворяет уравнению замыкания уже при насыщенности
в 1–2 %: газ настолько подвижен, что для выноса нужного объёма хватает
ничтожной насыщенности.

Насыщенность — не мера «интенсивности разгазирования», а мера того,
насколько трудно газу уходить.

### Запись истории

Шаг записи равен шагу интегрирования: один объект `time.history`
`{"duration": 259200.0, "dt_out": 300.0, ...}` — 864 интервала по 300 с,
по одному шагу решателя на запись, 865 записей; `profiles.csv` — около 11 МБ.
Частая запись позволяет смотреть ранний переходный процесс:
[plot_profiles_50k.py](plot_profiles_50k.py) строит по готовому
`profiles.csv` десять профилей на интервале 0…50 000 с.

Баланс энергии копится на шагах решателя и от структуры истории не зависит
(тест `test_balance_independent_of_history_structure`). Жёстких требований
к шагу записи нет. Чтобы после смены `dt_integration` запись по-прежнему
шла на каждом шаге, достаточно поменять одно поле `dt_out` (`duration` =
259 200 с должна на него делиться).

### Первый шаг

Скачок забойного давления 20 → 4 МПа: при шаге 300 с целиком под $p_b$
уходят сразу 79 ячеек из 150 (53 %). Исходный алгоритм Newton и запасной
путь этот шаг не решают; его целиком, без дробления, решает третья
ступень `advance` — линейный поиск по $\|F\|_2$ и ограничитель

расчёт не влияет. К концу первого шага газ есть в 56 ячейках. Все 864
шага идут без дробления.

## Проверки

### 1. Замкнутое решение

Дебит квадратурой, профиль давления — ОДУ от контура внутрь
([diagnostics/closed_form.py](../../gpn_multiphase_solver/diagnostics/closed_form.py)); из расчёта не берётся ничего.

| величина | замкнутое решение | расчёт | расхождение |
|---|---|---|---|
| $q_o$, м³ст/с | $4.913667\cdot10^{-3}$ | $4.940866\cdot10^{-3}$ | 0.550 % |
| $\max\lvert p_{ана}-p_{чис}\rvert$ | — | — | 35.0 кПа (0.218 % депрессии) |
| $S_g^{max}$ | 0.69993 | 0.69996 | — |
| фронт $r_b$, м | 1.476 | 1.507 | 2.1 % |

Расхождение — погрешность конечных объёмов: оно убывает первым порядком по
сетке (см. «Сходимость по сетке»).

### 2. Замыкание $S_g(p)$

$S_g$ из уравнения замыкания при **численном** $p$ против расчётной:

| где | $\max\lvert\Delta S_g\rvert$ |
|---|---|
| у забоя | $3\cdot10^{-5}$ (0.69996 против 0.69993, 0.005 %) |
| двухфазная зона ($p < p_b$, 65 ячеек) | $1.0\cdot10^{-3}$, в последней ячейке перед фронтом |
| за фронтом ($p \ge p_b$, 5 ячеек) | $1.4\cdot10^{-2}$ |

$R_s = R_s^{eq}(p)$ в 70 ячейках с газом выполняется с точностью
$3.6\cdot10^{-15}$, в том числе в пяти за изобарой $p_b$: там
$R_s^{eq}(p) = R_{s,0}$.

**Газ за фронтом — остаток переходного процесса**, а не ошибка замыкания.
В первый час изобара $p_b$ доходит до 1.8 м (см. «Переходный процесс»), и в
ячейках 1.51…1.78 м выделяется газ. Когда фронт отступает, растворяться
этому газу некуда: таблица даёт $R_s^{eq}(p) = 30 = R_{s,0}$ при всех
$p \ge 15$ МПа, нефть там уже насыщена. Уходит он только потоком, а при
$S_g \sim 0.01$ подвижность $k_{rg} = k_{rg}^{max} S_g^2 \sim 10^{-7}$
ничтожна: в ближней к скважине из этих ячеек $S_g$ = 0.106 через 6 ч,
0.033 через 24 ч, 0.014 через 72 ч. Отсюда 70 ячеек с газом при 65 ячейках
с $p < p_b$.

Метрика согласия с замыканием — значение у забоя и абсолютная невязка.
Относительная ошибка за фронтом вырождается в 100 %: замыкание даёт там
строго 0.

### 3. Температура

Аналитической проверки температуры в двухфазной зоне нет. Схема
проверяется поэлементной сверкой матрицы с постановкой
(`tests/test_energy_matrix_examples.py`) и балансом энергии (п. 4).

В однофазной зоне (80 ячеек) стационарная асимптотика
$T = T_{ext} + \mu_{JT,o}(p - p_0)$ (отсчёт от давления на контуре)
отличается от расчёта на 1.24 К:
за 3 суток температура не установилась.

Табличный PVT от $T$ не зависит, поэтому гидродинамика ($S_g$, $q_o$, GOR)

## Поведение у фронта — вертикальная касательная, а не разрыв

Вблизи $p_b$ насыщенность мала, $k_{ro} \approx 1$, и из замыкания
$k_{rg}^{max} S_g^2 \cdot (\mu_o B_o)/(\mu_g B_g) \approx R_{s,0} - R_s(p) \propto (p_b - p)$
следует

$$S_g \propto \sqrt{p_b - p}, \qquad \frac{dS_g}{dp} \to -\infty.$$

Значение $S_g$ **непрерывно** и стремится к нулю при $p \to p_b^{-}$, но
производная бесконечна. По замыканию (множитель
$(\mu_o B_o)/(\mu_g B_g) \approx 1.6\cdot10^4$ у $p_b$):

| $p_b - p$ | $S_g$ |
|---|---|
| 0 | 0 |
| 1 Па | $3.7\cdot10^{-4}$ |
| 1 кПа | 0.0115 |
| 10 кПа | 0.0359 |
| 0.1 МПа | 0.1092 |
| 1 МПа | 0.3099 |

Десятикратный шаг по $p_b - p$ умножает $S_g$ почти в $\sqrt{10} \approx 3.2$
раза. На сетке $N = 150$ последняя ячейка перед фронтом
($p_b - p = 58$ кПа) имеет $S_g = 0.086$ — это дискретизация вертикальной
касательной, а не разрыв решения.

## Почему $n_o = 1$

`SimulatorFactory` при `relperm.model = "corey"` создаёт `CoreyRP`, но
`RadialBlackOilModel` (решатель прототипа) требует `TabulatedRelPerm`.
Поэтому фабрика **табулирует Кори на 101 равномерном узле** и дальше
интерполирует линейно — гидродинамика решается не по гладкой Кори, а по её
кусочно-линейной аппроксимации с шагом 0.01.

Линейная $k_{ro}$ ($n_o = 1$) воспроизводится линейной интерполяцией
**точно**, поэтому погрешность остаётся только от $k_{rg} \propto S_g^2$ и
составляет $O(h^2)$:

| $S_g$ | $k_{rg}/k_{ro}$ точно | по таблице (101 узел) | отклонение |
|---|---|---|---|
| 0.11 | $1.90337\cdot10^{-5}$ | $1.90337\cdot10^{-5}$ | 0.0000 % |
| 0.695 | $2.21716\cdot10^{-3}$ | $2.21728\cdot10^{-3}$ | 0.0052 % |
| 0.700 | $2.28667\cdot10^{-3}$ | $2.28667\cdot10^{-3}$ | 0.0000 % |

Целевое $S_g = 0.7$ вдобавок попадает ровно в узел. Поэтому аналитику можно
строить на **точной** Кори — это обосновано, а не самоочевидно.

## Плато: $S_g$ у забоя не зависит от дальнейшего снижения $p_{wf}$

Ниже 5 МПа $R_s^{sat} = 0$, а PVT-свойства в таблицах экстраполируются
константой. Обе части уравнения замыкания перестают зависеть от $p$:

| $p$, МПа | $R_s$ | $(\mu_o B_o)/(\mu_g B_g)$ | $S_g$ по замыканию |
|---|---|---|---|
| 6.0 | 3.00 | 13234 | 0.6814 |
| 5.0 | 0.00 | 13125 | 0.6999 |
| 4.0 | 0.00 | 13125 | 0.6999 |
| 3.0 | 0.00 | 13125 | 0.6999 |

Замкнутое решение при $p_{wf} = 3$ МПа: $S_g$ у забоя та же (0.69993),
дебит на 2.0 % выше ($5.010\cdot10^{-3}$ против $4.914\cdot10^{-3}$ м³ст/с),
фронт смещается от скважины — 1.58 м против 1.48 м. Значение $p_b$ задано
таблицей, но положение изобары $p = p_b$ зависит от профиля давления.

⚠️ Плато — **свойство демонстрационной PVT-таблицы** (константная
экстраполяция ниже последнего узла), а не физический закон.

## Независимость $S_g(p)$ от $k$, $\varphi$, $h$, $q_o$

Их нет в уравнении замыкания. Проницаемость, пористость, толщина пласта и
дебит определяют, **как быстро** и **при каком градиенте** течёт флюид, но
не то, какая доля порового объёма занята газом при данном $p$: она задаётся
балансом компонентов, то есть PVT и ОФП.

## Цена выбора $n_g = 2$

Обратная задача решается при любом $n_g$ — меняется только вычисляемое
$k_{rg}^{max}$. Выбор $n_g = 2$ сделан ради корневой особенности
$S_g \propto \sqrt{p_b - p}$. Сравнение при $N = 150$:

| $n_g$ | $k_{rg}^{max}$ | $S_g(r_w)$ | $\max\lvert\Delta S_g\rvert$ замыкания | ячеек $p < p_b$ / $S_g > 0$ | ошибка $q_o$ |
|---|---|---|---|---|---|
| 1 | 0.00098 | 0.6999 | $3.3\cdot10^{-8}$ | 70 / 70 | 0.58 % |
| **2 (выбран)** | **0.0014** | **0.7000** | $1.4\cdot10^{-2}$ | 65 / 70 | 0.55 % |

При $n_g = 1$ функция $k_{rg}$ линейна, вертикальной касательной нет, зоны
совпадают, и замыкание выполняется до $10^{-8}$. Точность дебита от выбора
$n_g$ практически не зависит. Цена $n_g = 2$ — невязка замыкания: газ за
фронтом (п. 2 «Проверок») и чувствительность $S_g$ к ошибке давления у
фронта, где $dS_g/dp \to \infty$.

## Сходимость по сетке

| $N$ | $S_g(r_w)$ | $q_o$, м³ст/с | ошибка к замкнутому решению | отношение ошибок | отношение шагов |
|---|---|---|---|---|---|
| 25 | 0.6991 | $5.082609\cdot10^{-3}$ | 3.32 % | | |
| 50 | 0.7000 | $4.997825\cdot10^{-3}$ | 1.68 % | 1.97 | 2 |
| 80 | 0.7000 | $4.965104\cdot10^{-3}$ | 1.04 % | 1.63 | 1.6 |
| 120 | 0.7000 | $4.948061\cdot10^{-3}$ | 0.70 % | 1.49 | 1.5 |
| **150** | **0.7000** | $4.940866\cdot10^{-3}$ | 0.55 % | 1.26 | 1.25 |

Таблицу печатает [grid_convergence.py](grid_convergence.py). Замкнутое
решение $q_o = 4.913667\cdot10^{-3}$ м³ст/с от сетки не зависит.

$S_g(r_w)$ стабильна с четвёртого знака начиная с $N = 50$, разброс по всему
ряду 0.0009 — **целевые 0.70 достигаются независимо от сетки**: параметр
выведен из замыкания, а не подогнан под дискретизацию.

Дебит сходится первым порядком: отношение ошибок совпадает с отношением
шагов сетки на всём ряду, систематического смещения нет.

## Как модифицировать

### Что менять безопасно

| Параметр | Эффект |
|---|---|
| `permeability`, `porosity`, `h` | дебит и время установления; $S_g(p)$ **не меняют** — их нет в уравнении замыкания |
| `grid.N` | первый шаг не дробится (замер 2026-10-07 при $N$ = 80, 150, 200, 300, 500; DEBT-041); до BUG-020 при 300 и 500 он дробился на 2 и 8 подшагов |
| `T0`, `c_p_*`, `mu_JT_*`, `L_degas` | только температура; гидродинамика не меняется |

### Как получить другую целевую $S_g$

Пересчитать $k_{rg}^{max}$ по формуле шага 4, подставив своё $S_g^{*}$:

$$k_{rg}^{max} = \frac{R_{s,0} - R_s}{(\mu_o B_o)/(\mu_g B_g)}\cdot\frac{1 - S_g^{*}}{(S_g^{*})^{n_g}}.$$

При $p_{wf} \le 5$ МПа множитель равен $30/13125$, и при $n_g = 2$ формула
сводится к $k_{rg}^{max} = 0.0022857\,(1 - S_g^{*})/(S_g^{*})^{2}$.

### Что требует осторожности

- **$p_{wf}$ выше 5 МПа** — выход из зоны полной дегазации: дефицит газа
  падает, и целевая $S_g$ не достигается (при 6 МПа замыкание даёт 0.681).
- **$n_o \neq 1$** — теряется точность табулирования Кори на 101 узле
  (раздел «Почему $n_o = 1$»).
- **`time.history`** — шаг записи `dt_out` можно укрупнить: решение при
  том же `dt_integration` и баланс энергии не изменятся, пропадут ранние
  моменты для «Переходного процесса» и `plot_profiles_50k.py`. `duration`
  должна делиться на `dt_out`, иначе конфиг не загрузится.

### Не трогать

- `oil_pvt.csv`, `gas_pvt.csv` — на их числах построен весь обратный расчёт
  (множитель 13125 и порог 5 МПа).

## Запуск

```powershell
cd numerical_solver
.venv\Scripts\python examples\04a_high_gas_saturation\main.py
.venv\Scripts\python examples\04a_high_gas_saturation\grid_convergence.py
.venv\Scripts\python examples\04a_high_gas_saturation\plot_profiles_50k.py
```

То же — командой пакета: `.venv\Scripts\python -m gpn_multiphase_solver run examples\04a_high_gas_saturation\config.json` (из `numerical_solver`; результаты — `examples\04a_high_gas_saturation\output\`; флаги `--output`, `--title`, `--profiles` — в [README папки examples](../README.md)).

| Файл | Назначение |
|---|---|
| `main.py` | запуск штатного расчёта (обёртка команды пакета), ~1 мин |
| `grid_convergence.py` | сходимость по сетке $N$ = 25…150, ~3 мин |
| `plot_profiles_50k.py` | профили на 0…50 000 с по готовому `output/profiles.csv`, секунды |
| `config.json`, `oil_pvt.csv`, `gas_pvt.csv` | конфигурация и PVT-таблицы |

Выход — в `output/`: `profiles.csv` (~11 МБ), `well_history.csv` и графики
из предыдущего раздела.

Аналитика $p$, $S_g$, $R_s$ и баланс энергии — в пакете ([diagnostics/](../../gpn_multiphase_solver/diagnostics/),
ряды баланса — [energy/balance.py](../../gpn_multiphase_solver/energy/balance.py)); печать
и рисунки — модули пакета [report/](../../gpn_multiphase_solver/report/), их подключает `run_case`.
