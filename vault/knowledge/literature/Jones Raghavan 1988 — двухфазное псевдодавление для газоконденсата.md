# Jones Raghavan 1988 — двухфазное псевдодавление для газоконденсата

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Jones J.R., Raghavan R. Interpretation of Flowing Well Response in Gas-Condensate Wells. *SPE Formation Evaluation*, 1988, 3(3), 578–594.

## Аннотация
Введена двухфазная функция псевдодавления (reservoir integral function), учитывающая ОФП обеих фаз: $m(p) = 2\int(\rho_o k_{ro}/\mu_o + \rho_g k_{rg}/\mu_g)\,dp$. Показано, что при использовании этой функции и знании профиля насыщенности достигается отличное совпадение с «жидкостным» решением. Steady-state приближение позволяет вычислить $m(p)$ без знания нестационарных профилей. Двухзонная модель флюида (O'Dell, Miller 1966): однофазная зона вдали от скважины + двухфазная вблизи.

## Потенциал для проекта
Методологически ключевая работа для PTA при двухфазном потоке. Двухфазная $m(p)$ — прямой аналог многофазного псевдодавления [[Краснов — многофазное псевдодавление и функции источника]]. Steady-state assumption для $S(r)$ — потенциально применимо к зоне разгазирования в ПЗП.
