# Обзор статьи для vault

Пользователь указал файл: `$ARGUMENTS`

## Инструкции

### 1. Найди и прочитай PDF

- Файл находится в `Refs/` или `Refs/GORM/`. Если `$ARGUMENTS` не содержит путь, ищи там.
- Если файл не найден — Glob `Refs/*` и `Refs/GORM/*`, предложи совпадения.
- Прочитай страницы 1–5 (abstract, introduction) и последние 2–3 страницы (conclusions, references). Если для секций «Метод» или «Результаты» нужны детали — дочитай средние секции.
- Если PDF нечитаем (скан без OCR, повреждённый файл) — сообщи пользователю, не угадывай.
- DJVU-файлы нечитаемы — сообщи пользователю.

### 2. Проверь дубли

Перед созданием заметки проверь `vault/knowledge/literature/` — нет ли заметки на эту же работу (по автору и году в имени файла или в frontmatter).

**Расширенная заметка уже есть:**
- Сообщи: «Расширенная заметка уже есть: `<имя файла>`».
- Предложи: (а) обновить/дополнить, (б) пропустить.
- Не создавай дубль.

**Краткая заметка уже есть** (`status: краткая (из контекста)`):
- Это нормальный сценарий — повышение из краткой в расширенную.
- Перезапиши файл расширенной версией, сохранив имя файла.
- Обнови `status: расширенная` в frontmatter.
- Удали warning-плашку `> [!warning]`.
- Перенеси запись из `cited-references.md` в `index-literature.md` (тематическую таблицу + «Расширенные обзоры»).
- Сохрани существующие перекрёстные ссылки из краткой заметки.

### 3. Собери контекст проекта

Перед написанием заметки сверься с релевантными заметками `vault/knowledge/science/`. Карта:

```
- Псевдодавление, линеаризация   → vault/knowledge/science/интегральная нормировка нелинейных коэффициентов.md
- Двухфазная фильтрация          → method_of_moments/two_phase_energy.tex (система PDE)
- Метод моментов Баренблатта     → method_of_moments/moments_method.tex
- Модели охлаждения ПЗП (М.1–М.6) → simplefied_approaches/cooling_models.tex
- Модель GORM                    → Refs/GORM/, simplefied_approaches/cooling_models.tex
- PVT-свойства Black Oil         → CLAUDE.md (нотация), method_of_moments/two_phase_energy.tex
- Температурные эффекты           → CLAUDE.md (нотация: JT, дегазация, энтальпия)
- Расширенные обзоры литературы   → vault/knowledge/literature/index-literature.md
```

Ключевые ориентиры проекта:
- Двухфазная фильтрация (нефть + свободный газ) в рамках Black Oil
- Температура из уравнения энергии: JT, дегазация, теплопроводность
- Призабойная зона пласта (ПЗП), радиальная геометрия
- Полуаналитический подход — метод моментов Баренблатта (PDE → ODE)
- Стадия проекта: подбор схематизации, сравнение вариантов постановки

Читай только релевантные заметки, не все подряд.

### 4. Создай заметку

Тип обзора — всегда **расширенный**.

Имя файла: `vault/knowledge/literature/Автор Год — краткая тема.md`

Правило для фамилии: иностранный автор — латиницей, русскоязычный — кириллицей.

Формат:

```markdown
---
author: "Фамилия И.О., Фамилия И.О."
year: ГГГГ
journal: "Название журнала/конференции"
volume: (если есть)
pages: (если есть)
doi: (если есть)
tags: [literature, тематические-теги]
date: ГГГГ-ММ-ДД
status: расширенная
---

# Автор Год — краткая тема

**Полная ссылка.** Авторы. Название. *Журнал*, год, том, страницы.

## Задача
Постановка задачи, уравнения.

## Метод
Подход, алгоритм, ключевые формулы — номера уравнений, таблиц, рисунков.

## Результаты
Численные примеры, точность, ограничения.

## Замечания
Критический анализ: ограничения, тонкости, подводные камни.
НЕ пересказ абстракта.

## Значение для проекта
Связь с моделью ПЗП. Wiki-ссылки на science-заметки и Draft-документы.
Что можно взять, что неприменимо, какие вопросы открывает.
Обратить внимание: применимость к двухфазной системе нефть+газ, радиальная геометрия, температурные эффекты.

## Цитируется в
- (wiki-ссылки)

## Ссылается на
- (wiki-ссылки)
```

### 5. Установи перекрёстные ссылки

Проверь **три источника** заметок:
1. `vault/knowledge/literature/` — основная папка.
2. `vault/` (корень) — legacy-заметки `ref_*.md` (если остались).
3. LaTeX-документы (`simplefied_approaches/`, `method_of_moments/`, `method_of_moments_isotermal/`, `GORM_2/`) — Grep по `\cite{автор_год}`, чтобы найти, какие документы ссылаются на разбираемую работу.

Действия:
- **«Ссылается на»** новой заметки: добавь wiki-ссылки на все заметки vault, соответствующие цитируемым работам.
- **«Цитируется в»** существующих заметок: найди заметки, чьи работы цитируются в новой статье, и обнови их секцию «Цитируется в».
- **Обратная ссылка**: найди заметки, которые ссылаются на ту же работу (общие цитируемые источники) — добавь wiki-ссылки, если тематически связаны.

**Экономия:** один Edit на файл, не по одному на каждую ссылку.

### 6. Создай краткие заметки для цитируемых работ

Просмотри **весь** список литературы статьи. Для каждой ссылки определи категорию:

| Категория | Критерий |
|---|---|
| **A — методологическая** | Цитируется ≥2-3 раз, используется для вывода формул, верификации, дискретизации. Или мотивирует исследование во введении |
| **B — прикладная** | Описывает конкретную задачу двухфазной фильтрации, призабойной зоны, конусообразования, температурных эффектов; источники промысловых/экспериментальных данных для верификации модели ПЗП; промышленный контекст (задачи, в которых существующие модели дают сбой) |
| **C — обзорная/справочная** | Обзоры, систематизирующие область (многофазная фильтрация, тепломассоперенос в пластах). Монографии, справочники |

Не создавай заметки для:
- PVT-корреляций и чисто эмпирических формул (вязкость, Z-фактор), если они не содержат постановок задач
- Работ, о которых из контекста цитирования невозможно сказать ничего содержательного (только фамилия в скобках без обсуждения)

Для каждой отобранной работы, **если заметки ещё нет** — создай краткую заметку.

Проверка существования: Grep по фамилии первого автора в `vault/knowledge/literature/` (по именам файлов). Это дешевле, чем Glob + чтение каждого файла. Если заметка (краткая или расширенная) уже есть — пропусти, но обнови секцию «Цитируется в», добавив ссылку на текущую статью.

Формат краткой заметки:

```markdown
---
author: "Полное имя авторов"
year: ГГГГ
journal: "Название журнала (если известно)"
tags: [literature, тематические-теги]
date: ГГГГ-ММ-ДД
status: краткая (из контекста)
source: контекст цитирования
---

# Автор Год — краткая тема

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Полное название. *Журнал*, год.

## Аннотация
2–3 предложения строго из контекста цитирования. Не домысливать.

## Потенциал для проекта
(Для категорий B и C.)

## Цитируется в
- [[статья, из обзора которой создана заметка]]

## Ссылается на
```

Добавь запись в `vault/knowledge/literature/cited-references.md` (алфавитный порядок, без дублей).

### 7. Обнови индекс литературы

Файл: `vault/knowledge/literature/index-literature.md`

- Добавь строку в тематическую таблицу (или создай новую секцию).
- Расширенный обзор — добавь в «Расширенные обзоры».
- Краткие заметки из шага 6 в основной индекс **не добавлять** — они в `cited-references.md`.

### 8. Стиль

- Язык: русский.
- Критический анализ, не пересказ абстракта.
- Конкретные формулы, номера уравнений, таблиц, рисунков из статьи.
- Расхождения в нотации с проектом (см. CLAUDE.md, секция «Обозначения и нотация») — отметить.
- Не хвалить — указывать на ограничения.
- Связь с моделями М.1–М.6 из simplefied_approaches/cooling_models.tex — указывать, если релевантно.
