# Ben-Omran Green 1978 — композиционная модель с методом подвижных точек

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Ben-Omran A.M., Green D.W.** A two-dimensional, two-phase compositional model which uses a moving point method. Paper SPE 7415, SPE Annual Fall Technical Conference and Exhibition, Houston, 1–3 October 1978.

## Аннотация
Категория A. В классификации [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] — пример подхода с неравновесным источником. Источник входит во все уравнения и приводит систему к равновесию, поэтому переключение переменных не нужно. Недостатки, по Salimi et al.: балансы компонентов записываются по каждой фазе (число уравнений почти удваивается), а источник, как правило, сильно нелинеен. Как именно метод подвижных точек из названия связан с источником, из контекста цитирования неясно.
