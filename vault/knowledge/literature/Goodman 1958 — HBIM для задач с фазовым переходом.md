# Goodman 1958 — HBIM для задач с фазовым переходом

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Goodman T.R.** The heat-balance integral and its application to problems involving a change of phase. *Trans. ASME*, 1958, Vol. 80, pp. 335–342.

## Аннотация
Основополагающая работа по методу теплового баланса (HBIM). Goodman адаптировал интегральный метод Кармана–Польгаузена [37] из теории пограничного слоя для задач теплопроводности с фазовым переходом (задача Стефана). Предложена квадратичная параметризация профиля температуры $u = a(s-x) + b(s-x)^2$, интегрирование PDE по $x$ от 0 до $s(t)$ сводит задачу к ODE для положения фронта $s(t)$. Квадратичная аппроксимация — исторический стандарт, но Mitchell & Myers [2010] показали, что кубическая точнее на порядок.

## Потенциал для проекта
Прямой методологический прототип для метода моментов в проекте ПЗП. Параметризация $u \sim (1-x/s)^n$ структурно идентична $S_g \sim (1-\eta)^\beta$ и $\Phi(\eta)$ из moments_method.tex. Ограничение: Goodman работал с линейным PDE, в задаче ПЗП коэффициенты нелинейны.
