# Goodman 1964 — интегральные методы для нелинейного теплопереноса

**Полная ссылка.** Goodman T.R. Application of integral methods to transient nonlinear heat transfer. *Advances in Heat Transfer*, 1964, Vol. 1, pp. 51–122. Academic Press.

## Задача

Обзорная глава (72 стр.), систематизирующая применение интегральных методов к задачам нестационарной теплопроводности с нелинейностями. Рассматриваются:
- линейное PDE с нелинейными ГУ (§II);
- PDE с температурно-зависимыми $k(T)$, $\rho c(T)$ (§III);
- фазовый переход — задача Стефана (§IV);
- импульсные тепловые нагрузки (§VI);
- конвективный перенос (§VIII);
- двумерная задача Стефана (§IX).

Базовое уравнение (ур. 1): $\alpha \partial^2 T/\partial x^2 = \partial T/\partial t$. Для температурно-зависимых свойств (ур. 76): $\rho c\,\partial T/\partial t = \partial/\partial x(k\,\partial T/\partial x)$.

## Метод

### Базовый HBIM (§I–II)

Глубина проникновения $\delta(t)$: за $x > \delta$ температура не изменилась. Интегрирование PDE от $x=0$ до $\delta$ даёт heat-balance integral (ур. 3):
$$\frac{d}{dt}(\theta + T_\infty \delta) = \alpha\left[\frac{\partial T}{\partial x}(\delta,t) - \frac{\partial T}{\partial x}(0,t)\right], \quad \theta = \int_0^{\delta} T\,dx.$$

Профиль — квадратичный (ур. 7): $T = (F/2k\delta)(\delta - x)^2$, или кубический (ур. 19): $T = (z/\delta^3)(\delta - x)^3$. Кубический снижает ошибку с 9% до 2% (сравнение ур. 13 и 14).

Условие сглаживания (smoothing condition, ур. 18): $\partial^2 T/\partial x^2|_{x=\delta} = 0$ — дополнительное ограничение на кубический профиль. Это аналог условия $\Phi''(1) = 0$ в moments_method.tex.

### Температурно-зависимые свойства (§III) — ключевая секция

Замена переменной Кирхгофа (ур. 77): $v = \int_0^T \rho c\,dT$. Уравнение принимает вид (ур. 78):
$$\frac{\partial v}{\partial t} = \frac{\partial}{\partial x}\left(\alpha(v)\frac{\partial v}{\partial x}\right),$$
где $\alpha(v) = k/(\rho c)$ — нелинейная диффузивность, зависящая от $v$ (и, значит, от $T$).

Кубический профиль в переменных $v$ (ур. 81a): $v = v_s(1-x/\delta)^3$. Heat-balance integral (ур. 82a–b):
$$\frac{d\theta}{dt} = 3\alpha_s v_s/\delta, \quad \frac{d\theta}{dt} = F.$$
Решение (ур. 85a–b): $\delta = (2\sqrt{6}/v_s)\left[\int_0^t \alpha_s v_s^2\,dt\right]^{1/2}$. **В решении участвует только $\alpha_s$ — диффузивность на поверхности**, а не усреднённая по толщине.

Для линейной зависимости $k = k_0(1+\alpha T/T_s)$: точное решение Янга (22) сравнивается с HBIM (ур. 89, Fig. 2). При $\alpha = \pm 0.5$ — различие неразличимо на графике.

**Полярная и сферическая симметрия (§III.B).** Lardner & Pohle (18) показали, что полиномиальный профиль неприменим в радиальной геометрии — решение не стремится к стационарному при $t \to \infty$. Необходим профиль вида (ур. 59): $T = \text{(полином от } \ln r\text{)}$. Аналогично для сферы: $T = \text{(полином от } r\text{)/}r$ (ур. 60).

### Фазовый переход (§IV)

Условие Стефана (ур. 92): $k_2\,\partial T_2/\partial x - k_1\,\partial T_1/\partial x = \pm \rho_2 L\,ds/dt$ при $x = s(t)$.

Плавление со ступенькой температуры (§IV.A): квадратичный профиль в одной фазе → ODE для $s(t)$, ур. 102: $s\,ds/dt = 6\alpha[1-(1+\mu)^{1/2}+\mu]/[5+\mu+(1+\mu)^{1/2}]$, где $\mu = 2T_s/(A_1\alpha) = 2T_s \rho c/(k \cdot \rho L/k) = 2\text{St}^{-1}$. Решение $s = K\sqrt{t}$ (ур. 103). Ошибка ≤ 7% для $\mu \leq 2.8$.

Абляция (§IV.C): граница и линия плавления совпадают, $F + k\,\partial T/\partial x = \rho L\,ds/dt$ (ур. 111). Система двух ODE для $s(t)$ и $\delta(t) - s(t)$ (ур. 115, 117). Точность сопоставима с точным решением Ландау (27).

### Связанные методы (§V)

**Метод Био (§V.A):** вариационный подход через лагранжиан теплового баланса (ур. 130–131): $\partial E/\partial q_i + \partial D/\partial \dot{q}_i = Q_i$. Обобщённые координаты — $\delta$ и $z$ (температура поверхности). Результаты идентичны HBIM с точностью до процентов (Table I).

**Метод Швеца (§V.B):** итерационное уточнение — последовательное решение $\alpha\,\partial^2 T_k/\partial x^2 = \partial T_{k-1}/\partial t$ (ур. 143–144). Нулевое приближение $T_0 = (1-x/\delta)$ → первое $T_1$ с проникновением $\delta = 2.45\sqrt{\alpha t}$ (ур. 149). Точное: $\delta = 2.45\sqrt{\alpha t}$ при замене $0.61 \to 0.564$ (ур. 150 vs точное). Метод «awkward», по оценке Goodman.

### Улучшение точности (§VII) — методологическое ядро

**Метод взвешенных невязок (§VII.A).** Уравнение $L(T) = 0$ умножается на весовую функцию $w_j$ и интегрируется (ур. 194): $\int w_j L(T_n)\,dv = 0$. Три варианта:
- $w_j = \Delta(x - x_j)$ → **коллокация** (PDE удовлетворяется в точках $x_j$);
- $w_j = \partial T_n/\partial C_{n,j}$ → **Галёркин**;
- $w_j = x^j$ или $T_n^j$ → **метод моментов**.

**Метод моментов (§VII.A.2).** Для нелинейного PDE с температурно-зависимыми свойствами (ур. 78) при $w_j = x^j$ (ур. 205):
$$\int_a^b x^j L(T_n)\,dx = 0, \quad j = 0, 1, 2, \ldots, n.$$
Fujita (47, Yamada 48) применил метод к уравнению с $k = k(T)$ при линейной зависимости. Для первого интервала (пока $\delta < b$) используется глубина проникновения, и HBIM — частный случай $j = 0$ (ур. 205 при $j = 0$). Первый момент $j = 1$ (ур. 206):
$$\frac{d}{dt}\int_0^\delta xv\,dx = -\int_0^\delta \alpha\,\frac{\partial v}{\partial x}\,dx.$$
Это даёт **два параметра** из двух уравнений (нулевой + первый момент). Goodman отмечает, что вариация $\alpha(v)$ теперь входит **по всей толщине** пласта, а не только на поверхности — существенное отличие от базового HBIM.

**Альтернатива — весовая функция по зависимой переменной** (ур. 208): $w_j = v^j$. Преимущество: области с большим отклонением $T$ от равновесия взвешиваются сильнее.

**Метод Янга (§VII.B).** Итерационное улучшение: базовое решение (HBIM) подставляется обратно в PDE → решается ODE для улучшенного профиля (ур. 224–227). Критерий ошибки $J$ (ур. 229) позволяет контролировать сходимость. Table III: для $k = k_0(1+\alpha T)$ критерий $J$ падает на 4 порядка за 1 итерацию при автомодельной задаче. Для неавтомодельных — итерации дороги.

**Метод Дородницына (§VII.C).** Разбиение области на полосы, HBIM применяется к каждой полосе отдельно (ур. 57). Сшивка — непрерывность температуры и потока на границах полос. При $N$ полосах — $N$ собственных функций. Аналог метода конечных элементов, но с интегральным балансом вместо слабой формулировки.

## Замечания

1. **Преобразование Кирхгофа $v = \int \rho c\,dT$ — ключевой приём.** Для температурно-зависимых свойств (§III) оно превращает PDE с переменными $k(T)$, $\rho c(T)$ в уравнение с **одной** нелинейной функцией $\alpha(v)$. Это прямой аналог псевдодавления $m(p)$ в фильтрации (Al-Hussainy 1966): оба поглощают зависимость коэффициентов от решения через интегральную замену переменной.

2. **Профиль в полярной/сферической геометрии.** Lardner & Pohle (18): полиномиальный профиль некорректен в радиальной геометрии. Нужен $T \sim \text{полином}(\ln r)$ (ур. 59) или $T \sim \text{полином}(r)/r$ (ур. 60). В проекте ПЗП используется $\Phi(\eta)$ с $\eta = \ln(r/r_w)/\ln(r_b/r_w)$ (§4.2 moments_method.tex), что согласуется с этим результатом.

3. **Замораживание свойств — ограничение базового HBIM.** В базовом решении (ур. 85) фигурирует только $\alpha_s$ — диффузивность на поверхности. Первый момент (ур. 206) вводит $\alpha(v)$ по всей толщине. Аналогия с проектом: «замораживание PVT» при среднем давлении (moments_method.tex §8.3) — базовый уровень; первый момент учитывает вариацию PVT по зоне.

4. **Нет доказательства сходимости для нелинейных задач** (заключение, стр. 119). Goodman прямо признаёт: «In most cases, no convergence proof exists in the literature, and this is especially so for nonlinear cases.» Это остаётся верным и для задачи ПЗП.

5. **Импульсные нагрузки (§VI) — слабое место HBIM.** Когда граничный поток немонотонен, профиль $(1-x/\delta)^n$ не может воспроизвести немонотонный $T(x)$ → ложные решения. Goodman предлагает extended integral method: два проникновения $\delta_1$, $\delta_2$ с разными профилями $T_1$, $T_2$ (ур. 152–159). Аналогия: если в задаче ПЗП дебит немонотонен (shut-in), параметризация одним $\Phi(\eta)$ может быть недостаточной.

6. **2D задача Стефана (§IX).** Единственный пример двумерного применения. Фронт затвердевания параметризуется одним параметром $\epsilon(t)$ (ур. 268). Goodman замечает, что «the concept of penetration distance is not clear for more than one space variable» (стр. 119). Это ограничивает расширение метода на 2D фильтрацию.

## Значение для проекта

**Что взять:**

1. **Преобразование Кирхгофа для PVT-зависимых коэффициентов.** Замена $v = \int \rho c\,dT$ (ур. 77) структурно идентична псевдодавлению $m(p) = \int (k_{r}/\mu B)\,dp$. Вопрос из заметки [[интегральная нормировка нелинейных коэффициентов]]: можно ли построить совместную замену по $(p,T)$? Goodman показывает, что для одной переменной ($T$) замена работает отлично. Для двух ($p$ и $T$) — открытый вопрос.

2. **Первый момент учитывает вариацию коэффициентов по всей зоне** (ур. 206), а не только на границе. Это обосновывает подход moments_method.tex: использование первого момента для определения $\beta$ — не просто улучшение формы профиля, а способ учесть нелинейность PVT-свойств.

3. **Замечание Lardner & Pohle о полярной симметрии** — обоснование использования $\eta \sim \ln r$ (а не полиномов от $r$) в профиле давления проекта.

4. **Table I (§V.A):** сравнение HBIM, Biot, коллокации, Галёркина — все дают ошибки одного порядка (1–9%). Выбор метода менее критичен, чем выбор профиля.

5. **Extended integral method (§VI):** при немонотонных нагрузках нужен составной профиль с двумя глубинами проникновения. Аналогия: двухзонная параметризация в moments_method.tex (зона разгазирования + однофазная зона) — правильная стратегия.

**Что неприменимо:**
- Все задачи Goodman — **одно уравнение** (теплопроводность). В проекте ПЗП — три связанных PDE. Взаимодействие между уравнениями (через PVT-свойства) — принципиальное усложнение, которого у Goodman нет.
- Goodman работает с $\rho c(T)$, $k(T)$ — скалярные функции одной переменной. В задаче ПЗП коэффициенты зависят от нескольких полей ($p$, $T$, $S_g$) — замена Кирхгофа напрямую не обобщается.

**Связь с моделями М.1–М.6:** §IV (фазовый переход) — прямая аналогия с М.4 (нестационарный энтальпийный баланс с подвижной границей разгазирования).
