## 1. Суть бага

Однофазная JT-асимптотика — предел уравнения энергии при $\lambda = 0$ в однофазной зоне: $dT = \mu_{JT,o}\,dp$ вдоль потока (изоэнтальпийное дросселирование). Нефть входит в область через контур $r = R_e$, где граничное условие задаёт $T = T_0$ **при $p = p_0$** (`factory.py:330`: `p_ext=ic.p0`). Поэтому верная асимптотика:

$$T(r) = T_0 + \mu_{JT,o}\,\bigl[p(r) - p_0\bigr].$$

Общий модуль `examples/temperature_asymptotics.py:88` вместо этого отсчитывает от давления в центре последней ячейки:

```python
return config.initial_conditions.T0 + config.thermal.mu_JT_oil * (p - p[-1])
```

то есть ставит $T_0$ в центр ячейки $N-1$ и теряет JT-охлаждение на полуячейке между контуром и этим центром. Сдвиг постоянен по всей однофазной зоне и равен $\mu_{JT,o}(p_0 - p_{N-1})$; он убывает как $1/N$.

### Почему схема отсчитывает от $p_0$

`TridiagEnergySolver.compute_jt` (`numerical_solver/gpn_multiphase_solver/energy/tridiag.py:329-399`) собирает JT-вклад из перепадов давления на гранях. Для контурной грани «давление за гранью» — из ГУ:

```python
p_right = np.concatenate((p, [ext['p']]))   # строка 358
dp_right = p_right[1:N + 1] - p             # строка 392
```

У ячейки $N-1$ в `dp_right` стоит $p_{ext} - p_{N-1}$ с $\mu_{JT}$ контура (строки 379-382, DEBT-017). Значит, в стационаре $T_{N-1} = T_0 - \mu_{JT,o}(p_0 - p_{N-1})$.

Предположительно отсчёт от `p[-1]` был верен до DEBT-017 (#34): тогда множитель $p$ в JT-потоке контурной грани был `p[-1]` (план DEBT-017, строки 88-89 и 528-538). Модуль асимптотики и пример 02 за правкой не последовали.

## 3. Воспроизведение

Существующий тест `test_02_relaxes_toward_jt_asymptote` баг **маскирует**: исключает приконтурную ячейку (`T[:-1]`) с объяснением «лежит на ~0.01 К ниже из-за адиабатического импульса». Замер по выводу 02 (3 суток, $N = 150$):

| | min$(T - T_{as})$ по всем ячейкам | без приконтурной |
|---|---|---|
| текущая формула (`p[-1]`) | $-0.0044$ К — **ниже асимптоты** | $+0.00034$ К |
| верная формула ($p_0$) | $+0.00227$ К | — |

То есть с верной формулой температура подходит к асимптоте сверху **во всех** ячейках, и исключение не нужно. Приконтурная ячейка за 3 суток охладилась на 0.0044 К (адиабатический импульс первого шага, оценка $\phi(1+\rho c_p\mu_{JT})\Delta p/(\rho c)_{\text{eff}} \approx 0.004$ К), но её стационар — $T_0 - 0.0067$ К, а не $T_0$.

Тест-воспроизводитель — переписанный `test_02_relaxes_toward_jt_asymptote` (шаг 1): на текущем коде падает на ячейке $N-1$.

## 4. Варианты решения

**Вариант 1 — отсчёт от $p_0$ из конфига (выбран).**
- `temperature_asymptotics.py:88`: `p - p[-1]` → `p - config.initial_conditions.p0`.
- Плюсы: одна строка; сигнатура прежняя, вызывающий код не меняется. Источник значения тот же, из которого фабрика строит ГУ (`factory.py:330`: `p_ext=ic.p0`), так что совпадение точное, а не приближённое.
- Минусы: связь «$p_{ext} = p_0$ конфига» неявная. Если когда-нибудь ГУ по давлению отделят от начального давления, модуль разойдётся со схемой молча — оговорить в докстринге со ссылкой на `factory.py:330`.

**Вариант 2 — отсчёт от `bc.p_ext` симулятора.**
- Передавать давление контура из объекта ГУ, по которому считает схема.
- Плюсы: единый источник со схемой (урок BUG-004: диагностика обязана считать так же, как ядро).
- Минусы: `single_phase_asymptote(config, history)` не получает ни `simulator`, ни `bc`; в `03/main.py` и `05/main.py` overlay получает `simulator`, но `bc` в нём не хранится (собирается фабрикой на интервал). Пришлось бы менять сигнатуру и три вызова ради значения, которое сейчас тождественно `config.initial_conditions.p0`.

**Вариант 3 — только документация** (оставить `p[-1]`, объяснить сдвиг). Отвергается: печатаемое число остаётся смещённым, а тест продолжает исключать ячейку.

**Выбор:** вариант 1 + устранение двух копий формулы (02 и тест вызывают общий модуль) + регрессионные тесты.

```python
    """Пример 02 идёт к аналитической JT-асимптотике T = T_ext + mu_JT·(p - p_0).

    При lambda = 0 стационарный энергобаланс rho·cp·u·dT/dr = rho·cp·mu_JT·u·dp/dr
    даёт dT/dr = mu_JT·dp/dr — скорость сокращается, профиль не зависит
    от дебита. Опорная точка — контур r = R_e: ГУ задаёт там T_ext при
    p = p_0 (factory.py). Нефть охлаждается уже на полуячейке между контуром
    и центром последней ячейки (compute_jt, перепад p_ext - p[N-1]), поэтому
    асимптота в ячейке N-1 равна T_ext - mu_JT·(p_0 - p[N-1]), а не T_ext
    (BUG-013).

    За 3 суток релаксация не завершается, поэтому проверяем не совпадение,
    а движение в нужную сторону: температура на забое монотонно падает
    и остаётся выше асимптотики (подходит сверху, не проскакивает).
    """
    res = results["02_single_phase_jt"]
    ta = _asymptotics_module()
    T_ext = res["config"].initial_conditions.T0

    T = res["T"]
    T_asymp = ta.single_phase_asymptote(res["config"], res["history"])

    # Подход сверху: JT только охлаждает, ниже асимптотики уйти не может.
    # Проверяются ВСЕ ячейки, включая приконтурную. За 3 суток она остыла
    # на ~0.0044 К (адиабатический импульс 1-го шага), но её асимптота ниже
    # T_ext на mu_JT·(p_0 - p[N-1]) ≈ 0.0067 К — запас ~0.002 К. Прежний
    # отсчёт от p[N-1] ставил асимптоту этой ячейки в T_ext, ячейку
    # приходилось исключать, и сдвиг асимптоты оставался незамеченным.
    assert np.all(T >= T_asymp - 1e-9), \
        "температура проскочила ниже JT-асимптотики"

    # Но уже прошла заметную часть пути: у забоя полный размах ~2 К,
    # за 3 суток остаётся отставание меньше половины.
    gap_well = T[0] - T_asymp[0]
    full_swing = T_ext - T_asymp[0]
    assert 0.0 < gap_well < 0.5 * full_swing, \
        f"отставание у забоя {gap_well:.3f} К вне ожидаемого диапазона"

    # (блок «Динамика» — без изменений)


def test_single_phase_asymptote_reference_is_contour(results):
    """Однофазная асимптотика отсчитывается от давления на контуре p_0 (BUG-013).

    ГУ задаёт T_ext при p = p_0 на контуре, а не в центре последней ячейки,
    поэтому асимптота в ячейке N-1 ниже T_ext на mu_JT·(p_0 - p[N-1]).
    Прежняя формула отсчитывала от p[N-1] и сдвигала асимптоту примера 02
    на ~0.0067 К по всей однофазной зоне.
    """
    res = results["02_single_phase_jt"]
    ta = _asymptotics_module()
    cfg = res["config"]
    T0 = cfg.initial_conditions.T0
    p0 = cfg.initial_conditions.p0
    mu = cfg.thermal.mu_JT_oil
    p = res["p"]

    T_as = ta.single_phase_asymptote(cfg, res["history"])

    # Та же формула, записанная независимо: отсчёт от p_0 на всей сетке.
    assert np.allclose(T_as, T0 + mu * (p - p0), rtol=0.0, atol=1e-12)

    # Приконтурная ячейка не опорная: её асимптота ниже T0 ровно на JT-перепад
    # полуячейки. Допуск абсолютный: T0 - T_as[-1] ~ 7e-3 К — разность
    # чисел ~350 К, её относительная ошибка округления ~1.5e-12, и rel=1e-12
    # давал бы ложное падение.
    assert T0 - T_as[-1] == pytest.approx(mu * (p0 - p[-1]), abs=1e-12)
    assert T0 - T_as[-1] > 0.0
```
