# Создание задачи в vault

Пользователь описал задачу: `$ARGUMENTS`

## Инструкции

### 1. Определи тип

| Тип | Метка | Файл roadmap |
|---|---|---|
| Баг | BUG-NNN | `vault/roadmap/известные баги и технический долг.md` |
| Технический долг | DEBT-NNN | `vault/roadmap/известные баги и технический долг.md` |
| Фича | FEAT-NNN | `vault/roadmap/планируемые фичи.md` |
| Валидационный кейс | VAL-NNN | `vault/roadmap/валидационные кейсы.md` |

### 2. Прочитай соответствующий roadmap-файл

Определи текущую нумерацию. Новый номер = max + 1.

### 3. Для BUG — исследуй

- Grep по симптому в `method_of_moments/src/`.
- Определи файл, строку, вероятную причину.
- Если есть тест, воспроизводящий баг — укажи.

### 4. Для FEAT — свяжи с формулами

- Определи, какие уравнения из `moments_method.tex` реализует фича.
- Укажи конкретные `\label{}` и номера уравнений.
- Определи модуль (`src/pvt/`, `src/profiles/`, `src/integrals.py`, ...).
- Перечисли необходимые тесты.

### 5. Для VAL — определи эталон

- Аналитическое решение (формула, ссылка на источник из `Refs/`).
- Или численный эталон (OPM Flow, конечные разности).
- Укажи tolerance и метрику сравнения.

### 6. Запиши в roadmap

Формат — по шаблону из соответствующего файла.

### 7. Подтверди

Выведи: тип, ID, одно предложение — суть задачи.
