# Upstream для подвижностей фаз, гармоническое среднее для гладких свойств

## Утверждение

При дискретизации потоков компонентов в уравнениях Black Oil подвижности фаз $k_{r\alpha}/(\mu_\alpha B_\alpha)$ на грани ячейки берутся из **upstream**-ячейки (откуда течёт фаза), а не как среднее по соседним ячейкам.

Гармоническое среднее (с логарифмическими весами для радиальной сетки) используется для **гладких скалярных** свойств: абсолютной проницаемости $k$, теплопроводности $\lambda_{\rm eff}$.

## Обоснование

Поток нефтяного компонента через грань:

$$G_{j+1/2}^o = \mathcal{T}_{j+1/2} \cdot \frac{k_{ro}}{\mu_o B_o}\bigg|_{j+1/2} \cdot (p_{j+1} - p_j)$$

Здесь $\mathcal{T}_{j+1/2} \cdot (p_{j+1} - p_j)$ — дискретный аналог $-k\nabla p$ (диффузионная/геометрическая часть). Множитель $k_{ro}/(\mu_o B_o)$ — подвижность фазы, зависящая от **насыщенности** $S_g$ через ОФП $k_{r\alpha}(S_g)$.

Насыщенность — гиперболическая переменная (переносится конвекцией, может иметь разрывы на фронте дегазации). Уравнения Black Oil — параболические с сильным конвективным характером. Если взять подвижность как среднее по соседним ячейкам (центральные разности), схема теряет монотонность: на фронте $S_g$ появляются осцилляции.

Upstream-взвешивание — аналог схемы против потока для конвективной части:
- **монотонность** (нет осцилляций на фронтах),
- **безусловная устойчивость** неявной схемы,
- ценой **первого порядка** точности по пространству.

## Когда что применять

| Величина на грани | Метод интерполяции | Причина |
|---|---|---|
| $k_{r\alpha}/(\mu_\alpha B_\alpha)$ — подвижность фазы | **Upstream** | Зависит от $S_g$ (гиперболическая переменная, возможны разрывы) |
| $k$ — абсолютная проницаемость | **Гармоническое среднее** (или не нужна, если $k$ = const) | Гладкое, не зависит от решения |
| $\lambda_{\rm eff}$ — теплопроводность | **Гармоническое среднее** с лог. весами | Гладкое, слабо зависит от $S_g$ |

## Стандарт отрасли

Upstream-взвешивание подвижностей — стандарт в коммерческих и открытых симуляторах пластов (ECLIPSE, OPM Flow, MRST/SINTEF). OPM Flow Reference Manual (2025-10), §1.2, формулы (1.16)–(1.20): upstream cell определяется по знаку потенциала $\Delta\Phi_{\alpha,ij}$.
