# Whitson Michelsen 1989 — отрицательный флэш-расчёт

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Whitson C.H., Michelsen M.L.** The negative flash. *Fluid Phase Equilibria*, 1989, 53, 51–71.

## Аннотация
Категория A. В [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] равновесные составы мнимых фаз в однофазной зоне (ур. 28, флэш при $P_c = 0$) отождествлены с отрицательным флэш-расчётом из этой работы. Отрицательный флэш — равновесный расчёт для физически однофазной системы с долями фаз вне $[0, 1]$. Это термодинамический аналог расширенной насыщенности, предложенный на 20 лет раньше метода отрицательных насыщенностей. Параллель отмечена в замечании 6 к [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]], но сама статья 2009 г. её не упоминает.
