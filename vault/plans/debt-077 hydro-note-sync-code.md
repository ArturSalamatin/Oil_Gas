# DEBT-077: заметка `модули-hydro-newton.md` — контракт по коду, действующий решатель (прототип), отменённая схема блочного Ньютона

## Кратко

- **Дефект.** `vault/knowledge/decisions/модули-hydro-newton.md` (308 строк, проектный этап 2026-08-25) описывает собственный гидродинамический решатель — блочный Ньютон на $3N$ неизвестных с блочной прогонкой, — которого в коде нет; пометки об этом нет. Устарел и «действующий» контракт в ней: в `HydroResult` нет `p_wf` и `int_G_*`, у `HydroSolver` — `component_inventories` и `HydroConvergenceError`; листинг тестовой заглушки зовёт удалённый в FEAT-020 `bc.well.boundary_pressure`. - **Что делается** (вариант 3 issue #126 + решения пользователя 2026-10-15, раздел 0):

3. **Порядок с DEBT-074 снят** — DEBT-074 влит `d74d2e8`: номера в заметке уже заменены метками, сторож `test_eq_references.py` проверяет и заметки `vault/knowledge/` без `literature/`.
