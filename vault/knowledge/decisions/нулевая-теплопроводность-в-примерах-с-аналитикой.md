# Теплопроводности обнуляются в примерах, где проверяется аналитика T

## Решение

В `config.json` примеров **01–09 и 04a**: `lambda_solid = lambda_oil = lambda_gas = 0`.
Ненулевые теплопроводности (1.5 / 0.14 / 0.04 Вт/(м·К)) — только в примерах
**10_deep_degassing** и **11_degassing_at_boundary**, где аналитика T не проверяется.

## Почему

Обе аналитические конструкции для температуры выведены **при λ = 0**:

1. **Телескопическая формула** (`examples/temperature_asymptotics.py`,
   `stationary_face_temperature`) суммирует конвективные и источниковые члены
   вдоль радиуса:

   ```
   T_f = [Φ_N T_ext - J_N + J_f - L ρ_g,ст (R_N - R_f)] / Φ_f
   ```

   Кондуктивный поток в это суммирование не входит. При λ ≠ 0 остаётся
   необъяснённая поправка.

2. **ОДУ-аналитика** — уравнение первого порядка. Теплопроводность добавила бы
   вторую производную и сделала задачу краевой.

При λ = 0 кондуктивная проводимость граней обращается в ноль тождественно,
и аналитика описывает ровно ту задачу, которую решает решатель.

## Что это даёт

Расхождение аналитики со схемой становится диагностическим: оно указывает
либо на ошибку сборки уравнения, либо на незавершённую релаксацию — но не
на отброшенную физику.

Проверено в примере 05 (`check_asymptotics_relaxation.py`): при выходе
на стационар расхождение падает до 7·10⁻¹¹ К и дальше не меняется.

| Длительность | max\|T_форм − T_числ\|, К |
|---|---|
| 3 сут | 3.9·10⁻¹ |
| 100 сут | 1.2·10⁻³ |
| 400 сут | 7.3·10⁻¹¹ |

В примере 03 те же асимптотики проверяются на длинном прогоне
(`check_asymptotics_long_run.py`, 600 суток): телескопическая формула
воспроизводит стационар схемы на всех гранях с точностью ~1e-12 К.

## Что теряется

Немного. В примере 03 вклад кондукции оценён прямо: контрольный прогон
с временной подстановкой физических теплопроводностей (`LAMBDA_PHYS`)
отличается на **тысячные доли К** против ~4 К полного эффекта охлаждения.
Физика ПЗП при добыче конвективная.

## Побочный эффект

При λ = 0 деление `w/λ` даёт `inf`, затем `2πh/inf = 0`. Результат корректен
(Q_T = 0, кондукции нет). Предупреждение `RuntimeWarning: divide by zero`
подавлено через `np.errstate(divide='ignore')` в
`compute_conductive_transmissibility` (`energy/tridiag.py`), с комментарием
о том, почему нулевая проводимость здесь — верный ответ.

## Следствие для верификации матрицы

Кондуктивный член $Q_T$ ненулевой только в 10 и 11 — значит поэлементная сверка
матрицы ([[матрица температурной задачи сверена с постановкой поэлементно]])
проверяет его только там же. Это не пробел покрытия: эталон считает по формуле
и при λ = 0 даёт тот же ноль, что и схема. Появится конфиг с теплопроводностью —
тот же тест отработает на нём без изменений.
