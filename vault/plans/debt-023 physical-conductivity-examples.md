## 1. Контекст

### 1.1. Что делает λ в схеме

Эффективная теплопроводность ячейки — `eq:lambda_eff` (`numerical_solver/doc/problem_statement.tex`):
$$\lambda_{\text{eff}} = (1-\phi)\lambda_s + \phi\,(S_o\lambda_o + S_g\lambda_g).$$
При $\phi = 0.2$, $S_g = 0$: $\lambda_{\text{eff}} = 0.8\cdot1.5 + 0.2\cdot0.14 = 1.228$ Вт/(м·К). Проводимость грани $\mathcal{Q}_T$ — последовательные сопротивления кольцевых слоёв (`eq:heat_cond_disc`, `eq:face_interp`). На забое — условие Неймана, кондуктивного потока в скважину нет (`ssec:bc_disc`); на контуре — Дирихле, $T = T_{ext} = T_0$ (`factory.py:634`). При λ = 0 все проводимости тождественно нулевые, уравнение энергии — первого порядка по $r$.

Кондуктивный член баланса энергии (`examples/energy_balance.py`, `cum_cond`) — суммарный поток через контур за расчёт: внутренние потоки при суммировании по объёму сокращаются. Знак суммы — направление **суммарного** потока: $> 0$ — тепло в сумме пришло через контур, $< 0$ — ушло.

### 1.2. Почему гидродинамика не меняется

Тепло в гидродинамику не возвращается:
- PVT Стендинга (03, 05) вычисляется при **постоянной** $T_0$: конструктор `StandingFullPVT(…, T0, …)` (`gpn_multiphase_solver/pvt/standing.py:34`, `self._T0` — строка 55, `self._T_F` — 61), фабрика передаёт `T0=ic.T0` (`factory.py:102-105`). README 03, п. 2а (абзац «Ограничение — изотермичность»): «PVT прототипа не зависит от $T$… обратной связи $T \to p$ в модели нет».
- Табличный PVT (04, 04a, 06–09) от $T$ не зависит. Это фиксирует `test_thermal_does_not_affect_hydro` (`tests/test_examples.py:340-356`, побитовое равенство 07/08/09).

Проба (раздел 2, часть A) подтвердила побитовое равенство $p$, $S_g$, $R_s$ по всем записям и $q_o$, $q_g$ по всем `well_data` во всех восьми примерах. Поэтому все гидродинамические числа README — дебиты, $S_g$, $R_s$, фронт, сверка с замкнутым решением, баланс массы — **не меняются**. Меняются только $T$ и члены баланса энергии.

### 1.3. Почему 01 и 02 остаются с λ = 0

Их пошаговая ОДУ-аналитика температуры выведена при λ = 0: теплопроводность добавляет вторую производную, и задача становится краевой (README 01, стр. 99; README 02, стр. 26–30 и раздел «Что даёт включение теплопроводности»). Кроме того, 01 и 02 держат ветку «λ = 0 → `cum_cond` ≡ 0» в `test_conduction_term_always_computed` (`tests/test_examples.py:719-754`). После задачи обе ветки теста по-прежнему покрыты: λ = 0 — 01, 02; λ ≠ 0 — 03–21.

### 1.4. Суперпозиция 04/07/08/09

`test_thermal_superposition` (`tests/test_examples.py:299-321`) требует $(T_{08} - T_{07}) + (T_{09} - T_{07}) = T_{04} - T_{07}$ с допуском $10^{-3}$ К. При замороженной гидродинамике уравнение энергии линейно по $T$. Коэффициенты зависят от $p$, $S_g$, $R_s$, а не от $T$; $\lambda_{\text{eff}}$ — от $S_g$. Значит, при **одинаковых** λ у четырёх примеров равенство точное. Замер на `ccc5ae3`: невязка 5.7·10⁻¹⁴ К при обоих наборах λ (на `6cf8515` при λ = 1.5 / 0.14 / 0.04 было ровно 0). Если у этих примеров λ разные, равенство сдвигается на 1–2 мК — на уровне допуска. Поэтому вариант «вернуть λ выборочно» отклонён (решение 1).

### 1.5. Однофазная асимптотика при λ ≠ 0

README 03 (стр. 16–19, п. 5, п. 7) обосновывал λ = 0 тем, что это «оставляет однофазную асимптотику $T = T_{ext} + \mu_{JT,o}(p - p_0)$ применимой». Довод слабый. В координате $\xi = \ln r$ кондуктивный поток через окружность равен $2\pi h\lambda_{\text{eff}}\,dT/d\xi$. В однофазной зоне $\lambda_{\text{eff}}$ постоянна, $p$ линейна по $\xi$ (Дюпюи; README 03, п. 4: отклонение $1.5\cdot10^{-8}$ Па). Асимптота линейна по $p$, значит и по $\xi$, поток на ней постоянен по радиусу и в баланс ячейки не входит. Отклонения дают нелинейность $p(\xi)$ при сжимаемой нефти (README 04: до 9.6 кПа, то есть $\mu_{JT}\cdot\Delta p \approx 4$ мК) и слой у фронта разгазирования толщиной по $\xi$ порядка $1/\text{Pe}$. Сводный README это уже утверждает: «От теплопроводности проверка не зависит и считается при любом $\lambda$» (раздел «Асимптотика температуры»). Замер: отставание от асимптоты за 3 сут меняется не больше чем на 3 мК (раздел 2).

Выход $T$ на стационар не проверяется и не обсуждается: длинные прогоны пользователь исключил (memory `feedback_no_temperature_steady_state`).

### 1.6. Число Пекле

$\text{Pe} = |\Phi_o|/(2\pi h\lambda_{\text{eff}})$, $2\pi h\lambda_{\text{eff}} = 2\pi\cdot10\cdot1.228 \approx 77$ Вт/К. README 03: $|\Phi_o| = 1.92\cdot10^4$ Вт/К, Pe ≈ 250; README 04: $1.03\cdot10^4$ Вт/К, Pe ≈ 130. Числа выводятся из конфига и не меняются — до задачи они описывали гипотетический случай, теперь описывают расчёт.

# Теплопроводности обнуляются только там, где проверяется аналитика T

## Решение

`lambda_solid = lambda_oil = lambda_gas = 0` — только в `config.json` примеров
**01** и **02**. Во всех остальных теплопроводности физические:
1.5 / 0.14 / 0.04 Вт/(м·К), у 17 и 19–21 — 2.5 / 0.13 / 0.05.

## Почему 01 и 02

Пошаговая ОДУ-аналитика температуры в 01 и 02 выведена при λ = 0:
теплопроводность добавила бы вторую производную и сделала задачу краевой.
При λ = 0 кондуктивная проводимость граней тождественно нулевая, и аналитика
описывает ровно ту задачу, которую решает решатель. Расхождение с ней
диагностично: ошибка сборки или незавершённая релаксация, а не отброшенная
физика.

## Пересмотр: 03–09 (DEBT-023)

До DEBT-023 нули стояли в 01–09 и 04a. Для двухфазных примеров обоснований
было два — телескопическая формула стационара (`stationary_face_temperature`)
и ОДУ-аналитика; обе удалены в DEBT-022, и нули остались без причины.
Нулевая теплопроводность физически невозможна, а кондуктивный член при нулях
проверялся только на 10–21.

Цена возврата — замер `vault/issues/debt-023/probes/plan_numbers.py`
(3 сут, λ = 1.5 / 0.14 / 0.04):
- гидродинамика побитово та же: PVT Стендинга считается при $T_0$,
  табличный от $T$ не зависит;
- $T(r_w)$ — от −2.3 до +1.0 мК; по области — до 5 мК, у 04a — до 0.022 К у забоя;
- суперпозиция 04/07/08/09 точная (невязка 6·10⁻¹⁴ К — машинный уровень):
  уравнение энергии линейно по $T$, λ у четырёх одинаковы;
- отставание от однофазной асимптотики меняется не больше чем на 3 мК.

Конвекция подавляет кондукцию: $\text{Pe} = |\Phi_o|/(2\pi h\lambda_{\text{eff}})$
≈ 130–250.

## Побочный эффект λ = 0

При λ = 0 деление `w/λ` даёт `inf`, затем `2πh/inf = 0`. Результат корректен
(Q_T = 0, кондукции нет). Предупреждение `RuntimeWarning: divide by zero`
подавлено через `np.errstate(divide='ignore')` в
`compute_conductive_transmissibility` (`energy/tridiag.py`), с комментарием
о том, почему нулевая проводимость здесь — верный ответ.

1. **Новых тестов нет.** Защиту от возврата нулей дают существующие тесты. `test_conduction_term_always_computed` требует $|E_{\text{конд}}| > 0$ при λ ≠ 0, у 03–09 — от $1.7\cdot10^{5}$ Дж. `test_matrix_matches_reference` впервые сверяет на 03–09 ненулевые проводимости граней. Тест «у 03–09 λ ≠ 0» был бы тестом на содержимое конфигов — пользователь такие отклонял (memory `feedback_examples_independent`).
