# Перенос команд проекта в навыки сохраняет их назначение

Перечень служит для сверки полноты переноса по [[перенос команд в навыки и сохранение контекста задач]]. Пользователь переносит команды последовательно. Состояние «сверка предстоит» означает, что в рамках этого плана контракт навыка ещё не сопоставлен с назначением команды. Это не проверка доступности навыка при вызове.

| Команда | Путь навыка | Сверка контракта |
|---|---|---|
| `draft` | `.agents/skills/draft/SKILL.md` | Доработка по общему плану |
| `issue` | `.agents/skills/issue/SKILL.md` | Доработка по общему плану |
| `plan-fix` | `.agents/skills/plan-fix/SKILL.md` | Сверка предстоит |
| `plan-improve` | `.agents/skills/plan-improve/SKILL.md` | Сверка предстоит |
| `plan-feature` | `.agents/skills/plan-feature/SKILL.md` | Сверка предстоит |
| `plan-validate` | `.agents/skills/plan-validate/SKILL.md` | Сверка предстоит |
| `audit-plan` | `.agents/skills/audit-plan/SKILL.md` | Сверка предстоит |
| `implement` | `.agents/skills/implement/SKILL.md` | Сверка предстоит |
| `merge` | `.agents/skills/merge/SKILL.md` | Сверка предстоит |
| `run` | `.agents/skills/run/SKILL.md` | Сверка предстоит |
| `review-paper` | `.agents/skills/review-paper/SKILL.md` | Сверка предстоит |
| `review-after` | `.agents/skills/review-after/SKILL.md` | Сверка предстоит |
| `review-book` | `.agents/skills/review-book/SKILL.md` | Сверка предстоит |
| `literature-synthesis` | `.agents/skills/literature-synthesis/SKILL.md` | Сверка предстоит |
| `card` | `.agents/skills/card/SKILL.md` | Сверка предстоит |

После сверки записывать дату, результат и фактический путь, если он отличается от указанного. Для `plan-*`, `implement` и `merge` отдельно проверять передачу черновика и порядок сохранения материалов по общему плану.
