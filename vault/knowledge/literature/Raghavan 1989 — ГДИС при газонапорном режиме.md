# Raghavan 1989 — ГДИС при газонапорном режиме

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Raghavan R.** Well Test Analysis: Wells Producing by Solution Gas Drive. *SPE Formation Evaluation*, 1989. SPE 5588.

## Аннотация
Методика интерпретации ГДИС для скважин, работающих при газонапорном режиме (solution gas drive). Используется функция псевдодавления с учётом двухфазного течения. В документе Краснова упоминается как подробный источник по использованию функций псевдодавления для этого режима. Также отдельно описан подход через использование материального баланса для вычисления функций псевдодавления.

## Потенциал для проекта
Режим solution gas drive — именно то, что моделируется в нашей задаче ПЗП (разгазирование при $p < p_b$). Методы Raghavan дают независимую верификацию давления и насыщенности.
