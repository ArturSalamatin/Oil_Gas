# Fevang Whitson 1996 — газоконденсат трёхзонная модель

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Fevang O., Whitson C.H. Modeling Gas-Condensate Well Deliverability. *SPE Reservoir Engineering*, 1996, 11(4), 221–230.

## Аннотация
Предложена трёхзонная модель газоконденсатного пласта: (1) внутренняя — двухфазный поток (газ + конденсат), (2) промежуточная — конденсат выпал, но неподвижен (только газ течёт), (3) внешняя — однофазный газ ($p > p_{dew}$). Эта концепция уточняет двухзонную модель O'Dell–Miller (1966). Используется для прогноза дебита скважины с учётом конденсатной банки.

## Потенциал для проекта
Трёхзонная структура — аналог ситуации с разгазированием нефти в ПЗП: (1) зона двухфазного потока (нефть + свободный газ), (2) зона с неподвижным газом ($S_g < S_{gc}$), (3) недонасыщенная нефть ($p > p_b$). Модель Fevang–Whitson может быть адаптирована для оценки продуктивности скважин с разгазированием.
