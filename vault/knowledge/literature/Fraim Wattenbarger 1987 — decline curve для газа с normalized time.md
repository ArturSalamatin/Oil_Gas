# Fraim Wattenbarger 1987 — decline curve для газа с normalized time

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Fraim M.L., Wattenbarger R.A.** Gas Reservoir Decline-Curve Analysis Using Type Curves with Real Gas Pseudopressure and Normalized Time. *SPE Formation Evaluation*, December 1987.

## Аннотация
Расширение метода type curve decline analysis на газовые пласты путём введения normalized time — нормировки на переменные свойства газа ($\mu c_t$). Позволяет использовать жидкостные type curves для анализа падения дебита газовых скважин. Является одним из ключевых источников стандартного определения псевдовремени $t_a$.

## Потенциал для проекта
Методологически связана с цепочкой Al-Hussainy 1966 (псевдодавление) → Agarwal 1979 (псевдовремя для buildup) → Fraim Wattenbarger 1987 (псевдовремя для decline). Потенциальный отправной пункт для обобщения на двухфазный случай, если проект выйдет на аналитические оценки дебита при разгазировании.
