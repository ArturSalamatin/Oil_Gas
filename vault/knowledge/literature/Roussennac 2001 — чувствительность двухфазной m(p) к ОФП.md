# Roussennac 2001 — чувствительность двухфазной m(p) к ОФП

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Roussennac B. Gas Condensate Well Test Analysis. *MSc dissertation*, Stanford University, 2001.

## Аннотация
Показано, что многофазная функция псевдодавления (Jones–Raghavan) чувствительна к входным данным ОФП: неточности в измерении относительных проницаемостей вносят бо́льшую ошибку, чем использование упрощённой однофазной $m(p)$. Это ключевой аргумент в пользу однофазного подхода при интерпретации ГДИС газоконденсатных скважин.

## Потенциал для проекта
Важное предупреждение для модели ПЗП: если ОФП известны неточно (что типично для разгазирующих нефтяных пластов), двухфазная $m(p)$ может дать худший результат, чем однофазная. Это влияет на выбор стратегии интерпретации ГДИС.
