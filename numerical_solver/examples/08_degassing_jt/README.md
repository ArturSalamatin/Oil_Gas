# 08 — Разгазирование: адиабатический эффект + Джоуль–Томсон

## Описание

Пример [07](../07_degassing_adiabatic_only/) с одним включённым эффектом:
дросселированием (Джоуль–Томсон). Скрытая теплота дегазации по-прежнему
выключена ($L = 0$).

Гидродинамика, PVT, ОФП, $p_{wf}$ — всё как в 07 и [04](../04_table_table/).
Разница между 08 и 07 — **чистый вклад JT**.

## Комбинация модулей (B: Table + Table)

Та же, что в 07. Изменены две строки:

```json
"thermal": {
    "c_p_oil": 2000.0,
    "c_p_gas": 1000.0,
    "mu_JT_oil": 4.0e-7,     ← было 0.0
    "mu_JT_gas": -4.0e-6,    ← было 0.0
    "L_degas": 0.0
}
```

Знаки разные: у нефти $\mu_{JT} > 0$ (дросселирование охлаждает жидкость),
у газа $\mu_{JT} < 0$ — при расширении реального газа в этих условиях
вклад противоположный. Модуль коэффициента газа на порядок больше.

| Модуль | Класс |
|---|---|
| PVT (гидро) | `TableFullPVT` |
| ОФП | `PrototypeRPAdapter` |
| Гидродинамика | `PrototypeHydroAdapter` |
| Энергия | `TridiagEnergySolver` |

## Ожидаемое поведение

| Величина | Значение |
|---|---|
| $T(r_w)$ финал | **348.558 К** |
| вклад JT ($T_{08} - T_{07}$) | **$-4.212$ К** |
| $S_g^{max}$ | 0.0147 (как в 07) |
| $R_s^{min}$ | 9.5 (как в 07) |
| $q_o$ финал | $5.876 \times 10^{-3}$ м³ст/с (как в 07) |

JT — **самый сильный** из тепловых эффектов в этой постановке: он даёт
охлаждение 4.2 К против 1.7 К у скрытой теплоты дегазации (пример 09).

## Место в семействе 07–09

| Сценарий | $\mu_{JT}$ | $L$ | $T(r_w)$, К | вклад относительно 07 |
|---|---|---|---|---|
| [07](../07_degassing_adiabatic_only/) | 0 | 0 | 352.770 | — (опора) |
| **08** (этот) | > 0 | 0 | 348.558 | **$-4.212$ К** |
| [09](../09_degassing_latent_heat/) | 0 | > 0 | 351.083 | $-1.687$ К |
| [04](../04_table_table/) | > 0 | > 0 | 346.871 | $-5.899$ К |

Суперпозиция: $(-4.212) + (-1.687) = -5.899$ К — точно равно полному эффекту.

**Гидродинамика идентична 07 побитово** ($S_g$, $p$, $R_s$, $q_o$ совпадают,
`np.array_equal` → `True`). Тепловые параметры не влияют на фильтрацию
из-за расщепления: `HydroSolver` не видит секцию `thermal`.

Смотреть: `temperature_profiles.png` рядом с одноимённым файлом из 07 —
профили различаются на 4 К у забоя. `saturation_profiles.png` совпадут.

## Как увеличить газонасыщенность

$S_g^{max} = 1.5\,\%$ — свойство демонстрационной таблицы ОФП.
Заменить `relperm` на модель Кори с крутой кривой:

```json
"relperm": {"model": "corey", "S_or": 0.2, "S_gc": 0.05,
            "n_o": 2.0, "n_g": 3.0, "kro_max": 1.0, "krg_max": 0.3}
```

даст $S_g^{max} = 0.165$ вместо 0.015. Подробный разбор — в README
примера [04](../04_table_table/). Увеличение длительности расчёта и
расширение $R_e$ не помогают: стационар наступает за 8–12 ч.

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| $\mu_{JT,o}$, $\mu_{JT,g}$ | `thermal` | прямо пропорционально усиливает вклад JT |
| $c_{p,o}$, $c_{p,g}$ | `thermal` | тепловая инерция флюида |
| $R_e$ | `geometry.R_ext` | шире область; фронт $r_b$ растёт |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[].dt` | ⚠️ стационар за 8–12 ч |
| `save_every` | `output.save_every` | 1 → 73 шага (0.22 МБ), 6 → 13, 24 → 4 |

Полезный эксперимент: удвоить $\mu_{JT,g}$ и проверить, что вклад JT
вырос примерно вдвое, а $S_g$ и дебит не изменились ни на знак.

### Что требует осторожности — $p_{wf}$

**Сверху:** при $p_{wf} > p_b = 15$ МПа разгазирования не будет.
**Снизу:** табличный PVT устойчив в диапазоне 14…3 МПа; при отказе
Newton помогает `"dt_integration": 600` (DEBT-007).

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.
