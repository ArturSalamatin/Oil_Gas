### План готов

**План:** `vault/plans/bug-025 short-step-residual-floor.md` (база `015a297`, после влития DEBT-054). 7 шагов: постановка `eq:newton_abs_tol` → тесты-воспроизводители (красные) → `_absolute_tol` в обоих Ньютонах прототипа → CHANGELOG → верификация → vault.

**Решение пользователя (2026-10-11):** вариант 2. Абсолютный допуск обоих Ньютонов: $\max(\varepsilon^{abs},\ \kappa\,\varepsilon_{маш}M_{max}/\Delta t) + \varepsilon^{rel}\max(\|F_0\|, 10^{-9})$, $\kappa = 4$. $M_{max}$ — наибольший запас ячейки старого слоя (нефть; газ / $s_g$) из кэша запасов.

**Замеры планирования** (`vault/issues/bug-025/probes/`, сценарий `bug020_rs150`):
- Механизм подтверждён. Первый шаг останова 1e-2, 1e-3, 1e-4 с: отказывают все четыре ступени `advance`. Ступень 1 выходит по линейному поиску (DEBT-054: «не выполнено только абсолютное условие»), ступень 4 стоит 40 итераций. $|F|\cdot\Delta t$ на остановке — 5–7e-13 м³ст при любом Δt, максимум у внешних ячеек.
- Шаг 0.0549 с из VAL-004 отказывает не на первом подшаге, а после спада притока: $\|F_0\|$ и с ним допуск падают до 1.33e-11. Минимальное воспроизведение: `Simulator`, 10 сут добычи + 16 интервалов по 0.0549 с — отказ на 5-м шаге.
- **Поправка к телу issue.** Пол растёт с $R_{ext}$ медленнее, чем $M_{max}$: на остановке $(0.07\text{–}0.67)\,\varepsilon_{маш}M_{max}$ при $R_{ext}$ = 800…50 м. В ячейке, состояние которой за шаг не изменилось, ошибки округления нет. Оценка «~5 с при $R_{ext}$ = 1 км» завышена: при 800 м граница первого шага ~0.03–0.05 с. $\varepsilon_{маш}M_{max}$ — верхняя оценка пола.
- С полом κ = 4 (подмена методов в пробе): первый шаг 1e-4…0.44 с сходится первой ступенью при $R_{ext}$ = 50, 200, 800 м, ошибка массы за шаг ≤ 1e-11 м³ст. Ряд VAL-004 продолжается до первого шага 0.0137 с без отказов: $R_s(r_w)$ на 1 ч = 40.612, 40.903, 41.052, 41.128, порядок → 1, предел ≈ 41.20 — совпадает с оценкой VAL-004.
- Перепись: допуск не меняется ни в одном решении 23 примеров (наименьшее $\kappa^* = \varepsilon^{abs}\Delta t/(\varepsilon_{маш}M_{max})$ = 63, пример 18) и регрессии прототипа (κ* = 34, T05S_N200_DT5m). Ожидание — истории и регрессия 17/17 побитово.
