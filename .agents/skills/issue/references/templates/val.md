# Шаблоны для валидационных расчетов (VAL)

## 1. Тело задачи (`01-issue-body.md`)

```markdown
## Описание
(что верифицируется и с какой целью)

## Эталонное решение
(аналитическое решение / метод сеток / внешние пакеты – формулы, литературные источники)

## Сценарий
(параметры расчетного случая, граничные условия, расчетный интервал времени)

## Метрики сравнения
(контролируемые величины, допустимая погрешность tolerance)

## Зависимости
(блокирующие задачи BUG/DEBT/FEAT)

## План валидации
1. **Эталон** – подготовка или импорт эталонного решения
2. **Сценарий** – настройка расчетного случая
3. **Сравнение** – расчет, сбор метрик, сопоставление с эталоном, графики

## Ветка
`<имя ветки>`

## Связанные issues
(Related: #N)

## Связанные заметки в vault
(wiki-ссылки на заметки)
```

## 2. Комментарий «Контекст при открытии» (`02-comment-open.md`)

```markdown
### Контекст при открытии

- **Ветка:** `<имя ветки>`
- **Коммит:** `<короткий SHA>`
- **Эталон:** <тип: аналитика / численный / внешнее ПО>
- **Tolerance:** <значение>
- **Блокирующие зависимости:** <список ID или "нет">
```
