# FEAT-036: расчёт по книге — `gpn-solver run книга.xlsx`

> **Черновик.** Записаны решения пользователя из обсуждения 2026-10-14…15 и найденное при нём. Шаги, тестовую стратегию и критерии завершения допишет `/plan-feature FEAT-036`.

Цепочка: [[feat-033 workbook-input-format|FEAT-033]] → [[feat-034 xlsx-cell-reader|FEAT-034]] → [[feat-035 workbook-to-config|FEAT-035]] → **FEAT-036** → FEAT-031 (поставка).

## 0. Решения пользователя

1. **Одна книга — один расчёт** (2026-10-14).
2. **Результаты выводятся так же, как сейчас** (2026-10-14) — штатный набор [[feat-030 run-command-from-config|FEAT-030]].
3. **Вход расчёта сохраняется** (2026-10-14, пункт 17 обсуждения): переведённые `config.json` и CSV — в `output/input/`; расчёт воспроизводится командой по ним.
4. **Защита книги от очистки каталога вывода** (2026-10-14, пункт 15): правило FEAT-030 «отказ, если внутри каталога вывода лежит конфиг или его CSV» распространяется на книгу.
5. **Книга — часть поставки**, FEAT-031 ждёт цепочку (2026-10-14). Инструкция инженера — в комплект.
6. **Файл `~$имя.xlsx`** рядом с открытой книгой команде на один файл не мешает (2026-10-14).
7. **Отдельный демонстрационный пример для расчёта по книге** (2026-10-15). Может повторять существующий пример, если книга не сильно противоречит ему по значениям параметров. Значения книги подбираем сами ([[feat-033 workbook-input-format|FEAT-033]], решение 7). Точно повторять пример не нужно, тестов на совпадение примеров нет; книга примера — своя (раздел 0.1).
8. **Листа OUTPUT в книге нет** (2026-10-15, [[feat-033 workbook-input-format|FEAT-033]] решение 44): параметры вывода — умолчания конфига, заголовок — имя книги без расширения; флаги `--title`, `--profiles` команды действуют и для книги.
9. **Умолчания** (предложены 2026-10-15 как «решу при `/plan-feature`, если не возразите» — возражений не было): инструкция инженера — в README пакета (`numerical_solver/README.md`, FEAT-031); ошибки книги — код возврата 2, как ошибки конфига в FEAT-030.
10. **Книга и её значения — на английском, сообщения — русские** (FEAT-033 решение 34).
11. **Строка «Run» листа COMMENTS — в этой задаче** ([[feat-033 workbook-input-format|FEAT-033]] решение 62, 2026-10-17): FEAT-033 описывает только работающие команды; FEAT-036 дописывает в `gpn_multiphase_solver/io/workbook_template.COMMENTS` строку о `gpn-solver run my_case.xlsx` (после `Template`), тест `test_comments_sheet` — проверку этой строки.

## 0.1. Демонстрационный пример (предложение 2026-10-15)

- **Номер и имя:** `examples/22_workbook_input` (следующий свободный номер; 01–21 заняты).
- **Сценарий — на основе примера 18:** гидродинамика черновика руководителя совпадает с книгой прототипа `INPUT_TEMPLATE.xlsx` ($k$ = 1 мД, $R_e$ = 100 м, $p_0$ = 200 бар, $R_{s,0}$ = 50, $p_{wf}$ 150 → 120 → 100 бар, 30 сут). Значения книги — демонстрационные значения [[feat-033 workbook-input-format|FEAT-033]]: ветвь $R_s = 60$ в PVTO, $h_0$ = 0.11 с, правдоподобные тепловые значения ($\rho_s$ = 2650 кг/м³, $c_s$ = 820 Дж/(кг·К), $T_0$ = 350 К, $L$ = 230 кДж/кг).
- **Точно повторять пример 18 не нужно, тестов на совпадение примеров нет** (решение пользователя 2026-10-15). Пример самостоятелен: сравнений с 18 в README и тестах нет.
- **Книга примера — своя, в папке примера** (решение пользователя 2026-10-15): ни теста на равенство с книгой генератора, ни ссылки на `configs/`.

## 1. Сводка (предварительно)

- **Суть:** `gpn-solver run` выбирает вход по расширению (`.json` — как сейчас, `.xlsx` — книга). Порядок для книги: отказ, если книга внутри каталога вывода → очистка каталога вывода → перевод в `output/input/` ([[feat-035 workbook-to-config|FEAT-035]]) → `run_case` по `output/input/config.json`.
- **Модули (предварительно):** `gpn_multiphase_solver/cli.py`, `report/pipeline.py`; README пакета (FEAT-031), `examples/README.md`, `CLAUDE.md` (строка «Расчёт по конфигу»).

## 2. Найдено при обсуждении

- **Заголовок по умолчанию.** `run_case` без `output.title` берёт имя папки конфига (`report/pipeline.py`, `run_case`: `config_path.resolve().parent.name`). Для `output/input/config.json` это «input». Заголовок по умолчанию — имя книги без расширения: перевод пишет его в `output.title` или `run_case` получает его явно — решить при планировании.
- **Защита FEAT-030** (отказ, если в каталоге вывода лежит конфиг или его CSV) не должна срабатывать на собственные файлы перевода: они пишутся после очистки — проверить порядок в `cli.py` / `run_case`.
- Каталог вывода по умолчанию — `output/` рядом с книгой (как у конфига).
