## Описание

На старте останова скважины после добычи с развитой газовой зоной шаг по времени короче ~0.1 с не сходится, и локальное дробление ([DEBT-015](https://github.com/ArturSalamatin/Oil_Gas/issues/61)) не помогает: Ньютон не расходится, невязка стоит на месте. Гипотеза: абсолютное условие сходимости задано в м³ст/с, а невязка содержит разность запасов, делённую на $\Delta t$. Ошибка округления этой разности ~$\varepsilon_{маш} M_{max}$ от шага не зависит, поэтому пол невязки растёт как $1/\Delta t$ и при малых шагах выходит за $\varepsilon^{abs} = 10^{-11}$ м³ст/с.

**Критичность:** низкая для примеров — их штатные шаги (минуты–часы) не затронуты. Но дефект закрывает сгущение по времени на старте останова: начальный шаг [FEAT-032] не может быть меньше ~0.2 с, а [BUG-026] нужен первый шаг ≲ 0.5 с; предел растёт с размером области дренирования.

## Симптомы

Сценарий `numerical_solver/tests/data/bug020_rs150/config.json` ($N$ = 350, $R_{ext}$ = 200 м, $r_w$ = 0.1 м, $h$ = 10 м, $\phi$ = 0.2): 10 сут добычи при 3 МПа, затем $q_{oil} = 0$, первый час останова нарастающими шагами.

| Первый шаг останова | Итог |
|---|---|
| 0.1099 с ($k$ = 6) | сходится, отказов 0 |
| 0.0549 с ($k$ = 7) | не сходится при дроблении до $0.0549/512 = 1.07\cdot10^{-4}$ с |

Текст отказа `Simulator`: «HydroSolver не сошёлся при дроблении шага до dt/512 = 1.07e-04 с на подшаге с t = 10.0000 сут: двухфазных ячеек 332 из 350, max S_g = 0.409». Последний отказ адаптера: «advance не сошёлся: dt = 1.073e-04 с, t = 10.0000 сут, итераций 4, невязка 5.00e-09».

**Наблюдение по коду (прогоном не проверено).** «Итераций 4» — отчёт первой ступени `advance`: при отказе всех ступеней в отчёт подставляется Ньютон исходного алгоритма (DEBT-030, `blackoil.py:424-434`). У первой ступени `max_newton` = 15, а 4 < 15, значит она вышла не по исчерпанию итераций, а по провалу линейного поиска (12 делений шага без строгого уменьшения $\|F\|_\infty$, `blackoil.py:372-379`) или по исключению линейного решателя. Это согласуется с гипотезой: ниже пола округления строгое уменьшение нормы невозможно. Причину выхода отчёт сейчас не называет — это добавляет [DEBT-054](https://github.com/ArturSalamatin/Oil_Gas/issues/102) (поле `exit_reason`).

## Корневая причина

Гипотеза: оценка по величине совпадает с замером, отдельным прогоном не проверена.

1. Невязка `physical_residual` (`blackoil.py:244-246`) в м³ст/с: $F_i = (M_i^{n+1} - M_i^{n})/\Delta t + q_i$, где запасы $M_i$ считает `component_inventories` (`blackoil.py:195-200`): нефть $V_p S_o/B_o$, газ $V_p(R_s S_o/B_o + S_g/B_g)$; газовые строки делятся на $s_g = \max(R_{s,ext}, 1)$.
2. $M^{n+1}$ и $M^{n}$ вычисляются по отдельности, каждый с относительной ошибкой ~$\varepsilon_{маш}$. Ошибка разности ~$\varepsilon_{маш} M_i$ от $\Delta t$ не зависит, после деления на $\Delta t$ пол невязки ячейки — ~$\varepsilon_{маш} M_i/\Delta t$.
3. Условие сходимости (`problem_statement.tex`, `ssec:convergence`; код — `blackoil.py:349`, ступень 4 — `:555`): $\|F\|_\infty \le \varepsilon^{abs} + \varepsilon^{rel}\max(\|F_0\|_\infty, 10^{-9})$, $\varepsilon^{abs} = 10^{-11}$ м³ст/с, $\varepsilon^{rel} = 10^{-8}$. Начальное приближение первой ступени — старое состояние, накопление на нём ноль, $\|F_0\|$ — порядка притока к закрытой скважине, и относительная часть допуска того же порядка, что $\varepsilon^{abs}$, или меньше.
4. Крупнейшая ячейка сценария — внешняя: $\Delta\ln r = \ln 2000/350 = 0.0217$, поровый объём $\approx 1.07\cdot10^4$ м³, запас нефти ~$7.6\cdot10^3$ м³ст, $\varepsilon_{маш} M_{max} \approx 1.7\cdot10^{-12}$ м³ст. Пол $1.7\cdot10^{-12}/\Delta t$ равен $\varepsilon^{abs}$ при $\Delta t \approx 0.17$ с (наблюдаемая граница — между 0.055 и 0.11 с) и составляет $1.6\cdot10^{-8}$ при $1.07\cdot10^{-4}$ с — наблюдалось $5\cdot10^{-9}$.
5. Условие по ячейке [BUG-022](https://github.com/ArturSalamatin/Oil_Gas/issues/82) ($|F_i|\Delta t/V_{p,i} \le \varepsilon^{cell}$) от $\Delta t$ не зависит и здесь ни при чём; у него свой пол округления — [DEBT-055].

**Следствие для других сценариев (оценка, не замерялось).** Пол пропорционален запасу внешней ячейки, то есть $\sim R_{ext}^2(1 - e^{-2\Delta\ln r})$. При $R_{ext}$ = 1 км и том же $N$ = 350 он в ~30 раз выше, и критический шаг — порядка 5 с: больше начального шага ≲ 0.5 с, нужного [BUG-026].

## Анализ вариантов решения

### Вариант 1. Абсолютный допуск в м³ст — условие на $|F|\Delta t$

**Суть.** Абсолютное условие ставится на ошибку массы за шаг: $\|F\|_\infty \Delta t \le \varepsilon^{abs}_M$ [м³ст], то есть $\varepsilon^{abs}$ в м³ст/с заменяется на $\varepsilon^{abs}_M/\Delta t$.
**Изменения.** `blackoil.py:349`, `:555`; `ssec:convergence`.
**Плюсы.** Физически ясная единица: допустимая ошибка баланса за шаг не зависит от длины шага (сейчас при $\Delta t$ = 3600 с она $3.6\cdot10^{-8}$ м³ст, при 60 с — $6\cdot10^{-10}$).
**Минусы.** Меняет условие при любом $\Delta t$ — не побитово для всех примеров, историй и эталона регрессии прототипа. $\varepsilon^{abs}_M$ должно быть выше $\varepsilon_{маш}M_{max}$, а тот зависит от $R_{ext}$ — фиксированная константа снова упрётся в пол при большой области; придётся задавать её относительно запаса, то есть фактически перейти к варианту 2.

### Вариант 2. Пол допуска по оценке округления (рекомендуется)

**Суть.** $\text{tol} = \max\bigl(\varepsilon^{abs},\ \kappa\,\varepsilon_{маш} M_{max}/\Delta t\bigr) + \varepsilon^{rel}\max(\|F_0\|_\infty, 10^{-9})$, где $M_{max} = \max\bigl(\max_i M^{o}_i,\ \max_i M^{g}_i/s_g\bigr)$ — по запасам старого слоя из кэша `_old_inventories`; $\kappa$ — запас на несколько единиц округления, подбирается замером.
**Изменения.** `blackoil.py:349`, `:555` (общая функция допуска для обоих Ньютонов); описание пола в `ssec:convergence`; комментарий с оценкой в коде.
**Плюсы.** Пока пол ниже $\varepsilon^{abs}$ (шаги длиннее ~$\kappa\cdot0.17$ с при $R_{ext}$ = 200 м), `max` возвращает $\varepsilon^{abs}$ тем же числом — все решения, истории примеров и эталон прототипа побитово прежние. Требование «точнее, чем представимо в запасах» снимается ровно там, где оно невыполнимо; ошибка баланса за шаг остаётся на уровне округления $\kappa\varepsilon_{маш}M_{max}$. Работает при любом $R_{ext}$ — нужно для [FEAT-032] и [BUG-026].
**Минусы.** $\kappa$ эмпирический. Оценка учитывает только округление запасов; округление потоков при малых $\Delta t$ мало, но не оценено. Линейный поиск со строгим уменьшением может застрять раньше, чем невязка дойдёт до поднятого допуска, если реальный шум выше $\kappa$-оценки — проверить замером.

### Вариант 3. Не менять Ньютон, запретить слишком короткие шаги

**Суть.** Оценить $\Delta t_{min} = \kappa\,\varepsilon_{маш}M_{max}/\varepsilon^{abs}$ по начальному состоянию в фабрике; предупреждать (или отклонять конфиг), если `dt_integration / 2**max_retries` или начальный шаг [FEAT-032] меньше $\Delta t_{min}$; в тексте отказа назвать предел.
**Изменения.** `gpn_multiphase_solver/factory.py` или `io/config.py` (`_validate`), текст `simulator.py:321`.
**Плюсы.** Численная схема не меняется, ничего не пересчитывается; отказ становится понятным.
**Минусы.** Предел остаётся. Уже сейчас `dt_integration` = 60 с при `max_retries` = 9 даёт 0.117 с — на грани, запрет пришлось бы делать предупреждением. При $R_{ext}$ ~ 1 км (оценка $\Delta t_{min}$ ~ 5 с) запрет несовместим с начальным шагом ≲ 0.5 с, нужным [BUG-026]. $M_{max}$ меняется с давлением — оценка по начальному состоянию грубая.

### Вариант 4. Разностная форма накопления

**Суть.** Считать $M^{n+1}-M^{n}$ через приращения неизвестных ($\Delta p$, $\Delta S_g$, $\Delta R_s$ и наклоны кусочно-линейных PVT-таблиц), а не вычитанием двух больших чисел.
**Плюсы.** Снижает сам пол, а не допуск.
**Минусы.** Сложно (сегменты PVT-таблиц, переходы фаз, сжимаемость пор), меняет все решения не побитово, полностью пол не убирает — остаётся разрешение самих неизвестных. Несоразмерно низкому приоритету.

**Рекомендация:** вариант 2; текст отказа (вариант 3, без запрета) — по желанию, после [DEBT-054]. Выбор — при планировании.

## План решения

0. **Зависимость.** Планировать после влития [DEBT-054](https://github.com/ArturSalamatin/Oil_Gas/issues/102) (сейчас в реализации): он правит те же `_newton_fixed_active_set`, `_newton_switching` и добавляет в отчёт `residual_tol` и `exit_reason`, которые прямо покажут, чем отказывает шаг 0.0549 с.
1. **Подтверждение и воспроизведение.** Проба: $\|F\|_\infty$ по итерациям при $\Delta t$ = 0.0549 с против оценки $\varepsilon_{маш}M_{max}/\Delta t$; причина выхода (линейный поиск или исчерпание итераций — закрывает пункт «Не проверено» записи реестра); критический шаг при $R_{ext}$ = 100, 200, 400 м должен расти как $M_{max}$. Тест, падающий до исправления: шаг ≤ 0.05 с на старте останова сценария `bug020_rs150` (или на уменьшенной сетке, если воспроизводится — для быстрого уровня).
2. **Исправление** (вариант 2). Общая функция допуска для обоих Ньютонов, $\kappa$ — замером (наименьший, при котором 0.0549 с и короче сходятся без лишних итераций); текст `ssec:convergence` с оценкой пола; комментарии в коде.
3. **Верификация.** Шаги 0.0549, 0.01, 0.001 с на сценарии сходятся; $R_s(r_w)$ через 1 ч при первом шаге 0.055 с продолжает ряд VAL-004 (39.02 → 40.06 → 40.61 при 0.44 → 0.22 → 0.11 с, предел Ричардсона ≈ 41.2); регрессия прототипа 17/17 и истории примеров побитово (штатные шаги — минуты–часы, пол там не срабатывает); быстрый и полный прогоны тестов.
