# Mosally Wood Al-Fhaid 2002 — экспоненциальный HBIM

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Mosally F., Wood A.S., Al-Fhaid A.** An exponential heat balance integral method. *Appl. Math. Comput.*, 2002, Vol. 130, pp. 87–100.

## Аннотация
Экспоненциальная аппроксимация для HBIM: $u = a + (bx/s)e^{-cx^2/s^2}$, мотивированная поведением erf-функции в точном решении. Для постоянной температуры на границе экспоненциальный профиль даёт наименьшую ошибку среди всех аппроксимаций (Mitchell & Myers 2010, Table 5.1). Однако для условия Робина — не лучший выбор: кубический профиль точнее (Table 5.2). Авторы также исследуют кусочно-линейную аппроксимацию [28] и показывают медленную сходимость.

## Потенциал для проекта
Экспоненциальная аппроксимация вряд ли применима к профилям $S_g(r)$ или $p(r)$ в задаче ПЗП (физический профиль — степенной, не гауссов). Но результат поучителен: форма аппроксимации должна соответствовать физике задачи.
