# Валидационные кейсы

## Формат записи

```
### VAL-NNN: Краткое описание
- **Эталон:** аналитическое решение / численное решение / OPM Flow
- **Сценарий:** параметры, ГУ, время
- **Метрика:** что сравнивать, tolerance
- **Статус:** 🔴 ОТКРЫТ / ✅ ПРОЙДЕН <дата>
- **План:** [[id slug]]
```

## Записи

### VAL-001: Однофазный стационарный приток (формула Дюпюи)
- **Эталон:** аналитическая формула q = 2πkh(pe−pw)/(μ·ln(Re/rw))
- **Сценарий:** Sg=0, T=const, стационарный режим
- **Метрика:** дебит на забое, tolerance < 1%
- **Статус:** 🔴 ОТКРЫТ

### VAL-002: Изотермическая задача (T=const)
- **Эталон:** сравнение с численным решением PDE (конечные разности)
- **Сценарий:** отключить уравнение энергии, только p(r,t) и Sg(r,t)
- **Метрика:** профили p(r), Sg(r) при t=1000,10000,86400 с; tolerance < 5%
- **Статус:** 🔴 ОТКРЫТ

### VAL-003: Полная задача vs OPM Flow
- **Эталон:** OPM Flow с эквивалентной радиальной сеткой
- **Сценарий:** baseline.json параметры, полная система с температурой
- **Метрика:** rb(t), pwf(t), T(rw,t); tolerance < 10%
- **Статус:** 🔴 ОТКРЫТ
