# FEAT-019: Пример 16 — останов скважины после добычи; рабочий диапазон рисунков PVT и ОФП по всей истории

## Цель

1. Добавить в `numerical_solver/examples/` самостоятельный сценарий
   `16_well_shut_in`: конфиг примера 12 ($R_{ext} = 200$ м, $p_0 = 15.5$ МПа,
   $p_b = 15$ МПа, $R_{s,0} = 30$, $N = 50$, табличные PVT и ОФП, полная
   термика), в котором скважина **15 сут добывает при $p_{wf} = 6$ МПа, затем
   останавливается на 15 сут** — управление по дебиту с $q_{oil} = 0$. Пример
   показывает то, чего нет ни в одном другом: восстановление давления выше
   $p_b$, растворение свободного газа, застывший неоднородный профиль $R_s$,
   нагрев забоя при сжатии и релаксацию температуры теплопроводностью.
2. Исправить общие модули рисунков: `examples/pvt_plot.py` и
   `examples/relperm_plot.py` берут рабочий диапазон ($p$, $S_g$) **по всей
   истории**, а не по последней записи. Без этого у примера 16 `relperm.png`
   пишет «однофазный расчёт: $S_g \equiv 0$» (15 сут добычи двухфазны,
   $S_g$ до 0.048), а `pvt.png` вырождает диапазон в точку 15.5 МПа.

Ядро библиотеки (`gpn_multiphase_solver/`), прототип
(`HydroSolverPrototype/`) и постановка (`problem_statement.tex`) **не
меняются**. Меняются: два общих модуля рисунков, новая папка примера,
тесты, README.

**Подтип:** режим (новый режим работы скважины в примерах — останов) +
инфраструктура (рабочий диапазон рисунков).

**Вне объёма:**
- останов из развитой газовой зоны ($S_g \gtrsim 0.2$) — не сходится,
  [[BUG-020]] (зарегистрирован при планировании); пример с сильным тепловым
  эффектом — после него;
- накопленный баланс массы компонентов — [[DEBT-039]] (зарегистрирован при
  планировании, решение пользователя);
- обобщение проверки $R_s$ — [[DEBT-026]], **предшественник** этой задачи
  (см. §0, решение 6);
- гидродинамическая сверка останова с кривой восстановления давления

- сценарии «ступенчатая депрессия» (дубль 13a) и «повторный пуск после

## 1. Физика и замеры

### 1.1. Что происходит при останове

Скважина 15 сут добывает при $p_{wf} = 6$ МПа: вокруг неё воронка давления
6.12–15.4 МПа, двухфазная зона до ~100 м, $S_g(r_w)$ спадает с 0.048 (1 сут)
до 0.024 (15 сут), $R_s$ у забоя 3.37 м³ст/м³ст.

Останов задаётся дебитом $q_{oil} = 0$. По `eq:bc_rate_well` поток нефти
через забойную грань $-G^o_{1/2} = 0$, по `eq:bc_rate_pwf`
$p_{wf} = p_0 - q/(\mathcal{T}\lambda_o) = p_0$ (здесь $p_0$ — давление
ячейки 0) — поток газа через забой тоже ноль. Через контур нефть
продолжает поступать (на первом подшаге $G^o_N = -3.4\cdot10^{-3}$ м³ст/с),
пока давление не выровняется, — **течение внутри пласта при останове не
прекращается сразу**, обнуляется только поток через забой.

Последствия:

1. **Восстановление давления.** $p(r_w)$: 6.12 → 12.64 МПа за 1 ч, 13.43
   за 2 ч, выше $p_b$ — к 12 ч, 15.42 — к концу первых суток, 15.4999 — к
   3-м суткам. Финал — $\max|p - p_{ext}| = 0.013$ Па.
2. **Растворение свободного газа.** Двухфазных ячеек 46 → 14 (1 ч) → 0 (7 ч,
   15.29 сут). В этот момент $p(r_w) = 14.48 < p_b$ — нефть у забоя
   **недонасыщена ниже $p_b$**: свободного газа не хватило.
3. **$R_s$ застывает неоднородным**: у забоя 4.79 (было 3.37 + растворённый
   свободный газ), у контура 30. После выравнивания давления течения нет,
   диффузии в модели нет — профиль больше не меняется
   ($\max|R_s(20\,\text{сут}) - R_s(30\,\text{сут})| = 7.6\cdot10^{-5}$).
   Возврата к $R_{s,0} = 30$ нет и быть не должно.
4. **Нагрев забоя при сжатии.** $T(r_w)$: 350.351 К (конец добычи) →
   350.655 (1 ч) → максимум **350.660 К на 2 ч** → монотонно вниз до
   350.313 К (30 сут) — теплопроводность. Члены баланса энергии за первые
   сутки останова: адиабатический $+4.86\cdot10^{10}$ Дж, дегазация
   (растворение — теплота выделяется) $+2.92\cdot10^{9}$, JT
   $+1.0\cdot10^{8}$, конвекция $+2.2\cdot10^{7}$, кондукция
   $+2.0\cdot10^{5}$; $\Delta E = +5.17\cdot10^{10}$ Дж. **Нагрев —
   адиабатическое сжатие** (член $\alpha T\,\partial p/\partial t$), а не
   растворение газа: газа мало ($S_g \le 0.024$).
5. На финале профиль $T$ немонотонен: у забоя 350.31 К, на 20–30 м — 349.95 К
   (зона охлаждения времён добычи ещё не прогрелась), у контура 350.00 К.

### 7.4. Класс `TestWellShutIn` (шаг 4)

```python
class TestWellShutIn:
    """Сценарий 16: конфиг 12, 15 сут добычи при 6 МПа, затем 15 сут останова.

    Останов — управление по дебиту q_oil = 0 (eq:bc_rate_well): потоки
    компонентов через забой нулевые, p_wf = p[0] (eq:bc_rate_pwf при q = 0).
    Записи: 0 — начальное состояние; 1..15 — концы суток добычи; 16..39 —
    часы первых суток останова (запись 15 + k — момент 15 сут + k ч);
    40..53 — концы суток 17..30. Числа — замер плана FEAT-019
    (vault/issues/feat-019/probes/plan_numbers.out.txt).
    """

    NAME = "16_well_shut_in"
    END_PROD = 15        # запись конца добычи (15 сут)

    def test_config_follows_decisions(self):
        """Расписание: 15 суточных интервалов при 6 МПа, 24 часовых и 14 суточных с q_oil = 0.

        Решения пользователя 2026-10-03: останов — по дебиту, min_bhp = 1 атм
        (обязателен по конфигу, при q = 0 не действует). Ловит: возврат к
        управлению по давлению, потерю часовой записи первых суток останова

        hist = cfg.time.history
        assert len(hist) == 15 + 24 + 14
        assert cfg.time.dt_integration == 3600.0
        for h in hist[:15]:
            assert (h.control, h.dt, h.p_wf) == ("pressure", 86400.0, 6.0e6)
        for k, h in enumerate(hist[15:]):
            assert h.control == "rate" and h.q_oil == 0.0
            assert h.min_bhp == 101325.0 and h.p_wf is None
            assert h.dt == (3600.0 if k < 24 else 86400.0)

    def test_production_phase_degasses(self, results):
        """На конце добычи скважина добывает нефть и газ, газ выделился в пласте.

        Утверждения общих тестов test_oil_production, test_gas_appears,
        test_gas_produced — на записи 15 вместо последней (16 исключён из
        них списком ENDS_SHUT_IN). Замер: q_o = 3.2365e-3, q_g = 0.11871

        st = r["history"].states[self.END_PROD]
        assert r["q_o"][self.END_PROD] == pytest.approx(3.2365e-3, rel=1e-4)
        assert r["q_g"][self.END_PROD] > 0.0
        assert st.Sg.max() > 0.0
        assert st.Rs.min() < r["Rs0"]

    def test_shut_in_stops_flow_through_well(self, results):
        """На всех записях останова q_o = q_g = 0 точно, фактическое p_wf = p[0].

        Знак: q_o_std = -G_o[0]; при q_oil = 0 прототип ставит потоки забоя
        ровно 0 (blackoil.py, _well_fluxes, ветка OIL_RATE: bhp = p0).
        Замер: max|p_wf - p[0]| = 0 Па. Ловит: утечку через забой (закачку
        или отбор) при останове, запись уставки вместо фактического p_wf.
        """
        r = results[self.NAME]
        h = r["history"]
        for n in range(self.END_PROD + 1, len(h.states)):
            assert r["q_o"][n] == 0.0 and r["q_g"][n] == 0.0, f"запись {n}"
            assert h.well_data[n].p_wf == h.states[n].p[0], f"запись {n}"

    def test_pressure_builds_up_past_pb(self, results):
        """p(r_w) не убывает после останова, выше p_b — с 12 ч, на финале p = p_ext.

        Замер: 6.1242 МПа (15 сут) → 12.635 (1 ч) → 15.0326 (запись 27,
        15.5 сут — первая выше p_b = 15 МПа) → 15.4207 (16 сут); финал
        max|p - p_ext| = 0.013 Па. Ловит: потерю притока через контур,
        «залипание» давления у забоя.
        """
        r = results[self.NAME]
        states = r["history"].states
        pw = np.array([s.p[0] for s in states])
        assert np.all(np.diff(pw[self.END_PROD:]) >= 0.0)

        above = [n for n in range(self.END_PROD, len(pw)) if pw[n] > pb]
        assert above[0] == 27, f"выше p_b с записи {above[0]}"
        p_ext = r["config"].initial_conditions.p0
        assert np.max(np.abs(states[-1].p - p_ext)) < 1.0

    def test_gas_redissolves_and_rs_freezes(self, results):
        """Свободный газ растворяется за 7 ч, R_s застывает неоднородным и ниже равновесного.

        Физика: давление поднимается, газ растворяется в пределах своего
        запаса; когда газ кончается, нефть остаётся недонасыщенной. Течения
        после выравнивания давления нет, диффузии в модели нет — профиль R_s
        больше не меняется и к R_s0 не возвращается.
        Замер: двухфазных ячеек нет с записи 22 (15 сут + 7 ч, p(r_w) =
        14.48 МПа < p_b); финал R_s(r_w) = 4.792, max(R_s - R_s^eq(p)) =
        2.8e-14; max|R_s(20 сут) - R_s(30 сут)| = 7.6e-5.

        газа через контур или забой), залипание ячеек в двухфазном режиме.
        """
        r = results[self.NAME]
        states = r["history"].states
        for n in range(22, len(states)):
```

### 7.4a. Тест расписания через останов (шаг 4)

В `numerical_solver/tests/test_energy_balance_examples.py` после

```python
# ──────────────────────────────────────────────────────────────
# FEAT-019: структура истории не влияет на расчёт и через останов
# ──────────────────────────────────────────────────────────────

def test_stepped_schedule_matches_uniform_across_shut_in(tmp_path):
    """Ступенчатое расписание совпадает с равномерным и через смену режима (FEAT-019).

    Тест из записи FEAT-019 («скачок ГУ одним интервалом и половинными —
    решение на общем моменте совпадает»). test_stepped_schedule_matches_uniform
    проверяет то же при постоянном p_wf; здесь 2 ч добычи при 6 МПа, затем
    2 ч останова (q_oil = 0) — смена и вида управления, и знака изменения
    давления. Конфиг примера 16, N = 25, шаг интегрирования 300 с делит все
    интервалы обоих расписаний:
      равномерно — 48 записей по 300 с;
      ступенчато — в каждом режиме 6 записей по 300 с, затем 3 по 1800 с.
    Длительность — 2 + 2 ч, а не 6 + 6: тест без метки slow идёт в быстрый
    уровень, табличный PVT считается медленно (6 + 6 ч — 20 с).
    Смена управления в обоих расписаниях — на границе интервала, подшаги
    одни и те же, поэтому на общих моментах записи состояние, данные скважины
    и накопленный баланс совпадают ПОБИТОВО (допуска нет — как в тесте FEAT-018).
    """
    src = _EXAMPLES / "16_well_shut_in" / "config.json"
    raw = json.loads(src.read_text(encoding="utf-8"))
    prod = {"control": "pressure", "p_wf": 6.0e6}
    shut = {"control": "rate", "q_oil": 0.0, "min_bhp": 101325.0}

    def run(name, blocks):
        raw["time"]["history"] = blocks
        raw["time"]["dt_integration"] = _DT_INT_SCHEDULE
        path = tmp_path / f"{name}.json"
        path.write_text(json.dumps(raw), encoding="utf-8")
        config = load_config(path)
        # Таблицы PVT и ОФП фабрика ищет относительно конфига — каталог примера
        config.config_dir = src.parent
        config.grid.N = 25
        config.output.log_level = "WARNING"
        simulator, initial_state = SimulatorFactory.from_config(config)
        return simulator.run(initial_state)

    uniform = run("uniform", [{"dt": 300.0, "repeat": 24, **prod},
                              {"dt": 300.0, "repeat": 24, **shut}])
    stepped = run("stepped", [{"duration": 1800.0, "dt_out": 300.0, **prod},
                              {"duration": 5400.0, "dt_out": 1800.0, **prod},
                              {"duration": 1800.0, "dt_out": 300.0, **shut},
                              {"duration": 5400.0, "dt_out": 1800.0, **shut}])

    assert uniform.n_saved == 1 + 48
    assert stepped.n_saved == 1 + 2 * (6 + 3)
    # Режимы действительно разные: на конце добычи (2 ч, запись 24) дебит
    # положителен и газ у забоя есть, на останове дебит — ноль
    # (q_o_std = -G_o[0], конвенция знаков)
    assert uniform.well_data[24].q_o_std > 0.0
    assert uniform.states[24].Sg.max() > 0.0
    assert uniform.well_data[-1].q_o_std == 0.0

    index = {t: k for k, t in enumerate(uniform.times)}
    for j, t in enumerate(stepped.times):
        k = index[t]        # KeyError — момент записи ступенчатой истории сдвинулся
        for name in ("p", "Sg", "Rs", "T", "regime"):
            assert np.array_equal(getattr(stepped.states[j], name),
                                  getattr(uniform.states[k], name)), (t, name)
        assert stepped.well_data[j] == uniform.well_data[k], t
        assert stepped.balance[j] == uniform.balance[k], t
```

двоичной арифметике, поэтому `index[t]` находит общие моменты.
