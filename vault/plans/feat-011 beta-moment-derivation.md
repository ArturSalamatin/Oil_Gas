## Контекст задачи

### Текущее состояние

Система метода моментов — 3 ODE для (r_b, Sg_w, ΔTw) при фиксированных формах профилей:
- p(r) = p_wf + (pb* − p_wf) · η^γ, где γ = γ(r_b) — алгебраическое замыкание
- Sg(r) = Sg_w · (1 − η^β), β = const = 2
- T(r) = T₀ − ΔTw · Ψ(ζ), σ = const

Три интегральных соотношения (нулевые моменты уравнений давления, насыщенности, энергии) дают систему A·ẏ = F, где A — 3×3.

### Проблема

Диагностика 2026-08-01: при β = const система 3×3 порождает затухающие осцилляции r_b, Sg_w, ΔTw. Sg_w уходит до −0.005. Причина: фиксированная форма профиля Sg(r) не вмещает перестройку при нестационарном процессе.

### Цель

Добавить β(t) как 4-ю ODE-переменную. Для этого нужен 4-й интегральный момент уравнения насыщенности, дающий эволюционное уравнение для β̇.

## Математическая основа

### Уравнение насыщенности (eq:Sg_eq2)

$$\frac{\partial S_g}{\partial t} = S_o (c_r + c_o^{sat}) \frac{\partial p}{\partial t} - S_o \beta_o^{sat} \frac{\partial T}{\partial t} - \frac{B_o}{\phi} \frac{1}{r} \frac{\partial}{\partial r}\left(\frac{r \lambda_o}{B_o} \frac{\partial p}{\partial r}\right)$$

### Профиль насыщенности (eq:Sg_profile)

$$S_g(r,t) = S_{g,w}(t) \left[1 - \eta(r)^{\beta(t)}\right], \quad \eta = \frac{\ln(r/r_w)}{\ln(r_b/r_w)}$$

### Существующие уравнения (при β = const)

**Нулевой момент** (вес w = r, уравнение 2):

$$\frac{d}{dt}\int_{r_w}^{r_b} r\, S_g\, dr = \text{[правая часть]}$$

Даёт уравнение для Sg_w (через A₂₁ṙ_b + A₂₂Ṡ_{g,w} + A₂₃ΔṪ_w = F₂).

**Ключевые формулы (β = const):**

- A₂₂ = ∫_{r_w}^{r_b} r(1 − η^β) dr — геометрический, > 0
- A₂₁ = (Sg_w β)/(r_b L_b) ∫r η^β dr − ∫r S_o (c_r + c_o^{sat}) (∂p/∂r_b) dr
- A₂₃ = −∫r S_o β_o^{sat} Ψ(ζ) dr
- F₂ = −(B_o/φ)[r λ_o/B_o · ∂p/∂r]_{r_w}^{r_b}

### КРИТИЧЕСКОЕ: влияние β(t) на существующие уравнения

При β = β(t) в разложении ∂Sg/∂t появляется **новый член**:

$$\frac{\partial S_g}{\partial t} = \frac{\partial S_g}{\partial r_b}\dot{r}_b + \frac{\partial S_g}{\partial S_{g,w}}\dot{S}_{g,w} + \underbrace{\frac{\partial S_g}{\partial \beta}\dot{\beta}}_{\text{НОВОЕ}}$$

где ∂Sg/∂β = −Sg_w η^β ln(η).

Это порождает **новый столбец** в матрице — элемент при β̇ во 2-й строке:

$$A_{2,\beta} = -S_{g,w} \int_{r_w}^{r_b} r\, \eta^\beta\, \ln\eta\, dr$$

Уравнения 1 (давление) и 3 (энергия) **не** содержат Sg явно → β̇ в них не появляется. Матрица 4×4:

```
     ṙ_b    Ṡg_w    β̇        ΔṪ_w
1  [ A₁₁    0       0         A₁₄  ]
2  [ A₂₁    A₂₂     A_{2,β}   A₂₄  ]    ← строка 2 расширяется!
3  [ A₃₁    0       0         A₃₄  ]
4  [ A₄₁    A₄₂     A₄₃       A₄₄  ]    ← новая строка
```

Это означает: FEAT-011 должен вывести не только 4-ю строку, но и элемент A_{2,β}. В tex нужно обновить eq:dSg_dt, добавив член ∂Sg/∂β·β̇.

## Шаг 1: Выбор весовой функции 4-го момента

**Цель:** определить весовую функцию w₄(r), с которой интегрируется уравнение насыщенности для получения уравнения на β̇.

**Что сделать:**

Рассмотреть три варианта и выбрать один.

### Вариант A: Первый момент с весом r·η^β

Умножить (eq:Sg_eq2) на r·η^β и проинтегрировать от r_w до r_b:

$$\frac{d}{dt}\int_{r_w}^{r_b} r\, \eta^\beta\, S_g\, dr = \text{[правая часть]}$$

Левая часть содержит ∂(η^β S_g)/∂t. Подставляя S_g = Sg_w(1 − η^β):

$$\frac{d}{dt}\int_{r_w}^{r_b} r\, \eta^\beta\, S_{g,w}(1 - \eta^\beta)\, dr$$

Подынтегральное зависит от t через Sg_w(t), β(t), r_b(t). Детальное раскрытие — в шаге 2.

**Плюсы:** естественный «первый момент» профиля Sg; интегралы ∫η^n(1−η^β)dη имеют замкнутые формулы.

**Минусы:** η^β зависит от β → нелинейность в левой части; при β→∞ подынтегральное выражение вырождается.

### Вариант B: Вес r·∂S_g/∂β = −r·Sg_w·η^β·ln(η)

Умножить (eq:Sg_eq2) на ∂S_g/∂β / Sg_w = −η^β ln(η):

$$\frac{d}{dt}\int_{r_w}^{r_b} r\, [-\eta^\beta \ln\eta]\, S_g\, dr = \text{[правая часть]}$$

**Плюсы:** прямая связь с ∂S_g/∂β — уравнение «ортогонально» к уравнению для Sg_w.

**Минусы:** ln(η) сингулярна при η→0 (r→r_w). Интегралы ∫η^n ln(η) dη сходятся, но вычислительно хуже.

### Вариант C: Вес r·(1 − η^β)² (квадрат профиля)

**Плюсы:** положительно определён, без сингулярностей.

**Минусы:** не ортогонален к нулевому моменту; плохая связь с β̇.

### Рекомендация

**Вариант A** (вес r·η^β) — наиболее естественный. Замкнутые интегралы:

$$I_S^{(n)}(\gamma, \beta) = \int_0^1 \eta^n (1 - \eta^\beta) d\eta = \frac{1}{n+1} - \frac{1}{n+\beta+1}$$

Новый интеграл для 4-го момента:

$$\tilde{I}_S^{(n)}(\gamma, \beta) = \int_0^1 \eta^{n+\beta} (1 - \eta^\beta) d\eta = \frac{1}{n+\beta+1} - \frac{1}{n+2\beta+1}$$

Оба имеют замкнутые формулы.

Если вариант A приводит к плохой обусловленности — перейти к варианту B.

**Проверка:** в плане, после вывода (шаг 3), оценить det(A) 4×4 при типичных параметрах.

**Подводные камни:**
- η^β зависит от β → при дифференцировании по t появится ∂(η^β)/∂β · β̇ = η^β ln(η) · β̇

При замороженных PVT: A_{2,β} — чисто геометрический интеграл.

## Шаг 2: Вывод левой части 4-го уравнения

**Цель:** получить коэффициенты A₄₁, A₄₂, A₄₃, A₄₄ (при ṙ_b, Ṡg_w, β̇, ΔṪ_w).

**Что сделать:**

Вычислить d/dt ∫_{r_w}^{r_b} r·η^β·S_g dr, где S_g = Sg_w(1 − η^β).

Подынтегральное:

$$r \cdot \eta^\beta \cdot S_{g,w}(1 - \eta^\beta)$$

Зависимость от t через: Sg_w(t), β(t), r_b(t) (η зависит от r_b).

По правилу Лейбница:

$$\frac{d}{dt}\int_{r_w}^{r_b} f(r,t)\, dr = \int_{r_w}^{r_b} \frac{\partial f}{\partial t}\, dr + f(r_b, t) \cdot \dot{r}_b$$

Граничный член: при r = r_b: η = 1, S_g(r_b) = 0, поэтому f(r_b) = r_b · 1 · 0 = 0.

Остаётся:

$$\int_{r_w}^{r_b} r \frac{\partial}{\partial t}\left[\eta^\beta S_{g,w}(1 - \eta^\beta)\right] dr$$

Раскрываем:

$$\frac{\partial}{\partial t}[\eta^\beta S_{g,w}(1 - \eta^\beta)] = \eta^\beta (1-\eta^\beta) \dot{S}_{g,w} + S_{g,w} \frac{\partial}{\partial t}[\eta^\beta(1 - \eta^\beta)]$$

Второй член:

$$\frac{\partial}{\partial t}[\eta^\beta(1-\eta^\beta)] = \frac{\partial}{\partial t}[\eta^\beta - \eta^{2\beta}]$$

Производная η^k по t (при фиксированном r):

η = ln(r/r_w)/L_b, где L_b = ln(r_b/r_w). Зависимость η от t — через r_b(t). Зависимость η^β от t — через r_b(t) и β(t):

$$\eta^\beta = \exp(\beta \ln\eta)$$

Дифференцируя:

$$\frac{\partial \eta^\beta}{\partial t} = \eta^\beta \left[\ln\eta \cdot \dot{\beta} - \frac{\beta}{r_b L_b} \dot{r}_b\right]$$

Здесь второй член — от ∂η/∂r_b = −η/(r_b L_b), поэтому ∂(η^β)/∂r_b = β η^{β-1} · (−η/(r_b L_b)) = −β η^β/(r_b L_b).

Аналогично для η^{2β}:

$$\frac{\partial \eta^{2\beta}}{\partial t} = \eta^{2\beta} \left[2\ln\eta \cdot \dot{\beta} - \frac{2\beta}{r_b L_b} \dot{r}_b\right]$$

Собирая все вклады, получим 4 коэффициента.

**Из левой части (∂S_g/∂t):**

$$\frac{\partial}{\partial t}[\eta^\beta(1-\eta^\beta)] = (\eta^\beta - 2\eta^{2\beta})\ln\eta \cdot \dot{\beta} - \frac{\beta}{r_b L_b}(\eta^\beta - 2\eta^{2\beta})\dot{r}_b$$

Полная производная подынтегрального:

$$\frac{\partial}{\partial t}[\eta^\beta S_{g,w}(1-\eta^\beta)] = \eta^\beta(1-\eta^\beta)\dot{S}_{g,w} + S_{g,w}(\eta^\beta - 2\eta^{2\beta})\ln\eta \cdot \dot{\beta} + S_{g,w}\frac{\beta}{r_b L_b}(2\eta^{2\beta} - \eta^\beta)\dot{r}_b$$

**Из правой части** (аналогично A₂₁ и A₂₃, но с весом η^β вместо 1):

- Давление: −∫r η^β S_o(c_r + c_o^{sat})(∂p/∂r_b) dr · ṙ_b → вклад в A₄₁
- Температура: −∫r η^β S_o β_o^{sat} Ψ(ζ) dr · ΔṪ_w → вклад в A₄₄

**Итого:**

- **A₄₁** (при ṙ_b): Sg_w β/(r_b L_b) ∫r(2η^{2β} − η^β) dr − ∫r η^β S_o(c_r + c_o^{sat})(∂p/∂r_b) dr
- **A₄₂** (при Ṡ_{g,w}): ∫r η^β(1 − η^β) dr — **геометрический, > 0**
- **A₄₃** (при β̇): Sg_w ∫r η^β ln(η)(1 − 2η^β) dr — **ключевой новый коэффициент**. Знак: ln η < 0, но (1−2η^β) меняет знак при η = (1/2)^{1/β}. Итоговый знак определяется интегрально; при β = 2 численная проверка показывает A₄₃ < 0 (необходимо подтвердить при выводе)
- **A₄₄** (при ΔṪ_w): −∫r η^β S_o β_o^{sat} Ψ(ζ) dr (аналогично A₂₃ с весом η^β)

**Формулы для записи в tex:**

A₄₂ = ∫_{r_w}^{r_b} r η^β(1 − η^β) dr — замкнутая формула через I̅_S.

A₄₃ = Sg_w ∫_{r_w}^{r_b} r η^β ln(η)(1 − 2η^β) dr — **требует нового интеграла с ln(η)**.

Интегралы с ln(η):

$$\int_0^1 \eta^n \ln\eta\, d\eta = -\frac{1}{(n+1)^2}$$

$$\int_0^1 \eta^{n+\beta} \ln\eta\, d\eta = -\frac{1}{(n+\beta+1)^2}$$

Замкнутые формулы существуют.

**Результат шага:** записанные в tex формулы A₄₁, A₄₂, A₄₃, A₄₄ с указанием знаков и предельных случаев.

## Шаг 3: Вывод правой части F₄

**Цель:** получить F₄ — правую часть 4-го уравнения.

**Что сделать:**

Правая часть уравнения насыщенности (eq:Sg_eq2) содержит дивергентный член:

$$-\frac{B_o}{\phi} \frac{1}{r} \frac{\partial}{\partial r}\left(\frac{r \lambda_o}{B_o} \frac{\partial p}{\partial r}\right)$$

Интегрирование с весом r·η^β:

$$F_4^{(div)} = -\frac{B_o}{\phi} \int_{r_w}^{r_b} \eta^\beta \frac{\partial}{\partial r}\left(\frac{r \lambda_o}{B_o} \frac{\partial p}{\partial r}\right) dr$$

Интегрирование по частям:

$$= -\frac{B_o}{\phi}\left[\eta^\beta \frac{r \lambda_o}{B_o} p'\right]_{r_w}^{r_b} + \frac{B_o}{\phi} \int_{r_w}^{r_b} \frac{d\eta^\beta}{dr} \frac{r \lambda_o}{B_o} p'\, dr$$

Граничные значения: η(r_b) = 1, η(r_w) = 0.

При r = r_b: η^β = 1, это даёт поток на фронте (как в F₂).
При r = r_w: η^β = 0, поток обнуляется — **сингулярность dp/dr при γ < 1 подавлена!**

Это преимущество веса η^β: он зануляет сингулярный поток на r_w.

Объёмный интеграл:

$$\frac{d\eta^\beta}{dr} = \frac{\beta \eta^{\beta-1}}{r L_b}$$

$$F_4^{(vol)} = \frac{B_o}{\phi} \int_{r_w}^{r_b} \frac{\beta \eta^{\beta-1}}{L_b} \frac{\lambda_o}{B_o} p'\, dr$$

С замороженными PVT это сводится к интегралу от η^{β-1+γ-1} = η^{β+γ-2}, который замкнуто вычисляется.

**Результат шага:** формула F₄ в tex.

## Шаг 4: Новые замкнутые интегралы

**Цель:** собрать все новые интегралы, необходимые для A₄ⱼ и F₄, и записать замкнутые формулы.

**Что сделать:**

Список новых интегралов (помимо существующих I_Φ^(n), I_S^(n), J^(m)):

1. **Ĩ_S^(n)(γ, β)** = ∫₀¹ η^{n+β}(1 − η^β) dη = 1/(n+β+1) − 1/(n+2β+1)

2. **K^(n)(β)** = ∫₀¹ η^n ln(η) dη = −1/(n+1)²

3. **K_S^(n)(β)** = ∫₀¹ η^{n+β} ln(η)(1 − 2η^β) dη
   = −1/(n+β+1)² + 2/(n+2β+1)²

4. Интеграл в F₄: при замороженных PVT объёмный член содержит dη^β/dr · (dp/dr) ~ η^{β-1} · η^{γ-1} = η^{β+γ-2}. Интеграл ∫₀¹ η^{β+γ-2} dη = 1/(β+γ-1), сходится при β+γ > 1 (всегда выполняется: β ≥ 1, γ > 0).

Все имеют замкнутые формулы. Записать в tex как дополнение к §5.4.

**Подводные камни:**
- При β+n+1 → 0 (нефизично, β > 0) — деление на ноль. Но β ≥ 1, n ≥ 0, поэтому безопасно.
- K^(n) < 0 (ln η < 0 при η ∈ (0,1)) — проверить знаки A₄₃.
- Якобиан перехода r → η: dr = r L_b dη. Все замкнутые интегралы (Ĩ_S, K, K_S) записаны в переменных η ∈ [0,1]. При переходе от ∫...dr к ∫...dη множитель r·L_b включается в подынтегральное. Это нужно аккуратно отследить при выводе A₄₁ (содержит ∫r·(...)·dr, а не ∫(...)·dη).

## Шаг 5: Предельные случаи и согласованность

**Цель:** проверить, что 4-е уравнение согласовано с существующей системой 3×3.

**Что сделать:**

### 5.1. β = const (β̇ = 0)

4-е уравнение становится алгебраическим: A₄₁ṙ_b + A₄₂Ṡ_{g,w} + A₄₄ΔṪ_w = F₄. Это — дополнительное ограничение на решение 3×3. Проверить: является ли оно следствием 3 существующих уравнений (тождественно выполняется), или это действительно независимое уравнение.

Если оно не является следствием — фиксация β = const означает переопределённую систему. Тогда при β = const нужно отбрасывать 4-ю строку (как сейчас).

### 5.2. Sg_w → 0

A₄₃ ∝ Sg_w → 0. Уравнение для β̇ вырождается. Нужно проверить: остаётся ли β конечным, или уходит в ∞? Физически: если газа нет (Sg_w = 0), β не имеет смысла — форма пустого профиля неопределена. Возможно, нужен clamp: β̇ = 0 при Sg_w < ε.

### 5.3. β → 1

Профиль S_g = Sg_w(1 − η) — линейный. Проверить конечность A₄ⱼ, F₄.

### 5.4. β → ∞

Профиль S_g → Sg_w (плоский, ступенька на r_b). Проверить: Ĩ_S → 0, K_S → 0. Уравнение для β̇ должно стабилизировать β.

### 5.5. Совместимость с A₁₂ = 0, A₃₂ = 0

Существующая 3×3 матрица имеет нули: A₁₂ = 0, A₃₂ = 0 (расщепление). Проверить, есть ли аналогичные нули в 4-й строке/столбце.

## Шаг 7: Оформление в moments_method.tex
