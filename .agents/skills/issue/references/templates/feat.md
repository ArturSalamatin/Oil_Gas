# Шаблоны для новых возможностей (FEAT)

## 1. Тело задачи (`01-issue-body.md`)

```markdown
## Описание
(что добавляется и с какой целью)

## Мотивация
(какую задачу решает, этап плана разработки)

## Физическое и математическое обоснование
(при необходимости – метки уравнений из numerical_solver/doc/problem_statement.tex и ссылки на литературу)

## Предлагаемый API
(новые функции/классы, параметры, значения по умолчанию)

## Зависимости
(FEAT/BUG, которые должны быть завершены ранее)

## Затронутые файлы
| Файл | Строки | Роль |
|---|---|---|
| `path/to/file.py` | L10–L20 | Точки интеграции |

## План реализации
1. **Проектирование** – API, структуры данных, формулы
2. **Реализация** – ядро → тесты → интеграция
3. **Верификация** – модульные тесты + проверка по аналитическим решениям + граничные случаи

## Ветка
`<имя ветки>`

## Связанные issues
(Related: #N)

## Связанные заметки в vault
(wiki-ссылки на заметки)
```

## 2. Комментарий «Контекст при открытии» (`02-comment-open.md`)

```markdown
### Контекст при открытии

- **Ветка:** `<имя ветки>`
- **Коммит:** `<короткий SHA>`
- **Этап плана разработки:** FEAT-NNN (+ зависимости)
- **Формулы:** <список меток уравнений>
- **Модуль:** `<рабочий каталог>/<пакет>/<module>.py`
- **Оценка сложности:** <простой / средний / сложный>
```
