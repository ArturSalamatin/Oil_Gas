# Bruining Van Duijn 2006 — бегущие волны при конечной скорости конденсации пара

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Bruining J., Van Duijn C.J.** Traveling waves in a finite condensation rate model for steam injection. *Computational Geosciences*, 2006, 10(4), 373–387.

## Аннотация
Категория B. В [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] вместе с [[Ben-Omran Green 1978 — композиционная модель с методом подвижных точек]] представляет подход с неравновесным источником, который приводит систему к равновесию. Судя по названию, модель закачки пара с конечной скоростью конденсации исследуется через решения типа бегущей волны. Недостатки подхода, по Salimi et al.: балансы компонентов по фазам и сильно нелинейный источник.

## Потенциал для проекта
Неизотермическая задача с фазовым переходом конечной скорости — ближайший аналог неравновесной дегазации с теплотой фазового перехода. Может пригодиться, если равновесная дегазация ($R_s = R_{s,\text{нас}}$ мгновенно) окажется узким местом модели ПЗП: например, при быстрых сменах $p_{wf}$ или для объяснения запаздывания охлаждения.
