# Пример — это конфиг и README, штатный набор рисунков и проверок даёт команда пакета

Решатель с примерами передаётся заказчику: инженеры и аналитики считают свои сценарии, отдел разработки развивает код ([[FEAT-031]]). Модель запуска «Б» (решение пользователя 2026-10-10): **команда установленного пакета по конфигу**, а не «скопировать папку примера и править» — копии конвейера по отделам не получают исправлений (как BUG-020, BUG-022), с копиями внутри репозитория уже боролись [[DEBT-037]], [[DEBT-046]]. Реализация — [[FEAT-030]] ([[feat-030 run-command-from-config]]).

## Как устроено

```
python -m gpn_multiphase_solver run config.json [--output DIR] [--title T] [--profiles N]
gpn-solver run config.json            # то же, [project.scripts]
```

- `gpn_multiphase_solver/cli.py::main` → `report/pipeline.py::run_case` — тот же штатный набор, что прежде давал `examples/example_runner.run_example`: CSV истории и профилей, рисунки, печать проверок. `run_case` возвращает `CaseResult` с решателем (`main.py` 01–05 больше не собирают второй `Simulator` ради PVT).
- Граница слоёв: `diagnostics/` считает проверки, `io/output.py` рисует на переданных осях, `report/` пишет PNG, печатает и подключает всё к расчёту, `io/figures.py` пишет PNG/SVG/EMF.
- **Побочные эффекты импорта убраны.** `examples/example_runner` при импорте перенастраивал `sys.stdout` в UTF-8 и выбирал режим matplotlib `Agg` — для пакета это недопустимо (сеанс Jupyter пользователя). Теперь это делает только `cli.configure_batch_run()`; её зовут команда и скрипты примеров. Страж — `tests/test_cli.py::test_report_import_has_no_side_effects`.
- Коды возврата: 0 — расчёт завершён; 1 — решатель отказал на шаге (`CaseRunError`, текст решателя, без трассировки; прежние результаты не тронуты — очистка каталога после расчёта); 2 — ошибка аргументов или конфига (`CaseConfigError`, расчёт не начат). Прочие исключения — с трассировкой: она нужна отделу разработки.
- **Вход-книга Excel** (`run книга.xlsx`, [[FEAT-036]]): у книги каталог вывода очищается **до** расчёта, при отказе в нём только `input/` — перевод книги; прежних результатов нет ([[расчёт по книге очищает каталог вывода до перевода — input и результаты от одного запуска]]). Код 2 — также ошибка книги.

## Решения пользователя (2026-10-13)

1. **Параметры примера — в секции `output` конфига**: `title`, `n_profiles`, `steady_state`, `closed_form_overlays`; флаги `--title`, `--profiles` их переопределяют. Почему не флаги: пример воспроизводится «голой» командой, строка в README и ожидания тестов не расходятся с конфигом молча. Тесты проверяют конфиг, а не текст `main.py`.
2. **`steady_state` по умолчанию `false`.** Замкнутое решение (GOR $= R_{s,0}$) и асимптотика температуры — пределы $t \to \infty$ одного режима. В реалистичных сценариях (14, 19–21) стационар не достигнут: сверка показала бы расхождение, не связанное с точностью расчёта. Автоматический выбор по результату отвергнут: у 14 GOR $= 149.2$ при $R_{s,0} = 150$ (0.5 %), а аналитика неприменима из-за $S_g < S_{gc}$ у фронта. Все 23 примера задают поле явно (`test_output_explicit`); с FEAT-036 — кроме 22: листа OUTPUT в книге нет, умолчание `false`.
3. **Каталог вывода очищается целиком (`shutil.rmtree`), как прежде** — плюс узкая защита: если внутри каталога вывода лежит конфиг или его CSV (`--output .` из папки конфига), отказ с кодом 2 до расчёта. Метка каталога и удаление только своих файлов — отклонены. У расчёта по книге (FEAT-036, решение 12) очистка — до расчёта, при отказе в каталоге только `input/`; открытый в другой программе файл ломает очистку после расчёта у конфига — [[DEBT-082]].
4. **EMF — как прежде** (FEAT-026, [[рисунки примеров дублируются в SVG и EMF через Inkscape]]): включён по умолчанию, `GPN_EXAMPLES_EMF=0` выключает; без Inkscape — одно предупреждение, SVG сохраняются (тест и приёмка).
5. **Форма команды** — `python -m … run` и `gpn-solver run`, одна функция `cli.main`; `--output` по умолчанию — `output` рядом с конфигом.
6. **`main.py` остаются у всех 23 примеров.** У 17 без своей логики — обёртка команды без параметров (`sys.exit(main(["run", <config.json>]))`), чтобы привычный запуск `python examples\NN\main.py` и из редактора работал; параметров в ней нет — разойтись с командой нечему (страж `test_thin_main_py_is_command_wrapper` сверяет дерево разбора с образцом). У 01–05 и 18 — собственная часть после `run_case`.

## Что проверено

- Снимок вывода 23 примеров (печать + побайтно `output/`) до переноса, после переноса конвейера (через временную обёртку `run_example` → `run_case`) и после перехода на команду — совпадает (`vault/issues/feat-030/probes/snapshot_examples.py`).
- Приёмка в чистом окружении из колёс без PyPI (`vault/issues/feat-030/probes/clean_env_command.py`): `python -I -m …` и `gpn-solver.exe` из постороннего каталога — файлы побайтно равны снимку, печать тоже; коды 2 на ошибке конфига и на каталоге вывода с конфигом; без Inkscape — одно предупреждение.
