# Uzun Kurtoglu Kazemi 2016 — RTA при многофазном потоке

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Uzun I., Kurtoglu B., Kazemi H.** Multiphase Rate-Transient Analysis in Unconventional Reservoirs: Theory and Application. *SPE Reservoir Evaluation & Engineering*, 2016, 19(04), pp. 553–566.

## Аннотация
Теория и применение RTA для многофазного потока в нетрадиционных коллекторах. Промысловые данные Bakken (North Dakota) используются для верификации. Показано, что Bakken — пример ультранизкопроницаемого коллектора с двухфазным потоком (Black Oil + газ). Al-Rbeawi 2018 использует данные Bakken Well No. 1 из этой работы для валидации.

## Потенциал для проекта
Источник промысловых данных для верификации. Однако Bakken — tight oil с ГРП, геометрия отличается от радиальной ПЗП.
