# 02 — Однофазная фильтрация с эффектом Джоуля–Томсона

## Описание

Тот же расчёт, что и в примере [01](../01_single_phase_no_jt/), с одним
отличием: включён коэффициент Джоуля–Томсона нефти
$\mu_{JT,o} = 4 \times 10^{-7}$ К/Па.

Смысл примера — показать вклад **одного** теплового эффекта в чистом виде.
Всё остальное (геометрия, PVT, ОФП, $p_{wf}$, длительность) не изменилось,
поэтому разница между 01 и 02 — это ровно вклад JT.

Газа по-прежнему нет: $R_{s,0} = 0$, $p_b = -0.18$ МПа, нефть несжимаема.

## Комбинация модулей (комбинация A)

Та же, что в 01. Изменена **одна строка** конфига:

```json
"thermal": {
    "c_p_oil": 2000.0,
    "c_p_gas": 1000.0,
    "mu_JT_oil": 4.0e-7,     ← было 0.0
    "mu_JT_gas": 0.0,
    "L_degas": 0.0
}
```

| Модуль | Класс |
|---|---|
| Сетка | `LogRadialGrid` |
| PVT (гидро) | `StandingFullPVT` |
| ОФП | `CoreyRP` |
| Гидродинамика | `PrototypeHydroAdapter` |
| Энергия | `TridiagEnergySolver` |
| Управление | `PressureControl` |

## Ожидаемое поведение

| Величина | 01 (без JT) | 02 (с JT) | Разница |
|---|---|---|---|
| $q_o$, м³ст/с | $1.9427 \times 10^{-3}$ | $1.9427 \times 10^{-3}$ | **0** |
| $p(r_w)$, МПа | 15.050 | 15.050 | **0** |
| $T(r_w)$ финал, К | 349.71 | **348.32** | $-1.40$ К |
| $S_g$ | 0 | 0 | — |

Два вывода:

1. **Гидродинамика не изменилась вообще.** Это следствие расщепления
   (operator splitting): `HydroSolver` не видит тепловых коэффициентов,
   а `EnergySolver` работает на замороженных $p$, $S_g$, $R_s$.
   Тепловые параметры влияют только на $T$.

2. **JT даёт стационарное охлаждение.** В отличие от адиабатического провала
   из примера 01 (который частично восстанавливается теплопроводностью),
   JT-источник действует постоянно, пока есть градиент давления.
   Порядок оценки: $\Delta T \sim \mu_{JT,o} (p_0 - p_{wf}) = 4 \times 10^{-7} \times 5 \times 10^6 = 2$ К.

Смотреть: `temperature_profiles.png` — сравнить с одноимённым файлом из 01.

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| $\mu_{JT,o}$ | `thermal.mu_JT_oil` | прямо пропорционально усиливает охлаждение |
| $c_{p,o}$ | `thermal.c_p_oil` | тепловая инерция флюида |
| $R_e$ | `geometry.R_ext` | шире область дренирования |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[].dt` | ⚠️ гидродинамика стационарна с 1-го шага |
| `save_every` | `output.save_every` | 1 → 73 шага (0.22 МБ), 6 → 13, 24 → 4 |

Полезный эксперимент: поставить $\mu_{JT,o} = 8 \times 10^{-7}$ и убедиться,
что охлаждение выросло примерно вдвое, а дебит не сдвинулся ни на знак.

### Что требует осторожности — $p_{wf}$

Как и в 01, при $R_{s,0} = 0$ забойное давление можно менять свободно
в диапазоне 1…19 МПа: разгазирования не будет, Newton устойчив.
Обратите внимание: JT-охлаждение растёт с депрессией.

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.

## Запуск

```powershell
cd numerical_solver
.venv\Scripts\python examples\02_single_phase_jt\main.py
```
