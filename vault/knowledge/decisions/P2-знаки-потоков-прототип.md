# P2. Знаки потоков: прототип → наша конвенция

## Наша конвенция (из CLAUDE.md)

**G > 0 = от скважины (рост r).** Единая для всех граней.

## Конвенция прототипа

Прототип определяет потоки через три типа граней:

### Internal (грани f=1..N-1)

```python
dp[i] = p[i] - p[i+1]              # p(ближе к скважине) - p(дальше)
qoi[i] = T * lo * dp[i] * BAR_TO_PA
```

При потоке к скважине: p[i] < p[i+1] → dp < 0 → qoi < 0.
При потоке от скважины: dp > 0 → qoi > 0.

**qoi > 0 = от скважины.** Совпадает с нашей конвенцией.

### Outer (грань f=N)

```python
dpo = p[-1] - p_outer               # p(ближе) - p(дальше)
qoo = To * lo * dpo * BAR_TO_PA
```

Та же структура, что internal. **qoo > 0 = от скважины.** Совпадает.

### Well (грань f=0)

```python
dpw = p[0] - bhp                    # p(дальше от центра) - p(ближе к центру)
qow = tw * lo * dpw * BAR_TO_PA
```

Порядок вычитания **обратный** по сравнению с internal/outer:
- Internal: p(ближе к скважине) - p(дальше от скважины) = p(меньший r) - p(больший r)
- Well: p(больший r) - p(меньший r) = p[0] - bhp

При потоке к скважине: p[0] > bhp → dpw > 0 → qow > 0.

**qow > 0 = к скважине.** Противоположно нашей конвенции.

## Почему это не нарушает схему прототипа

Инверсия знака well-потока **компенсируется** инверсией знака при входе в невязку:

```python
# net_component_outflow:
oil[0]   += qow             # well: плюс (outflow convention)
oil[:-1] += qoi             # internal: плюс к ЛЕВОЙ ячейке
oil[1:]  -= qoi             # internal: минус из ПРАВОЙ ячейки
oil[-1]  += qoo             # outer: плюс (outflow convention)
```

Для ячейки 0 (граничная у скважины):
```
net_outflow[0] = qow + qoi[0]
```

При стационаре net_outflow = 0:
```
qow = -qoi[0]
```

qow > 0, qoi[0] < 0 → qow = |qoi[0]|. Баланс сходится.

Если бы well-поток определялся в той же конвенции, что internal:
```
qow_alt = tw * lo * (bhp - p[0]) * BAR_TO_PA = -qow    (< 0 при добыче)
```
Тогда в net_outflow пришлось бы написать:
```
oil[0] -= qow_alt    (минус отрицательного = плюс = отток)
```
Результат тот же: `oil[0] += qow` ≡ `oil[0] -= (-qow)`.

Две инверсии компенсируют друг друга. Автор прототипа выбрал `qow > 0 = добыча` для удобства интерпретации дебита.

## Правило для Adapter

```python
G_o[0]   = -fluxes['oil_well']         # инверсия: well outflow → поток через грань
G_o[1:N] =  fluxes['oil_internal']     # без инверсии: совпадает с нашей конвенцией
G_o[N]   =  fluxes['oil_outer']        # без инверсии: совпадает

G_g[0]   = -fluxes['gas_component_well']
G_g[1:N] =  fluxes['gas_component_internal']
G_g[N]   =  fluxes['gas_component_outer']

G_free_gas[0]   = -fluxes['free_gas_well']
G_free_gas[1:N] =  fluxes['free_gas_internal']
G_free_gas[N]   =  fluxes['free_gas_outer']
```

## Доказательство корректности: стационар

При стационарном однофазном потоке все G_o[f] должны быть одинаковы (закон сохранения массы компонента).

Из net_outflow прототипа при стационаре (net_outflow[j] = 0 для всех j):
```
Ячейка 0: qow + qoi[0] = 0            → qow = -qoi[0]
Ячейка 1: -qoi[0] + qoi[1] = 0        → qoi[0] = qoi[1]
...
Ячейка N-1: -qoi[N-2] + qoo = 0       → qoi[N-2] = qoo
```

Значит: `qoi[0] = qoi[1] = ... = qoi[N-2] = qoo = -qow`.

В нашей сборке:
```
G_o[0] = -qow = qoi[0]
G_o[1] = qoi[0]
G_o[2] = qoi[1] = qoi[0]
...
G_o[N] = qoo = qoi[0]
```

Все G_o[f] = qoi[0] = const. ✓

Наша невязка: `F[j] = accum + G[j+1] - G[j] = 0 + const - const = 0`. ✓

## Доказательство корректности: дебит

```
q_o_std = -G_o[0] = -(-qow) = qow > 0     (при добыче)
```

Дебит положительный. ✓ Совпадает с `well_rates` прототипа: `oil_sm3_s = qow`.

## Доказательство корректности: баланс масс

Наша формула глобального баланса:
```
Σ_j V[j]·φ·Δ(So/Bo) / dt + G_o[N] - G_o[0] = 0
```

G_o[N] - G_o[0] = qoo - (-qow) = qoo + qow.

Прототип (step_global_balance):
```
Σ(oi1-oi0) + dt*(qow + qoo) = 0
```

Та же формула: `dt * (qow + qoo) = dt * (G_o[N] - G_o[0])`. ✓
