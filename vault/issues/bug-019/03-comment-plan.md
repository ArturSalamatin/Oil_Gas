### План готов (2026-10-03)

**План:** `vault/plans/bug-019 pvt-negative-compressibility-check.md`

**Причина установлена опытом — PVT, а не Ньютон.** Корреляция Стендинга с $B_g$ идеального газа у нефти примера 20 ($R_{s,0} = 500$ м³ст/м³ст — вдвое выше диапазона данных Стендинга, 1425 scf/STB ≈ 254 м³ст/м³ст) даёт отрицательную сжимаемость насыщенной нефти вместе с выделяющимся газом $c_{ot} = (B_g\,dR_s/dp - dB_o/dp)/B_o < 0$ при $p > 34.55$ МПа. В двухфазных ячейках с малой $S_g$ полная сжимаемость отрицательна, уравнение давления — обратное уравнение теплопроводности, якобиан шага вырождается на последовательности $\Delta t$ (…, 167.6, 211.5, 277.4, 382, … с); отказы A-retry ложатся на неё (шаг 168.75 с — в 0.7 % от 167.6 с). Гипотезы issue — излом $k_{ro}$, якобиан, критерий — опровергнуты: якобиан согласован с невязкой, невязка гладкая вдоль направления Ньютона. Штатный пример 20 (30 мД) затронут тем же: суточный шаг проходит, мельчение шага — нет.

Это известное условие согласованности Black Oil: (A3) $B_o' - B_g R_s' \le 0$ у Peszyńska (Transport in Porous Media 63, 2006; Coats, SPE 49774, 1999). ECLIPSE при нарушении выдаёт предупреждение «Negative Compressibility Found», OPM Flow не проверяет.

**Решение пользователя — вариант В:** проверка согласованности PVT при сборке модели, ориентир — коммерческие симуляторы:
- предупреждение, расчёт продолжается (как ECLIPSE);
- проверяются $c_{ot}$, $c_g$, $c_o$ в 30 равноотстоящих точках диапазона давлений задачи, численные производные по той же интерполяции, что у решателя; границы интервала уточняются делением пополам.

**Шаги (9):** подготовка → `pvt/consistency.py` → тесты функций (9) → `factory._warn_negative_compressibility` → замороженный конфиг и тесты фабрики (25) → `eq:c_ot` в `problem_statement.tex` → README примера 20 → полный прогон (1145 → 1179) → vault.

**Проверено до реализации на черновике:** 34 новых теста — passed; быстрый уровень существующих — 918 passed; из конфигов проекта предупреждение получает только пример 20 (и конфиги тестов с его PVT): «от 34.55 до 46.38 МПа».

**Не устраняется:** отказ примера 20 при 10 мД — некорректная постановка, не дефект решателя.

**Новые записи реестра:** DEBT-034 — пример 20 на несогласованной PVT (варианты: согласованная PVT по SPE 109596 или $R_{s,0} \le 351$); DEBT-035 — README 19–21 называют исправленную BUG-018 действующей ошибкой.
