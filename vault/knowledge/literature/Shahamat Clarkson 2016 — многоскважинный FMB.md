# Shahamat Clarkson 2016 — многоскважинный FMB

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Shahamat M.S., Clarkson C.R.** Multi-Well Flowing Material Balance. *SPE*, 2016. SPE 185052-MS.

## Аннотация
Расширение методики текущего материального баланса (Flowing Material Balance) на многоскважинный случай для трёхфазного течения. В документе Краснова используется для апробации (Рис. 2): графики нормированного дебита нефти и газа vs. нормированной накопленной добычи. Краснов отмечает ошибку в формуле D-9 этой работы.

## Потенциал для проекта
Формализм FMB может быть полезен для валидации моделей ПЗП на уровне интегральных характеристик (запасы, среднее давление).
