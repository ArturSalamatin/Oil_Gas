# 08 — Разгазирование: адиабатический эффект + Джоуль–Томсон

## Описание

Двухфазный сценарий с разгазированием: табличные PVT и ОФП,
$R_{s,0} = 30$, $p_{wf} = 8$ МПа. Включены адиабатический эффект и
дросселирование (Джоуль–Томсон); скрытая теплота дегазации выключена
($L = 0$).

## Комбинация модулей (B: Table + Table)

```json
"thermal": {
    "c_p_oil": 2000.0,
    "c_p_gas": 1000.0,
    "mu_JT_oil": -4.0e-7,
    "mu_JT_gas": 4.0e-6,
    "L_degas": 0.0
}
```

Знаки разные. В постановке $\mu_{JT} = (\partial T/\partial p)_h$: у нефти
$\mu_{JT} < 0$ — жидкость при дросселировании греется, у газа
$\mu_{JT} > 0$ — газ охлаждается. Модуль коэффициента газа на порядок
больше, но газа мало ($S_g \le 0.015$), и итог — нагрев.

| Модуль | Класс |
|---|---|
| PVT (гидро) | `TableFullPVT` |
| ОФП | `PrototypeRPAdapter` |
| Гидродинамика | `PrototypeHydroAdapter` |
| Энергия | `TridiagEnergySolver` |

Теплопроводность — 1.5 / 0.14 / 0.04 Вт/(м·К).

## Ожидаемое поведение

| Величина | Значение |
|---|---|
| $T(r_w)$ финал | **353.169 К** — нагрев на 3.2 К |
| $S_g^{max}$ | 0.0147 |
| $R_s^{min}$ | 9.5 м³ст/м³ст |
| $q_o$ финал | $5.876 \times 10^{-3}$ м³ст/с |

Баланс энергии за 3 сут:

| Компонент | Значение, Дж |
|---|---|
| Джоуль–Томсон | $+1.221\times10^{10}$ |
| адиабатика | $-5.579\times10^{9}$ |
| конвекция | $-7.402\times10^{9}$ |
| теплопроводность | $+1.271\times10^{6}$ |
| $\Delta E$ (накопление) | $-7.73\times10^{8}$ |
| относительная невязка | $2.4\times10^{-16}$ |

Нагрев при дросселировании — главный тепловой источник: он вдвое
больше адиабатического охлаждения. Множитель адиабатического члена
$1 + \rho c_p \mu_{JT}$ равен $\alpha T$ фазы (у нефти 0.35), поэтому
адиабатическое охлаждение здесь ослаблено.

Гидродинамика от тепловых параметров не зависит — следствие расщепления:
`HydroSolver` не видит секцию `thermal`.

## Как увеличить газонасыщенность

$S_g^{max} = 1.5\,\%$ — свойство демонстрационной таблицы ОФП:
`relperm.csv` даёт $k_{rg} = 0.01$ уже при $S_g = 0.1$, газ подвижен и
выносится потоком. Заменить `relperm` на модель Кори с крутой кривой:

```json
"relperm": {"model": "corey", "S_or": 0.2, "S_gc": 0.05,
            "n_o": 2.0, "n_g": 3.0, "kro_max": 1.0, "krg_max": 0.3}
```

даст $S_g^{max} = 0.165$ вместо 0.015. Увеличение длительности расчёта и
расширение $R_e$ не помогают: стационар наступает за 8–12 ч.

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| $\mu_{JT,o}$, $\mu_{JT,g}$ | `thermal` | прямо пропорционально меняют член JT |
| $c_{p,o}$, $c_{p,g}$ | `thermal` | тепловая инерция флюида |
| $R_e$ | `geometry.R_ext` | шире область; фронт $r_b$ растёт |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[0].duration` | ⚠️ стационар за 8–12 ч |
| частота записи | `time.history[0].dt_out` | запись раз в `dt_out` на этапе `duration`: 259 200 / 3600 → 72 интервала, 73 шага; `duration` должна делиться на `dt_out` |

Полезный эксперимент: удвоить оба коэффициента $\mu_{JT}$ и проверить, что
член JT в балансе энергии вырос ровно вдвое (он линеен по $\mu_{JT}$), а
$S_g$ и дебит не изменились ни на знак.

### Что требует осторожности — $p_{wf}$

**Сверху:** при $p_{wf} > p_b = 15$ МПа разгазирования не будет.
**Снизу:** табличный PVT устойчив в диапазоне 14…3 МПа; при отказе
Newton помогает увеличение `"max_retries"` в секции `numerics`
(по умолчанию 9).

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.
