# Agarwal 1979 — псевдовремя для реального газа

**Полная ссылка.** Agarwal R.G. Real Gas Pseudo-Time — A New Function for Pressure Buildup Analysis of MHF Gas Wells. *SPE 8279*, 54th Annual Fall Technical Conference and Exhibition of SPE-AIME, Las Vegas, Nevada, Sept. 23–26, 1979.

## Задача

Анализ КПД (buildup) в газовых скважинах с массированным гидроразрывом пласта (MHF) методом type curve matching. Проблема: типовые кривые строятся для жидкостной системы ($\mu c_t = \mathrm{const}$), а в газовой скважине произведение $\mu c_t$ зависит от давления, которое, в свою очередь, зависит от времени. При buildup давление растёт, $\mu c_t$ падает — поэтому при наложении данных buildup на drawdown-кривые возникает систематическая ошибка в определённой длине трещины $x_f$:

- оценка $(\mu c_t)_i$ завышает $x_f$;
- оценка $(\mu c_t)$ при $p_{wf}$ занижает $x_f$;
- среднее давление тоже не даёт удовлетворительного результата (Table 4).

## Метод

### Псевдовремя $t_a(p)$

По аналогии с псевдодавлением $m(p)$ (Al-Hussainy et al., 1966) вводится функция (ур. 10):

$$t_a(p) = \int_{p_0}^{p} \frac{dp}{\mu(p)\,c_t(p)}$$

Если принять линейную связь $p(t)$ на малых интервалах $\Delta t_j$, приближённо (ур. 11):

$$t_a(p) \approx \sum_{j=1}^{n} \frac{\Delta t_j}{(\mu c_t)_j}$$

Практически удобнее вычислять вспомогательный интеграл (ур. 13):

$$I(p) = \int_{p_0}^{p} \frac{dp}{\mu\, c_t}$$

и затем пересчитывает реальное время в псевдовремя (ур. 12): для каждого интервала $\Delta t_j$ с давлением от $p_{j-1}$ до $p_j$ вычисляется приращение $\Delta t_{a,j} = [I(p_j) - I(p_{j-1})] \cdot \Delta t_j / \Delta p_j$. Суммирование приращений даёт $t_a$. Функция $I(p)$ рассчитывается однократно для данного газа и пласта (Table 3, Fig. 9) и используется как «мастер-кривая» для всех скважин в пласте.

### Безразмерное время через $t_a$

$$t_{Dax_f} = \frac{k\, t_a(p)}{\phi\, x_f^2}$$

Произведение $\mu c_t$ уже «поглощено» интегралом, поэтому не входит в определение $t_{Dax_f}$ (ур. 18). Для совместимости с жидкостными типовыми кривыми Agarwal вводит эквивалентное текущее время (ур. 21):

$$t_{\mathrm{eq}} = (\mu c_t)_i \cdot t_a(p)$$

что позволяет наложить buildup-данные на drawdown-кривую.

### Длина трещины

При type curve matching (ур. 22):

$$x_f = \sqrt{\frac{k\,(\mu c_t)_i \cdot t_a(p)}{\phi\,(\mu c_t)_i\, t_{Dax_f}\big|_M}}$$

Замечание автора: если $t_a$ вычислен через $c_g$ вместо $c_t$, то вместо полной пористости $\phi$ следует использовать газовую пористость $\phi S_g$ (стр. 7).

## Результаты

Численное моделирование (симулятор MHF, Table 1): газовый пласт $p_i = 5000$ psi, $k = 0.01$ md, $\phi = 0.07$, $2x_f = 1000$ ft, $F_{cD} = 10$. Два режима расхода (500 и 650 Mcf/D), два уровня давления (Table 4):

| Метод оценки $(\mu c_t)$ | Вычисленная $2x_f$, ft | Отклонение от эталона (1000 ft) |
|---|---|---|
| $(\mu c_t)_i$ | 1370 | +37% |
| $(\mu c_t)$ при $p_{wf}$ | 955 | −4.5% |
| $t_a(p)$ | 1025 | +2.5% |

Использование $t_a(p)$ устраняет систематическую ошибку type curve matching для buildup-данных (Fig. 12). Реальное время закрытия $\Delta t$ составляет лишь ~60% эквивалентного текущего времени (Fig. 11), т.е. для получения информации, эквивалентной 6 суткам работы, КПД нужно проводить ~10 суток.

## Замечания

1. **Приближённость.** Автор подчёркивает, что $t_a(p)$ — приближённая функция (в отличие от $m(p)$, которая точна при допущении $\mu z = f(p)$). Приближение $p(t) \approx \mathrm{linear}$ на малых интервалах — основное допущение. Строгого доказательства корреляции drawdown и buildup через $t_a$ не приводится; аргументация через «наблюдения» (стр. 5: "based on certain observations rather than rigorous mathematical solutions").

2. **Ограничение по $t_p$.** Type curve matching buildup через drawdown-кривые корректен только при $t_p \gg \Delta t$ ($(t_p + \Delta t)/\Delta t \approx 1$). Для коротких $t_p$ необходимы специальные buildup-кривые (Raghavan, Ref. 7).

3. **Однофазная система.** Статья рассматривает только однофазный газ. Двухфазная система (газ + конденсат или нефть + газ) не обсуждается, хотя принцип нормировки $\mu c_t$ в принципе обобщается на эффективные многофазные свойства.

4. **Нотация.** $c_t$ включает $S_g c_g + S_o c_o + S_w c_w + c_f$ (ур. 14), но для газового пласта упрощается до $c_t \approx S_g c_g$ (ур. 15). Обозначение $t_a$ — «apparent» или «pseudo-time»; в нотации проекта аналогом было бы $\tau(p)$.

5. **Связь с PTA.** Метод применён к вертикально-трещинным скважинам (infinite-conductivity и finite-conductivity), но автор указывает на более широкую применимость (радиальные скважины, газоконденсат).

## Значение для проекта

### Прямое применение

Статья решает задачу для однофазного газа, а в проекте — двухфазная система нефть + свободный газ. Но идея нормировки времени на переменный $\mu c_t$ напрямую переносится на двухфазный случай: в уравнении пьезопроводности для многофазной системы эффективная подвижность и сжимаемость зависят от насыщенности (а значит, от давления). Обобщение $t_a(p)$ на двухфазный случай используется в [[Краснов — многофазное псевдодавление и функции источника]] и [[Kamal Pan 2011 — PTA при многофазном потоке]].

### Методологическая ценность

Подход Agarwal — пример «поглощения» нелинейности коэффициентов путём интегральной замены переменной. Та же идея лежит в основе:
- псевдодавления $m(p)$ ([[Al-Hussainy 1966 — псевдодавление для реальных газов]]) — нормировка давления;
- метода интегральных соотношений (method_of_moments_isotermal/) — свёртка по пространству;
- моментов Баренблатта ([[ref_moments_method]]) — интегральное осреднение PDE.

### Ограничения

Для модели ПЗП с уравнением энергии (method_of_moments/two_phase_energy.tex) температура добавляет ещё одну зависимость: $\mu(p,T)$, $c_t(p,T)$. Простая нормировка $t_a(p)$ недостаточна, нужна совместная трансформация по $p$ и $T$.
