Исправлено в плане:
- Проба `run_mains.py` (консоль `main.py` для сверки README) падала после DEBT-059 на подмене строки, которой больше нет. Подмена теперь условная.

- В шаге 5 недоставало строк README 17 «расчёт — около 100 с» и даты замера в сводном README. Номера строк обновлены по `123247a`.
