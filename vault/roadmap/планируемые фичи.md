### FEAT-010: Показатель формы β как ODE-переменная
- **Фаза:** расширение ODE-системы
- **Зависит от:** FEAT-005, FEAT-007
- **Описание:** Перевести показатель формы профиля насыщенности β из фиксированного параметра (β=2) в 4-ю ODE-переменную. Сейчас Sg(r) = Sg,w·(1 − η^β) с фиксированным β. При нестационарных процессах (переключение p_wf, пуск-остановка) три ODE-переменные (r_b, Sg_w, ΔTw) не могут описать перестройку формы профиля — возникают фиктивные затухающие осцилляции, Sg_w уходит в отрицательные значения. Добавление β(t) расширяет пространство допустимых профилей: при росте r_b форма сглаживается (β растёт), при сжатии — обостряется (β падает). Для этого нужен 4-й интегральный момент уравнения массы газа, дающий эволюционное уравнение для β. Система 3×3 → 4×4: (r_b, Sg_w, β, ΔTw).
- **Мотивация:** диагностика 2026-08-01 показала осцилляции r_b (±4 м), Sg_w (до −0.005), ΔTw (0→0.12→0 К) с периодом ~10 000 с при постоянном p_wf. Причина — фиксированная форма β=2 не вмещает перестройку профиля. При циклических граничных условиях проблема усугубится.
- **Формулы:** moments_method.tex — вывести 4-й момент ∫r·η^β·(масс. баланс газа)dr, получить уравнение для β̇; пересчитать I_S^(n) с учётом β(t).
- **Модуль:** `src/profiles/saturation.py` (β → переменная), `src/integrals.py` (I_S^(n)(β)), `src/coefficients.py` (строка 4 матрицы A, элемент F₄), `src/ode_system.py` (4×4), `src/solver.py` (y₀ расширить)
- **Тесты:** при β=const новая система воспроизводит результаты 3×3; β(t) остаётся в [1, ∞); Sg_w ≥ 0 на суточном расчёте; осцилляции подавлены по сравнению с 3×3
- **Блокируется:** FEAT-011 (вывод формул)
- **GitHub:** [#13](https://github.com/ArturSalamatin/Oil_Gas/issues/13)
- **Ветка:** `feat/feat-010/beta-ode-variable`
- **Статус:** 🔴 ОТКРЫТ (заблокирован FEAT-011)

### FEAT-011: Вывод 4-го момента для уравнения на β̇
- **Фаза:** теория (LaTeX)
- **Зависит от:** —
- **Блокирует:** FEAT-010
- **Описание:** Вывести в `moments_method.tex` замкнутую систему уравнений для 4-й ODE-переменной β(t) — показателя формы профиля Sg(r) = Sg,w·(1 − η^β). Нужно: (1) выбрать весовую функцию 4-го момента; (2) проинтегрировать уравнение массы газа с этим весом по двухфазной зоне [r_w, r_b]; (3) получить выражения для A₄₁, A₄₂, A₄₃, A₄₄ и F₄ в терминах существующих интегралов I_Φ, I_S, I_Ψ; (4) при необходимости — новые интегралы; (5) проверить согласованность с существующими 3 уравнениями; (6) предельный случай β=const → 3×3 воспроизводится.
- **Результат:** новая секция в `moments_method.tex` с пронумерованными уравнениями, готовая к реализации в FEAT-010.
- **Ключевые вопросы:**
  - Какая весовая функция оптимальна? Варианты: `r·η^β`, `r·ln(η)·η^β`, `r·(1−η^β)·ln(η)`. Выбор влияет на обусловленность матрицы 4×4.
  - Нужны ли новые замкнутые интегралы, или 4-й момент выражается через существующие I_S^(n)?
  - Поведение при β → ∞ (плоский профиль) и β → 1 (линейный) — корректны ли предельные случаи?
- **Формулы:** moments_method.tex §5 (ODE-система), §4.3 (профиль Sg), §5.4 (интегралы I_S^(n))
- **Модуль:** нет (только LaTeX)
- **Тесты:** нет (только LaTeX, верификация — аналитическая)
- **План:** [[feat-011 beta-moment-derivation]]
- **GitHub:** [#14](https://github.com/ArturSalamatin/Oil_Gas/issues/14)
