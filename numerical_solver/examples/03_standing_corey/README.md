# 03 — Разгазирование: PVT Стендинга + ОФП Кори (комбинация A)

**Начинать отсюда, если лабораторных данных нет** — вся физика задаётся
числами в JSON, внешние файлы не нужны.

## Описание

Первый двухфазный сценарий. Нефть содержит растворённый газ
($R_{s,0} = 50$ м³ст/м³ст), забойное давление 8 МПа — ниже давления
насыщения $p_b = 9.43$ МПа. Возле скважины газ выходит из раствора,
образуется зона двухфазного течения.

Включены все тепловые эффекты: Джоуль–Томсон обеих фаз, скрытая теплота
дегазации, адиабатический член.

## Комбинация модулей (A: Standing + Corey)

| Модуль | Класс | Ключ конфига | Внешние файлы |
|---|---|---|---|
| Сетка | `LogRadialGrid` | `grid.N = 50` | — |
| PVT (гидро) | `StandingFullPVT` | `pvt.model = "standing"` | **нет** |
| ОФП | `CoreyRP` | `relperm.model = "corey"` | **нет** |
| Гидродинамика | `PrototypeHydroAdapter` | (единственный) | — |
| Энергия | `TridiagEnergySolver` | (единственный) | — |
| Управление | `PressureControl` | `control = "pressure"` | — |

Как это задаётся:

```json
"pvt": {"model": "standing", "rho_o_std": 850.0, "rho_g_std": 0.85},
"relperm": {"model": "corey", "S_or": 0.2, "S_gc": 0.05,
            "n_o": 2.0, "n_g": 2.0, "kro_max": 1.0, "krg_max": 0.8}
```

Свойства нефти и газа считаются по корреляциям (Стендинг для $R_s$ и $B_o$,
Беггс–Робинсон для $\mu_o$, Ли–Гонсалес–Икин для $\mu_g$), ОФП — по
аналитическим степенным зависимостям Кори.

## Ключевые параметры

| Параметр | Значение | Смысл |
|---|---|---|
| $R_{s,0}$ | 50 м³ст/м³ст | газосодержание нефти |
| $p_b$ | **9.43 МПа** | давление насыщения (по Стендингу при $R_s = 50$) |
| $p_0$ / $p_{wf}$ | 20 / **8** МПа | депрессия 12 МПа, $p_{wf} < p_b$ → разгазирование |
| $T_0$ | 350 К | |
| $\mu_{JT,o}$ / $\mu_{JT,g}$ | $4\times10^{-7}$ / $-4\times10^{-6}$ К/Па | |
| $L$ | 168000 Дж/кг | скрытая теплота дегазации |
| $\Delta t$ / длительность | 3600 с / 3 суток | |

## Ожидаемое поведение

Эталонные числа (получены прогоном этого конфига):

| Величина | Значение |
|---|---|
| $S_g^{max}$ | 0.0804 |
| $R_s^{min}$ | 42.0 м³ст/м³ст (было 50) |
| $T(r_w)$ финал | 346.22 К (охлаждение на 3.8 К) |
| $q_o$ финал | $1.087 \times 10^{-2}$ м³ст/с |
| фронт разгазирования $r_b$ | ≈ 0.20 м |

Что смотреть:

- `saturation_profiles.png` — газ появляется только у самой скважины,
  фронт около 0.20 м. Дальше $S_g = 0$.
- `temperature_profiles.png` — охлаждение к забою: JT + скрытая теплота.
- `well_rates.png` — $q_g > 0$ (газ пошёл), $q_o$ стабилен.

⚠️ **Сравнение с примером [05](../05_standing_table_rp/).** Пример 05 —
это тот же расчёт с табличной ОФП вместо Кори. Графики температуры и дебитов
у 03 и 05 будут выглядеть **практически одинаково** (разница $T$ — 0.001 К,
дебита — 0.4 %). Это не ошибка и не перепутанные конфиги: разные ОФП
компенсируют разницу насыщенности до одной подвижности
($S_g = 0.080$ при $k_{rg} = 0.00132$ здесь против $S_g = 0.014$
при $k_{rg} = 0.00140$ в 05). Смотреть надо `saturation_profiles.png` —
там разница шестикратная.

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| $R_e$ | `geometry.R_ext` | шире область; фронт $r_b$ растёт |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит; фронт почти не двигается |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[].dt` | ⚠️ гидродинамика выходит на стационар за 8–12 ч, дольше меняется только $T$ |
| `save_every` | `output.save_every` | 1 → 73 шага (0.22 МБ), 6 → 13, 24 → 4 |
| тепловые скаляры | `thermal` | только $T$; гидродинамика не меняется вовсе (расщепление) |
| параметры Кори | `relperm` | сильно влияет на $S_g$, слабо — на $T$ и дебит |

### Что требует осторожности — $p_{wf}$

Самый чувствительный параметр. Ограничения с обеих сторон:

**Сверху:** при $p_{wf} > p_b = 9.43$ МПа разгазирования не будет вообще
($S_g \equiv 0$), расчёт пройдёт без ошибок — сценарий молча станет однофазным.

**Снизу:** Newton может разойтись с
`RuntimeError: HydroSolver не сошёлся после 32 подшагов`.
Граница нерегулярна (проверено на этом конфиге):

| $p_{wf}$, МПа | 8.5 | 8.0 | 7.5 | 7.0 |
|---|---|---|---|---|
| результат | OK | OK | **отказ** | OK |

Лечится добавлением `"dt_integration": 600` в секцию `time`
(вместо 3600) — тогда сходится на всём диапазоне. Подробности — DEBT-007.

Этот эффект специфичен для PVT Стендинга: у табличного PVT
(примеры 04, 06–10) сходимость устойчива в диапазоне 14…3 МПа.

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.
