# Финальные решения (2026-08-25)

## A1. Знак JT-вклада — разрешено

Знаки корректны по определению. Q_JT = Σ ρ·c_p·μ_JT·u·∂p/∂r. Эффект определяется знаком μ_JT:
- Газ: μ_JT < 0 (в обозначениях Шарафутдинова ε₂ = -4.0 К/МПа) → охлаждение при дросселировании
- Нефть: μ_JT > 0 (ε₁ = 0.4 К/МПа) → нагрев при дросселировании

JT-эффект не обязательно охлаждает. Суммарное изменение T зависит от соотношения фаз и знаков μ_JT.

Подробности: [[конвенции-знаков]].

## A2. Правка problem_statement.tex — выполнено

Документ уже исправлен в отдельной сессии. Потоки: G = T·mob·(p_j − p_{j+1}). G > 0 = от скважины. Невязка: F = accum + G[j+1] − G[j]. Дебит: q = −G[0] > 0.

Проверено: забой (p_wf − p_0), контур (p_{N-1} − p_ext), комментарии «потоки отрицательны — приток».

## A3. AnalyticalHydroSolver — аналитические потоки

> Удалён из пакета в DEBT-005. Живёт как тестовый двойник `LogProfileHydroStub` в `numerical_solver/tests/_doubles.py`; описанная ниже арифметика перенесена без изменений.

Заглушка вычисляет всё аналитически:
- p(r) = p_wf + (p_ext − p_wf) · ln(r/r_w) / ln(R_ext/r_w)
- Q_o = const = −2πhk/(μ_o · ln(R_ext/r_w)) · (p_ext − p_wf) для всех граней (< 0, к скважине)
- G_o = Q_o / Bo
- u_o = Q_o / (2πh·r_face)
- Sg = 0, Rs = Rs0, Q_g = 0

Не через fluxes.py — аналитически. Для валидации: точные потоки, без ошибки дискретизации.

## B1. fluxes + граничные условия — решено

fluxes.py получает числовое p_wf (не WellControl). Цепочка: Simulator → WellControl.boundary_pressure() → p_wf → fluxes.compute_fluxes(..., p_wf). Циклической зависимости нет.

Полное состояние на границе (потоки, скорости, насыщенности) восстанавливается как результат решения. WellControl задаёт только **управляющий параметр** (давление или расход), а характеристики потока через забой — следствие.

## B3. Тесты fluxes.py — инвариантность относительно сетки

Задавать характеристики (p, Sg, Rs) на отрезках длины (аналитические профили), а не в ячейках. Результат (например, дебит q_o) не должен зависеть от N при достаточно мелкой сетке. Тест: q_o(N=50) ≈ q_o(N=200) с точностью < 1%.

## B5. Начальное состояние (t=0)

На t=0 — начальные условия. Все производные по времени = 0 (скважина закрыта, пласт в равновесии). Дебит = 0. EnergyResult: все вклады = 0. Это первая запись SimulationHistory.
