# Muskat 1945 — дифференциальный материальный баланс gas drive

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Muskat M.** The Production Histories of Oil Producing Gas-Drive Reservoirs. *J. Applied Phys.*, March 1945, 147–159.

## Аннотация

Предложил дифференциальные уравнения материального баланса (tank model) для прогноза истории добычи пласта при газонапорном режиме (solution gas drive). Уравнения связывают изменение среднего давления с накопленной добычей через PVT-свойства и ОФП, позволяя рассчитать GOR как функцию давления. Raghavan (1976) и Levine–Prats (1961) используют GOR из материального баланса Муската для определения связи $S_o(p)$, необходимой при вычислении многофазного псевдодавления $m(p)$.

## Потенциал для проекта

Дифференциальный материальный баланс Муската — одно из возможных замыкающих соотношений для связи $S_o(p)$ в моделях ПЗП. В моделях М.1–М.2 (simplefied_approaches/cooling_models.tex) может использоваться для алгебраической оценки GOR без решения полной PDE. Ограничение: tank model не учитывает пространственное распределение давления и насыщенности.
