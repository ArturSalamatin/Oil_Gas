# Теплота дегазации следует из $R_s(p,T)$ по Клапейрону и падает с ростом давления насыщения

Удельная теплота дегазации $L$ (`eq:L_def`, `numerical_solver/doc/problem_statement.tex`)
не является независимой константой: она однозначно определяется температурной
зависимостью газосодержания. По корреляциям давления насыщения
$L \approx 125$–$190$ кДж/кг газа при $p_b = 4$–$8$ МПа и $L \approx 35$–$105$ кДж/кг
при $p_b = 15$–$25$ МПа. Значение 168 кДж/кг из литературы согласуется только
с низким давлением насыщения; 275 кДж/кг выше всех оценок.

## 2. Связь $L$ с $R_s(p,T)$

$L = h_g - \bar h_{go}$ — разность удельной энтальпии свободного газа и
парциальной энтальпии растворённого (`eq:L_def`). Равновесие фаз —
равенство химических потенциалов газового компонента
$\mu_g(p,T) = \bar\mu_{go}(p,T,R_s)$. Вдоль кривой насыщения при $R_s = \text{const}$:

$$-s_g\,dT + v_g\,dp = -\bar s_{go}\,dT + \bar v_{go}\,dp, \qquad s_g - \bar s_{go} = L/T,$$

откуда уравнение Клапейрона для растворения:

$$\boxed{L = T\,(v_g - \bar v_{go})\left(\frac{\partial p_b}{\partial T}\right)_{R_s}}$$

В переменных Black Oil ($v_g = B_g/\rho_g^{ст}$,
$\bar v_{go} = (\partial B_o/\partial R_s)_{p,T}/\rho_g^{ст}$):

$$L = \frac{T}{\rho_g^{ст}}\left(B_g - \frac{\partial B_o}{\partial R_s}\right)\left(\frac{\partial p_b}{\partial T}\right)_{R_s}.$$

Допущение: газовая фаза — чистый газовый компонент (то же, что в Black Oil).

Предельные случаи:
- идеальный газ и $\bar v_{go} \ll v_g$ → уравнение Вант-Гоффа
  $L = \dfrac{R T^2}{M_g}\left(\dfrac{\partial \ln p_b}{\partial T}\right)_{R_s}$;
- приближение к критической точке смеси: $v_g \to \bar v_{go}$, $L \to 0$;
- растворимость не зависит от $T$ (закон Генри с постоянным $R$, как у Шарафутдинова):
  $\partial p_b/\partial T = 0$ → $L = 0$. Значение $q = -168$ кДж/кг в такой модели —
  внешний параметр, не согласованный с её же PVT.

Знак: у всех корреляций $\partial p_b/\partial T > 0$ и $v_g > \bar v_{go}$ → $L > 0$,
выделение газа поглощает теплоту (охлаждение).

## 3. Оценки по корреляциям

Скрипт: `vault/knowledge/science/probes/degassing_heat_clapeyron.py`
(запуск с `PYTHONIOENCODING=utf-8`). Нефть 850 кг/м³ст (34.8 °API).
$Z$ — Папай с псевдокритическими параметрами Саттона; $\bar v_{go} = dB_{ob}/dR_s$
по Стендингу. Три уровня: Вант-Гофф ($Z = 1$, $\bar v_{go} = 0$); реальный газ
($\bar v_{go} = 0$); полная формула.

Наблюдения:
- Вант-Гофф почти не зависит от $R_s$, а полная формула падает с ростом $p_b$:
  $\bar v_{go}$ составляет 40–55 % от $v_g$ при $p_b > 15$ МПа. Идеальная оценка
  завышает $L$ в 1.2 раза при 4 МПа и в 2.7–3.3 раза при 22–25 МПа.
- Разброс между корреляциями — до 2.5 раз (Гласо против Стендинга): температурная
  зависимость $p_b$ — наименее надёжная часть корреляций.
- Вдоль пути разгазирования ($p$ и $R_s$ падают вместе) $L$ растёт: при 350 К
  от ≈ 94 кДж/кг при 16.8 МПа до ≈ 168 при 4.3 МПа.

Не учтено: сжимаемость недонасыщенной нефти в $\bar v_{go}$ (добавка
$B_o c_o\,\partial p_b/\partial R_s$, уменьшает $L$ ещё порядка 10 %); погрешность $Z$ по Папаю
(единицы процентов); многокомпонентность газа.

## 4. Значение для проекта

- **168 кДж/кг** ([[baseline-параметры]], [[P6-тепловые-свойства]]) согласуется
  с давлением насыщения статьи Шарафутдинова (7–8.6 МПа → 126–162 кДж/кг по
  таблице 2, $R_s = 40$, 330–370 К). Для больших $p_b$ это завышение.
- **275 кДж/кг** в рассмотренном диапазоне ($T \le 370$ К, $p_b \ge 4$ МПа)
  не достигается ни одной корреляцией даже в приближении Вант-Гоффа при
  $\gamma_g \ge 0.65$.
- В решателе $L$ — скаляр, задаваемый независимо от $R_s$; Стендинг в
  гидродинамике вычисляется при $T = T_0$ ([[pvt-корреляции-стендинг]]),
  табличные PVTO изотермичны. Согласованность $L$ с PVT в коде не обеспечивается.
  Термодинамически согласованное значение — по формуле раздела 2 при
  $T_0$, $\gamma_g$ и характерном давлении зоны разгазирования.
- Пример 14 ([[feat-024 high-gor-cooling-example]]): $R_{s,0} = 150$, $p_b \approx 24$ МПа,
  $T_0 = 350$ К, $\gamma_g \approx 0.69$, задано $L = 168$ кДж/кг. По таблице 2 на кривой
  насыщения $L \approx 65$ кДж/кг, у забоя (давление ниже) — больше. Величина
  охлаждения в примере, вероятно, завышена. Решение не принято — вопрос для обсуждения.
