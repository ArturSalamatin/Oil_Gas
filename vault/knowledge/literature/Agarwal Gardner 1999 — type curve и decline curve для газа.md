# Agarwal Gardner 1999 — type curve и decline curve для газа

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Agarwal R.G., Gardner D.C., Kleinsteiber S.W., Fussell D.D.** Analyzing Well Production Data Using Combined Type-Curve and Decline-Curve Analysis Concepts. *SPE Reservoir Evaluation and Engineering*, October 1999.

## Аннотация
Комбинирование type curve analysis и decline curve analysis для интерпретации промысловых данных газовых скважин. Метод использует псевдовремя и псевдодавление для коррекции нелинейных свойств газа, позволяя оценивать OGIP и продуктивность из данных эксплуатации.

## Потенциал для проекта
Type curve / decline analysis для газовых скважин — аналитический инструмент, потенциально расширяемый на двухфазный случай при разгазировании в ПЗП.
