# Al-Khalifa 1989 — pressure-squared method для многофазного PTA

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Al-Khalifa A.J., Horne R.N., Aziz K.** Multiphase Well Test Analysis: Pressure and Pressure-Squared Methods. *SPE-18803-MS*, 1989.

## Аннотация
Предложен метод нормировки дебита через квадрат давления (pressure-squared approach) для PTA при многофазном потоке как альтернатива псевдодавлению. По утверждению авторов, метод даёт приемлемые оценки фазовых проницаемостей без необходимости знать зависимость $S_o(p)$, которую требует подход Perrine–Martin.

## Потенциал для проекта
Альтернативная нормировка PTA — может быть полезна для верификации интегральных характеристик модели ПЗП.
