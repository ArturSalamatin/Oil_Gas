## Варианты решения

**Вариант A – только скрипт.** `release.py` склеивает строки абзацев (и при желании сам выделяет номер задачи).
- Плюсы: команды не меняются; исправляет и старые, и новые пункты; ~20 строк.
- Минусы: пункт остаётся сплошным абзацем – вторая половина задачи не решена.
- Промежуточные состояния: одно.

**Вариант B – только команда.** `/implement` 4.1 пишет абзацы одной строкой и делит пункт на блоки.
- Плюсы: без кода.
- Минусы: `<br>` возвращается при первом переносе строки (все пункты 1.0.0–1.0.6 и FEAT-040 перенесены – Claude переносит строки по привычке); в одном файле – две формы строк; проверки нет, форма держится на дисциплине.

**Вариант C – комбинированный (выбран, решение пользователя).** Скрипт склеивает строки при сборке `notes.md`, команда задаёт блоки, тест проверяет форму текущего раздела.
- Плюсы: форму задаёт исходный `CHANGELOG.md` – файл, который получает и заказчик (`tools/handover.py`); строки можно переносить как угодно; отступление ловится при `/implement` (4.1, шаг 3), при `/merge` (быстрый уровень) и до публикации выпуска (`selfcheck` дерева метки).
- Минусы: правки в семи файлах, из них два – тексты команд.
- Промежуточные состояния: шаги 1–3 независимы по тестам; шаг 2 обязан перевести FEAT-040 в том же коммите, что и тест формы (иначе тест красный).

Критерии DEBT: diff минимален для двух дефектов; каждый шаг оставляет тесты зелёными; публичный интерфейс пакета не меняется; результат проверяется тестами, а не глазами.

Рассмотрено и отклонено: проверка формы в `preflight` `release.py` (отказ до любых изменений). Самопроверка шага 3 и так останавливает выпуск с откатом, а раздел к выпуску проходит проверку раньше – при `/implement` и `/merge`. Лишняя ветка кода не нужна (правило «сначала самая простая рабочая схема»).

# Заголовок – «#»…«######» и пробел (или конец строки): «#143» в начале
# перенесённой строки – продолжение абзаца, а не заголовок
HEADING_RE = re.compile(r"\s*#{1,6}(\s|$)")
# Начало элемента разметки: пустая строка, заголовок, пункт списка (и
# вложенного), строка таблицы, цитата. Такая строка к предыдущей не клеится
BLOCK_START_RE = re.compile(r"\s*($|#{1,6}(\s|$)|[-*+] |\d+[.)] |\||>)")


def unwrap_paragraphs(text: str) -> str:
    """Строки каждого абзаца и пункта списка – в одну; блоки кода не трогаются (DEBT-086)."""
    # В описании выпуска GitHub отображает перенос строки исходного текста
    # как <br>: пункт журнала, перенесённый по ~76 знаков, рвался посреди фраз
    out: list[str] = []
    fence = False                       # внутри блока кода ```
    for line in text.splitlines():
        s = line.strip()
        if s.startswith("```"):
            fence = not fence
            out.append(line)
            continue
        prev = out[-1].strip() if out else ""
        # Продолжение абзаца: предыдущая строка – текст (не пустая, не
        # заголовок, не ограда кода), текущая не начинает новый элемент
        if (not fence and prev and not prev.startswith("```") and not HEADING_RE.match(prev)
                and not BLOCK_START_RE.match(line)):
            out[-1] = f"{out[-1].rstrip()} {s}"
        else:
            out.append(line)
    return "\n".join(out)


def release_notes(text: str, version: str) -> str:
    """Описание выпуска: раздел «## X.Y.Z — …» журнала со склеенными строками и NOTES_TAIL."""
    notes = unwrap_paragraphs(section_body(text, f"## {version} — "))
    return f"{notes}\n\n{NOTES_TAIL}\n"

def _changelog_format_problems(lines: list) -> list:
    """Нарушения формы пунктов в строках раздела журнала без заголовка «## …»; пусто – форма верна."""
    problems, subsections, labels, prev = [], [], [], ""
    item = None                          # номер строки, с которой начался текущий пункт

    def close_item():
        if item is not None and labels not in CHANGELOG_LABEL_SETS:
            problems.append(f"строка {item}: блоки пункта {labels}, нужны «Было», «Стало» "
                            "и, если изменяются результаты, «Числа» – по порядку")

    for n, line in enumerate(lines, 1):
        plain = CHANGELOG_CODE_SPAN_RE.sub("", line)      # без цитат вывода программ
        if CHANGELOG_EM_DASH in plain:
            problems.append(f"строка {n}: длинное тире (U+2014), нужно «–»")
        if re.search(r"\d,\d", plain):
            problems.append(f"строка {n}: десятичная запятая, нужна точка")
        label = CHANGELOG_LABEL_RE.match(line)
        if line.startswith("#"):
            close_item()
            item = None
            if line not in CHANGELOG_SUBSECTIONS:
                problems.append(f"строка {n}: подраздел {line!r} не из {CHANGELOG_SUBSECTIONS}")
            subsections.append(line)
        elif line.startswith("- "):
            close_item()
            item, labels = n, []
            m = CHANGELOG_ITEM_RE.match(line)
            if m is None:
                problems.append(f"строка {n}: пункт не начинается с «- **<номер задачи или область>.** »")
            elif re.search(r"\d", m[1]) and not CHANGELOG_TASK_ID_RE.fullmatch(m[1]):
                # Цифра в выделении – номер задачи: опечатка «FEAT-40» не должна сойти за область

            if prev:
                problems.append(f"строка {n}: перед пунктом нет пустой строки")
            if not subsections:
                problems.append(f"строка {n}: пункт вне подраздела")
        elif (item is not None and prev and label is not None
