## Контекст

### Что считает $E_{\text{конд}}$

Кондуктивный член баланса энергии накапливается решателем на каждом подшаге (`numerical_solver/gpn_multiphase_solver/energy/balance.py:335-355`):
$$E_{\text{конд}} = \sum_n Q_{T,ext}\,\bigl(T_{ext} - T^{n+1}_{N-1}\bigr)\,\Delta t_n .$$
Потоки через внутренние грани при суммировании по объёму сокращаются. Остаётся только контур: там стоит условие Дирихле $T = T_{ext}$, и по `numerical_solver/gpn_multiphase_solver/factory.py:544` $T_{ext} = T_0$. Проводимость контурной грани $Q_{T,ext} = \text{geom}\cdot\lambda_{\text{eff},N-1} > 0$. Отсюда смысл знака:

- на подшаге: вклад $> 0$ — тепло приходит через контур (ячейка у контура холоднее $T_{ext}$), $< 0$ — уходит (теплее);
- для суммы: знак $E_{\text{конд}}$ — направление **суммарного** потока через контур за расчёт; о знаке $T_{N-1} - T_{ext}$ в каждый момент он ничего не говорит.

Таблица README и `energy_balance.py` выводят `cum_cond[-1]`, то есть значение на конец расчёта.
