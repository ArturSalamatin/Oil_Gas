# Vogel 1968 — IPR для газонапорного режима

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Vogel J.V.** Inflow Performance Relationships for Solution-Gas Drive Wells. *J. Pet. Tech.*, January 1968, p. 83–93.

## Аннотация
Классическая работа, предложившая безразмерную кривую притока (IPR) для скважин при газонапорном режиме (solution gas drive). Кривая Вогеля связывает забойное давление с дебитом через параболическую аппроксимацию и широко используется в инженерной практике. В документе Краснова цитируется в контексте многофазных IPR и их обобщений.

## Потенциал для проекта
Кривая Вогеля — простейшая модель притока при разгазировании, может служить базовой верификацией для наших моделей ПЗП.
