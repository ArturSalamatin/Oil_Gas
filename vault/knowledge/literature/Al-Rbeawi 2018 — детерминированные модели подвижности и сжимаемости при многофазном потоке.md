# Al-Rbeawi 2018 — детерминированные модели подвижности и сжимаемости при многофазном потоке

**Полная ссылка.** Al-Rbeawi S., Owayed J. New Approach for Multiphase-Flow Rate and Pressure Transient Analysis in Hydraulically Fractured Porous Media: Deterministic Models for Reservoir Total Mobility and Compressibility. *SPE-192764-MS*, Abu Dhabi, 12–15 November 2018.

## Задача

Аналитические модели давления и дебита (PTA/RTA) обычно предполагают однофазный поток. При работе ниже давления насыщения — две фазы (нефть + газ), и параметры $c_t(p)$, $M_t(t)$ перестают быть константами. Авторы ставят задачу: построить детерминированные (curve-fitting) модели для суммарной сжимаемости $c_t(p)$ и суммарной подвижности $M_t(t)$ и встроить их в аналитические решения для гидроразрыва.

Система: трёхфазный поток (нефть, газ, вода) в пласте с множественным ГРП. Геометрия — SRV/USRV (стимулированный/нестимулированный объём). Решение в пространстве Лапласа.

## Метод

### Модель сжимаемости

Суммарная сжимаемость флюида разбивается на три функции (Martin 1959, Raghavan 1976):

$$c_t^{(\text{fluid})} = S_o f(C_o) + S_w f(C_w) + S_g f(C_g)$$

где, например, $f(C_o) = -\frac{B_o'}{B_o} + \frac{B_g R_s'}{B_o}$ (Eq. 4).

Каждая функция аппроксимируется степенным curve-fit по PVT-данным Boe et al. 1989. Насыщенности вычисляются тремя способами:
1. Однофазный подход — фиксированные $S_o$, $S_g$, $S_w$
2. Двухфазный — $S_o(p)$ по модели Tabatabaie 2015 (Eq. 17), $S_w = \text{const}$
3. Многофазный — все три $S(p)$ из уравнений Martin 1959 (Eqs. 18–19), требующих ОФП

Итоговая модель (Eq. 20):
$$c_t^{(\text{fluid})} = A \cdot p^{-B}$$

### Модель подвижности

Суммарная подвижность $M_t = \sum_\alpha k_{r\alpha}/\mu_\alpha$ аппроксимируется как функция времени (Eq. 22):
$$M_t = C \cdot t^D$$

### Эквивалентные время и давление

Вводятся безразмерные эквиваленты для многофазного потока через отношения $M_t/c_t$ (Eqs. 24–30), аналогично подходу псевдодавления/псевдовремени, но с регрессионными моделями вместо табуляции.

### Аналитическое решение

Модель Brown et al. 2011 для SRV/USRV (Eq. 32) — решение в пространстве Лапласа, обратное преобразование по Стефесту (Stehfest 1970). Двойная пористость: transient (de Swaan 1976) или PSS (Warren–Root 1963).

Дебит при $p_{wf} = \text{const}$ — через свёртку Дюамеля (Eq. 44). Индекс продуктивности (Eq. 52) — через Babu–Odeh 1988.

## Результаты

- Перепад давления при многофазном потоке **больше**, чем при однофазном (Fig. 19).
- Главное влияние оказывает подвижность $M_t$ (константы $C$, $D$), а не сжимаемость (Fig. 20 vs Fig. 21).
- Режимы течения (билинейный $\propto t^{1/4}$, линейный $\propto t^{1/2}$, PSS) **не меняются** при переходе к многофазному потоку — меняются только амплитуды.
- Стабилизированный индекс продуктивности при многофазном потоке ниже (Fig. 23).
- Время начала PSS не зависит от многофазности.
- Верификация: сопоставление с промысловыми данными Bakken Well No. 1 (Uzun et al. 2016), Table 8, Fig. 31 — "excellent matching".

## Замечания

1. **Curve-fit вместо физики.** Модели $c_t = A p^{-B}$ и $M_t = C t^D$ — чисто эмпирические аппроксимации PVT-данных одного набора (Boe et al. 1989). Авторы утверждают (Conclusion 2), что эти степенные формы универсальны для любых PVT, но не приводят обоснования. Это сильное утверждение, скорее всего несостоятельное при $p \approx p_b$.

2. **Подвижность как функция только времени.** $M_t = C t^D$ подразумевает, что $M_t$ не зависит от пространственной координаты (однородное поле насыщенности). Это противоречит задаче о двухфазной фильтрации, где $S(r,t)$ — пространственно неоднородна, особенно в ПЗП.

3. **Нет уравнения переноса насыщенности.** Насыщенности вычисляются либо как $S = \text{const}$, либо из алгебраических моделей Tabatabaie/Martin, но не из PDE Buckley–Leverett или Mass Balance. Это упрощение приемлемо для integral/average характеристик, но не для пространственных задач.

4. **Геометрия — множественный ГРП.** SRV/USRV + линейный поток. Радиальная геометрия не рассматривается.

5. **Вода.** Трёхфазная система (нефть + газ + вода). В нашем проекте воды нет, поэтому формулы сжимаемости упрощаются: $c_t^{(\text{fluid})} = S_o f(C_o) + S_g f(C_g)$.

6. **Температура.** Полностью изотермический подход. Температурные эффекты (JT, дегазация) не учитываются. PVT-свойства — функции только давления.

7. **Верификация — одна скважина.** Bakken Well No. 1 — единственный пример. "Excellent matching" — субъективная оценка без метрик.

8. **Сравнение с подходом автомодельной $S(p)$.** [[Краснов — многофазное псевдодавление и функции источника]] использует автомодельную связь $S(p)$ для замыкания псевдодавления — физически обоснованный переход от $S(r,t)$ к $S(p)$. Al-Rbeawi заменяет пространственное описание насыщенности на эмпирическую $M_t(t)$ — curve-fit без физического обоснования. Оба подхода элиминируют пространственную неоднородность, но Краснов сохраняет связь с PVT через $S(p)$, а Al-Rbeawi — нет.

## Значение для проекта

### Что можно взять

- **Разложение $c_t$ на компоненты** (Eqs. 3–6) — полезно для контроля вклада каждой фазы в суммарную сжимаемость. В нашей двухфазной системе (без воды) это упрощается и может быть использовано для оценок в моделях М.1–М.2 из [[cooling_models.tex]].

- **Наблюдение, что $M_t$ важнее $c_t$.** Практически полезно: при построении упрощённых моделей ПЗП можно в первом приближении считать $c_t \approx \text{const}$, но подвижность — обязательно переменная.

- **Формулы режимов течения** (Eqs. 54–79) для билинейного и линейного потока содержат явные выражения с $M_t$ и $c_t$ — могут служить асимптотическими проверками численных решений.

### Что неприменимо

- Геометрия SRV/USRV и множественный ГРП — наш проект работает с радиальной геометрией ПЗП.
- Степенные curve-fit модели $M_t(t)$ — для пространственной задачи нужна локальная $M_t(S(r,t))$.
- Изотермический подход — наш проект решает уравнение энергии.

### Открытые вопросы

- Как соотносятся integral-average подвижности Al-Rbeawi с моментами Баренблатта из [[ref_moments_method]]? В обоих подходах PDE заменяется ODE/алгебраическими замыканиями, но физическое обоснование разное.
- [[Хасанов 2010 — приток при разгазировании]] решает задачу притока при разгазировании в **радиальной** геометрии — прямой контраст с линейной геометрией Al-Rbeawi. Сопоставление результатов по влиянию $M_t$ на дебит было бы полезно для модели ПЗП.
