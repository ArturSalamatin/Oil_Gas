**SPE-202436-MS** — Samuel & Muggeridge (2020), Imperial College London.
"Fast Modelling of Gas Reservoirs Using POD-RBF Non-Intrusive Reduced Order Modelling."

Data-driven reduced order model (NIROM): POD снэпшотов + RBF-интерполяция.
Обучается на ~10 прогонах коммерческого симулятора, физику не использует.
Применён к газовым пластам (синтетический, Norne, конус обводнения).

Ключевые результаты:
- Ускорение 10–280x при точности >99% для постоянных режимов (rate/BHP).
- Плохо работает при нестационарных режимах (varying rate/BHP) — Figure 20.
- Насыщенность требует больше POD-базисных функций, чем давление.

**Связь с проектом:** контрастный пример к [[ref-moments-method]]. NIROM — data-driven редукция, метод моментов — physics-based (PDE → ODE через интегральные соотношения Баренблатта). Провал NIROM при переменных режимах — аргумент в пользу physics-based подхода для задачи разгазирования в ПЗП, где режим принципиально нестационарен.
