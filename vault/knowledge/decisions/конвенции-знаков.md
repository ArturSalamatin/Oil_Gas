# Конвенции знаков

## Главное правило

**Положительное направление — от скважины, в сторону роста радиальной координаты r.**

Это относится ко ВСЕМ величинам: скорости u, расходы фаз Q, потоки компонентов G, конвективные коэффициенты Φ, потоки энергии F_conv, кондуктивные потоки Q_cond.

## Скорость Дарси u

```
u_α = −(k·kr_α/μ_α) · ∂p/∂r = −Λ_α · ∂p/∂r
```

| Ситуация | dp/dr | u | Смысл |
|---|---|---|---|
| Типичный поток к скважине | > 0 | < 0 | жидкость движется к скважине |
| Поток от скважины (нагнетание) | < 0 | > 0 | жидкость движется от скважины |

## Расходы фаз Q (дискретные, на гранях)

```
Q_α[f] = −T_f · (kr_α/μ_α)_up · (p[f] − p[f-1])
```

Знак «−» обеспечивает: Q > 0 → поток от скважины (рост r).

Эквивалентная запись:
```
Q_α[f] = T_f · (kr_α/μ_α)_up · (p[f-1] − p[f])
```

| Ситуация | p[f-1] vs p[f] | Q | Смысл |
|---|---|---|---|
| Типичный поток к скважине | p[f-1] < p[f] | < 0 | фаза течёт к скважине |
| Поток от скважины | p[f-1] > p[f] | > 0 | фаза течёт от скважины |

## Потоки компонентов G (дискретные, на гранях)

```
G_o[f] = T_f · (kro/(μo·Bo))_up · (p[f-1] − p[f])
G_g[f] = T_f · [Rs_up·(kro/(μo·Bo))_up + (krg/(μg·Bg))_up] · (p[f-1] − p[f])
```

Знак тот же, что у Q: **G > 0 → от скважины**.

При типичном потоке к скважине: G < 0.

## Конвективный коэффициент Φ

```
Φ_α[f] = ρ_α_up · c_{p,α} · Q_α[f]
```

Знак определяется знаком Q: **Φ > 0 → от скважины, Φ < 0 → к скважине**.

Upstream-разделение: Φ⁺ = max(Φ, 0) ≥ 0, Φ⁻ = min(Φ, 0) ≤ 0.

## Невязки гидродинамики

Невязка баланса нефтяного компонента для ячейки j:

```
F_oil[j] = V[j]·φ · ((1-Sg[j])/Bo[j] − (1-Sg_prev[j])/Bo_prev[j]) / dt
           + G_o[j] − G_o[j+1]
```

**Знак «+» перед G[j] и «−» перед G[j+1]:**
- G_o[j] — поток через левую грань. G[j] > 0 → поток наружу через левую грань → **отток** из ячейки → вклад > 0 в невязку.
- G_o[j+1] — поток через правую грань. G[j+1] > 0 → поток наружу через правую грань → **отток** из ячейки → вклад с «−» (знак уже в формуле).

Нет! Пересмотрим. Уравнение неразрывности в интегральной форме:
```
∂/∂t (масса в ячейке) + (поток_наружу_правая − поток_наружу_левая) = 0
```

Поток наружу = поток в направлении роста r = G (при нашей конвенции G > 0 = наружу). Тогда:
```
accum + G[j+1] − G[j] = 0
```

Но G[j] — поток через левую грань ячейки j, направленный наружу (вправо). Это «приток» в ячейку j через левую грань? Нет: G[j] > 0 означает поток вправо (от скважины), т.е. через грань j поток идёт **в ячейку j** (грань j — левая грань ячейки j, поток вправо = внутрь ячейки). А G[j+1] > 0 — поток вправо через правую грань = **из ячейки j**.

Итого:
- G[j] > 0 → приток в ячейку j (через левую грань)
- G[j+1] > 0 → отток из ячейки j (через правую грань)
- Баланс: accum + отток − приток = accum + G[j+1] − G[j] = 0

```
F_oil[j] = V[j]·φ · Δ(So/Bo)/dt + G_o[j+1] − G_o[j]
```

**Это та же формула, что в problem_statement.tex** (eq. 14), с той же структурой `+ (G_right − G_left)`. Поменялся только знак самих G (теперь G < 0 при типичном потоке), но структура невязки та же.

Проверка стационара: G_o[f] = const < 0 для всех f. G_o[j+1] − G_o[j] = 0. F = 0. ✓

Невязка баланса газового компонента — аналогично:
```
F_gas[j] = V[j]·φ · Δ(Rs·So/Bo + Sg/Bg)/dt + G_g[j+1] − G_g[j]
```

## Граничные потоки

### Забой (грань f=0)

```
G_o[0] = T_well · (kro/(μo·Bo))_0 · (p_wf − p[0])
```

При типичном потоке: p_wf < p[0] → p_wf − p[0] < 0 → **G_o[0] < 0** (поток к скважине). ✓

Дебит скважины (положительное число):
```
q_o_std = −G_o[0] > 0
```

### Контур (грань f=N)

```
G_o[N] = T_ext · (kro/(μo·Bo))_{N-1} · (p[N-1] − p_ext)
```

При типичном потоке: p[N-1] < p_ext → p[N-1] − p_ext < 0 → **G_o[N] < 0** (поток к скважине, т.е. жидкость **входит** в область). ✓

## Upstream-правило (с учётом новой конвенции)

Для грани f между ячейками f-1 и f:

```
Если p[f-1] > p[f]  (G > 0, поток от скважины, нетипично):
    upstream = ячейка f-1 (откуда течёт)

Если p[f-1] < p[f]  (G < 0, поток к скважине, типично):
    upstream = ячейка f (откуда течёт)
```

Правило: upstream = ячейка с **бо́льшим давлением**.

## Источники в уравнении энергии

### Q_ad — адиабатический эффект

```
Q_ad[j] = φ · Σ_α S_α[j] · (1 + ρ_α·c_{p,α}·μ_{JT,α}) · (p[j]^{n+1} − p[j]^n) / dt
```

| Δp | μ_JT (типичный) | Скобка | Q_ad | Эффект |
|---|---|---|---|---|
| < 0 (снижение p) | < 0 | > 0 | < 0 | **охлаждение** |

### J_jt — эффект Джоуля-Томсона

```
J_face[f] = Σ_α μ_{JT,α}^{up} · Φ_α[f] · p_up
```

Нужно аккуратнее: `<Φ_α · p>_f` — upstream-оператор. При потоке к скважине Φ < 0, μ_JT < 0. Произведение μ_JT · Φ > 0. Умножение на p > 0 → J_face > 0.

J_jt[j] = J_face[j+1] − J_face[j]. При потоке к скважине J_face убывает от контура к скважине (p и |Φ| убывают) → J_face[j+1] > J_face[j] → J_jt > 0.

Но это нагрев? Нет — нужно учесть знак Φ корректно. Разберём:

```
Φ_α < 0 (типично, к скважине)
<Φ_α · p>_f = Φ_α^+ · p[f-1] + Φ_α^- · p[f]
            = 0 · p[f-1] + Φ_α · p[f]    (Φ < 0 → Φ^+ = 0, Φ^- = Φ)
            = Φ_α · p[f]
```

J_face[f] = μ_JT · Φ_α · p[f]. μ_JT < 0, Φ < 0, p > 0 → J_face > 0.

J_jt[j] = J_face[j+1] − J_face[j] = μ_JT · Φ · (p[j+1] − p[j]).

При dp/dr > 0: p[j+1] > p[j], μ_JT·Φ > 0 → J_jt > 0. В правой части d[j]: это **увеличивает** T? Это неправильно — JT должен охлаждать.

Проблема: upstream-оператор `<Φ·p>` раскрывается по-разному в зависимости от знака Φ. При Φ < 0 upstream берёт p из ячейки f (правая, выше по давлению). Нужно проверить полную формулу из problem_statement.tex.

Вернёмся к eq. 28: `J_{j+1/2} = Σ_α μ_{JT,α}^{up} · <Φ_α · p>_{j+1/2}`.

В уравнении энергии (eq. 32) JT-вклад стоит в **правой** части: `= ... + J_j + ...`. Если J_j > 0, то T увеличивается. Но JT должен охлаждать.

Нужно проверить это по документу более аккуратно. Возможно, знак J_jt зависит от соотношения p на разных гранях не так тривиально.

**Вывод:** знаки источников JT и адиабатики при новой конвенции потоков требуют отдельной тщательной проверки. Эту проверку нужно сделать вместе с правкой problem_statement.tex.

## Все величины, которые хранятся

HydroResult:
- `G_o[N+1]` — потоки нефтяного компонента, м³ст/с
- `G_g[N+1]` — потоки газового компонента, м³ст/с
- `Q_o[N+1]` — расходы нефтяной фазы, м³пл/с
- `Q_g[N+1]` — расходы газовой фазы, м³пл/с
- `u_o[N+1]` — скорости фильтрации нефти, м/с
- `u_g[N+1]` — скорости фильтрации газа, м/с

Все хранятся. Связь: `u_α = Q_α / (2π·h·r_face)`.

WellData (на каждом шаге истории):
- `q_o_std = −G_o[0]` — дебит нефти, м³ст/с (> 0 при добыче)
- `q_g_std = −G_g[0]` — дебит газа, м³ст/с
- `m_o = ρ_o_ст · q_o_std` — массовый дебит нефти, кг/с
- `m_g = ρ_g_ст · q_g_std` — массовый дебит газа, кг/с

## Тест-проверки

1. При типичном потоке: u < 0, Q < 0, G < 0, Φ < 0 — все отрицательные
2. Дебит q = −G_o[0] > 0
3. Стационар: F_oil = F_gas = 0
4. Баланс масс: Σ(V·φ·Δ(So/Bo)) = dt·(G_o[0] − G_o[N])
5. Охлаждение: T(r_w) < T0 при снижении p
