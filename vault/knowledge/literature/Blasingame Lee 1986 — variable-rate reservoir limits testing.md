# Blasingame Lee 1986 — variable-rate reservoir limits testing

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Blasingame T.A., Lee W.J.** Variable-Rate Reservoir Limits Testing. *SPE 15028*, Permian Basin Oil and Gas Recovery Conference, Midland, TX, March 13–14, 1986.

## Аннотация
Вывод уравнения pseudo-steady-state (PSS) для газовых пластов при переменном дебите. Уравнение PSS с коррекцией на свойства газа через псевдодавление и псевдовремя — базовая формула большинства методов modern production decline analysis. Anderson & Mattar (2005) используют это уравнение (ур. 2) как отправную точку для модификации псевдовремени при транзиентном потоке.

## Потенциал для проекта
Формула PSS при переменном дебите — потенциальная основа для аналитических оценок производительности скважины при разгазировании, если удастся обобщить псевдовремя на двухфазный случай (нефть + свободный газ).
