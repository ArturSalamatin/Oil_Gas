# Perrine 1956 — PTA при многофазном потоке

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Perrine R.L.** Analysis of Pressure Buildup Curves. *API Drilling and Production Practice*, 1956, 482–509.

## Аннотация

Предложил заменить однофазную подвижность $k/\mu$ на суммарную подвижность $\lambda_t = \sum_\alpha k_{r\alpha}/\mu_\alpha$ при анализе кривых восстановления давления (КВД) в условиях многофазного потока. Развил концепцию расчёта эффективной проницаемости отдельных фаз из наклона полулогарифмической прямой IARF. Метод Perrine–Martin остаётся стандартом в коммерческом ПО для PTA, хотя даёт «эквивалентную» проницаемость без физического смысла и некорректный скин-фактор при двухфазном потоке.

## Потенциал для проекта

Базовый подход к PTA при двухфазном потоке. Для верификации модели ПЗП (сравнение модельных КВД с промысловыми) необходимо учитывать ограничения Perrine–Martin: невозможность восстановить абсолютную проницаемость и насыщенности.
