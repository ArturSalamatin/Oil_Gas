# Lake 1989 — методы увеличения нефтеотдачи

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Lake L.W.** Enhanced Oil Recovery. Prentice Hall, Englewood Cliffs, 1989.

## Аннотация
Категория C. Монография по методам увеличения нефтеотдачи (закачка газа, химические и тепловые методы). В [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] цитируется трижды. Первый раз — как источник систем уравнений для однофазных и двухфазных зон. Второй — как обоснование упрощения уравнения энергии: работа давления отбрасывается, внутренняя энергия заменяется энтальпией. Третий — как источник теории дробного потока, расширением которой является метод волновых кривых.

## Потенциал для проекта
Упрощение $U \approx H$ из этой книги в нашей задаче неприменимо: оно убирает адиабатический член и, вместе с $H = C_pT$, эффект Джоуля–Томсона — ключевые эффекты модели ПЗП. Полезно знать, откуда это упрощение, при сравнении с термическими моделями из литературы по закачке пара и CO₂.
