# Dykstra 1961 — build-up для газоконденсата

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Dykstra H.** Calculated Pressure Build-up for a Low Permeability Gas-Condensate Well. *J. Pet. Tech.*, 1961, 1131.

## Аннотация

Конечно-разностные решения для КВД низкопроницаемой газоконденсатной скважины. Моделируется переменный расход (квадратично убывающий от 6556 до 2500 Mcf/D за 50 дней), $k=0.25$ мД, $h=179$ фут, $p_i=6150$ psi. Al-Hussainy 1966 использует эти решения как наиболее жёсткий тест суперпозиции линеаризованных решений (Fig. 9–10): ошибка суперпозиции при добыче — 0.9%, при build-up — наклон совпадает, абсолютная ошибка ~60 psi (~1.1%).

## Потенциал для проекта

Режим с переменным расходом и низкой проницаемостью — прямой аналог условий ПЗП при разгазировании, где расход меняется из-за изменения подвижности.
