# Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации

**Полная ссылка.** Salimi H., Wolf K.-H., Bruining J. Negative Saturation Approach for Non-Isothermal Compositional Two-Phase Flow Simulations. *Transport in Porous Media*, 2012, 91, 391–422. DOI 10.1007/s11242-011-9851-5. Опубликована онлайн 23.09.2011 (отсюда имя файла `Refs/salimi2011.pdf`).

## Задача

Неизотермическая двухфазная (жидкость l + газ g) фильтрация смеси из $N_c$ компонентов с появлением и исчезновением фаз. Пример — закачка холодной смеси CO₂–вода в горячий геотермальный пласт. Здесь «газ» — богатая CO₂ фаза (переохлаждённая или сверхкритическая), «жидкость» — водная фаза. Солёность не учитывается.

Двухфазная система (§2.1):
- баланс компонента (3): $\partial_t\big(\varphi\sum_\alpha x_{i\alpha}\rho_\alpha S_\alpha\big) + \nabla\cdot\sum_\alpha x_{i\alpha}\rho_\alpha\mathbf u_\alpha = 0$, $\rho_\alpha$ — **мольная** плотность;
- закон Дарси (4) с массовой плотностью $\xi_\alpha$ в гравитационном члене; капиллярное давление (5);
- уравнение энергии (6):
$$\partial_t\Big(\varphi\sum_\alpha \rho_\alpha S_\alpha H_\alpha + (1-\varphi)\rho_s C_s T\Big) + \nabla\cdot\sum_\alpha\rho_\alpha\mathbf u_\alpha H_\alpha - \nabla\cdot(k_T\nabla T) = 0, \qquad H_\alpha = C_{p\alpha}T;$$
- равенство фугитивностей (8), полная мольная переменная $F = \rho_l S_l + \rho_g S_g$ (9), доли фаз $L$, $V$ (10), полный состав $z_i$ (11)–(13).

Однофазная система (§2.2) — уравнения (14), (15): те же балансы в одной фазе, $k_r = 1$.

Упрощения уравнения энергии, принятые явно: кинетическая и потенциальная энергия не учитываются; работа давления отброшена, внутренняя энергия заменена энтальпией (со ссылкой на [[Lake 1989 — методы увеличения нефтеотдачи]]); энергия смешения не учитывается. Теплоёмкость фазы — сумма мольных теплоёмкостей компонентов (40)–(41).

## Метод

**Стандартная техника** (§3, по [[Chen Huan Ma 2006 — вычислительные методы многофазной фильтрации]]). Первичные неизвестные зависят от фазового состояния ячейки. В двухфазной ячейке это $(P, S_g, T, z_1, \dots, z_{N_c-2})$, в однофазной — $(P, T, z_1, \dots, z_{N_c-1})$. Число неизвестных в обоих случаях $N_c + 1$ (правило фаз Гиббса). На каждой ячейке нужны тест устойчивости, флэш-расчёт с переключением статуса и неявный флэш внутри итераций Ньютона. Недостатки, по авторам: дорогие тесты и неоднозначность переключения, когда тесты одновременно предлагают переход в обе стороны.

**Четыре подхода к появлению и исчезновению фаз** (введение):

| Подход | Работы | Суть и недостаток, по авторам |
|---|---|---|
| 1. Переключение переменных | Bonnerot, Jamet 1981; Pruess 2004; Zhu et al. 2004; [[Chen Huan Ma 2006 — вычислительные методы многофазной фильтрации]]; Bruining, Marchesin 2007 | громоздкая логика; ячейка на итерациях Ньютона прыгает между состояниями |
| 2. Неравновесный источник | [[Ben-Omran Green 1978 — композиционная модель с методом подвижных точек]]; [[Bruining Van Duijn 2006 — бегущие волны при конечной скорости конденсации пара]] | балансы компонентов по фазам — число уравнений почти удваивается; сильно нелинейный источник |
| 3. Параметризация композиционного пространства | [[Voskov Tchelepi 2009 — параметризация композиционного пространства]]; [[Voskov 2010 — набор переменных на основе параметризации композиционного пространства]] | интерполированные продолженные коноды; дополнительное уравнение для плотности в однофазной зоне |
| 4. Отрицательные насыщенности | [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]]; [[Panfilov Rasoulzadeh 2010 — отрицательные насыщенности с диффузией и капиллярностью]] | только изотермическая постановка |

**Фиктивная двухфазная система** (§4, ур. (16)–(19)). Величины со «шляпкой» определены и в однофазной, и в двухфазной зоне; температура — без шляпки:
$$\partial_t\Big(\varphi\big(\hat x_{ig}\hat\rho_g\hat S_g + \hat x_{il}\hat\rho_l(1-\hat S_g)\big)\Big) + \nabla\cdot\big(\hat x_{ig}\hat\rho_g\hat{\mathbf u}_g + \hat x_{il}\hat\rho_l\hat{\mathbf u}_l\big) = 0, \tag{16}$$
$$\partial_t\Big(\varphi T\big(\hat\rho_g\hat S_g\hat C_{pg} + \hat\rho_l(1-\hat S_g)\hat C_{pl}\big) + (1-\varphi)\rho_s C_s T\Big) + \nabla\cdot\Big(T\big(\hat\rho_g\hat{\mathbf u}_g\hat C_{pg} + \hat\rho_l\hat{\mathbf u}_l\hat C_{pl}\big)\Big) - \nabla\cdot(k_T\nabla T) = 0. \tag{19}$$

**Условия эквивалентности для недонасыщенной жидкости** (§4.1.1, $\hat S_g < 0$). Выведены из трёх требований: равенство полной мольной плотности (20), полного состава (22) и потока каждого компонента (23):

| Величина | Условие | Ур. |
|---|---|---|
| плотности мнимых фаз | $\hat\rho_g = \hat\rho_l = \rho_l$ | (21) |
| вязкости | $\hat\mu_g = \hat\mu_l = \mu_l$ | (24) |
| давления | $\hat P_g = \hat P_l = P_l$, то есть $P_c \equiv 0$ | (25) |
| массовые плотности (гравитация) | $\hat\xi_g = \hat\xi_l = \xi_l$ | (26) |
| ОФП | $\hat k_{rg} = \hat S_g$, $\hat k_{rl} = 1 - \hat S_g$ | (27) |
| составы фаз | равновесные при $P_c = 0$, то есть отрицательный флэш ([[Whitson Michelsen 1989 — отрицательный флэш-расчёт]]) | (28) |
| **теплоёмкости** | $\hat C_{pg} = \hat C_{pl} = C_{pl}$ | **(29)** |

Условие (29) — единственное новое по сравнению с [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]]: обе мнимые фазы несут теплоёмкость истинной однофазной жидкости. Авторы пишут, что ранее оно не выводилось. Расширенная насыщенность из (22) — ур. (30):
$$\hat S_g = \frac{z_i - \hat x_{il}}{\hat x_{ig} - \hat x_{il}}, \quad i = 1, \dots, N_c.$$
Знак $\hat S_g < 0$ обоснован для лёгких ($x_{ig}/x_{il} > 1$) и тяжёлых компонентов отдельно (с. 401). Для пересыщенного газа (§4.1.2, $\hat S_g > 1$) условия (31)–(37) симметричны: все свойства мнимых фаз равны свойствам газа, $\hat C_{pg} = \hat C_{pl} = C_{pg}$ (36). Истинная насыщенность — $\operatorname{clip}(\hat S_g, 0, 1)$.

Заявленное преимущество перед подходом 3 (с. 402): $z_i$ вычисляется из $\hat S_g$ и $\hat x_{i\alpha}$ по (22) без плотности, и дополнительное уравнение с неизвестной $L$ или $V$ не нужно.

## Результаты

**Численная модель** (§5.2). 1D, горизонтальный пласт 1500 × 1500 × 100 м, 2000 ячеек. Неявная схема конечных объёмов «против потока» с узлами в вершинах, совместное решение методом Ньютона. Давление постоянно (200 бар) — проницаемость принята настолько высокой, что перепад давления от течения пренебрежим. Суммарная скорость Дарси $u$ — первичная неизвестная. Капиллярное давление, гравитация, диффузия и теплопотери в кровлю и подошву не учитываются; продольная теплопроводность учитывается. Термодинамика: уравнение состояния Пенга–Робинсона–Стрыжека–Веры с правилом смешения Хурона–Видаля второго порядка и моделью NRTL, поправка объёма (по [[Wahanik 2010 — аналитические решения для закачки CO₂ с водой в геотермальный пласт]]). Вязкости зависят только от $T$ (38)–(39). Таблица 1: $T_0 = 353.15$ К, $T_{\text{зак}} = 293.15$ К, $\varphi = 0.2$, $k = 100$ мД, $k_T = 2.1$ Вт/(м·К), $k_{rl} = (1-S_g)^4$, $k_{rg} = S_g^2(1-(1-S_g)^2)$, остаточные насыщенности нулевые.

**Проверка по аналитическому решению** (§5.3, рис. 1). Решение методом волновых кривых из [[Wahanik 2010 — аналитические решения для закачки CO₂ с водой в геотермальный пласт]]: 100 бар, 358 К, $T_{\text{зак}} = 298$ К, $z_{\text{CO}_2} = 0.29$, $k_{rg} = 0.95S_g^2$, $k_{rl} = 0.5(1-S_g)^2$. Последовательность волн: скачок Бакли–Леверетта, тепловая волна, волна разрежения Бакли–Леверетта, композиционный скачок. Совпадение «отличное» — только визуально, в плоскости $(T, S_g)$. Тепловая волна численного решения заметно размыта.

**Семь вариантов** по мольной доле CO₂ в закачке (§5.4–5.10):

| Вариант | $z_{\text{CO}_2}^{\text{зак}}$ | Картина |
|---|---|---|
| 1 | 0.01 | всюду однофазная водная зона, $\hat S_g \in [-0.028, -0.01]$ (рис. 2) |
| 2 | 0.02 | растущий газовый вал; скачки испарения и конденсации (рис. 3) |
| 3 | 0.03 | вал с двухфазным постоянным состоянием, скачок Бакли–Леверетта (рис. 4) |
| 4 | 0.07 | двухфазная закачка, монотонный $z_{\text{CO}_2}$ (рис. 5) |
| 5 | 0.15 | немонотонная тепловая волна разрежения $\hat S_g$ (рис. 6) |
| 6 | 0.29 | отдельная волна Бакли–Леверетта после тепловой (рис. 7) |
| 7 | 0.999 | $\hat S_g > 1$ у нагнетательной стороны; тепловая волна и волна Бакли–Леверетта сливаются в точке $C$ (рис. 8) |

Во всех вариантах композиционная волна опережает тепловую. Отношение скоростей без теплопроводности — ур. (42):
$$\frac{v_c}{v_{th}} = 1 + \frac{(1-\varphi)(\rho c)_s}{\varphi(\rho c)_l} \approx 3.53.$$
Выделено шесть бифуркаций, то есть смен качественного типа решения. График «эксергия — запасённый CO₂» (рис. 9) имеет Z-образную форму. Ветвь высокой эксергии — 1160 ТДж при 7.1 Мт CO₂, ветвь низкой — 490 ТДж при 11.5 Мт; при закачке только холодной воды — 3590 ТДж.

## Замечания

1. **Тепловая модель тривиальна для фазовых переходов.** $H_\alpha = C_{p\alpha}T$ с аддитивной теплоёмкостью и без энергии смешения означает, что парциальная энтальпия компонента одинакова в обеих фазах. Значит, переход компонента между фазами не несёт теплоты. «Скачок испарения» воды в сухой CO₂ (вариант 7) и растворение CO₂ проходят без теплового эффекта, хотя испарение воды в CO₂ у нагнетательной скважины — механизм охлаждения (по памяти, не сверено). Работа давления отброшена ($U \approx H$), зависимости $H$ от $P$ нет. Эффекта Джоуля–Томсона и адиабатического эффекта в модели нет. Поэтому условие (29) выведено для случая, где скрытой теплоты нет вовсе. Обобщение $\hat H_g = \hat H_l = H_l(P, T, z)$ естественно, но в статье не выведено и не проверено.
2. **Давление постоянно.** Фазовые переходы вызываются только изменением $T$ и состава. Переход, вызванный падением давления, — единственный механизм в нашей задаче — не проверялся. То же ограничение, что в замечании 6 к [[Panfilov Panfilova 2014 — отрицательные насыщенности для трёх фаз и многих компонентов]].
3. **Эффективность не измерена.** Нет ни числа итераций Ньютона, ни шагов по времени, ни отказов, ни времени счёта. Нет сравнения со стандартной техникой из §3, хотя она подробно описана. Тезис «can be implemented efficiently» (аннотация) не подкреплён.
4. **Изломы ОФП не обсуждаются.** При $\hat S_g = 0$: $k_{rg}'(0^+) = 0$ против $\hat k_{rg}' = 1$ слева; $k_{rl}'(0^+) = -4$ против $-1$. При $\hat S_g = 1$: $k_{rg}'(1^-) = 2$ против 1. Якобиан разрывен на обеих границах двухфазной области — то же, что замечание 3 к [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]].
5. **«Вывод» условий эквивалентности даёт достаточные, а не необходимые условия.** (21) получено из требования, чтобы (20) выполнялось «для любого $\hat S_g$». Но $\hat S_g$ не произвольна, она задана составом через (30). (24)–(27) получены сравнением слагаемых (23), единственность не показана. Панфилов и Панфилова (2014) показали, что плотности мнимых фаз определены неединственно. Преимущество перед подходом 3 (вычисление $z_i$ по (22) без плотности) держится именно на выборе $\hat\rho_g = \hat\rho_l$; при другом выборе оно пропадает.
6. **$N_c > 2$ заявлено, но не проверено.** (30) должно выполняться для всех $i$ одновременно, то есть $z$ должен лежать на продолжении коноды. Это отрицательный флэш (28); его существование и сходимость вдали от границы двухфазной области не обсуждаются. Все расчёты — бинарная смесь CO₂–вода.
7. **Проверка слабая.** Единственное сравнение с аналитикой (рис. 1) выполнено при других условиях, чем семь вариантов: 100 бар и 358 К вместо 200 бар и 353 К, другие ОФП. Аналитическое решение получено той же группой (Bruining и Marchesin — соавторы Wahanik et al. 2010), то есть проверка не независимая. Мер погрешности нет; плато $V_m$ численного решения на рис. 1 выше аналитического (на глаз ≈ 0.72 против 0.70). Сходимость по сетке — одна фраза без чисел. Тип волн (скачок или волна разрежения) в вариантах 1–7 определён по профилям с теплопроводностью и схемной вязкостью; авторы признают, что в ряде случаев это предположение (с. 405).
8. **$\hat S_g$ в однофазной зоне зависит от $T$ при неизменном составе** (рис. 2а: $-0.028$ в холодной и $-0.01$ в горячей зоне при $z_{\text{CO}_2} = 0.01$), потому что равновесные $\hat x_{i\alpha}$ зависят от $T$. Расширенная переменная связывает состав и температуру там, где физически они развязаны. При совместном решении это только замена переменных; при последовательном — см. «Значение для проекта».
9. **Мелочи.** $H_\alpha$ названа удельной на единицу массы, но умножается на мольную плотность $\rho_\alpha$, а $C_p$ в (40)–(41) задана в Дж/(моль·К). Вязкости (38)–(39) не зависят от состава, поэтому (24) в расчётах тривиально.

**Нотация.** $\rho_\alpha$ — мольная плотность, $\xi_\alpha$ — массовая (в проекте $\rho_\alpha$ — массовая). $H_\alpha$ = $h_\alpha$ проекта; $C_{p\alpha}$ — мольная теплоёмкость (в проекте $c_{p,\alpha}$ — массовая). $k_T$ = $\lambda_{\text{eff}}$; $\rho_s C_s$ = $(\rho c_p)_s$; $K$ = $k$; индекс $l$ = $o$; $P \equiv P_g$. **Конфликт:** $L$ в статье — мольная доля жидкой фазы, в проекте $L$ — удельная теплота дегазации. $\hat S_g$ = $\widetilde S_g$ в заметках по [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]].

## Значение для проекта

**Отвечает на открытый вопрос из заметок 2009 и 2014 гг.** — как метод отрицательных насыщенностей стыкуется с уравнением энергии. Ответ Salimi: мнимые фазы несут энтальпию истинной фазы (29). Это то же условие $h_g^* \equiv h_o$, что в наброске продолжения для Black Oil в [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]]. Выбор плотностей тот же, что у Abadpour и Panfilov (обе мнимые фазы несут свойства истинной однофазной нефти), а не альтернативный из [[Panfilov Panfilova 2014 — отрицательные насыщенности для трёх фаз и многих компонентов]]. Но подтверждение ограничено замечанием 1: в модели Salimi скрытой теплоты нет, а у нас $Q_{\text{deg}}$ — один из ключевых источников.

Условие (29) — частное решение интегрального условия $\sum_i \tilde\rho_i\widetilde S_i h_i = \tilde\rho^* h^*$ из обзора 2014 г. Оно записано по каждой фазе отдельно и выполняет интегральное условие при любой $\widetilde S$, но не единственно. Интегральная форма нужна, если плотности мнимых фаз выбраны иначе, например в варианте с насыщенной нефтью из обзора 2014 г. Тогда мнимые фазы различимы, и $h_g^*$ находится из интегрального условия, а не приравниванием к $h_o$.

**Почленные условия для нашей формы уравнения энергии** (мой вывод, расчётом не проверен). Уравнение энергии решателя записано через $T$ с явными источниками ([[модули-energy-tridiag]]): конвекция $\Phi_\alpha$, JT-поток $J$, адиабатический член $Q_{\text{ad}} \propto \sum_\alpha S_\alpha(1 + \rho_\alpha c_{p,\alpha}\mu_{JT,\alpha})$, теплота дегазации $Q_{\text{deg}} = -L\dot m$. Если мнимый газ при $\widetilde S_g < 0$ несёт свойства нефти ($\rho_o$, $c_{p,o}$, $\mu_{JT,o}$ — аналог (21), (29)), все суммы по фазам с весами $\widetilde S_g$, $1 - \widetilde S_g$ точно сводятся к однофазным. Сюда входят $\rho c_{\text{eff}}$, $\Phi_\alpha$, $J$ и $Q_{\text{ad}}$. Тогда оговорка из заметки 2014 г. — вычислять теплоёмкость флюидов по зажатой насыщенности — становится ненужной, а для нелинейных по $S_g$ величин вроде $\lambda_{\text{eff}}(S_g)$ остаётся в силе.

**Теплота дегазации — отдельное условие, и оно не выполняется само собой.** $\dot m$ (eq. 31 в [[модули-energy-tridiag]]) вычисляется по изменению $R_s$ нефтяной фазы. В продолжении по Salimi мнимая нефть имеет равновесный состав $R_{s,\text{нас}}(p, T)$, аналог (28). Тогда при любом изменении $p$ или $T$ в недонасыщенной зоне между мнимыми фазами идёт переход массы, и $Q_{\text{deg}} = -L\dot m \ne 0$, хотя физически $\dot m = 0$ (режим 2). Этот ложный источник равен теплоте дегазации насыщенной нефти при том же $p$ и том же темпе падения давления с множителем $B_o^{\text{нас}}/B_o = 1.01$–$1.16$.

Масштаб — расчёт на PVT примеров (`numerical_solver/examples/measure_spurious_degas_heat.py`, 2026-09-30). Мнимая нефть несёт всю нефть ст, то есть $1/B_o(p, R_s)$ м³ст на м³ пор. Отсюда $Q_{\text{deg}}^{\text{ложн}} = \varphi\Lambda\dot p$, где $\Lambda = L\rho_{g,\text{ст}}(dR_{s,\text{нас}}/dp)/B_o$. Адиабатический член однофазной зоны: $Q_{\text{ad}} = \varphi T\alpha\,\dot p$, $T\alpha = 1 + \rho_o c_{p,o}\mu_{JT,o}$. Конвективная часть ложного источника вдоль потока нефти эквивалентна добавке к коэффициенту JT: $\mu_{\text{ложн}} = \Lambda/(\rho_o c_{p,o})$.

Ложный источник в 2–2.3 раза больше адиабатического члена. По конвекции он в 1.3–1.5 раза превышает физический эффект JT и противоположен ему по знаку: в недонасыщенной зоне нагрев от JT сменился бы охлаждением.

В примере 12 (таблицы) $R_{s,\text{нас}}(p)$ выше $p_b(R_{s0}) = 15$ МПа постоянна: таблица кончается на $R_s = 30$. Ложного источника там нет, но и $\widetilde S_g \equiv 0$ для нефти с $R_s = R_{s0}$ во всей недонасыщенной зоне: недонасыщенное состояние неотличимо от точки насыщения. Продолжение требует PVT-таблиц, продолженных выше $p_b$ начального состояния. Условие согласования: $\hat L = 0$ при $\widetilde S_g < 0$ или $\dot m$ по истинному $R_s$. Смысл тот же, что у (29): переход между неразличимыми фазами не несёт теплоты. У Salimi это выполнено автоматически, потому что $L \equiv 0$ везде. На $\widetilde S_g = 0$ источник $Q_{\text{deg}}$ меняется скачком — это физика (дегазация начинается на $p_b$), а не артефакт, но для Ньютона это ещё один излом невязки.

**Последовательная связка гидродинамики и энергии** (мой вывод). В решателе $T^{n+1}$ находится из трёхдиагональной СЛАУ при уже известном $p^{n+1}$ ([[модули-energy-tridiag]]). В текущем коде $R_{s,\text{нас}}$ от $T$ не зависит (`Rs_eq(p)` в `pvt/base.py`), и проблема возникнет только при переходе к $R_s(p, T)$. Тогда $\widetilde S_g$ одного и того же физического состояния меняется после шага по $T$ (замечание 8). Ячейка может пересечь $p_b(T)$ из-за одного нагрева или охлаждения, без изменения давления. Тогда первичными в сохранении должны оставаться массы компонентов, а $\widetilde S_g$ пересчитываться из них после шага по $T$. Переключение состояний полностью не исчезает. Salimi решают систему совместно (§3) и с этим не сталкиваются.

**Что статья не даёт для [[единая формулировка с расширенной S_g могла бы заменить переключение режимов 1 и 2]].** Пункт 1 «Что проверить» — выигрыш по итерациям и отказам — остаётся открытым: замеров в статье нет (замечание 3). Пункт 2 — массовое появление газа при глубокой депрессии — тоже: давление в статье постоянно (замечание 2).

**Прочее.** Формула (42) — стандартное отставание теплового фронта от фронта переноса массы. При двухфазном течении без теплопроводности локальная скорость конвективного переноса $T$ равна
$$v_{th} = \frac{\sum_\alpha \rho_\alpha c_{p,\alpha} u_\alpha}{\varphi\sum_\alpha S_\alpha\rho_\alpha c_{p,\alpha} + (1-\varphi)(\rho c_p)_s}.$$
В числителе теплоёмкость взвешена по потокам фаз, в знаменателе — по насыщенностям. При одной фазе формула переходит в (42). Классификация четырёх подходов во введении полезна как карта альтернатив переключению режимов ([[P3-маппинг-состояния]]). Подход 2 (неравновесный источник) у нас соответствовал бы кинетике дегазации — в проекте не рассматривался. Эксергия, запасание CO₂ и бифуркации в пространстве $z_{\text{CO}_2}$ к проекту отношения не имеют.

К алгебраическим моделям М.1–М.4 из `simplefied_approaches/cooling_models.tex` статья отношения не имеет; касается только численного решения PDE (М.5–М.6, `numerical_solver/`).
