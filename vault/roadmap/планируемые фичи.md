- **Модуль:** `src/coefficients.py`
- **Тесты:** det(A)≠0, A₁₂=0, A₃₂=0 (расщепление §5), размерности

- **Тесты:** A₁₂=0; A₁₁, F₁ при известных PVT vs ручной расчёт; размерности
- **Статус:** 🔴 ОТКРЫТ

#### FEAT-005b: Уравнение массы газа (строка 2)
- **Зависит от:** FEAT-004

- **Тесты:** A₂ₓ, F₂ при Sg=0 (предельный случай без газа); размерности

#### FEAT-005c: Уравнение энергии (строка 3)

- **Тесты:** A₃₂=0; F₃ содержит JT-вклад и теплопроводность; размерности

### FEAT-007: ODE-решатель
- **Фаза:** 5 (решатель)
- **Зависит от:** FEAT-005, FEAT-006
- **Описание:** интеграция системы A·ẋ=F через scipy.integrate.solve_ivp(Radau)
- **Формулы:** \eqref{eq:ode_system}, правая часть из coefficients.py
- **Модуль:** `src/ode_system.py`, `src/solver.py`
- **Тесты:** rb(t) растёт монотонно, Sg,w ∈ [0,1], ΔTw ≤ 0, массовый баланс
- **Статус:** 🔴 ОТКРЫТ

**Подзадачи:**

#### FEAT-007a: Правая часть ODE
- **Зависит от:** FEAT-005d
- **Описание:** функция `rhs(t, y)` в `ode_system.py` — формирование A и F по текущему состоянию (rb, Sgw, ΔTw), вычисление ẋ = A⁻¹·F
- **Тесты:** rhs при baseline НУ возвращает конечные значения; ṙb > 0; знаки ẋ физичны
- **Статус:** 🔴 ОТКРЫТ

#### FEAT-007b: Обёртка solver и постпроцессинг
- **Зависит от:** FEAT-007a, FEAT-006
- **Описание:** `solver.py` — параметры → solve_ivp(Radau) → решение (rb(t), Sgw(t), ΔTw(t)), events, постпроцессинг профилей
- **Тесты:** rb(t) монотонно растёт, Sgw ∈ [0,1], ΔTw ≤ 0, массовый баланс, корректный выход при rb→re
- **Статус:** 🔴 ОТКРЫТ

### FEAT-009: z-фактор газа (корреляция вместо идеального газа)
- **Фаза:** улучшение PVT
- **Зависит от:** FEAT-001
- **Описание:** заменить z=1 на корреляцию Dranchuk–Abou-Kassem (или Hall–Yarborough) для z(p,T). Затрагивает Bg, dBg/dp, dBg/dT, ρ_g, μ_g. При пластовых условиях (15–20 МПа, 350 К, γ_g≈0.69) z≈0.85–0.95, ошибка идеального газа ~5–15%.
- **Модуль:** `src/pvt/correlations.py`, `src/pvt/black_oil.py`
- **Тесты:** z vs табличные данные; Bg, ρ_g, μ_g пересчитанные с z; предельный случай z→1 при p→0
- **Статус:** 🔴 ОТКРЫТ
