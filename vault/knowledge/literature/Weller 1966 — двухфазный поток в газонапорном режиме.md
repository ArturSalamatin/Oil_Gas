# Weller 1966 — двухфазный поток в газонапорном режиме

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Weller W.T.** Reservoir Performance During Two-Phase Flow. *JPT*, Feb. 1966, pp. 240–246; Trans., AIME, 237.

## Аннотация

Исследование продуктивности пласта при двухфазном потоке (solution-gas drive). Boe et al. (1989) отмечают, что метод суммарной подвижности/сжимаемости (Perrine–Martin) становится менее надёжным с ростом газонасыщенности — этот факт установлен в работе Weller.

## Потенциал для проекта

Источник экспериментальных/расчётных данных об ограничениях приближения Perrine–Martin при значительном разгазировании — релевантно для оценки границ применимости упрощённых моделей ПЗП.
