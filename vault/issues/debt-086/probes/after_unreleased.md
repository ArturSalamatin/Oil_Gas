### Добавлено

- **FEAT-040.** Пример 23 считает без установки пакетов, а функции штатного
  набора результатов вошли в публичный интерфейс.

  *Было.* Как вызывать решатель из своего скрипта, когда пакеты решателя и
  прототипа не установлены и есть только папка с исходным кодом, показывал
  лишь фрагмент README, а функции, из которых собран штатный набор рисунков
  и проверок, не были описаны.

  *Стало.* Добавлен пример 23 `23_source_tree_run`: его `main.py` сам
  добавляет папку с исходным кодом и папку прототипа в путь поиска модулей,
  отсчитывая их от своего расположения, считает по книге Excel вызовами
  `convert_workbook`, `load_config`, `SimulatorFactory.from_config`,
  `Simulator.run` и по образцу `run_case` строит набор результатов, вызывая
  функции пакета по одной. В публичный интерфейс (HTML-документация,
  «Публичный интерфейс») вошли функции штатного набора `plot_relperm`,
  `plot_pvt`, `plot_energy_balance`, `plot_mass_balance`, `make_overlay_rs`,
  `report_rs`, `report_pvt` модулей `gpn_multiphase_solver.report`. Их
  поведение не изменилось: числа и рисунки расчётов при тех же исходных
  данных те же. В архив примеров поставки для расчётов пример 23 не входит:
  ему нужен исходный код решателя и прототипа.

### Изменено

- **DEBT-086.** Пункты журнала разделены на смысловые блоки, в описании
  выпуска на GitHub строки не обрываются.

  *Было.* Пункт журнала был одним абзацем из 3–8 предложений. В описании
  выпуска на GitHub каждая строка пункта обрывалась посреди фразы, поскольку
  там каждый перенос строки исходного текста сохраняется при отображении.

  *Стало.* Пункт начинается с номера задачи (у правок без задачи – с
  названия области, например, README) и сути одной фразой, дальше идут блоки
  «Было», «Стало» и, если при тех же исходных данных изменяются результаты,
  «Числа». В описании выпуска строки каждого абзаца склеены в одну. Форму
  раздела проверяет `tests/test_packaging.py`, в том числе при самопроверке
  выпуска.
