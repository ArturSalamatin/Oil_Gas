### Отклонение от плана
План ожидал, что у примера 03 README на конец расчёта не изменится. Физические величины действительно те же: $q_o$, $T$, $S_g$, $r_b$.

Сдвинулись величины на уровне допуска Ньютона и округления:
- |GOR − $R_{s,0}$| на забое: 2.1e-7 → 2.5e-9;
- разброс потоков по граням: 1e-9 → 1e-11;
- столбец GOR таблицы по сетке при $N$ = 100…200.

Утверждение README «на 1-м шаге GOR = $R_{s,0}$ до шести знаков» больше неверно. Первый час теперь считается одним неявным шагом, и GOR на 1 ч равен 49.9907.

Причина проверена на копии прототипа до правки. В стационаре Ньютон делает 0 итераций и состояние «застывает»: раньше — с 1-го часа, теперь — с 3-го. README 03 обновлён по факту. Разбор — в заметке `vault/knowledge/numerics/запасной путь с отрицательной насыщенностью и веткой скважины снимает порог шага на скачке p_wf вверх.md`.
