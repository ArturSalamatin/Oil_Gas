# Earlougher 1977 — ГДИС монография

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Earlougher R.C. Jr.** Advances in Well Test Analysis. *SPE Monograph Series*, Vol. 5, 1977, 264 pp.

## Аннотация

Монография, систематизирующая методы анализа гидродинамических исследований скважин (PTA). Описаны типовые кривые (type curves) для различных моделей — радиальные скважины, вертикальные трещины, границы пласта. Agarwal 1979 ссылается на неё как на общий источник по type curve analysis.

## Потенциал для проекта

Справочник по классическим методам ГДИС; полезен при обосновании постановки задачи и верификации решений.
