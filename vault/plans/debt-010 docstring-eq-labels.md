# DEBT-010: ссылки «формула → код» — метками problem_statement.tex, не номерами

## Кратко

- **Дефект.** Ссылки на уравнения постановки `numerical_solver/doc/problem_statement.tex` в докстрингах и комментариях частью записаны **номерами** (`eq. 8`, `Eq. 10-13`, `Eq. 51`), частью — **номерами строк** `.tex` (`problem_statement.tex:1334`). Нумерация уехала при правках документа: все 27 числовых ссылок и все 3 ссылки на строки указывают не туда (таблица — issue [#92](https://github.com/ArturSalamatin/Oil_Gas/issues/92), раздел «Текущее состояние»). Ещё 10 ссылок записаны нестандартно, `eq. bc_Sg_ext` вместо `eq:bc_Sg_ext`: не уезжают, но ни один инструмент их не проверяет. Справочник `vault/knowledge/decisions/словарь-код-физика.md` использует ту же устаревшую нумерацию (41 ссылка), а его разделы 5–6 описывают дивергентную схему энергии, которая была до BUG-012.
- **Что делается** (решения пользователя 2026-10-10, раздел 0):
  - 42 нарушения в 14 файлах (`.py` ядра, тестов, примеров и 2 README примеров) → ссылки меткой `eq:<метка>`;

  - правило «меткой, не номером» — в CLAUDE.md, раздел «Связь формула → код»;
  - словарь vault: 41 номер → метки; разделы 5–6 переписаны под действующую адвективную схему.
- **Код не меняется.** Правки — только в докстрингах и комментариях; это доказывает проба `ast_same.py` (AST изменённых `.py` без докстрингов совпадает с базой). Числа, истории, графики — те же.

```python
"""Логика .py не изменилась: AST без докстрингов совпадает с базой (DEBT-010).

Запуск из корня worktree:  python ast_same.py <коммит базы>
Сравниваются изменённые (M) файлы *.py; новые (A) пропускаются.
Комментарии в AST не входят, докстринги модуля, классов и функций удаляются.
"""
import ast
import subprocess
import sys


def _strip_docstrings(src: str) -> str:
    """ast.dump без докстрингов модуля, классов и функций."""
    tree = ast.parse(src)
    for node in ast.walk(tree):
        if isinstance(node, (ast.Module, ast.ClassDef,
                             ast.FunctionDef, ast.AsyncFunctionDef)):
            body = node.body
            if (body and isinstance(body[0], ast.Expr)
                    and isinstance(body[0].value, ast.Constant)
                    and isinstance(body[0].value.value, str)):
                node.body = body[1:] or [ast.Pass()]
    # Позиции (lineno, col_offset) ast.dump по умолчанию не печатает —
    # сдвиг строк от переноса докстринга сравнению не мешает.
    return ast.dump(tree)


def _git(*args) -> bytes:
    return subprocess.run(["git", *args], capture_output=True, check=True).stdout


base = sys.argv[1]
files = _git("diff", "--name-only", "--diff-filter=M", base,
             "--", "*.py").decode().split()
bad = 0
for rel in files:
    old = _git("show", f"{base}:{rel}").decode("utf-8")
    with open(rel, encoding="utf-8") as fh:
        new = fh.read()
    same = _strip_docstrings(old) == _strip_docstrings(new)
    bad += not same
    print(("OK   " if same else "DIFF ") + rel)
print(f"файлов: {len(files)}, с изменённой логикой: {bad}")
sys.exit(1 if bad else 0)
```

```python
"""Ссылки «формула → код» — метками problem_statement.tex, не номерами (DEBT-010).

Номер уравнения и номер строки .tex сдвигаются молча при любой вставке выше
по документу: к DEBT-010 все 27 числовых ссылок numerical_solver/ и все 3
ссылки на строки указывали не туда (вставка eq:c_ot в BUG-019 сдвинула
нумерацию ещё на единицу). Метка \\label{} при правках не сдвигается; её
удаление или переименование ловит второй тест.

Обход: .py ядра, тестов и примеров и README примеров. Этот файл исключён —
в нём записаны сами запрещённые формы.
"""

import re
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]          # numerical_solver/
TEX = ROOT / "doc" / "problem_statement.tex"
SELF = Path(__file__).resolve()

# Запрещённые формы ссылки на постановку. Уравнение чужой статьи называется
# словами («формула (5) у Coats 1999»), а не «eq. 5» — иначе его не отличить
# от номера постановки.
FORBIDDEN = {
    "номер уравнения «eq. N»": re.compile(r"\b[Ee]qs?\.\s*\(?\d"),
    "номер уравнения «ур. N»": re.compile(r"\b[Уу]р\.\s*\d"),
    "метка без двоеточия «eq. имя»": re.compile(r"\b[Ee]q\.\s*`?[A-Za-z_]"),
    "номер строки «.tex:N»": re.compile(r"\.tex:\s*\d"),
    "номер строки «.tex, строки N»": re.compile(r"\.tex,?\s*строк"),
}

# Ссылка на метку постановки — уравнения (eq:) или раздела (sec:, ssec:,
# sssec:, app:) — в докстринге, комментарии или \\eqref{...}. Слева не буква,
# чтобы не зацепить слово, оканчивающееся на «eq». Префикс tab: не берётся:
# в коде это цвета matplotlib («tab:blue»), а не метки.
LABEL_REF = re.compile(r"(?<![A-Za-z])(?:eq|sec|ssec|sssec|app):[A-Za-z0-9_]+")
LABEL_DEF = re.compile(r"\\label\{((?:eq|sec|ssec|sssec|app):[A-Za-z0-9_]+)\}")


def _sources():
    """Файлы со ссылками на постановку: .py ядра, тестов, примеров и README примеров."""
    files = [p for d in ("gpn_multiphase_solver", "tests", "examples")
             for p in (ROOT / d).rglob("*.py")]
    files += (ROOT / "examples").rglob("*.md")
    return sorted(f for f in files if f.resolve() != SELF)


def _lines():
    """(путь от numerical_solver/, номер строки, текст) по всем источникам."""
    for f in _sources():
        rel = f.relative_to(ROOT)
        for n, line in enumerate(f.read_text(encoding="utf-8").splitlines(), 1):
            yield rel, n, line


def test_no_numeric_equation_or_line_references():
    """Ни одной ссылки номером уравнения или номером строки .tex.

    До DEBT-010 (c0ec060) — 42 нарушения в 14 файлах, после — ни одного.
    """
    bad = [f"{rel}:{n}: {what}: {line.strip()}"
           for rel, n, line in _lines()
           for what, rx in FORBIDDEN.items() if rx.search(line)]
    assert not bad, ("Ссылка на постановку не меткой (DEBT-010; пишите "
                     "«Ур. (eq:<метка>) problem_statement.tex»):\n"
                     + "\n".join(bad))


def test_label_references_exist_in_problem_statement():
    """Каждая метка из кода, тестов и примеров объявлена в problem_statement.tex.

    Ловит переименование или удаление метки в документе: ссылка осталась,
    а уравнения (раздела) под ней больше нет. На c0ec060 — 162 ссылки
    (152 на уравнения, 10 на раздел ssec:bc_disc), 157 меток.
    """
    labels = set(LABEL_DEF.findall(TEX.read_text(encoding="utf-8")))
    # Разбор .tex не сломан: меток заведомо больше сотни (157 на c0ec060).
    assert len(labels) > 100
    missing = [f"{rel}:{n}: {m.group()}"
               for rel, n, line in _lines()
               for m in LABEL_REF.finditer(line) if m.group() not in labels]
    assert not missing, ("Метки нет в doc/problem_statement.tex — переименована "
                         "или удалена; поправьте ссылку:\n" + "\n".join(missing))
```

## 5. Уравнение энергии (1 уравнение на ячейку)

Форма — **адвективная** (BUG-012): конвекция, JT и перенос $R_s$ собираются как вклады граней с **разностью** переносимой величины; теплопроводность остаётся дивергентной. Код — `gpn_multiphase_solver/energy/tridiag.py` (`TridiagEnergySolver`), шапка модуля объясняет, почему не дивергентная: разность потоков через грани дискретизирует $\operatorname{div}(\Phi T)$ вместо $\Phi\,\partial T/\partial r$ и даёт лишний член $T_j D_j$, $D_j = \Phi_{j+1/2} - \Phi_{j-1/2}$, — работу расширения газа второй раз (она уже в $Q_{ad}$ и JT).

### 5.1 Дискретное уравнение (`eq:energy_disc_full`)

```
V[j]·(ρcp)_eff[j] · (T[j] − T_prev[j]) / dt + F_j
    = −(Q_λ[j+1] − Q_λ[j]) + J_jt[j] + V[j]·(Q_ad[j] + Q_deg[j])
```

`F_j` — конвективный член (`eq:energy_conv_face`); отдельным массивом в коде не хранится, входит в коэффициенты `a`, `b`, `c` через `Phi_plus`, `Phi_minus`. `Q_λ[f] > 0` — поток тепла от скважины.

В трёхдиагональную СЛАУ (`eq:energy_tridiag`): `a[j]·T[j−1] + b[j]·T[j] + c[j]·T[j+1] = d[j]`.

### 5.3 Конвекция (`eq:energy_conv_face`)

```
F_j = Σ_α [ Φ⁺_α[j]·(T[j] − T[j−1]) + Φ⁻_α[j+1]·(T[j+1] − T[j]) ]
```

`Φ_α[f] = ρ_α^up · c_{p,α}^up · Q_α[f]` — свойства из ячейки выше по потоку, **раздельно по каждой фазе** (по знаку `Q_α`); на контурной грани при притоке — при условиях контура (`eq:bc_props_ext`). `Φ⁺ = max(Φ, 0)`, `Φ⁻ = min(Φ, 0)`. Раздельно по фазам — потому что при противотоке фаз `Φ_o` и `Φ_g` на одной грани разных знаков.

Забойная грань (f = 0) конвективного вклада не даёт: слева ячейки нет, разность T нулевая (условие Неймана).

### 5.4 Теплопроводность (`eq:heat_cond_disc`, дивергентная форма)

```
Q_λ[f] = Q^T_f · (T[f−1] − T[f]),     Q^T_f = 2πh / (w_L/λ_L + w_R/λ_R)
w_L = ln(r_faces[f] / r_centers[f−1]),  w_R = ln(r_centers[f] / r_faces[f])
```

Последовательные кольцевые сопротивления. При однородном λ: `Q^T_f = 2πhλ / ln(r_centers[f]/r_centers[f−1])` — один логарифм (BUG-002). Контур: `Q_T_ext = 2πh·λ_eff[N−1] / ln(R_ext/r_centers[N−1])`. Забой: `Q_λ[0] = 0` (Нейман).

⚠️ В `problem_statement.tex` среднее $\lambda^{j+1/2}$ под `eq:heat_cond_disc` (и `eq:face_interp`) записано без множителя $(w_L + w_R) = \ln(r_{j+1}/r_j)$ — в такой записи логарифм входит дважды. Код верен, документ — нет: BUG-027.

### 5.5 Джоуль–Томсон (`eq:QJT_disc`)

```
J_jt[j] = Σ_α [ μ_JT,α[j]·Φ⁺_α[j]·(p[j] − p[j−1]) + μ_JT,α[j+1]·Φ⁻_α[j+1]·(p[j+1] − p[j]) ]   [Вт]
```

Здесь `μ_JT,α[f]` — значение **на грани** f (в коде `mu_o_face`, `mu_g_face`): из ячейки выше по потоку (тот же выбор, что для `Φ_α`; на забойной грани — ячейка 0), на контуре при притоке — при условиях контура. Давление «за гранью»: на забое — `p_wf` шага (`HydroResult.p_wf`), на контуре — `p_ext`. Забойная грань входит с весом `Φ⁺`: при добыче (`Φ < 0`) её вклад нулевой. При однородном p член обращается в нуль тождественно.

### 5.6 Адиабатический эффект (`eq:Qad_disc`)

```
Q_ad[j] = φ · Σ_α S_α[j]·(1 + ρ_α[j]·c_{p,α}[j]·μ_JT,α[j]) · (p[j] − p_prev[j]) / dt
```

Совпадает с `eq:Qad_disc` (там единица вне суммы; равны, так как S_o + S_g = 1). Это форма при $c_r = 0$: непрерывная `eq:main_Qad_muJT` содержит ещё член $c_r\,(p + (\rho c_p)_s T)$ — см. DEBT-057. Единицы: Вт/м³.

### 5.7 Теплота дегазации (`eq:Qdeg_disc`, `eq:mdot_disc`, `eq:mdot_conv_face`)

```
Q_deg[j] = −L · mdot[j]
V[j]·mdot[j] = −ρ_g,ст · [ V[j]·φ·(1 − Sg[j])/Bo[j] · (Rs[j] − Rs_prev[j])/dt + R_adv[j] ]
R_adv[j] = G_o⁺[j]·(Rs[j] − Rs[j−1]) + G_o⁻[j+1]·(Rs[j+1] − Rs[j])
```

Расщепление — по знаку `G_o` (потока нефтяного **компонента**), как для `Φ` и `J_jt`. Слева от ячейки 0 соседом считается она сама (разность нулевая при любом знаке потока); справа от ячейки N−1 — состав притока `Rs_ext` (`eq:bc_Sg_ext`), не `Rs[N−1]` (DEBT-009). Множитель 1/B_o пространственного члена сидит внутри `G_o` и снесён по потоку, временного — из ячейки: так воспроизводится дискретное правило Лейбница гидродинамики (невязка ~1e-15).

При однородном Rs (режим 2, Rs = Rs0): `R_adv = 0`, `ΔRs/dt = 0` → `mdot = 0`, `Q_deg = 0` — тождественно.

## 6. Коэффициенты трёхдиагональной СЛАУ (`eq:tridiag_a` … `eq:tridiag_d`)

Внутренние ячейки j = 1..N−2 (`assemble_tridiag`); `cap[j] = V[j]·(ρcp)_eff[j]/dt`:

| Код | Документ | Формула |
|---|---|---|
| `a[j]` | a_j, `eq:tridiag_a` | −Q^T_{j−1/2} − Φ⁺_{j−1/2} = `−Q_T_internal[j−1] − Phi_plus[j]` (≤ 0) |
| `c[j]` | c_j, `eq:tridiag_c` | −Q^T_{j+1/2} + Φ⁻_{j+1/2} = `−Q_T_internal[j] + Phi_minus[j+1]` (≤ 0) |
| `b[j]` | b_j, `eq:tridiag_b` | cap + Q^T_{j−1/2} + Q^T_{j+1/2} + Φ⁺_{j−1/2} − Φ⁻_{j+1/2} = `cap[j] + Q_T_internal[j−1] + Q_T_internal[j] + Phi_plus[j] − Phi_minus[j+1]` (> 0) |
| `d[j]` | d_j, `eq:tridiag_d` | `cap[j]·T^n[j] + J_jt[j] + V[j]·(Q_ad[j] + Q_deg[j])` |

`Φ⁺` и `Φ⁻` в `b_j` — с тех же граней, что в `a_j` и `c_j`. Дивергентная форма брала противоположные (`Φ⁺_{j+1/2} − Φ⁻_{j−1/2}`); разность двух версий `b_j` равна ровно $D_j$ (BUG-012).

Граничные ячейки:
- **j = 0** (забой, Нейман): `a[0] = 0`; `c[0] = −Q_T_internal[0] + Phi_minus[1]`; `b[0] = cap[0] + Q_T_internal[0] − Phi_minus[1]`; `d[0]` — как у внутренних. Грань 0 в `b` не входит.
- **j = N−1** (контур, Дирихле `T = T_ext`): `a` — по общему правилу; `c[N−1] = 0`; `b[N−1] = cap + Q_T_internal[N−2] + Q_T_ext + Phi_plus[N−1] − Phi_minus[N]`; к `d[N−1]` добавляется `(Q_T_ext − Phi_minus[N])·T_ext`.
- **N = 1** — отдельная ветвь `assemble_tridiag` (обе грани граничные).

Здесь `Q^T_f` — кондуктивная проводимость грани (> 0, раздел 5.4); `Φ⁺_f = Σ_α max(Φ_{α,f}, 0) ≥ 0`, `Φ⁻_f = Σ_α min(Φ_{α,f}, 0) ≤ 0`; `J_jt`, `Q_ad`, `Q_deg` — известные числа (из p^{n+1}, T^n).

СЛАУ решается в отклонениях θ = T − T_ext (DEBT-043): матрица та же, правая часть собирается от T^n − T_ext.

Диагональное преобладание: `b_j − |a_j| − |c_j| = cap[j] > 0` (`eq:diag_dominance`) — обеспечено конструкцией.
