# Пост-обработка обзора статьи

Может вызываться многократно — и в том же разговоре после `/review-paper`, и в новом.

## Определи режим

- **Тот же разговор**: в контексте есть `/review-paper`, прочитанный PDF, созданные заметки. Не перечитывай файлы.
- **Новый разговор**: определи заметку по `$ARGUMENTS` (автор, год или имя файла). Если `$ARGUMENTS` пуст — найди последнюю по дате в `vault/knowledge/literature/`. Прочитай заметку и связанный PDF (страницы, не покрытые в обзоре).

## Повторные вызовы

При повторном вызове:
- **Не предлагай отклонённые действия.**
- **Не проверяй повторно** исправленное.
- Сосредоточься на новых находках.

## Инструкции

### 1. Проверь полноту заметки

| Секция | Что проверить |
|---|---|
| Frontmatter | `author`, `year`, `journal`, `tags`, `date`, `status` — все заполнены? |
| Задача | Есть постановка, уравнения? |
| Метод | Описан подход, алгоритм, конкретные формулы? |
| Результаты | Есть численные примеры, ссылки на таблицы/рисунки? |
| Замечания | Критический анализ (не пересказ)? |
| Значение для проекта | Связь с моделью ПЗП, wiki-ссылки на science-заметки/Draft-файлы? |
| Цитируется в | Заполнено или обоснованно пусто? |
| Ссылается на | Заполнено? |

### 2. Проверь перекрёстные ссылки и индексы

- «Ссылается на» — нет ли битых ссылок?
- Заметки, которые должны были обновиться в «Цитируется в», но не обновились?
- Краткие заметки для ключевых цитируемых работ — созданы? Есть в `cited-references.md`?
- `index-literature.md` — строка добавлена в тематическую таблицу и в «Расширенные обзоры»?

### 3. Проверь полноту покрытия списка литературы

Просмотри весь список литературы из PDF. Для каждой ссылки:
- Есть ли заметка в vault? Проверь и `vault/knowledge/literature/`, и legacy-заметки в `vault/` (корень).
- Если нет — попадает ли в категорию A/B/C?

Категории (для справки — полные критерии в `/review-paper`, шаг 6):

| Категория | Критерий |
|---|---|
| **A — методологическая** | Цитируется ≥2-3 раз, используется для формул/верификации, мотивирует исследование |
| **B — прикладная** | Задачи ПЗП, двухфазной фильтрации, температурных эффектов; промысловые данные |
| **C — обзорная/справочная** | Обзоры, монографии, справочники |

Составь таблицу непокрытых работ с категорией и причиной включения.

### 4. Перечитай пропущенные секции PDF

Признаки неполного покрытия:
- «Метод» без формул/уравнений/номеров
- «Результаты» без ссылок на таблицы/рисунки/числа
- Есть appendix/derivation/discussion, не отражённые в заметке

Предложи конкретные страницы/секции для дочтения. Выполняй после подтверждения.

### 5. Проверь согласованность с другими обзорами

Есть ли в `vault/knowledge/literature/` обзоры смежных работ? Проверь:
- Нет ли противоречий в выводах?
- Нет ли дублирования замечаний без перекрёстных ссылок?
- Согласованы ли секции «Значение для проекта»?

### 6. Предложи дополнения

Конкретные действия (не общие советы):
- **Углубить «Замечания»**: ограничения, расхождения с постановкой ПЗП
- **Углубить «Значение для проекта»**: связи с моделями М.1–М.6 (`simplefied_approaches/cooling_models.tex`), текущей постановкой (`method_of_moments/two_phase_energy.tex`), science-заметками (`vault/knowledge/science/`)
- **Обновить science-заметки**: если статья дополняет/противоречит существующим
- **Создать недостающие краткие заметки**: из шага 3
- **Добавить формулы/уравнения**: если упомянуты без записи
- **Согласовать обзоры**: если шаг 5 выявил противоречия
- **Обновить навигацию**: если статья меняет понимание задачи или открывает новое направление → правка в `vault/00-home/index.md`

Формат: пронумерованный список. Каждый пункт — одно предложение с указанием файла.

### 7. Спроси пользователя

Какие из предложенных действий выполнить? Выполняй только подтверждённое.
