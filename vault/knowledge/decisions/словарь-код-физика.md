# Словарь: код ↔ физика ↔ уравнения

Каждая переменная программы однозначно соответствует физической величине из problem_statement.tex. Этот словарь — единственный источник истины при реализации.

## 1. Сетка (Grid)

### Индексация

Ячейки нумеруются j = 0, 1, ..., N-1. Грани нумеруются f = 0, 1, ..., N.

```
грань 0     ячейка 0     грань 1     ячейка 1     ...     ячейка N-1     грань N
(забой)                                                                   (контур)
r_w ─────── r_centers[0] ─────── r_centers[1] ─── ... ─── r_centers[N-1] ─── R_ext
r_faces[0]               r_faces[1]              ...                      r_faces[N]
```

### Соответствие кода и документа

| Код | Документ (problem_statement.tex) | Уравнение | Размер |
|---|---|---|---|
| `r_faces[f]` | r_{f+1/2} при нумерации ячеек с 1; r_faces[0]=r_w, r_faces[N]=R_ext | eq. 10 | [N+1] |
| `r_centers[j]` | r_j (центр масс кольца) | eq. 12 | [N] |
| `volumes[j]` | V_j = π·h·(r_faces[j+1]² − r_faces[j]²) | eq. 13 | [N] |
| `trans_internal[f]` | T_{f+1} = 2πhk / ln(r_centers[f+1]/r_centers[f]), f=0..N-2 | eq. 19 | [N-1] |
| `trans_well` | T_{1/2} = 2πhk / ln(r_centers[0]/r_w) | §4.3 | скаляр |
| `trans_ext` | T_{N+1/2} = 2πhk / ln(R_ext/r_centers[N-1]) | §4.3 | скаляр |

### Правило: грань f расположена **между ячейкой f-1 и ячейкой f**

- Грань f=0: между забоем и ячейкой 0 (левая граничная)
- Грань f=1..N-1: между ячейками f-1 и f (внутренние)
- Грань f=N: между ячейкой N-1 и контуром (правая граничная)

Проводимость `trans_internal[f]` соответствует грани f+1 (между ячейками f и f+1), f=0..N-2. Альтернативная интерпретация: проводимость грани между ячейками f и f+1.

## 3. Потоки через грани (HydroResult)

### 3.1 Потоки компонентов (для балансов масс и ṁ)

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `G_o[f]` | G^o_{f} | м³ст/с | eq. 8 | [N+1] |
| `G_g[f]` | G^g_{f} | м³ст/с | eq. 9 | [N+1] |

**Определение:** поток нефтяного (газового) **компонента** при стандартных условиях через грань f.

**Формулы (конвенция: G > 0 = от скважины):**
```
Внутренние грани (f = 1..N-1):
G_o[f] = trans_internal[f-1] · (kro/(μo·Bo))_up · (p[f-1] - p[f])
G_g[f] = trans_internal[f-1] · [Rs_up·(kro/(μo·Bo))_up + (krg/(μg·Bg))_up] · (p[f-1] - p[f])

Граничная грань забоя (f = 0):
G_o[0] = trans_well · (kro/(μo·Bo))_0 · (p_wf - p[0])
G_g[0] = trans_well · [Rs_0·(kro/(μo·Bo))_0 + (krg/(μg·Bg))_0] · (p_wf - p[0])

Граничная грань контура (f = N):
G_o[N] = trans_ext · (kro/(μo·Bo))_{N-1} · (p[N-1] - p_ext)
G_g[N] = trans_ext · Rs0·(kro/(μo·Bo))_{N-1} · (p[N-1] - p_ext)
         // krg=0 на контуре (Sg=0)
```

При типичном потоке: все G < 0 (к скважине).

### 3.2 Конвенция знака потоков

**Положительное направление — от скважины (рост r).** См. [[конвенции-знаков]].

```
G_o[f] > 0  ⟹  поток от скважины (в сторону роста r)
G_o[f] < 0  ⟹  поток к скважине (в сторону убывания r) — ТИПИЧНЫЙ СЛУЧАЙ
```

Формула: `G_o[f] = T_f · mob_up · (p[f-1] − p[f])`.

Проверка: на забое p_wf < p[0] → (p_wf − p[0]) < 0 → G_o[0] < 0 → поток к скважине. ✓
На контуре p[N-1] < p_ext → (p[N-1] − p_ext) < 0 → G_o[N] < 0 → поток к скважине (приток в область). ✓

Дебит: `q_o_std = −G_o[0] > 0`.

### 3.3 Upstream-правило

Upstream = ячейка с бо́льшим давлением (откуда течёт жидкость).

Для грани f между ячейками f-1 и f:
```
Если p[f-1] > p[f]  (G > 0, поток от скважины, нетипично):
    upstream = ячейка f-1

Если p[f-1] < p[f]  (G < 0, поток к скважине, типично):
    upstream = ячейка f
```

### 3.4 Расходы фаз (для уравнения энергии)

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `Q_o[f]` | Q_{o,f} | м³пл/с | eq. 24 | [N+1] |
| `Q_g[f]` | Q_{g,f} | м³пл/с | eq. 24 | [N+1] |

**Отличие от G:** расход фазы в **пластовых** условиях, без деления на Bo.

```
Q_o[f] = trans[f] · (kro/μo)_up · Δp    // без 1/Bo!
Q_g[f] = trans[f] · (krg/μg)_up · Δp    // без 1/Bg!
```

Связь: `G_o[f] = Q_o[f] / Bo_up`, `G_g[f] = Q_g[f] / Bg_up`.

**Где вычисляется:** EnergySolver вычисляет Q_o, Q_g самостоятельно из p, grid.trans, PVT, ОФП. Не из HydroResult.G_o.

### 3.5 Скорости Дарси

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `u_o[f]` | u_{o,f} | м/с | eq. 1 | [N+1] |
| `u_g[f]` | u_{g,f} | м/с | eq. 1 | [N+1] |

```
u_α[f] = Q_α[f] / (2π·h·r_faces[f])
```

Единая конвенция: **u > 0 → от скважины**. При типичном потоке u < 0. Совпадает с непрерывным определением u = −Λ·∂p/∂r.

### 3.6 Массовые расходы

| Код | Документ | Единицы | Размер |
|---|---|---|---|
| `m_o[f]` | ρ_o·u_o·2πrh | кг/с | [N+1] |
| `m_g[f]` | ρ_g·u_g·2πrh | кг/с | [N+1] |

```
m_α[f] = ρ_α_up · Q_α[f]
```

Знак тот же, что у Q и u.

## 4. Невязки гидродинамики (3 штуки на ячейку)

### 4.1 Невязка баланса нефтяного компонента

| Код | Документ | Уравнение |
|---|---|---|
| `F_oil[j]` | F_j^{oil} | eq. 14 |

```
F_oil[j] = V[j]·φ · ((1-Sg[j])/Bo[j] - (1-Sg_prev[j])/Bo_prev[j]) / dt
           + G_o[j+1] - G_o[j]
```

Единицы: м³ст/с (объёмный расход нефтяного компонента при ст. условиях).

Слагаемые:
- **Накопление**: V·φ · Δ(So/Bo) / dt — изменение запаса нефтяного компонента в ячейке за dt
- **Потоки**: G_o[j+1] − G_o[j] — отток через правую грань минус приток через левую грань

При стационаре: accum = 0, G_o[j+1] = G_o[j] = const < 0 → F = 0. ✓
Баланс масс: изменение запаса + чистый отток = 0.

### 4.2 Невязка баланса газового компонента

| Код | Документ | Уравнение |
|---|---|---|
| `F_gas[j]` | F_j^{gas} | eq. 15 |

```
F_gas[j] = V[j]·φ · ((Rs[j]·(1-Sg[j])/Bo[j] + Sg[j]/Bg[j])
                     - (Rs_prev[j]·(1-Sg_prev[j])/Bo_prev[j] + Sg_prev[j]/Bg_prev[j])) / dt
           + G_g[j+1] - G_g[j]
```

Единицы: м³ст/с (объёмный расход газового компонента при ст. условиях).

### 4.3 Невязка замыкающего уравнения

| Код | Документ | Уравнение |
|---|---|---|
| `F_eq[j]` | F_j^{eq} | eq. 16 (режим 1), eq. 17 (режим 2) |

```
Режим 1 (Sg > 0):  F_eq[j] = Rs[j] - Rs_eq(p[j])
Режим 2 (Sg = 0):  F_eq[j] = Sg[j]
```

Единицы: м³ст/м³ст (режим 1), безразмерное (режим 2).

### 4.4 Источниковые члены

В балансах масс (eq. 14, 15) **нет** явных источниковых членов. Дегазация учтена неявно через Rs и замыкающее уравнение. Все источники — в уравнении энергии.

## 5. Уравнение энергии (1 уравнение на ячейку)

### 5.1 Дискретное уравнение (eq. 32)

```
V[j]·(ρcp)_eff[j] · (T[j] - T_prev[j]) / dt
+ (F_conv[j+1] - F_conv[j])
= (Q_cond[j+1] - Q_cond[j])
+ J_jt[j]
+ V[j]·(Q_ad[j] + Q_deg[j])
```

Перенося в трёхдиагональную СЛАУ: a[j]·T[j-1] + b[j]·T[j] + c[j]·T[j+1] = d[j].

### 5.2 Слагаемые уравнения энергии

| Код | Документ | Единицы | Уравнение | Описание |
|---|---|---|---|---|
| `rho_cp_eff[j]` | (ρc_p)_{eff,j} | Дж/(м³·К) | eq. 5 | Эффективная теплоёмкость |
| `F_conv[f]` | F_{f} | Вт | eq. 23 | Конвективный поток энергии через грань |
| `Q_cond[f]` | Q_{λ,f} | Вт | eq. 25 | Кондуктивный поток через грань |
| `J_jt[j]` | J_j | Вт | eq. 28-29 | JT-вклад в ячейку (разность JT-потоков на гранях) |
| `Q_ad[j]` | Q_{ad,j} | Вт/м³ | eq. 29 | Адиабатический эффект (поточечно) |
| `Q_deg[j]` | Q_{deg,j} | Вт/м³ | eq. 30 | Теплота дегазации (поточечно) |
| `mdot[j]` | ṁ_j | кг/(м³·с) | eq. 31 | Массовый темп дегазации |

### 5.3 Конвективный поток энергии через грань (eq. 23)

```
F_conv[f] = Σ_α <Φ_α · T>_f
```

где `Φ_α = ρ_α · c_{p,α} · Q_α` — конвективный коэффициент фазы α [Вт/К].

Upstream-оператор (eq. 22): для каждой фазы **раздельно**:
```
<Φ_α · T>_f = Φ_α^+ · T[f-1] + Φ_α^- · T[f]
```

Φ_α^+ = max(Φ_α, 0), Φ_α^- = min(Φ_α, 0). Знак определяется знаком Q_α (расхода фазы α).

### 5.4 Кондуктивный поток через грань (eq. 25)

```
Q_cond[f] = (2πh / ln(r_centers[f]/r_centers[f-1])) · λ_eff_face · (T[f] - T[f-1])
```

λ_eff_face — гармоническое среднее с логарифмическими весами (eq. 21).

### 5.5 JT-поток через грань (eq. 28)

```
J_face[f] = Σ_α μ_{JT,α}^{up} · <Φ_α · p>_f
```

JT-вклад в ячейку (eq. 29):
```
J_jt[j] = J_face[j+1] - J_face[j]
```

### 5.6 Адиабатический эффект (eq. 29)

```
Q_ad[j] = φ · Σ_α S_α[j] · (1 + ρ_α[j]·c_{p,α}[j]·μ_{JT,α}[j]) · (p[j] - p_prev[j]) / dt
```

При c_r = 0 (наша модель). Единицы: Вт/м³.

### 5.7 Теплота дегазации (eq. 30-31)

```
Q_deg[j] = -L · mdot[j]
```

Массовый темп дегазации:
```
V[j]·mdot[j] = -ρ_g_ст · [V[j]·φ·(1-Sg[j])/Bo[j] · (Rs[j]-Rs_prev[j])/dt
                           + (R_conv[j+1] - R_conv[j])]
```

R_conv[f] — конвективный поток газосодержания через грань (eq. 32):
```
R_conv[f] = <G_o · Rs>_f
```

Upstream по знаку G_o (потока нефтяного компонента):
```
R_conv[f] = G_o[f]^+ · Rs[f-1] + G_o[f]^- · Rs[f]
```

При Sg=0 (режим 2): Rs = Rs0 = const → ΔRs/dt = 0, ΔRs по пространству = 0 → mdot = 0 → Q_deg = 0. Автоматически.

## 6. Коэффициенты трёхдиагональной СЛАУ (eq. 33-36)

| Код | Документ | Формула |
|---|---|---|
| `a[j]` | a_j | −Q^T_{j-1/2} − Φ^+_{j-1/2} (≤ 0) |
| `c[j]` | c_j | −Q^T_{j+1/2} + Φ^−_{j+1/2} (≤ 0) |
| `b[j]` | b_j | V·(ρcp)_eff/dt + Q^T_{j-1/2} + Q^T_{j+1/2} + Φ^+_{j+1/2} − Φ^−_{j-1/2} (> 0) |
| `d[j]` | d_j | V·(ρcp)_eff/dt · T^n + J_jt + V·(Q_ad + Q_deg) |

Здесь:
- Q^T_f = кондуктивная проводимость грани f (> 0)
- Φ^+_f = Σ_α max(Φ_{α,f}, 0) ≥ 0
- Φ^−_f = Σ_α min(Φ_{α,f}, 0) ≤ 0
- J_jt, Q_ad, Q_deg — известные числа (вычислены из p^{n+1}, T^n)

Диагональное преобладание: b > |a| + |c| — обеспечено конструкцией.
