# Oil_Gas — навигационный хаб vault

## Проект

Математическая модель призабойной зоны пласта (ПЗП): двухфазная фильтрация Black Oil + уравнение энергии.

- [[после останова из развитой газовой зоны забой прогревается теплопроводностью, а не притоком тёплой нефти]] — пример 17: в первый час зону $r < 1$ м греют растворение газа (61 %) и сжатие (35 %), со вторых суток — теплопроводность (97 %); баланс по всей области этого не показывает; гипотеза притока тёплой нефти опровергнута (конвекция 3 %)
- [[сжимаемость породы входит в уравнение энергии только через поровый объём φ(p) — члены c_r в Q_ad были артефактом вывода]] — у флюида $\varphi(p)$, у скелета $1-\varphi_0$ (масса постоянна); $c_r p$ сокращается с работой над стенками пор, $c_r(\rho c_p)_s T$ зависел бы от нуля энтальпии; проверка энтропией обратимого сжатия; пример 18 — $\Delta T(r_w)$ до 1.29 мК, сравнимо с погрешностью шага (DEBT-057)
- [[ОФП фазы обязана обращаться в ноль при нулевой насыщенности — иначе модель переносит фазу, которой нет]] — $\Lambda_\alpha(0) = 0$ необходимо, из определения скорости фильтрации следует даже $k_{r\alpha} = O(S_\alpha)$; при $\Lambda_\alpha(0) > 0$ в точке $S_\alpha = 0$ имеем $\partial_t S_\alpha \propto -\Lambda_\alpha(0)\,\nabla\cdot(\ldots)$ — насыщенность уходит в минус или фаза появляется из ничего, у забоя $S_o$ падает линейно (DEBT-073), граничное условие «втекает только нефть» записать нельзя (DEBT-079); порог $S_{\alpha c}$ — эмпирика; OPM SGOF требует нуль только у $k_{ro}$
