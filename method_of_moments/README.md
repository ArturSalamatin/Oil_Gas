# Метод моментов Баренблатта для двухфазной фильтрации Black Oil

Полуаналитический решатель задачи фильтрации нефти с растворённым газом в призабойной зоне пласта (ПЗП). Метод сводит систему PDE (давление, насыщенность, температура) к системе ODE для трёх интегральных параметров: радиуса зоны разгазирования $r_b(t)$, забойной газонасыщенности $S_{g,w}(t)$ и отклонения температуры на забое $\Delta T_w(t)$.

## Физическая постановка

- **Фазы:** нефть с растворённым газом (o) и свободный газ (g). Воды нет.
- **Модель PVT:** Black Oil (Standing, Beggs-Robinson, Lee-Gonzalez-Eakin).
- **Геометрия:** радиальная, одномерная (r от скважины к контуру питания).
- **Температура:** определяется балансом энергии: эффект Джоуля-Томсона, адиабатическое расширение, скрытая теплота разгазирования.

Математическая постановка описана в:
- `moments_method.tex` -- метод моментов, формулы для кода
- `two_phase_energy.tex` -- двухфазная фильтрация с уравнением энергии

## Реализованные модули

### PVT-корреляции (FEAT-001) -- завершено

**Файл:** `src/pvt/correlations.py`

Чистые функции, все в СИ (Па, К, м³/м³). Пересчёт в полевые единицы (psia, °F, scf/STB) -- внутри функций.

| Функция | Корреляция | Примечание |
|---|---|---|
| `Rs(p, T, ...)` | Standing (1947) | газосодержание, м³ст/м³ст |
| `pb(Rs, T, ...)` | Standing (обратная) | давление насыщения, Па |
| `dRs_dp`, `dRs_dT` | аналитические | проверены vs конечные разности |
| `Bo(p, T, Rs, ...)` | Standing | объёмный коэфф. нефти |
| `dBo_dRs`, `dBo_dT_fixed_Rs` | аналитические | ∂Bo/∂Rs и ∂Bo/∂T при фикс. Rs |
| `Bg(p, T)`, `dBg_dp`, `dBg_dT` | идеальный газ (z=1) | FEAT-009: замена на z(p,T) |
| `mu_dead_oil(T, ...)` | Beggs-Robinson (1975) | μ_od, мёртвая нефть |
| `mu_o(T, Rs, ...)` | Beggs et al. (1975) | μ_o, живая нефть |
| `mu_g(p, T, ...)` | Lee-Gonzalez-Eakin (1966) | μ_g газа |

**Файл:** `src/pvt/black_oil.py`

Класс `BlackOilFluid` -- единый интерфейс для downstream-модулей:

```python
from src.pvt import BlackOilFluid

fluid = BlackOilFluid(config["pvt"], p_b=18e6, T_0=350.0)

fluid.Rs(p, T)          # газосодержание (с обрезкой при p > pb)
fluid.Bo(p, T)          # объёмный коэфф. нефти
fluid.rho_o(p, T)       # плотность нефти = (ρ_o_ст + Rs·ρ_g_ст) / Bo
fluid.rho_g(p, T)       # плотность газа = ρ_g_ст / Bg
fluid.co(p, T)          # сжимаемость (= 0 для Standing)
fluid.co_sat(p, T)      # полная сжимаемость вдоль кривой насыщения
fluid.beta_o(p, T)      # (1/Bo)·∂Bo/∂T при фикс. Rs
fluid.beta_o_sat(p, T)  # полный коэфф. расширения
fluid.alpha_o(p, T)     # = beta_o (доказано аналитически для Standing)
fluid.mu_o(p, T)        # вязкость нефти
fluid.mu_g(p, T)        # вязкость газа
fluid.xi_o(p, T, Sg)    # (1-Sg)/Bo
fluid.cp_o(p, T)        # теплоёмкость нефти (const, default 2000)
fluid.cp_g(p, T)        # теплоёмкость газа (const, default 1000)
fluid.L(p, T)           # теплота дегазации (const, default 300 кДж/кг)
```

## Принятые решения

### Идеальный газ (z = 1)

Bg, ρ_g, μ_g вычислены при z = 1. При пластовых условиях (15-20 МПа, 350 К, γ_g ≈ 0.69) это даёт ошибку 5-15%. Замена на корреляцию z(p,T) запланирована как FEAT-009.

### co = 0 для Standing

Корреляция Standing: Bo зависит от p только через Rs. При фиксированном составе ∂Bo/∂p = 0, т.е. co = 0. Реальная нефть сжимается (co ~ 1e-9 Па⁻¹), но для консистентности со Standing принято co = 0. Полная сжимаемость co_sat != 0 (через dBo/dRs · dRs/dp).

### Теплоёмкости и теплота дегазации -- константы

cp_o = 2000 Дж/(кг·К), cp_g = 1000 Дж/(кг·К), L = 300 кДж/кг. Задаются в конфиге, значения по умолчанию. Корреляции для cp(p,T) и L(p,T) -- потенциальное улучшение.

### alpha_o = beta_o

Для Standing ρ_o = (ρ_o_ст + Rs·ρ_g_ст)/Bo, числитель не зависит от T при фикс. Rs, поэтому αo = −(1/ρo)·∂ρo/∂T = (1/Bo)·∂Bo/∂T = βo. Доказано аналитически, проверено тестом.

### Разрыв dRs/dp при p = pb

Производная dRs/dp имеет скачок: > 0 при p < pb, = 0 при p >= pb. Это не ошибка PVT-модуля. ODE-решатель (FEAT-007) должен обрабатывать эту негладкость через event detection или регуляризацию.
