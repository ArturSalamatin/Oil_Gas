**План:** `vault/plans/bug-028 first-step-phase-set.md` — 5 шагов, база `6d27358` (код = `209326d`), тестов 1932 → 1942.

**Выбран вариант В1б** — правка `_advance_phases` прототипа:
- в лимит `max_active_iter` (12) идут только проходы, где газ включается хотя бы в одной ячейке;
- проход, где газ только снимается, строго сужает набор фаз — подряд таких не больше $N$;
- всего проходов не больше `max_active_iter` + $N$, поэтому худший случай линеен по $N$;
- где цикл кончался за ≤ 12 проходов, он идёт как прежде, побитово: проход $k \le 12$ выполняется в обоих вариантах, тело прохода не меняется.
