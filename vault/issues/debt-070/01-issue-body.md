## Описание

В постановке `numerical_solver/doc/problem_statement.tex` два конфликта обозначений на границах области. Оба мешают читать граничные условия — раздел, который заказчик проверяет первым.

1. **Символы $p_0$, $T_0$ означают две разные величины.** Макросы `\ppl`, `\Tpl` (контурные/начальные значения) печатаются как $p_0$, $T_0$. Ячейки нумеруются $j = 0, \ldots, N-1$, поэтому в `ssec:bc_disc` те же $p_0$, $T_0$ — значения ячейки 0.
2. **Индексы граней — в трёх соглашениях.** В балансах и уравнении энергии ячейка $j$ лежит между гранями $j \mp \tfrac12$. В `ssec:grid` и `ssec:bc_disc` забойная грань — $\tfrac12$, контурная — $N+\tfrac12$. В коде грань $f = 0 \ldots N$ лежит между ячейками $f-1$ и $f$.

Приоритет низкий: на расчёт не влияет, код считает верно. Страдает только текст.

### 2. Индексы граней

Одной и той же величине документ даёт разные индексы, а один и тот же индекс означает разные грани:

| Где | Забойная грань | Правая грань ячейки 0 | Контурная грань |
|---|---|---|---|
| `eq:log_grid` (стр. 950–954) | $r_{1/2} = r_w$ | $r_{3/2}$ | $r_{N+1/2} = R_{ext}$ |
| `eq:cell_center`, `eq:volume`, балансы, `eq:energy_conv_face`, `eq:QJT_disc`, `eq:tridiag_a`…`eq:tridiag_d` | $j - \tfrac12 = -\tfrac12$ | $\tfrac12$ | $N - \tfrac12$ |
| `eq:transmissibility` (стр. 1015) | — | $\mathcal{T}_{1/2} = 2\pi hk/\ln(r_1/r_0)$ | — |
| `ssec:bc_disc` | $\mathcal{T}_{1/2} = 2\pi hk/\ln(r_0/r_w)$, $G_{1/2}$, $\Phi_{1/2}$ | $G_{3/2}$ (стр. 1846), $\Phi^-_{1/2+1}$ (стр. 2051) | $\mathcal{T}_{N+1/2}$, $G_{N+1/2}$; $\Phi^-_N$ (стр. 2026–2030) |
| случай $N = 1$ (стр. 2078–2083) | — | — | $Q^T_{\lambda,1+1/2}$ и $\Phi^-_1$ в одной формуле |
| диагональное преобладание (стр. 1778) | — | — | $Q^T_{\lambda,N+1/2}$ и $-\Phi^-_N$ в одной скобке |
| код, `vault/knowledge/decisions/словарь-код-физика.md` | $f = 0$ | $f = 1$ | $f = N$ |

Два места — уже не стиль, а противоречие:
- **`ssec:grid` противоречит сам себе.** `eq:log_grid` задаёт грани $r_{j+1/2}$, $j = 0 \ldots N$, с $r_{1/2} = r_w$. `eq:cell_center` и `eq:volume` для ячейки $j = 0$ требуют $r_{-1/2}$, которая не определена. Если подставить буквально, $r_0 = \sqrt{r_{-1/2}\,r_w} < r_w$.
- **$\mathcal{T}_{1/2}$ — две разные величины.** По `eq:transmissibility` это проводимость грани между ячейками 0 и 1, по `ssec:bc_disc` — забойной грани.

Словарь `словарь-код-физика.md` (стр. 364–366) переводит $a_j = -Q^T_{j-1/2} - \Phi^+_{j-1/2}$ в `−Q_T[j] − Phi_plus[j]`, то есть $f = j \leftrightarrow j - \tfrac12$: забой $-\tfrac12$, контур $N - \tfrac12$. С этим согласуются балансы и уравнение энергии, но не `eq:log_grid` и не `ssec:bc_disc`.

В коде соглашение `ssec:bc_disc` встречается один раз: докстринг `energy/tridiag.py:428–429` («μ·Φ⁺_{1/2}·(p[0] − p_wf)» для грани 0).

## Целевое состояние

- Символ ячейки 0 ($p_0$, $T_0$, $T_0^n$) не совпадает ни с одним символом начальных или контурных значений.
- Во всём документе одно соглашение об индексах граней, согласованное с балансами, `eq:tridiag_*` и словарём код ↔ физика. `eq:log_grid`, `eq:cell_center`, `eq:volume` и `eq:transmissibility` при $j = 0$ определены и не противоречат `ssec:bc_disc`.
- Обозначения в CLAUDE.md, `словарь-код-физика.md` и таблице обозначений постановки совпадают. Если какое-то из них меняется, это решение пользователя.
- PDF собирается без ошибок и неопределённых ссылок. `tests/test_eq_references.py` зелёный: метки не меняются.

## Анализ вариантов решения

### Часть 1: $p_0$, $T_0$

**Вариант 1.1 — по словарю CLAUDE.md:** `\Tpl` → $T_{\text{пл}}$, `\ppl` остаётся $p_0$. Значения ячейки 0 в `ssec:bc_disc` помечаются явно, например $p_{(0)}$, $T_{(0)}$.
- Плюсы: словарь CLAUDE.md не меняется.
- Минусы: ~26 правок в формулах ячейки 0; запись $p_j$ при $j = 0$ перестаёт быть единообразной ($p_{(0)}$ рядом с $p_1$, $p_{N-1}$); `eq:porosity` с $(p - p_0)$ по-прежнему читается двояко.

**Вариант 1.2 — две правки макросов:** `\ppl` → $p_{\text{пл}}$, `\Tpl` → $T_{\text{пл}}$, плюс буквальные $p_0$, $T_0$ на стр. 120 и 152.
- Плюсы: коллизия снимается во всём документе сразу; ячейка 0 остаётся $p_0$, $T_0$, как любая $p_j$, $T_j$; $T_{\text{пл}}$ совпадает со словарём.
- Минусы: $p_{\text{пл}}$ расходится со словарём CLAUDE.md ($p_0$). Нужно либо поправить словарь (решение пользователя), либо записать исключение для `numerical_solver/doc/`. В коде имена другие: конфиг `p0`, `T0` (начальные, `io/config.py:109–110`), состояние `p_ext`, `T_ext` (контурные, `state.py:117–118`).

**Вариант 1.3 — разделить начальные и контурные значения:** макросы $p_{\text{конт}}$, $T_{\text{конт}}$ для граничного условия на $R_{ext}$ (как в коде `p_ext`, `T_ext`; абзац BUG-015 на стр. 1949–1951 уже так пишет) и $p_{\text{пл}}$, $T_{\text{пл}}$ для начальных.
- Плюсы: соответствие коду; граничное условие $p|_{R_{ext}} = p_{\text{конт}}$ читается без отсылки к начальному состоянию.
- Минусы: два новых макроса; в постановке $p_{\text{конт}} = p_{\text{пл}}$ тождественно, и различие может показаться избыточным.

**Вариант 1.4 — только пояснение** в начале `ssec:bc_disc`.
- Плюсы: одна вставка.
- Минусы: формулы с $p_0$ двух смыслов по-прежнему стоят на одной странице; противоречие не снимается.

### Часть 2: индексы граней

**Вариант 2.A — везде $j \mp \tfrac12$:** ячейка $j$ лежит между гранями $j - \tfrac12$ и $j + \tfrac12$; забой — $-\tfrac12$, контур — $N - \tfrac12$. Меняются `eq:log_grid` ($r_{j-1/2} = r_w (R_{ext}/r_w)^{j/N}$, $j = 0 \ldots N$), стр. 954, `ssec:bc_disc` (~30 мест), стр. 1778, докстринг `tridiag.py`.
- Плюсы: одно правило; совпадает с балансами, `eq:tridiag_*` и словарём ($f = j \leftrightarrow j - \tfrac12$); снимает обе внутренние неопределённости.
- Минусы: отрицательный индекс $-\tfrac12$ непривычен для читателя.

**Вариант 2.B — 2.A плюс именованные граничные грани:** $\mathcal{T}_w$, $G_w$, $\Phi_w$ для забоя и $\mathcal{T}_{ext}$, $G_{ext}$, $\Phi_{ext}$ для контура, с одной фразой «$-\tfrac12 \equiv w$, $N - \tfrac12 \equiv ext$».
- Плюсы: формулы `ssec:bc_disc` читаются без арифметики индексов; индекс `ext` у подвижностей на контуре уже используется (`eq:bc_flux_ext`).
- Минусы: для каждой граничной величины два имени; общие формулы при $j = 0$ всё равно дают $-\tfrac12$.

**Вариант 2.C — везде соглашение `ssec:bc_disc`** (ячейка $j$ между $j + \tfrac12$ и $j + \tfrac32$).
- Минусы: переписываются все балансы, `eq:energy_conv_face`, `eq:QJT_disc`, `eq:tridiag_*`, словарь. Не рекомендуется.

### Рекомендация

1.2 или 1.3 (выбор на `/plan-improve`; правка CLAUDE.md — только с согласия пользователя) + 2.A или 2.B. Обе части — один документ и одни и те же абзацы `ssec:bc_disc`, поэтому делаются одной задачей.
