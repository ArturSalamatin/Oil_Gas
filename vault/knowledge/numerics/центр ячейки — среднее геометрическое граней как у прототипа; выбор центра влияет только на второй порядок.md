# Центр ячейки — среднее геометрическое граней, как у прототипа; выбор центра влияет только на второй порядок

**Задача:** [[debt-063 unify-grid-prototype-centers]] ([#98](https://github.com/ArturSalamatin/Oil_Gas/issues/98)); поглотила DEBT-060 ([#96](https://github.com/ArturSalamatin/Oil_Gas/issues/96)).

## Что было

В одном расчёте — две сетки с общими гранями. Гидродинамику считает прототип (`RadialGrid`, центры $\sqrt{r_{j-1/2}r_{j+1/2}}$), энергию, вывод профилей и аналитику примеров — `LogRadialGrid` с центрами $\exp\langle\ln r\rangle$ по площади слоя (`eq:cell_center` до DEBT-063; в документах ошибочно «центр масс кольцевого слоя»). Шаг сетки $h = \ln(R_{ext}/r_w)/N$:

- центры расходились на $\ln(r^{GPN}/r^{прот}) \approx h^2/6$ — 1.6 % по $r$ при $N = 20$, 0.064 % при $N = 100$;
- граничные проводимости — на $\approx h/3$ (забой $h/2 + h^2/6$ против $h/2$, контур $h/2 - h^2/6$ против $h/2$); внутренние совпадали (отношение соседних центров у обеих формул $e^h$).

## Что стало

`LogRadialGrid.r_centers = np.sqrt(faces[:-1] * faces[1:])` — побитово как у прототипа (тест `test_prototype_adapter.py::TestGridsMatchPrototype`). `eq:cell_center`: $\ln r_j = \tfrac12(\ln r_{j-1/2} + \ln r_{j+1/2})$. Прототип не менялся.

## Почему именно так — замеры

Проба `vault/issues/debt-063/probes/center_accuracy.py` — однофазный упругий приток, точное по времени решение через собственные пары, эталон $N = 2000$:

| | $\sqrt{r_{j-1/2}r_{j+1/2}}$ | $\exp\langle\ln r\rangle$ |
|---|---|---|
| стационар (Дюпюи) | точно, 1e-13 | точно, 1e-13 |
| порядок в нестационаре | 2 | 2 |
| ошибка дебита, $N = 100$, $t$ = 0.1…100 | 4–11e-5 | 8–18e-5 |
| ошибка среднего по ячейке давления, $N = 100$ | 1–6e-4 | 0.1–3e-4 |

- **Дюпюи точен при любом центре.** При $p = A + B\ln r$ и проводимости $2\pi kh/\ln(r_{j+1}/r_j)$ поток между любыми двумя точками $= 2\pi khB/\mu$ — свойство логарифмической проводимости грани, не центра. Тест VAL-001 центры не различает.
- **Равномерно лучшего центра нет:** $\sqrt{\cdot}$ — середина ячейки по $\ln r$, грань ровно между узлами (поток точнее); $\exp\langle\ln r\rangle$ — значение в узле равно среднему по ячейке для профилей, линейных по $\ln r$ (запас точнее). Разница при фиксированном $N$ — вдвое, то есть $N\times\sqrt2$.
- Дефект был в смешении двух сеток, а не в выборе формулы. Сетку прототипа (√) взяли потому, что его эталон регрессии сверен с CMG IMEX — правка прототипа потребовала бы пересъёма эталона.

## Следствия перехода

- **Гидродинамика** всех 23 примеров — побитово та же (прототип наших центров не видит); **температура** — на $\le 2\cdot10^{-8}$ К у забоя, $\le 10^{-5}$ К по полю (`examples_shift.py`); член теплопроводности баланса энергии 10–21 — меньше на 0.6–5.1 % (контурная проводимость), невязка баланса — уровень округления.
- **Тесты, сверявшие решение прототипа с Дюпюи в чужих точках** (`test_val001`, `test_factory_standing_hydro`): отклонение было 8.5e-4 и 1.03e-4 при допуске 1e-2 и объяснении «нестационарное решение»; в общих точках — 0 и 6.7e-16, допуск 1e-12. `TestMassBalance` объяснял допуск 0.02 «разными центрами», хотя центры в баланс не входят: невязка 5.5e-12, гарантия критерия Ньютона прототипа на этом шаге 3.7e-7 ($\|F_0\|_\infty \approx 37\,|G_o[0]|$) — допуск 1e-6.
- **Числа README** (108 замен в 21 README и скриптах, 13 строк сводной таблицы): сверка с замкнутым решением $\max|p_{ана}-p_{чис}|$ в 13 примерах меньше на 1–34 % (из неё ушла разница точек); численный фронт $r_b$ — множитель $e^{-\delta_N}$; радиусы центров в тексте и таблицах; таблицы сходимости 03, 04, 05. В 05 наблюдаемый порядок сходимости давления к замкнутому решению — 0.93 вместо 1.16: прежний «сверхпервый» порядок давала добавка разницы точек $\propto h^2$; в 04 отношения ошибок давления стали 1.97 / 1.96 / 1.50 — как у дебита.
- В README 12 ячейка у фронта (центр 117.5 м, а не 117.9) оказалась не «сразу за», а в 0.1 м внутри стационарного фронта 117.6 м — расчёт тот же, сменилось толкование.
