# Bedrikovetsky 1993 — математическая теория вытеснения нефти и газа

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Bedrikovetsky P.** Mathematical Theory of Oil and Gas Recovery. *Kluwer Academic Publishers*, Dordrecht, 1993.

## Аннотация
Категория A. Монография по аналитической теории процессов повышения нефтеотдачи, в том числе смешивающегося вытеснения, в формулировке через полную (объёмную) концентрацию компонентов при идеальном растворе, постоянных $P$, $T$ и без капиллярного давления; такая формулировка позволяет аналитически выделить все скачки. Обобщённая теория дробного потока из книги даёт точное решение задачи вытеснения жидкости смешивающимся газом, использованное как эталон для проверки метода отрицательных насыщенностей (пример 1, рис. 3 в [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]]).

## Потенциал для проекта
Аналитические решения типа Баклея–Леверетта с фазовыми переходами — возможный эталон для проверки FVM-решателя в линейной геометрии. Есть ли в книге решения для радиальной геометрии с разгазированием — из контекста неизвестно.
