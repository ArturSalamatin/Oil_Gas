### План готов

План: `vault/plans/debt-041 example03-max-retries-table.md`. Ветка: `refactor/debt-041/example03-max-retries-table`. Шагов: 7 (0–6).

- **Объём:** вариант 2 по решению пользователя. Правятся README 03, комментарий `NumericsConfig.max_retries` (`io/config.py:149-154`) и docstring двух тестов: `test_factory_standing_hydro.py:119-123` и `test_config.py:199-203`. Второй из них найден при планировании, в нём то же устаревшее обоснование «измеренный порог N = 75, p_wf = 6 МПа». Исполняемый код и значение 9 не меняются.
- **Замер** (`3bd659e`, `vault/issues/debt-041/probes/max_retries_probe.txt`). Мерился максимум $\log_2 n_{substeps}$ по **всем** вызовам `hydro.solve` за прогон, а не только по первому шагу: после дробления симулятор проходит интервал заново подшагами, и каждый из этих вызовов адаптера может дробиться с тем же лимитом. Результаты:
  - таблица README 03 верна во всех точках, кроме 0.5 МПа: нужно **4**, а не 9;
  - дробится только первый шаг, вложенного дробления нет;
  - сгущение сетки при 8 МПа ($N$ = 50…200) дробления не требует.
- **Контроль минимальности:** при `max_retries = k − 1` прогон падает на первом вызове при $t = 0$; при `k` конечное $p$ побитно совпадает с прогоном при умолчании.
- **README 04** в объём не входит: его таблица не перемерялась. Скрипт переносится на пример 04 заменой конфига и списка точек.
