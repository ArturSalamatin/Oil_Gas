# Boe 1989 — двухфазный анализ КПД

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Boe A., Skjaeveland S.M., Whitson C.H.** Two-Phase Pressure Test Analysis. *SPE Formation Evaluation*, 1989. SPE 10224.

## Аннотация
Предложен метод анализа кривых падения давления (КПД) для двухфазной системы газ–нефть с использованием многофазных функций псевдодавления. Показано совпадение аналитических зависимостей с результатами численного моделирования (Рис. 1 в документе Краснова). Работа является ключевой для обоснования применимости автомодельных решений к двухфазной фильтрации ниже давления насыщения.

## Потенциал для проекта
Методика связи $S(p)$ для КПД может быть использована как верификационное решение для наших моделей ПЗП при разгазировании.
