## Корневая причина

### Диагностика

Solver (`solve_moments`) с baseline-параметрами даёт NaN при `t ≈ 9.86 с`, `r_b ≈ 3.73 м`, `Sg_w ≈ 0.172`, `dT_w ≈ 0.461 К`.

В этой точке `gamma = 0.4998` — **ниже порога интегрируемости 0.5**.

### Физика

Параметризация давления: $p(r) = p_{wf} + \Delta p_1 \cdot \eta^\gamma$, где $\eta = \ln(r/r_w)/\ln(r_b/r_w)$.

Градиент: $\frac{\partial p}{\partial r} = \frac{\Delta p_1 \cdot \gamma}{r \cdot L_b} \cdot \eta^{\gamma-1}$.

Квадратичный интеграл $Q_{\text{quad}}$ (\eqref{eq:Q_quad} в `moments_method.tex`, строка 1040) содержит $(\partial p / \partial r)^2 \sim \eta^{2(\gamma-1)}$.

- При $\gamma > 1/2$: $2(\gamma-1) > -1$ → интегрируемая сингулярность
- При $\gamma \leq 1/2$: $2(\gamma-1) \leq -1$ → **расходимость** (логарифмическая при $\gamma = 1/2$)

Tex предупреждает (строки 1062–1070):
> При γ ≤ 1/2 — расходится. При конечном r_b с γ < 1/2: требуется **регуляризация** (замена переменных или выделение сингулярности).

### Формула gamma

$\gamma = \frac{\Delta p_2}{\Delta p_1} \cdot \frac{L_b}{L_e}$, где $\Delta p_1 = p_b^* - p_{wf}$, $\Delta p_2 = p_0 - p_b^*$.

При baseline: $\Delta p_2 / \Delta p_1 \approx 2/3$. Когда $r_b$ растёт, $L_b = \ln(r_b/r_w)$ растёт, $L_e = \ln(R_{ext}/r_b)$ убывает → $\gamma$ растёт. Но при малых $r_b \approx r_w$: $L_b \approx 0$ → $\gamma \approx 0$.

При $r_b \approx 3.73$ м: $L_b/L_e \approx \ln(37.3)/\ln(134) \approx 0.739$ → $\gamma \approx 0.667 \times 0.739 \approx 0.493$ — ниже 0.5.

### Что происходит в коде

`coefficients.py:188–191` (`oil_F1`):
```python
if gam > 0.5:
    Q_quad, _ = quad(Q_quad_integrand, r_w, r_b)
else:
    Q_quad, _ = quad(Q_quad_integrand, r_w, r_b, points=[r_w + r_w * 1e-6])
```

`points=` подсказка для `quad` **не решает** проблему: интеграл $\int \eta^{-1} d\eta$ расходится принципиально, никакая адаптивность не поможет.

Аналогичная проблема в `energy_F3` (строки 1401–1404 tex): JT-интеграл тоже содержит $(\partial p/\partial r)^2$.

### Где ещё (dp/dr)² входит в коэффициенты

Grep по `dp_dr_val * dp_dr_val` и аналогичным паттернам:

| Коэффициент | Содержит $(dp/dr)^2$? | Файл:строка |
|---|---|---|
| `oil_F1` → `Q_quad` | **да** | `coefficients.py:186` |
| `energy_F3` → JT-интеграл | **да** | `coefficients.py:~465` |
| `oil_A11` | нет — `Cp·∂p/∂r_b` (одна степень) | |
| `gas_A21` | нет — `∂Sg/∂r_b` | |
| Другие $A_{ij}$ | нет | |

### Недетерминизм rhs

При baseline `dp_wf_dt = 0.0` → `dp_dpwf_numerical` **не вызывается** (строка 195: `if state.dp_wf_dt != 0.0`). Мутация `p_profile.p_wf` — не причина для baseline. Недетерминизм объясняется внутренним состоянием `quad()` (adaptive subdivision) — при расходящемся интеграле `quad` может вернуть `inf` или большое конечное число в зависимости от порядка подразбиений.

## Варианты решения

### Вариант A: Аналитическое выделение сингулярности

- **Суть:** $Q_{\text{quad}}$ и JT-интеграл содержат $\sim \eta^{2(\gamma-1)}$. Вынести сингулярную часть аналитически:
  $$\int_{r_w}^{r_b} f(r) \cdot \eta^{2(\gamma-1)} \, dr = f_0 \cdot \underbrace{\int \eta^{2(\gamma-1)} \, dr}_{\text{аналитически}} + \int (f(r) - f_0) \cdot \eta^{2(\gamma-1)} \, dr$$
  где $f_0 = f(r_w)$ — «замороженное» значение гладкой части.
- **Плюсы:** математически чисто, работает при любом $\gamma > 0$
- **Минусы:** сложная реализация (~100 строк), нужно вывести аналитические формулы для каждого интеграла
- **Трудоёмкость:** сложный

### Вариант B: Регуляризация — ε-отсечка нижнего предела

- **Суть:** заменить `r_w` на `r_w + ε` в интегралах с $(dp/dr)^2$, где $\varepsilon = r_w \cdot \delta$ с малым $\delta$. Вблизи $r_w$ подынтегральная ≈ бесконечна, но её вклад в физический интеграл конечен (расход через забой регуляризуется подвижностью).
- **Реализация:** в `oil_F1` и `energy_F3` заменить `quad(..., r_w, r_b)` на `quad(..., r_w + eps, r_b)` для интегралов с `dp_dr^2`
- **Плюсы:** ~5 строк изменений, быстро, сохраняет физический смысл (поток через забой уже обрезан при `gamma < 1`, строка 170–173)
- **Минусы:** вносит O(ε)-ошибку; нужно обосновать выбор ε
- **Трудоёмкость:** простой

### Вариант C: Замена переменных в quad

- **Суть:** замена $r \to \eta$ в подынтегральной: $dr = r \cdot L_b \cdot d\eta$. Тогда $\eta^{2(\gamma-1)} \cdot d\eta$ — интегрируемо при $2(\gamma-1) + 1 > 0$, т.е. $\gamma > 0$. Но при $\gamma = 0.5$ показатель = $-1+1 = 0$, т.е. интеграл $\int_0^1 d\eta = 1$ — **конечен**.
- Подождём — это не так. $\int r \cdot (dp/dr)^2 \, dr$: после замены $dr = r \cdot L_b \cdot d\eta$ получим $\int r^2 L_b \cdot (dp1 \cdot \gamma / (r \cdot L_b))^2 \cdot \eta^{2(\gamma-1)} \cdot d\eta = (dp1 \cdot \gamma)^2 / L_b \int \eta^{2(\gamma-1)} d\eta$.
  При $\gamma = 0.5$: $\int_0^1 \eta^{-1} d\eta$ — **расходится**. Замена переменных не помогает.
- **Вывод:** Вариант C не работает.

### Выбор: **Вариант B** (ε-отсечка)

Обоснование:
1. Код уже использует ε-отсечку для потока на забое (строки 170–173: `r_w + eps_r` при `gamma < 1`). Это тот же подход.
2. Физически: при $\gamma < 1$ поток через забой бесконечен (сингулярность $dp/dr$ при $r \to r_w$). Это артефакт параметризации $\Phi = \eta^\gamma$, а не физики. Реальный поток конечен (скин-фактор, конечность скважины). ε-отсечка — физически обоснованная регуляризация.
3. Значение ε: уже используется `eps_r = r_w * 1e-3` в потоке. Тот же масштаб для интегралов.

## Подводные камни

- ✅ **Обратная совместимость:** при `gamma > 0.5` ε-отсечка не нужна (интеграл сходится); добавлять только при `gamma ≤ 0.5`
- ⚠️ **Два интеграла:** `Q_quad` в `oil_F1` и JT-интеграл в `energy_F3` — оба нужно регуляризовать
- ⚠️ **Согласованность ε:** использовать тот же `eps_r = r_w * 1e-3`, что и в потоке (строка 171)
- ✅ **Другие коэффициенты:** `A_ij` не содержат `(dp/dr)^2` — только `dp/dr_b` (одна степень), сингулярность $\eta^{\gamma-1}$ интегрируема при любом $\gamma > 0$
- ⚠️ **Точность:** ε-отсечка вносит ошибку O(ε). При `eps_r/r_w = 1e-3` — пренебрежимо мало
- ✅ **Мутация `p_profile.p_wf`:** при baseline `dp_wf_dt = 0` → `dp_dpwf_numerical` не вызывается. Мутация не причина NaN. Оставить как DEBT (отдельная задача)
- ✅ **Тесты:** существующие 317 тестов не затрагиваются (работают при `t_end=0.1`, `gamma > 0.5`)
- ⚠️ **gamma = 0.5 точно:** при `gamma = 0.5` расходимость логарифмическая (`∫ η^{-1} dη = ln η → -∞`). ε-отсечка даёт `ln(ε)` — конечное число
- ⚠️ **Разрыв rhs при gamma = 0.5:** переключение `if gam > 0.5` создаёт скачок в `F_1` и `F_3` при пересечении gamma = 0.5. Radau может уменьшить шаг. Аналогичный разрыв при `gamma = 1` (строки 167–173) не вызывает проблем — solver справляется. Если всё же будет проблема при длинном интегрировании → сгладить порог (DEBT-002)

### Шаг 2: ε-отсечка в `Q_quad` (`oil_F1`)

**Цель:** регуляризовать сингулярность $(dp/dr)^2$ в `Q_quad` при `gamma ≤ 0.5`.

**Файлы:** `method_of_moments/src/coefficients.py`

**Контекст:**
`oil_F1` (строки 145–212) вычисляет $\mathcal{F}_1$ — правую часть уравнения массы нефти. Интеграл `Q_quad` (строка 186) содержит `dp_dr_val * dp_dr_val` — квадрат градиента давления. При `gamma ≤ 0.5` подынтегральная $\sim \eta^{2(\gamma-1)} = \eta^{-1}$ — расходится.

Код уже использует ε-отсечку для потока на забое (строки 170–173):
```python
if gam >= 1.0:
    dp_dr_w = p_profile.dp_dr(r_w, r_b, pbs, gam)
    flux_w = r_w * Lambda_w * dp_dr_w
else:
    eps_r = r_w * 1e-3
    dp_dr_w = p_profile.dp_dr(r_w + eps_r, r_b, pbs, gam)
    flux_w = (r_w + eps_r) * Lambda_w * dp_dr_w
```

**Что сделать:**

В `oil_F1`, строки 188–191, заменить:

До:
```python
    if gam > 0.5:
        Q_quad, _ = quad(Q_quad_integrand, r_w, r_b)
    else:
        Q_quad, _ = quad(Q_quad_integrand, r_w, r_b, points=[r_w + r_w * 1e-6])
```

После:
```python
    if gam > 0.5:
        Q_quad, _ = quad(Q_quad_integrand, r_w, r_b)
    else:
        lower = r_w + r_w * 1e-3
        Q_quad, _ = quad(Q_quad_integrand, lower, r_b)
```

**Обоснование ε = r_w * 1e-3:** тот же масштаб, что уже используется для потока (строка 171). При `r_w = 0.1 м` → `ε = 1e-4 м` — пренебрежимо мало по сравнению с `r_b ≈ 3.73 м`. При `gam > 0.5` оставляем `r_w` как есть — интеграл сходится.
