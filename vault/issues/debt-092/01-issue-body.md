# DEBT-092: Инструкция поставки содержит неоднозначные пути и описания результатов

## Проблема

При проверке установки и запуска в новом окружении коллега обнаружил неоднозначности в инструкции и описании результатов. Нужно уточнить руководство и связанные материалы, чтобы команды можно было воспроизвести после распаковки. Формулы постановки не изменяются.

## Текущее состояние

- В архиве для разработки папка называется `gpn-multiphase-solver-X.Y.Z`, а команды из репозитория используют `cd numerical_solver`. В случае работы без установки приведён пример пути `D:\gpn\solver` без явного шага его создания. Коллега сообщил об отказах запуска примера 23 и двух команд `Copy-Item`.
- Перечень содержимого папки без установки можно принять за полный. По сообщению коллеги, при сборке папки только по перечню pytest не распознал метку `slow` и не нашёл `doc/source/api.rst`. В проекте метка объявлена в `pyproject.toml`, а `tests/test_docs.py` читает `api.rst` и `package.rst`. Нужно проверить состав архива соответствующей версии и зависимости тестов.
- README объясняет работу без Inkscape в §1, но случай без установки не направляет к этому объяснению. Коллега сообщил о предупреждении об отсутствии EMF.
- По сообщению коллеги, невязка энергии примера 23 и `max|Rs - Rs_eq|` различаются в последних разрядах между окружениями `setup.bat` и Anaconda. Повторный расчёт не проводился. Критерии сравнения и причины различий требуют проверки.
- Формулировку об `output\input\` в §3.6 можно понять как сохранение самой книги. По сообщению коллеги, сохраняются `config.json` и три CSV.
- XlsxWriter заявлен зависимостью, команда `template` использует его для создания книги. Проверить зависимости чтения и записи и уточнить пояснение в инструкции.
- Комментарий в `pyproject.toml` ссылается на `tools/release.py`, который находится вне `numerical_solver`. Проверить применимость ссылки в поставке.
- README примера 06 указывает фронт 2.48 м без уточнения способа определения. По сообщению коллеги, консоль выводит дискретный фронт 2.4378 м и интерполированное значение 2.4873 м. Проверить определения и округление: 2.4873 м округляется до 2.49 м.

Сообщения коллеги не воспроизведены независимо. Зависимость двух тестов прототипа от окружения вынесена в DEBT-093.

## Целевое состояние

Инструкция различает пути для репозитория и распакованной поставки, поясняет замену примеров путей, состав папки и зависимости. Описания входных данных, дополнительных программ и численных результатов соответствуют проверенному поведению соответствующей версии.

## Варианты и решение

Для путей можно использовать явные команды для каждого расположения либо единый пример с указанием подстановки фактического пути. Выбор способа правки и проверок пока не принят. Для численных результатов сначала определить смысл показателей и обоснованные допуски. Точное совпадение последних разрядов не следует задавать без обоснования. Состав архива для расчётов изменяется в DEBT-091, поэтому согласовать инструкции с состоянием соответствующей версии.

## Этапы и проверки

1. Проверить состав поставок и воспроизвести замечания на соответствующей версии, уточнить определения результатов и зависимости.
2. Согласовать способ описания путей и внести исправления в руководство и связанные материалы.
3. Проверить команды в условиях репозитория и распакованного архива, сценарий без установки, результаты примеров и связанные тесты документации и поставки.
