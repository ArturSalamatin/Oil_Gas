### Закрыто без реализации

**Решение (2026-10-01):** вариант А из аудита плана, раунд 2. Код не меняется.

**Почему.** Дефект из заголовка («энергия входит при $T = 0$ K») устранён BUG-012. В адвективной форме вклад ячейки $j$ — $\Phi^+_{j-1/2}(T_j - T_{j-1}) + \Phi^-_{j+1/2}(T_{j+1} - T_j)$; у ячейки 0 левый сосед — она сама (условие Неймана), поэтому забойная грань не даёт вклада при любом знаке потока. Члена `+ Phi_plus[0]` в `b[0]` больше нет. Замер `vault/issues/debt-019/probes/round2_energy_inflow.py`: при подменённом втекании поле $T$ побитово совпадает с добычей; прежний член дал бы $\Delta T[0] \approx -348$ K.

Втекания через забой на рабочем пути нет: прототип закрывает скважину при $p[0] \le p_{wf}$ и не допускает отрицательного дебита. Постановка фиксирует это условием `eq:bc_pwf_shutin` (FEAT-020, FEAT-023). Закрытие скважины сторожат четыре теста `tests/test_prototype_adapter.py`.

**Что вынесено:**
- **DEBT-028** — `compute_fluxes` не вызывается в рабочем расчёте, дублирует логику адаптера и при $p_{wf} > p[0]$ считает втекание вместо закрытия скважины. Двухфазная фикстура `tests/test_fluxes.py` проверяет формулу забойной грани при втекании (82 теста).
- Блокирующая зависимость FEAT-019 от DEBT-019 снята.
