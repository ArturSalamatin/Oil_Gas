|---|---|---|
| [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]] | расширенная | Расширенная насыщенность $\widetilde S \notin [0,1]$ для пересыщенных однофазных зон; условия согласования мнимой фазы ($k_g = \widetilde S$); основа варианта N в BUG-014 |

| [[Jaffré Sboui 2010 — закон Генри и исчезновение газовой фазы]] | расширенная | Исчезновение газа как смешанная задача дополнительности $\mathcal H = 0$, $\mathcal F^\top\mathcal G = 0$; решателя и чисел нет; режимы 1/2 проекта — та же NCP, метод S BUG-014 — Newton-min |

## Расширенные обзоры (подробный разбор)

- [[ref_spe202436]] — SPE-202436-MS, Samuel & Muggeridge 2020, POD-RBF NIROM
- [[ref_moments_method]] — метод моментов Баренблатта для двухфазной фильтрации с энергией
- [[Краснов — многофазное псевдодавление и функции источника]] — многофазное псевдодавление, FMB, автомодельная $S(p)$, функции источника
- [[Al-Hussainy 1966 — псевдодавление для реальных газов]] — функция $m(p)$, линеаризация уравнения фильтрации реального газа
- [[Agarwal 1979 — псевдовремя для реального газа]] — $t_a(p)$, type curve matching для buildup газовых MHF-скважин
- [[Kamal Pan 2011 — PTA при многофазном потоке]] — абсолютная проницаемость и насыщенности из КВД при двухфазном потоке
- [[Al-Rbeawi 2018 — детерминированные модели подвижности и сжимаемости при многофазном потоке]] — эмпирические $c_t(p)$, $M_t(t)$, PTA/RTA для HF при многофазном потоке
- [[Raghavan 1976 — псевдодавление для solution gas drive]] — двухфазное $m(p)$ для solution gas drive, drawdown/buildup, абсолютная $k$
- [[Hamdi Jamiolahmady Corbett 2013 — газоконденсат и геологическая гетерогенность в PTA]] — kernel function, TDSC, ramp-эффект при интерференции конденсата и геологии
- [[Boe 1989 — двухфазный анализ КПД]] — автомодельная $S(p)$ через Больцмана, многофазное псевдодавление, стабилизация GOR при drawdown
- [[Anderson Mattar 2005 — улучшенное псевдовремя для газовых пластов при транзиентном потоке]] — корректированное $\tilde{t}_a$ через «область влияния», транзиентный поток в газе
- [[Mitchell Myers 2010 — HBIM и RIM для задач Стефана]] — HBIM/RIM/ARIM для задач Стефана, систематическое сравнение профилей и показателей формы
- [[Goodman 1964 — интегральные методы для нелинейного теплопереноса]] — обзор HBIM (72 стр.): нелинейные $k(T)$, Кирхгоф, полярная симметрия, метод моментов, коллокация, Галёркин
- [[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]] — отрицательные насыщенности для однофазных зон, условия согласования; сравнение с вариантом N прототипа и набросок продолжения для Black Oil
- [[Panfilov Panfilova 2014 — отрицательные насыщенности для трёх фаз и многих компонентов]] — обобщение на $M$ фаз и $N$ компонентов; критика доказательства и тестов; альтернативное продолжение $\widetilde S_g = 1 - B_o^\text{нас}/B_o$ для Black Oil
- [[Panfilov Rasoulzadeh 2010 — отрицательные насыщенности с диффузией и капиллярностью]] — $N$ компонентов, диффузия, капиллярность; критика «аналитического» решения с диффузией и $Pe = 7$; классификация фронта разгазирования ПЗП, где возможны PT-скачки
- [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] — условие согласования для энергии (29); почленные условия для нашей формы уравнения энергии, ложная $Q_{\text{deg}}$ в недонасыщенной зоне, связь с последовательной схемой по $T$
- [[Bourgeat Jurak Smaï 2009 — двухфазная фильтрация с растворением газа в хранилище отходов]] — формулировка без переключения и без мнимых фаз; перевод на Black Oil проекта, сравнение с вариантом N и отрицательными насыщенностями; при $p_c = 0$ разрыв производных на $p_b$ остаётся
- [[Jaffré Sboui 2010 — закон Генри и исчезновение газовой фазы]] — условия дополнительности вместо переключения переменных; ошибка в определении $C$; классификация методов BUG-014 в терминах NCP, связь с отрицательными насыщенностями, масштаб NCP-функции
- [[Ben Gharbia Jaffré 2014 — полугладкий Ньютон для появления и исчезновения газовой фазы]] — Newton-min для исчезновения газа; критика теста (неприменимость теории у $s_\ell = 1$, табл. 1, рис. 7); ветка скважины прототипа и метод S BUG-014 как полугладкий Ньютон без глобализации
