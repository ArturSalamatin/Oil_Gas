# План реализации численного решателя

Двухфазная фильтрация Black Oil с уравнением энергии. Численная схема на радиальной сетке (PDE), замена метода моментов (ODE).

## Ключевое решение

Гидродинамика (давление + насыщенность) решается независимо от температуры. PVT-свойства в гидродинамической части зависят только от давления при фиксированной температуре. Вычисленные поля давления, скоростей и газонасыщенности передаются в уравнение энергии для определения температуры.

## Блоки

**1. Постановка задачи и численная схема.** Система дифференциальных уравнений, допущения, дискретизация, граничные и начальные условия — документ для заказчика. 20.08 – 09.09.2026.

**2. Каркас и изотермическая однофазная задача.** Радиальная сетка (метод конечных объёмов), уравнение давления при p > p_b, валидация. 10.09 – 30.09.2026.

**3. Двухфазная гидродинамика.** Уравнения давления и насыщенности при p < p_b, относительные фазовые проницаемости, разгазирование, PVT-свойства при фиксированной температуре. 01.10 – 28.10.2026.

**4. Уравнение энергии.** Конвекция, теплопроводность, эффект Джоуля–Томсона, адиабатический эффект, теплота дегазации; входные данные — поля давления, скоростей и насыщенности из блока 3. 29.10 – 18.11.2026.

**5. Тестирование и валидация.** Регрессионные тесты, сравнение с аналитическими и численными эталонами. 19.11 – 09.12.2026.

**6. Документация и отчёт.** Описание результатов, руководство по запуску, материалы для отчёта заказчику. 10.12 – 23.12.2026.

## Итого

20.08.2026 – 23.12.2026 (при нагрузке 0.5 ставки).

## Организация проекта

Новая папка `numerical_solver/` в корне проекта. Папка `method_of_moments/` остаётся как архив, не модифицируется.

### Структура numerical_solver/

```
numerical_solver/
├── pyproject.toml
├── doc/                    # документ постановки и численной схемы (блок 1)
├── configs/
│   └── baseline.json
├── src/
│   ├── pvt/                # копия из method_of_moments/src/pvt/
│   │   ├── correlations.py
│   │   └── black_oil.py
│   ├── grid.py             # радиальная логарифмическая сетка (FVM)
│   ├── flux.py             # потоки Дарси на сетке, дивергенции
│   ├── coefficients.py     # Cp, CT, (ρcp)eff — поточечные
│   ├── equations/
│   │   ├── pressure.py     # дискретизация уравнения давления
│   │   ├── saturation.py   # дискретизация уравнения Sg
│   │   └── energy.py       # дискретизация уравнения энергии
│   ├── boundary.py         # граничные условия
│   ├── initial.py          # начальные условия на сетке
│   ├── solver.py           # интегратор
│   ├── postprocess.py      # вывод, визуализация
│   └── main.py             # CLI
├── tests/
│   ├── test_pvt.py         # копия из method_of_moments/tests/
│   ├── test_relperm.py     # копия из method_of_moments/tests/
│   └── ...                 # новые тесты по мере реализации
└── results/                # выходные данные
```

### Переиспользование из метода моментов

PVT-модуль **копируется** (не импортируется) — полная независимость от архивного проекта.

- `pvt/correlations.py` — копия, с заменой `import math` → `import numpy`
- `pvt/black_oil.py` — копия (класс BlackOilFluid: PVT + ОФП)
- `tests/test_pvt.py`, `tests/test_relperm.py` — копия
- `profiles/`, `integrals.py`, `ode_system.py` — не используются

### Источник уравнений

`method_of_moments/two_phase_energy.tex` — LaTeX-документ с полной постановкой системы PDE. Используется как справочник при реализации, не модифицируется.
