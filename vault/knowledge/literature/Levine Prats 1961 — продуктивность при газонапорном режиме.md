# Levine Prats 1961 — продуктивность при газонапорном режиме

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Levine J.S., Prats M.** The Calculated Performance of Solution-Gas-Drive Reservoirs. *Soc. Pet. Eng. J.*, Sept. 1961, 142–152; Trans., AIME, Vol. 222.

## Аннотация

Показали, что при допущении постоянной скорости выработки нефти уравнение радиального потока может быть непосредственно проинтегрировано (ур. 3 в Raghavan 1976). Для вычисления связи $S_o(p)$ используется GOR из дифференциального материального баланса Муската с двумя дополнительными допущениями: (1) GOR постоянен в пространстве и совпадает с решением по Муската; (2) GOR соответствует давлению и насыщенности на внешней границе. Raghavan (1976) показал, что подход Levine–Prats даёт менее точную корреляцию, чем использование мгновенного забойного GOR.

## Потенциал для проекта

Альтернативный способ замыкания связи $S_o(p)$ для вычисления $m(p)$. Допущение о пространственно-постоянном GOR — грубое, но может быть полезно как нулевое приближение в моделях М.1–М.2 (Draft/cooling_models.tex).
