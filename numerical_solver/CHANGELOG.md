# Журнал изменений gpn-multiphase-solver

Изменения пакета `gpn-multiphase-solver` от выпуска к выпуску. Номер
установленной версии печатает команда `gpn-solver --version` (или
`python -m gpn_multiphase_solver --version`), а из Python он доступен как
`gpn_multiphase_solver.__version__`. Версии, которыми получены результаты
расчёта, записаны в файле `versions.txt` каталога вывода.

## Правило номеров

Номер версии состоит из трёх чисел MAJOR.MINOR.PATCH и записывается в форме
PEP 440.

- **MAJOR** повышается при несовместимом изменении публичного интерфейса
  пакета (README, раздел «Использование из Python»), формата файла
  конфигурации или книги ввода Excel: прежние программы, конфигурации или
  книги без правки перестают работать.
- **MINOR** повышается при добавлении возможностей без потери совместимости:
  прежние конфигурации и книги считаются без правки.
- **PATCH** повышается при исправлении ошибок.
- Изменение, после которого при тех же исходных данных получаются другие
  числа, описывается в разделе выпуска отдельно: какие величины изменяются и
  насколько.
- Между выпусками номер имеет суффикс `.devN`: `1.0.0.dev0` означает
  разработку к выпуску 1.0.0. Номер без суффикса ставится при выпуске.
- Прототип гидродинамики `radial-blackoil` нумеруется отдельно:
  `1.0.3+gpn.N`, где 1.0.3 – версия исходного прототипа, N – номер набора
  изменений, внесённых в него в рамках проекта. N повышается при выпуске
  решателя, если код прототипа изменился с прошлого выпуска. Решатель
  требует ровно одну версию прототипа (`pyproject.toml`).

Раздел выпуска озаглавлен `## <номер> — <дата>` и делится на подразделы
«Добавлено», «Изменено», «Исправлено», «Удалено». Изменения, ещё не вошедшие
в выпуск, собраны в разделе «Не выпущено».

## 1.0.6 — 2026-10-20

### Добавлено

- **FEAT-039.** Нарастающий шаг `time.dt_after_control_change` действовал
  только после смены режима скважины: пуск из равновесия – первый интервал
  истории – всегда шёл полным шагом `time.dt_integration`, и первая запись
  после пуска считалась с погрешностью первого порядка по времени (у
  температуры у забоя – до десятых долей К). Теперь пуск тоже считается
  сменой режима: при заданном поле первый шаг расчёта начинается с подшага
  не длиннее h0 и удваивается, в журнале расчёта – «первый шаг от … с
  (пуск)». Конфигурации без поля (`null`) считаются как прежде. Числа
  меняются в конфигурациях с полем и в расчётах по книгам Excel с h0 меньше
  Δt (в шаблоне книги h0 = 0,11 с): первые записи после пуска, дальше
  отличия затухают. Пример 22: через 1 мин дебит нефти 10,67 → 8,21
  м³ст/сут, T(r_w) − T0 −0,267 → −0,252 К, p(r_w) 151,79 → 151,38 бар; на
  30 сут T(r_w) та же до 10⁻⁴ К. Пример 17: T(r_w) на 1 сут +0,050 К, на
  30 сут −0,0003 К.

## 1.0.0 — 2026-10-18

Первый выпуск.

### Добавлено

- Расчёт одномерной осесимметричной задачи для призабойной зоны пласта:
  фильтрация нефти с растворённым газом и свободного газа (модель Black
  Oil, вода отсутствует) совместно с уравнением энергии — конвекция,
  теплопроводность, адиабатический эффект, эффект Джоуля–Томсона и
  скрытая теплота разгазирования. Метод конечных объёмов на
  логарифмической сетке по радиусу. Давление, газонасыщенность и
  газосодержание рассчитывает прототип гидродинамики `radial-blackoil`
  (требуется ровно версия `1.0.3+gpn.2`), температуру — решатель пакета.
- Свойства флюидов (PVT): корреляции Стендинга — с необязательными
  сжимаемостью недонасыщенной нефти (`pvt.co_undersaturated`) и поправкой
  вязкости Била–Стендинга выше давления насыщения
  (`pvt.mu_o_undersaturated`) — или таблицы CSV: нефть в формате PVTO,
  газ. При табличном задании корреляции не используются.
- Относительные фазовые проницаемости: модель Кори или таблица CSV.
- Режим работы скважины по этапам (`time.history`): заданное забойное
  давление или заданный дебит нефти с нижним пределом забойного
  давления; останов — дебит 0. Продолжительность этапа — одним
  интервалом, серией одинаковых интервалов или длительностью с шагом
  записи. Скин-фактор. Нарастающий шаг после смены режима
  (`time.dt_after_control_change`).
- Проверка исходных данных до расчёта: опечатка в имени поля,
  недопустимое значение, отсутствие обязательного поля, перенасыщенная
  газом начальная нефть — отказ с сообщением, в котором указано поле;
  таблицы CSV — формат, пределы значений, монотонность, отрицательная
  сжимаемость (отказ или предупреждение). Во время расчёта выход
  состояния за пределы таблиц PVT и ОФП отмечается в журнале решателя;
  нефизичное состояние (давление или температура не больше нуля,
  газонасыщенность вне [0, 1], отрицательное газосодержание, нечисловые
  значения) останавливает расчёт с сообщением.
- Книга ввода Excel, версия 1: величины в инженерных единицах, проверка
  ячеек — все ошибки сразу, с листом и ячейкой. Книга переводится в файл
  конфигурации и таблицы CSV в СИ; перевод сохраняется в `output/input/`,
  по нему расчёт повторяется без книги.
- Команда `gpn-solver` (или `python -m gpn_multiphase_solver`): `run` —
  расчёт по файлу конфигурации или по книге (ключи `--output`, `--title`,
  `--profiles`; коды возврата 0, 1, 2); `template` — шаблон книги с
  демонстрационными значениями; `convert` — перевод книги без расчёта;
  `--version` — номер решателя.
- Результаты расчёта: `well_history.csv`, `profiles.csv`; рисунки
  профилей давления, температуры, газонасыщенности и газосодержания,
  дебитов, динамики у забоя, использованных ОФП и PVT, балансов энергии
  и массы компонентов — PNG, а также SVG и EMF (EMF — при установленном
  Inkscape); `versions.txt` — версии решателя, прототипа, Python, numpy и
  scipy. В консоли — сводка, невязки балансов, проверка равновесия
  газосодержания; по выбору — сравнение со стационарным режимом
  (`output.steady_state`).
- Использование из Python: `run_case` — тот же набор результатов с
  доступом к данным расчёта; `load_config`, `SimulatorFactory.from_config`
  и `simulator.run` — только расчёт.
- 24 примера расчёта (`examples/`): файл конфигурации или книга, README
  с описанием физики и контрольными значениями.
- Номер версии пакета `gpn_multiphase_solver.__version__`, журнал
  изменений (этот файл).
