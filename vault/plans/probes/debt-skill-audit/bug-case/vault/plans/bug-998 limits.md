# План BUG-998: допустимость нулевого лимита

## Исходное состояние

В `src/limits.py` выражение `value <= 0` отклоняет ноль. По записи реестра допустимы неотрицательные значения.

## Шаг 1: тест до исправления

Создать `tests/test_limits.py`: проверить, что `validate(0)` возвращает `0`, `validate(1)` возвращает `1`, а `validate(-1)` вызывает `ValueError`. Запустить из корня фикстуры интерпретатором `numerical_solver/.venv/Scripts/python.exe` из корня Oil_Gas команду `-m pytest tests/test_limits.py`. До исправления первый тест должен падать.

## Шаг 2: исправление

В `src/limits.py` заменить `value <= 0` на `value < 0`. Повторно запустить указанные тесты. Все три должны проходить, исходный интерфейс остаётся прежним.
