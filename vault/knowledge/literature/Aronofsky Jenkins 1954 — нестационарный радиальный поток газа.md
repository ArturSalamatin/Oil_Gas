# Aronofsky Jenkins 1954 — нестационарный радиальный поток газа

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Aronofsky J.S., Jenkins R.** A Simplified Analysis of Unsteady Radial Gas Flow. *Trans. AIME*, 1954, **201**, 149.

## Аннотация

Показано, что решения для нестационарной радиальной фильтрации идеального газа из замкнутого пласта коррелируют с решениями van Everdingen–Hurst для жидкости через безразмерное время, основанное на сжимаемости при начальном давлении. Введено понятие транзиентного дренажного радиуса $r_d$. Корреляция слабо зависит от расхода — достаточно для инженерной точности. Al-Hussainy 1966 обобщил этот подход на реальные газы через функцию $m(p)$.

## Потенциал для проекта

Концепция дренажного радиуса и жидкостной аналогии — базовые идеи для квазистационарных приближений (модели М.3–М.4).
