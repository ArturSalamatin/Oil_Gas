# Oliver 1990 — kernel function для оценки проницаемости из PTA

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Oliver D.S. The Averaging Process in Permeability Estimation From Well-Test Data. *SPE Formation Evaluation*, 1990, 5(3), 319–324.

## Аннотация
Введена нелинейная весовая (ядерная) функция $K(r_D, t_{Di})$, показывающая вклад проницаемости на расстоянии $r$ в отклик давления в момент $t$. Более 90% вклада приходится на кольцевую зону $r_D \in [0.12\sqrt{t_{Di}},\, 2.34\sqrt{t_{Di}}]$. Функция выражена через функцию Уиттекера (confluent hypergeometric function). Мгновенная проницаемость (instantaneous permeability) — взвешенное гармоническое среднее радиальных проницаемостей. Концепция изначально разработана для однофазного drawdown нефтяных скважин.

## Потенциал для проекта
Kernel function — инструмент для анализа радиального профиля подвижности при ГДИС. Применима к ПЗП с зоной разгазирования: «moving average window» показывает, из какой радиальной зоны приходит информация в данный момент buildup. Возможная адаптация для двухфазного случая (нефть + свободный газ).
