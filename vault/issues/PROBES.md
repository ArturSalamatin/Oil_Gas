# Диагностические скрипты (`probes/`)

Скрипты, воспроизводящие замеры, на которые ссылаются планы и записи
реестра. Живут в `vault/issues/<id-lowercase>/probes/`.

## Откуда взялись

Перенесены 2026-09-20 из временных каталогов Claude Code, куда их
складывали прежние сессии по указанию команд `/issue`, `/audit-plan`
и `/plan-*`. Это противоречило CLAUDE.md («Все новые файлы — только
в папке проекта»); инструкции команд исправлены тем же днём.

Перенесено выборочно — 23 скрипта из 44. Не переносились:
- `inj_*.py` (5 файлов по 234 строки) — прототипы эталона DEBT-016
  с внесёнными ошибками. Дублируют `numerical_solver/tests/test_energy_matrix_examples.py`,
  который реализован и покрывает те же шесть инъекций;
- `balance_*.py`, `apply_plan.py`, `run_with_patch.py`, `conftest_patch.py` —
  патчи рабочих файлов для аудита DEBT-013, привязаны к снятому с тех пор
  состоянию кода;
- `check9.py`, `check_n150.py`, `check_retry5.py`, `rollback_check.py`,
  `audit_step2_check.py`, `audit2_*.py`, `check_noguard.py` — одноразовые
  проверки без самостоятельной ценности.

## ⚠️ Ограничения

1. **Абсолютные пути.** Скрипты содержат жёстко прописанный
   `ROOT = Path(r"d:\Lessons\Grants\2026\GPN\Oil_Gas\numerical_solver")`
   и на другой машине не запустятся без правки. Оставлено как есть:
   переписывание 23 файлов на относительные пути выходит за рамки
   переноса и потребовало бы повторной проверки каждого.

2. **Привязка к состоянию кода.** Скрипты писались под конкретную
   ревизию. Часть обращается к внутренним атрибутам (`solver._grid`,
   `_pvt`), которые могли измениться. Перед доверием результату —
   запустить и убедиться, что он не падает.

3. **Запуск** — из `numerical_solver/`, чтобы подхватился venv:
   ```powershell
   cd numerical_solver
   .venv\Scripts\python ..\vault\issues\bug-007\probes\diag_bug007_matrix.py
   ```
   Проверено на `diag_bug007_matrix.py` (2026-09-20): работает,
   расхождение 0.000e+00 — подтверждает, что BUG-007 исправлен.

4. **Кодировка.** Вывод на русском в консоли Windows может отображаться
   кракозябрами (cp1251 против UTF-8). На результат не влияет.
