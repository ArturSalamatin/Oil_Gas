# Cinco-Ley Samaniego 1978 — трещина конечной проводимости

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Cinco-Ley H., Samaniego-V. F., Dominguez-A. N.** Transient Pressure Behavior for a Well With a Finite Conductivity Vertical Fracture. *Soc. Pet. Eng. J.*, August 1978, 253–264.

## Аннотация

Решение задачи о нестационарном давлении для скважины с вертикальной трещиной конечной проводимости (finite-conductivity vertical fracture). Введена безразмерная проводимость трещины $F_{cD}$. Типовые кривые из этой работы используются в Agarwal 1979 для type curve matching при анализе buildup газовых скважин.
