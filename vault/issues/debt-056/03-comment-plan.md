План: `vault/plans/debt-056 skin-bhp-range-check.md`. Ветка: `refactor/debt-056/skin-bhp-range-check`. Шагов: 6. База `eee5334` (DEBT-051 влит), тестов 1592 → 1613 (+21).

**Решения пользователя (2026-10-10):** прототип не меняется — проверка при загрузке конфига (`io/config.py`); **отказ при любом $s < 0$** (отрицательный скин в проекте не предусмотрен), в сообщении обход — `geometry.r_well` = $r_w e^{-s}$, `skin` = 0, с оговоркой, что температура забоя тогда относится к $r_w e^{-s}$; FEAT на эквивалентный радиус не регистрируется; **предупреждение при $s > 50$**; **предупреждение о `p_wf` / `min_bhp` $\ge p_0$ для любого интервала**.

**Устройство:**
- Отказ и предупреждение о скине — в конце `_validate`, после всех прочих отказов. Предупреждение даёт долю установившегося притока $\ln(R_{ext}/r_w)/(\ln(R_{ext}/r_w) + s)$ (baseline, $s = 50$ — 11 %).
- Предупреждение о забое — `_warn_well_shut` после `_validate`: одно на объект `time.history` с местом `history[i]` (`_expand_history` возвращает ещё пары «место — образец»). При `q_oil = 0` (намеренный останов, примеры 16, 17) — без предупреждения.
- P8 §5 переписывается по коду: скалярные поля проверяет `_validate`, таблицы и согласованность — фабрика, прототип только повторяет часть проверок.
- `problem_statement.tex`: абзац о скине у проводимости забойной грани (сейчас формула без $s$).

**Замер при планировании:** проба `vault/issues/debt-056/probes/configs_scan.py` — 32 конфига проекта, ни одного с `skin` ≠ 0, `p_wf`/`min_bhp` $\ge p_0$, отказом или предупреждением `load_config`. Расчётный код и прототип не меняются.
