# FEAT-029: Пример 17 — останов после добычи с развитой газовой зоной и сильным охлаждением забоя

## Цель

Добавить в `numerical_solver/examples/` самостоятельный сценарий
`17_shut_in_strong_cooling`: конфиг примера 20 (PVT Стендинга, ОФП Кори,
$R_{s,0} = 300$, $p_b = 30.29$ МПа, $p_0 = 33$ МПа, $T_0 = 380$ К, $k = 10$ мД)
на сетке $N = 200$. Скважина **15 сут добывает при $p_{wf} = 5$ МПа, затем
останавливается на 15 сут** (управление по дебиту, $q_{oil} = 0$),
`dt_integration` = 3600 с. Пример показывает то, чего нет ни в одном другом:

- забой, охлаждённый при добыче на 15 К, после останова прогревается — на 3.76 К
  за первый час, к 30 сут недогрев 2.69 К;
- у забоя свободный газ ($S_g = 0.45$) растворяется за первый час, нефть
  остаётся недонасыщенной;
- дальше от скважины, на 3.6–24 м, газ остаётся и при $p = p_0$ — **кольцо
  газа**; нефть в нём насыщена сверх $R_{s,0}$ ($R_s = R_s^{eq}(33\ \text{МПа}) = 332.4$),
  кольцо теплее $T_0$ на 0.22 К.

Ядро библиотеки (`gpn_multiphase_solver/`), прототип
(`HydroSolverPrototype/`), общие модули `examples/*.py` и постановка
(`problem_statement.tex`) **не меняются**. Меняются: новая папка примера,
списки и класс проверок в тестах, сводный README примеров, одна ссылка в
README 16, комментарии в `tests/test_energy_matrix_examples.py`.

**Подтип:** режим (останов скважины из развитой газовой зоны в примерах).

**Вне объёма:**
- ускорение останова (ступени `advance`) — [[DEBT-040]] (#69);
- локальное дробление вместо равномерного A-retry, которое сняло бы
  требование `dt_integration` ≤ 3600 с, — [[DEBT-015]] (#61);
- согласование $c_{p,g}$ и $\mu_{JT,g}$ с $R_{s,0} = 300$ — тепловые константы
  берутся из конфига 20 как есть (решение пользователя: конфиг 20);
- повторный пуск после останова, останов через давление — не входят.

### 1.1. Добыча (0–15 сут)

Забойное давление 5 МПа — на 25 МПа ниже $p_b$. Давление у забоя (центр
ячейки 0) — 5.17 → 5.15 МПа. Газ выделяется в зоне до 51.9 м (165 ячеек из
200), $S_g(r_w)$ = 0.443 → 0.449. Газ неподвижен до $S_{gc} = 0.1$ и копится в
пласте: GOR = 256.2 → 271.9 < $R_{s,0}$ = 300 и растёт. Дебит нефти
$3.81\cdot10^{-3}$ → $3.33\cdot10^{-3}$ м³ст/с (329 → 288 м³ст/сут).

Забой охлаждается: $\Delta T(r_w)$ = −13.68 К за 1 сут, −14.98 К на 15 сут
($T(r_w)$ = 365.0166 К). Члены баланса энергии по области за добычу, Дж:
дегазация $-2.23\cdot10^{11}$, адиабатический (расширение при падении давления)
$-1.33\cdot10^{11}$, конвекция $+1.65\cdot10^{11}$, Джоуль–Томсон
$+3.8\cdot10^{10}$. Адиабатический член по области — это истощение всего
пласта; у забоя давление выходит на 5.15 МПа за первые сутки, и охлаждение
от 1 до 15 сут (−13.68 → −14.98 К) идёт уже при почти постоянном давлении.
Что без теплоты дегазации забой не охлаждается, а греется (+0.49 К на
30 сут), известно из README 20 (тот же флюид и тепловые константы); README 17
это число не приводит (правило самостоятельности примеров). Зона охлаждения
($\Delta T < -1.5$ К) — до 7.8 м.

### 1.3. Откуда тепло на останове

**По всей области** (приращения накопленных членов от конца добычи,
`energy_balance.compute_balance`), Дж:

| член | первые сутки останова | весь останов (15 сут) |
|---|---|---|
| изменение запаса $\Delta E$ | $+1.013\cdot10^{11}$ | $+1.776\cdot10^{11}$ |
| адиабатический (сжатие) | $+6.674\cdot10^{10}$ | $+1.371\cdot10^{11}$ (77 %) |
| дегазация (здесь — растворение) | $+3.373\cdot10^{10}$ | $+3.960\cdot10^{10}$ (22 %) |
| Джоуль–Томсон | $+5.9\cdot10^{8}$ | $+6.8\cdot10^{8}$ |
| конвекция | $+1.9\cdot10^{8}$ | $+2.0\cdot10^{8}$ |
| теплопроводность через контур | $+5.8\cdot10^{5}$ | $-6.1\cdot10^{6}$ |

За добычу член дегазации $-2.226\cdot10^{11}$ Дж; на останове знак обратный —
газ растворяется, теплота выделяется. Невязка баланса — $1.49\cdot10^{-15}$
(финал), не больше $2.24\cdot10^{-15}$ по записям.

**У забоя** (члены схемы, просуммированные по ячейкам зоны, проба
`plan_numbers.py`; теплопроводность — остаток уравнения зоны; адвективная
форма конвекции `eq:energy_conv_face` — поячеечный член):

| зона $r < 1$ м (61 яч.) | $\Delta E$, Дж | сжатие | растворение | конвекция | теплопроводность |
|---|---|---|---|---|---|
| 1-й час | $+8.6\cdot10^{7}$ | 35 % | 61 % | 3 % | 1 % |
| 2–24 ч | $+5.6\cdot10^{7}$ | 38 % | 10 % | 1 % | 51 % |
| сутки 2–15 | $+1.5\cdot10^{8}$ | 3 % | 0 % | 0 % | 97 % |

В первый час зона у забоя греется сама — растворяется её газ, сжимаются
нефть и скелет. Дальше газа у забоя нет, и тепло приходит теплопроводностью
из зоны 1–25 м, где газ растворяется и нефть сжимается ещё сутки (в зоне
$r < 10$ м за весь останов: сжатие 46 %, растворение 52 %, теплопроводность
1 %). **Конвекция на забой не работает:** поры, освобождённые растворившимся
газом, заполняет нефть из соседних слоёв почти той же температуры (3 % в
первый час). Гипотеза «тёплая нефть притекает к забою» проверена и
отвергнута замером.

## Шаг интегрирования и время расчёта

`time.dt_integration` = 3600 с. Первый час останова решается одним шагом;
дальше решатель сам дробит отдельные часы на 2–8 подшагов (A-retry, от 7.5
до 30 мин) — с 3-го по 18-й час первых суток и в сутки 2–6 останова. Шаг
длиннее часа на останове из развитой газовой зоны дробится так же, но на
равные подшаги, и сходиться обязан каждый: расчёт дольше, а при неудачном
сочетании шага и состояния может остановиться с ошибкой (BUG-020, реестр
проекта).

Сетка $N = 200$. Около 70 % времени расчёта — первые трое суток останова,
пока выравнивается давление; после этого шаги почти ничего не стоят. Чем
больше $N$, тем дороже останов: его цена растёт с $N$ быстрее линейной.

## Как модифицировать

- **Длительности добычи и останова, частота записи** — поля `duration` и
  `dt_out` блоков `time.history`. Расписание удобно пересобрать короткой
  программой (из папки примера):

  ```python
  import json
  from pathlib import Path

  path = Path("config.json")
  cfg = json.loads(path.read_text(encoding="utf-8"))
  SHUT = {"control": "rate", "q_oil": 0.0, "min_bhp": 101325.0}
  cfg["time"]["history"] = [
      {"duration": 15 * 86400.0, "dt_out": 86400.0, "control": "pressure", "p_wf": 5.0e6},
      {"duration": 86400.0, "dt_out": 3600.0, **SHUT},
      {"duration": 14 * 86400.0, "dt_out": 86400.0, **SHUT},
  ]
  path.write_text(json.dumps(cfg, indent=2, ensure_ascii=False) + "\n",
                  encoding="utf-8")
  ```

- **Сетка** — `grid.N`. Чем больше $N$, тем дольше останов (см. выше);
  $T(r_w)$ от сетки почти не зависит.
- **Без скрытой теплоты:** `thermal.L_degas = 0` обнуляет член дегазации —
  и охлаждение при выделении газа на добыче, и нагрев при растворении на
  останове.
- **Шаг расчёта** задаёт только `time.dt_integration`; на останове из
  развитой газовой зоны — не больше 3600 с (раздел выше). Поля
  `numerics.dt_min`, `numerics.dt_max` и `time.start_day` решателем не
  читаются.
- **Число моментов на профилях** — `n_profiles` в `main.py` (равномерно по
  времени, ближайшие записи).
