# Kamal Pan 2011 — PTA при многофазном потоке

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Kamal M.M., Pan Y.** Pressure Transient Testing Under Multiphase Flow Conditions. *SPE*, 2011. SPE 141572.

## Аннотация
Рассматривается анализ давления (Pressure Transient Analysis) при многофазном потоке. В документе Краснова цитируется в контексте общего описания подходов к интерпретации ГДИС с учётом многофазности — связь функций псевдодавления с данными промысловых исследований скважин.

## Потенциал для проекта
Методика PTA для двухфазного потока может быть использована для верификации моделей ПЗП: сравнение модельных кривых давления с результатами промысловых КПД/КВД.
