# Agarwal Carter Pollock 1979 — MHF симулятор

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Agarwal R.G., Carter R.D., Pollock C.B.** Evaluation and Performance Prediction of Low-Permeability Gas Wells Stimulated by Massive Hydraulic Fracturing. *J. Pet. Tech.*, March 1979, 362–372.

## Аннотация

Разработан численный симулятор для газовых скважин с массированным ГРП (MHF) в пластах с низкой проницаемостью. Симулятор генерирует типовые кривые для трещин конечной проводимости. В Agarwal 1979 использован как инструмент для моделирования drawdown и buildup данных, на которых проверяется метод псевдовремени $t_a(p)$.

## Потенциал для проекта

Методологическая основа для верификации — аналог стандартного теста (manufactured solution) для проверки аналитических/полуаналитических методов в задачах с трещинами.
