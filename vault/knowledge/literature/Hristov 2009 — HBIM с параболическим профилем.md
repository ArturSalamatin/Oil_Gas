# Hristov 2009 — HBIM с параболическим профилем

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Hristov J.** The heat-balance integral method by a parabolic profile with unspecified exponent: Analysis and benchmark exercises. *Thermal Sci.*, 2009, Vol. 13, pp. 27–48.

## Аннотация
Обзорная работа по HBIM с параболическим профилем $u \sim (1-x/\delta)^n$ при нефиксированном показателе $n$. Систематизация бенчмарков и сравнение с другими подходами. Mitchell & Myers (2010) ссылаются как на общее введение в HBIM с произвольным показателем.

## Потенциал для проекта
Обзорный источник категории C. Полезен для обоснования выбора профиля $(1-\eta)^\beta$ в moments_method.tex.
