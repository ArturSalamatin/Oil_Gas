#### 🟡 Команды плана не исполнялись бы в PowerShell

Девять команд в блоках, помеченных **`powershell`**, использовали `grep` — в том числе с regex-альтернативой `"a|b|c"`. Проверено:

```powershell
Get-Command grep   # -> ничего не найдено
```

`grep` в этой среде отсутствует, а вертикальная черта была бы разобрана как конвейер. Именно этими командами проверяется главный критерий завершения — «ни одного совпадения `temperature_ode|ode_grid_convergence|diag_ode_dt`».

**Исправлено:** все девять заменены на `Select-String`, проверенный прогоном (43 совпадения по `.py`+`.md` на текущем состоянии). Добавлена плашка с таблицей замен и оговоркой, что из Git Bash исходные `grep` по-прежнему верны.

| Инструмент | Команда | Особенности |
|---|---|---|
| `Select-String` | `Get-ChildItem -Recurse -Include *.py,*.md \| Select-String -Pattern "a\|b"` | видит и неотслеживаемые файлы |
| `git grep` | `git grep -n -E "a\|b" -- "*.py"` | быстрее, но только файлы под git |

#### 🟡 База ветвления указана неверно

План требовал ветвиться от `fix/bug-012/advective-convection-form`, «иначе ядро будет дивергентным и замеры не сойдутся». Проверено — **это не так**:

```powershell
git diff --stat numerical_scheme/implementation fix/bug-012/advective-convection-form -- numerical_solver/examples/
# -> пусто
git diff --stat numerical_scheme/implementation fix/bug-012/advective-convection-form -- numerical_solver/gpn_multiphase_solver/
# -> пусто
```

Адвективная форма BUG-012 **уже влита** в базовую ветку. Ветка BUG-012 опережает её на 2 коммита: merge и `bcbd403`, который правит только `tests/test_energy_matrix_examples.py` — файлов этой задачи не касается. Состав тестов в обеих ветках идентичен, baseline 861 верен для любой базы.

**Исправлено:** база изменена на `numerical_scheme/implementation` — как требует конвенция проекта. Ветвление от ветки другой задачи затянуло бы в историю DEBT-022 чужой незавершённый коммит.
