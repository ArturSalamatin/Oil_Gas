# Carter 1962 — нестационарный радиальный поток газа

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Carter R.D.** Solutions of Unsteady-State Radial Gas Flow. *J. Pet. Tech.*, 1962, 549.

## Аннотация

Конечно-разностные решения для нестационарного радиального потока реального газа. Введена функция газовой подвижности $M(p) = kph / (T\mu z)$, интеграл от которой пропорционален $m(p)$ Al-Hussainy. Учтён эффект wellbore storage (ёмкость ствола скважины). Решения Carter использованы Al-Hussainy 1966 для верификации суперпозиции линеаризованных решений с нарастающим расходом.
