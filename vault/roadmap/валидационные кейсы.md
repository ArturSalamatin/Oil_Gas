# Валидационные кейсы

## Формат записи

```
### VAL-NNN: Краткое описание
- **Эталон:** аналитическое решение / численное решение / OPM Flow
- **Сценарий:** параметры, ГУ, время
- **Метрика:** что сравнивать, tolerance
- **Статус:** 🔴 ОТКРЫТ / ✅ ПРОЙДЕН <дата> / ⏸️ ОТЛОЖЕН <дата>
- **План:** [[id slug]]
```

Статус ⏸️ ОТЛОЖЕН — кейс не выполняется по внешней причине (нет эталона,
нет инструмента, направление закрыто). Обязательно указать причину
отложения и что именно снимет отложение.

## Записи

### VAL-001: Однофазный стационарный приток (формула Дюпюи)
- **Фаза:** 8
- **Зависит от:** фазы 0–7 (завершены)
- **Эталон:** аналитическая формула q = 2πkh(pe−pw)/(μ·Bo·ln(Re/rw)), лог-профиль p(r)
- **Сценарий:** Sg=0, μ_JT=0, L=0, co=0, стационарный режим
- **Метрика:** дебит rel=1e-10, давление rel=1e-12, T→T_ext atol=1 К
- **GitHub:** [#16](https://github.com/ArturSalamatin/Oil_Gas/issues/16)
- **Ветка:** `val/val-001/dupuit-steady-state`
- **План:** [[val-001 dupuit-steady-state]]
- **Статус:** ✅ ПРОЙДЕН (2026-08-29)

### VAL-002: Верификация TridiagEnergySolver на аналитических эталонах
- **Фаза:** 6
- **Зависит от:** VAL-001
- **Эталон:** аналитические решения в радиальной геометрии (конвекция+теплопроводность, JT, диффузия E₁)
- **Сценарий:** 4 кейса (A–D): стационарные (A: конвекция+кондукция, B: чистый JT, C: конвекция+JT) и нестационарный (D: диффузия)
- **Метрика:** T(r) rel < 1% (стационар), < 5% (нестационар); энергобаланс < 1e-10; принцип максимума
- **GitHub:** [#18](https://github.com/ArturSalamatin/Oil_Gas/issues/18)
- **Ветка:** `val/val-002/energy-solver-verification`
- **План:** [[val-002 energy-solver-verification]]
- **Статус:** ✅ ПРОЙДЕН (2026-09-01) — 18 тестов, BUG-002 обнаружен (порядок сходимости 0.5 вместо 2)

### VAL-003: Полная задача vs OPM Flow
- **Фаза:** 6
- **Зависит от:** VAL-002
- **Эталон:** OPM Flow с эквивалентной радиальной сеткой
- **Сценарий:** baseline.json параметры, полная система с температурой
- **Метрика:** rb(t), pwf(t), T(rw,t); tolerance < 10%
- **Причина отложения (2026-09-09, решение пользователя):** внешний эталон требует установленного и настроенного OPM Flow с эквивалентной радиальной сеткой; в проекте есть только руководство (`Refs/OPM Flow Reference Manual`). Скорее всего задача выполняться не будет вовсе.
- **Следствие:** внешнего подтверждения корректности у решателя нет и не планируется. Валидация остаётся внутренней — замкнутые решения (VAL-001, VAL-002), интегральные балансы, сходимость по сетке и по $\Delta t$.
- **Что снимет отложение:** появление работающего OPM Flow либо иного независимого эталона.
- **Статус:** ⏸️ ОТЛОЖЕН (2026-09-09)

### VAL-004: Сходимость по шагу времени на останове скважины из развитой газовой зоны
- **Эталон:** численный — тот же расчёт с последовательно уменьшаемым $\Delta t$ (предел $\Delta t \to 0$, оценка порядка по Ричардсону; неявный Эйлер — ожидаемо первый порядок)
- **Сценарий:** `numerical_solver/tests/data/bug020_rs150/config.json` — 10 сут добычи при 3 МПа, затем `q_oil = 0`; величины $p(r_w)$, $T(r_w)$, $S_g$, $R_s$ на 1 ч и 1 сут останова при $\Delta t$ = 3600 с (одним шагом ступени 4), 1800, 900, … до единиц секунд. При необходимости — конфиги 19–21 (10 сут добычи + сутки останова)
- **Наблюдение (2026-10-07, планирование [[DEBT-015]]):** первый час останова одним шагом 3600 с — $p(r_w)$ = 176.6086 бар, $T(r_w)$ = 397.7928 К, двухфазных 263; подшагами 7–112 с (локальное дробление G1a без ступени 4) — 185.3065 бар, 397.8867 К, 255; подшагами по 7 с (G0) — 185.4483 бар, 397.8887 К. Расхождение шага 1 ч с мелкими — 8.7 бар и 0.09 К; мелкие между собой — 0.14 бар. Выводы: `vault/issues/debt-015/probes/case_rs150.out.txt`, `examples_g1a.out.txt`. Ступень 4 решает те же дискретные уравнения (тот же корень, `test_same_root_as_standard_stages`), поэтому расхождение — погрешность шага по времени, а не решателя
- **Метрика:** порядок сходимости по $\Delta t$ и отклонение шага 3600 с от предела по $p(r_w)$, $T(r_w)$ на 1 ч и 1 сут; tolerance — решить при планировании (вопрос: нужен ли предел шага после смены управления скважиной)
- **Зачем:** пример 16 и пример FEAT-029 считают останов шагом 1 ч, и ступень 4 принимает его целиком — точность первых часов не контролируется. Внешнего эталона нет ([[VAL-003]]), валидация внутренняя — сходимость по $\Delta t$
- **Связано с:** [[DEBT-015]], [[BUG-020]], [[FEAT-029]], [[VAL-003]]
- **Обнаружено:** 2026-10-07 — планирование [[DEBT-015]], регистрация по решению пользователя
- **Статус:** 🔴 ОТКРЫТ
