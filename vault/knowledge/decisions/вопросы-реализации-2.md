# Вопросы реализации — второй раунд

Решения приняты 2026-08-25.

## Решённые

### 1. fluxes.py — отдельный модуль вычисления потоков

**Решение:** вынести в `src/fluxes.py`. Единое место для:
- Upstream-логика (выбор ячейки с бо́льшим давлением)
- Вычисление G_o, G_g (потоки компонентов)
- Вычисление Q_o, Q_g (расходы фаз)
- Вычисление u_o, u_g (скорости)
- Вычисление m_o, m_g (массовые расходы)

Используется: AnalyticalHydroSolver, AdapterHydroSolver, EnergySolver (для Q), тесты.

### 2. EnergyResult — хранить вклады в истории

**Решение:** EnergySolver.solve() возвращает EnergyResult. Все вклады хранятся в SimulationHistory на концах интервалов.

```python
@dataclass
class EnergyResult:
    T: np.ndarray           # [N] — температура, К
    Q_conv: np.ndarray      # [N] — конвективный вклад, Вт
    Q_cond: np.ndarray      # [N] — кондуктивный, Вт
    Q_jt: np.ndarray        # [N] — JT, Вт
    Q_ad: np.ndarray        # [N] — адиабатический, Вт
    Q_deg: np.ndarray       # [N] — дегазация, Вт
    mdot: np.ndarray        # [N] — темп дегазации, кг/(м³·с)
```

### 6. Пакет numerical_solver — полностью независим

**Решение:** отдельный пакет, никаких зависимостей от method_of_moments. PVT-корреляции реализуются заново (numpy, новые производные, ветвление p≷pb). method_of_moments — только справочный.

### 7. Тестирование EnergySolver

**Решение:** стационарная заглушка (AnalyticalHydroSolver) покрывает часть тестов: кондуктивный профиль T(r), стационарный JT-эффект, λ_eff. Для нестационарных эффектов (Q_ad, ṁ) — придумаем при реализации.

### 9. BoundaryConditions — отдельный модуль

**Решение:** выделить в `src/bc.py`. Сейчас — задание по давлению (Дирихле). В будущем — разные контроли: по давлению, по общему расходу, по расходу фазы, по забойному давлению + ограничение по расходу, и др. Контроль может переключаться между интервалами истории. Реализуется через ABC:

```python
class WellControl(ABC):
    @abstractmethod
    def apply(self, state, grid, pvt, relperm) -> ...:
        """Вычислить граничные потоки на забое."""
        ...

class PressureControl(WellControl):
    """Задано забойное давление p_wf."""
    def __init__(self, p_wf: float): ...

class RateControl(WellControl):
    """Задан общий объёмный расход (при ст. условиях)."""
    def __init__(self, q_total: float): ...
```

Сейчас реализуется только PressureControl. ABC и структура — сразу.

## Отложенные

### 4. Checkpoint/restart

SimulationState содержит всю информацию для рестарта. Формат: npz. Не реализовывать сейчас.

**Когда понадобится:** при расчётах > 1 часа, или при отладке конкретного интервала.
