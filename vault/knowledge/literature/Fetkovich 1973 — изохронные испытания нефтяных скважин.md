# Fetkovich 1973 — изохронные испытания нефтяных скважин

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Fetkovich M.J.** The Isochronal Testing of Oil Wells. SPE 4529, presented at the 1973 SPE Annual Meeting, Las Vegas.

## Аннотация

Предложена функция многофазного псевдодавления $p_p = \int \alpha \, dp$ по аналогии с однофазной газовой $m(p)$ Аль-Хуссэйни. Boe et al. (1989) используют именно определения Fetkovich (Eqs. 6–8) как отправную точку для построения теоретической связи $S(p)$, необходимой для вычисления интегралов псевдодавления при двухфазном потоке.

## Потенциал для проекта

Определения псевдодавления Fetkovich — стандартная отправная точка для любой работы с многофазным PTA. Прямого развития для температурных эффектов нет.
