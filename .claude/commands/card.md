# Быстрая карточка в vault

Пользователь описал факт, решение или наблюдение: `$ARGUMENTS`

## Инструкции

### 1. Определи тип карточки

| Тип | Папка | Когда |
|---|---|---|
| Научный факт, физика, формула | `vault/knowledge/science/` | Утверждение о физике, модели, методе |
| Решение/выбор подхода | `vault/knowledge/decisions/` | Принято решение с обоснованием |
| Заметка по литературе (без PDF) | `vault/knowledge/literature/` | Ссылка на работу с аннотацией |
| Необработанная мысль | `vault/inbox/` | Всё остальное |

Если тип неочевиден — спроси пользователя.

### 2. Придумай имя файла

Имя = утверждение, не категория.

| Плохо | Хорошо |
|---|---|
| `температура.md` | `эффект JT доминирует при разгазировании в ПЗП.md` |
| `газ.md` | `свободный газ появляется при p ниже давления насыщения.md` |
| `решение.md` | `выбран метод моментов вместо конечных разностей.md` |

### 3. Создай заметку

```markdown
---
tags: [тип, тематические-теги]
date: ГГГГ-ММ-ДД
---

# Утверждение-заголовок

Содержание: конкретный факт, формула, решение.

Wiki-ссылки на связанные заметки: [[...]].

**ПОЧЕМУ:** обоснование (для decisions).
```

### 4. Обнови связи

- Если заметка связана с существующими — добавь wiki-ссылки в обе стороны.
- Если это решение — обнови `vault/00-home/index.md` (если существует).
- Если тип = литература — добавь строку в `vault/knowledge/literature/index-literature.md` (тематическая таблица).
- Проверь и `vault/knowledge/literature/`, и legacy-заметки в `vault/` (корень).

### 5. Подтверди

Выведи: имя файла, тип, одно предложение — содержание.
