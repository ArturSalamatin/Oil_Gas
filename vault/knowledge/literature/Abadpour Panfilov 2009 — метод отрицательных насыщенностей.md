# Abadpour Panfilov 2009 — метод отрицательных насыщенностей

**Полная ссылка.** Abadpour A., Panfilov M. Method of Negative Saturations for Modeling Two-phase Compositional Flow with Oversaturated Zones. *Transport in Porous Media*, 2009, 79, 197–214. DOI 10.1007/s11242-008-9310-0. Опубликована онлайн 09.12.2008 (отсюда имя файла `Refs/abadpour2008.pdf`).

## Задача

Изотермическая двухфазная (газ g + жидкость l) фильтрация **бинарной** смеси частично растворимых компонентов при локальном фазовом равновесии. Примеры: закачка CO₂, смешивающееся вытеснение нефти газом, H₂ + вода в хранилище радиоактивных отходов.

Уравнения баланса компонента $k = 1, 2$ — ур. (1): закон Дарси + закон Фика в каждой фазе,
$$\phi\,\partial_t(\rho C^{(k)}) = \operatorname{div}\Big(\tfrac{\rho_g c_g^{(k)} K k_g(S)}{\mu_g}(\nabla P + \rho_g \mathbf g) + \rho_g D_g S\phi\nabla c_g^{(k)}\Big) + (\text{то же для } l).$$
Полная концентрация (2): $\rho = \rho_g S + \rho_l(1-S)$, $C^{(k)} = [\rho_g c_g^{(k)} S + \rho_l c_l^{(k)}(1-S)]/\rho$. Равновесие фаз (4) — равенство химпотенциалов, (5) — капиллярное давление; при $P_c \to 0$ составы фаз зависят только от давления, (7): $c_g = c_g(P)$, $c_l = c_l(P)$. Принцип Кюри (§2.2) используется как обоснование локального равновесия на фоне неравновесной диффузии.

Ключевой объект — **пересыщенные однофазные зоны**: состав далеко за границей двухфазной области (рис. 1). В них (1) вырождается, и течение описывается другой системой (8) с неизвестными $(P, C)$ вместо $(P, S)$. Постановка §3: одномерная область $0 < x < L$, недонасыщенная жидкость вытесняется пересыщенным газом; три подвижные зоны $\Omega_g$, $\Omega_{gl}$, $\Omega_l$ с неизвестными границами $x_1(t)$, $x_2(t)$.

Два тезиса о постановке:
- Условия (9) в насыщенности **физически неверны**: $S^{inj} = 1$ не отличает пересыщенный газ от равновесного, $S^0 = 0$ — недонасыщенную жидкость от равновесной. Корректны условия (10) в $C$.
- На границе пересыщенной и двухфазной зон — скачок $C$; условия Гюгонио (11), (12) записаны в смешанных переменных ($S$ с одной стороны, $C$ с другой) и требуют априорного знания взаимного расположения зон (§4.1).

## Метод

**Расширенная насыщенность** $\widetilde S$ (§5.1) вычисляется по той же формуле, что и насыщенность в двухфазной зоне, но из полной концентрации вне её — ур. (15):
$$\widetilde S = \frac{\rho_l(c_l - C)}{\rho_l(c_l - C) + \rho_g(C - c_g)},$$
где $c_g$, $c_l$ — равновесные составы на коноде при текущем $P$. $0 \le \widetilde S \le 1$ — двухфазная зона, $\widetilde S > 1$ — пересыщенный газ, $\widetilde S < 0$ — недонасыщенная жидкость. Истинная $S = \operatorname{clip}(\widetilde S, 0, 1)$. $|\widetilde S|$ вне $[0,1]$ — мера удалённости от двухфазной области.

Однофазное состояние трактуется как двухфазное с **мнимой** фазой. **Условия согласования** (16) для $\widetilde S > 1$ (мнимая жидкость) и (17) для $\widetilde S < 0$ (мнимый газ):

| | $\widetilde S > 1$ — ур. (16) | $\widetilde S < 0$ — ур. (17) |
|---|---|---|
| плотность, вязкость мнимой фазы | $\rho_l \equiv \rho_g$, $\mu_l \equiv \mu_g$ | $\rho_g \equiv \rho_l$, $\mu_g \equiv \mu_l$ |
| ОФП | $k_l = 1 - \widetilde S$, $k_g = \widetilde S$ | $k_l = 1 - \widetilde S$, $k_g = \widetilde S$ |
| капиллярное давление | $P_c \equiv 0$ | $P_c \equiv 0$ |
| диффузия мнимой фазы | (16d) | (17d) |
| составы фаз | равновесные при $P$, (7) | равновесные при $P$, (7) |

Следствие — ур. (18): $\widetilde S = (C - c_l)/(c_g - c_l)$, то есть **$\widetilde S$ аффинно зависит от $C$** при фиксированном $P$. Доказательство (§5.3) — прямая подстановка в (1): суммарная подвижность $(k_l + k_g)/\mu = 1/\mu$, поток компонента $\tfrac{\rho K}{\mu}[c_g\widetilde S + c_l(1-\widetilde S)]\nabla P = \tfrac{\rho K C}{\mu}\nabla P$ — точно однофазное уравнение (8). Роль **отрицательной ОФП** $k_g = \widetilde S < 0$ мнимой фазы принципиальна: её встречный поток корректирует состав переносимого флюида.

Начальные и граничные условия переписываются в $\widetilde S$ через (18) — ур. (19): $\widetilde S^0 = (C^0 - c_l^0)/(c_g^0 - c_l^0)$ на начальной коноде, $\widetilde S^{inj} = (C^{inj} - c_l^{inj})/(c_g^{inj} - c_l^{inj})$ на коноде закачки. Условия Гюгонио становятся единообразными для любых скачков — ур. (20):
$$U_s = \frac{\big[\rho_g c_g^{(k)}\widetilde S\,U_g^{(k)} + \rho_l c_l^{(k)}(1-\widetilde S)\,U_l^{(k)}\big]}{\big[\rho_g c_g^{(k)}\widetilde S + \rho_l c_l^{(k)}(1-\widetilde S)\big]}, \quad k = 1, 2,$$
где $[f] = f^+ - f^-$, $U_j^{(k)} = V_j^{(k)}/(\phi S_j)$ — истинная скорость компонента $k$ в фазе $j$, $V_j^{(k)}$ из (3). В отличие от (11), (12), одна формула для обоих типов скачков и без априорного знания, по какую сторону однофазная зона. Заявленное достоинство: существующий двухфазный решатель в переменных $(P, S)$ получает однофазные зоны «подключаемым модулем» без изменения структуры.

## Результаты

Во всех примерах — явная по времени конечно-разностная схема «против потока» (§6.1), 1D, $P_c = 0$, без гравитации.

| Пример | Условия | Результат |
|---|---|---|
| 1, рис. 3 | идеальное смешение, CH₄–C₁₀, $c_g = 0.787$, $c_l = 0.213$, $k_g = S^2$, $k_l = (1-S)^2$, $\mu_l/\mu_g = 5$; $\widetilde S^0 = -0.37$, $\widetilde S^{inj} = 1.37$ | Два скачка (задний: пересыщенный газ / двухфазная зона; передний: двухфазная зона / недонасыщенная жидкость). Сравнение с аналитическим решением теории дробного потока ([[Bedrikovetsky 1993 — математическая теория вытеснения нефти и газа]]) — «адекватное», только визуально |
| 2, рис. 4 | неидеальное смешение, переменное $P$ (90–150 бар), составы — полиномы по $P$ из аппроксимации расчётов по уравнению Пенга–Робинсона при 300 К; $K = 10^{-14}$ м²; $\widetilde S^0 = -0.68$, $\widetilde S^{inj} = 1.06$ | Классическая постановка (1), (9) даёт **неверные скорости обоих скачков и не видит задний скачок** вовсе; метод отрицательных насыщенностей — верную картину |
| 3, рис. 5–6 | то же + диффузия, $Pe = K\Delta P/(\mu_g D_g L) = 0.03$, $D_l = 10^{-4} D_g$ | $\widetilde S$ непрерывна везде; истинная $S$ имеет **слабые разрывы** (изломы, точки M, N на рис. 5) на границах однофазной и двухфазной зон; границы $x_*$, $x^*$ определяются пересечением $\widetilde S$ с уровнями 0 и 1 |

Количественных мер погрешности, размеров сетки, исследования сходимости по сетке нет («шаг по пространству очень мал» — без чисел).

## Замечания

1. **Условие (17a) точно только при плотности и вязкости, не зависящих от состава.** Мнимая фаза получает $\rho_l$, $\mu_l$ — но «реальная жидкость» в двухфазной записи имеет равновесный состав $c_l(P)$, а фактическая недонасыщенная жидкость — другой состав $C$. В примере 2 это скрыто моделью слабосжимаемой жидкости $\rho_l(P)$ без зависимости от состава. Для общего случая обе фазы в однофазной зоне должны нести $\rho(P, C)$, $\mu(P, C)$, то есть PVT-функции начинают зависеть от $\widetilde S$ — это уже изменение PVT-модуля, а не «подключаемый модуль без модификации». В неизотермической версии это сделано явно: $z_i$ вычисляется из $\hat S_g$ и составов фаз, затем по $z$, $T$, $P$ — плотность однофазной зоны ([[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]], с. 402).
2. **Диффузионные условия (16d), (17d) определены только в 1D.** Выражение $\nabla\widetilde S\cdot\nabla^{-1}c_l$ — отношение векторов; при $c_j = c_j(P)$ оно имеет смысл, лишь если $\nabla\widetilde S \parallel \nabla P$. В 2D/3D условие не определено, при $\nabla P \to 0$ сингулярно. Кроме того, $D_g \propto 1/\widetilde S$ при $\widetilde S \to 0^-$: в коде нужно считать произведение $D_g\widetilde S$, а не $D_g$. Смежный артефакт: в двухфазной зоне при $P_c = 0$ диффузия в фазе $\propto (dc_j/dP)\nabla P$ (§2.2) и исчезает при однородном давлении.
3. **ОФП за пределами $[0, 1]$ обязаны быть линейными и знакопеременными:** $k_g(\widetilde S) = \widetilde S < 0$. Решатель с табличными ОФП, зажатыми на краю таблицы, условия согласования нарушает. Кроме того, (16b)/(17b) неявно предполагают $k_l(0) = k_g(1) = 1$; при концевых точках ОФП меньше единицы нужна перенормировка. Стыковка $k_g = S^2$ (слева от 0 — наклон 1, справа — 0) даёт излом производной в $\widetilde S = 0$ — источник трудностей для метода Ньютона, в статье не обсуждается.
4. **Только явная схема.** Поведение неявной схемы и метода Ньютона с $\widetilde S \notin [0, 1]$ не исследовано — а именно это нужно в промышленном решателе.
5. **Сравнения с переключением первичных переменных нет.** Статья противопоставляет себя только формулировке в полных концентрациях (§4.2). Переключение переменных (Black Oil: $S_g \leftrightarrow R_s$, как в OPM Flow и в нашем решателе) — стандартный промышленный способ обработки однофазных зон; тезис «существующие двухфазные решатели не умеют однофазные зоны» для Black Oil неверен. Аргумент статьи сильнее для композиционных задач, где пересыщенное состояние далеко от границы двухфазной области.
6. **Только бинарная смесь.** При $N > 2$ конода по $(P, C)$ не единственна, нужна процедура типа «отрицательного флэша» ([[Whitson Michelsen 1989 — отрицательный флэш-расчёт]]; *Fluid Phase Equilibria*, 1989, 53, 51–71 — сверено): равновесный расчёт для физически однофазной системы с долями фаз вне $[0, 1]$, седловая точка энергии Гиббса. Это термодинамический аналог $\widetilde S$, на 20 лет раньше; статья эту параллель не упоминает.
7. **Изотермическая постановка.** Условия согласования для уравнения энергии не выведены (см. «Значение для проекта»).
8. Мелочи: в примере 2 дважды указано $\mu_l$ (второе значение 0.00002 Па·с — очевидно $\mu_g$); $\rho_j$ в (1) названы молярными (моль/м³), но заданы в кг/м³; гравитационный член $\rho_j\mathbf g$ с молярной плотностью размерно некорректен.
9. По существу метод — это формулировка в полной концентрации (18), записанная в переменной, которая совпадает с $S$ в двухфазной зоне. Отсюда «автоматическое» выделение скачков — это обычное сквозное выделение разрывов консервативной схемой, а не свойство $\widetilde S$ как таковое.
10. **Число Пекле примера 3 размерное — ошибка статьи.** В §6.3 (с. 211) $Pe = K\Delta P/(\mu_g D_g L)$ имеет размерность 1/м, и значение 0.03 зависит от единиц $L$. Безразмерная форма — $K\Delta P/(\mu D)$, $L$ сокращается (так в [[Panfilov Rasoulzadeh 2010 — отрицательные насыщенности с диффузией и капиллярностью]], §6.1). При параметрах примера 2 ($K = 10^{-14}$ м², $\Delta P = 60$ бар, $\mu_g = 2\cdot10^{-5}$ Па·с) безразмерное $Pe = 0.03$ требует $D_g \approx 0.1$ м²/с — в $10^4$–$10^6$ раз больше реальных коэффициентов диффузии газа ($10^{-7}$–$10^{-5}$ м²/с; мой пересчёт). Вывод о слабых разрывах вместо скачков (рис. 5) получен в режиме, где диффузия подавляет конвекцию; при реальных $Pe$ он не проверен. Та же критика $Pe = 7$ — замечание 2 обзора 2010 г.

**Нотация.** $S$ статьи = $S_g$ проекта; индекс $l$ = $o$; $P \equiv P_g$; $K$ = $k$; $k_g$, $k_l$ = $k_{rg}$, $k_{ro}$; $C$ — полная молярная доля лёгкого компонента; $\rho_j$ — молярные плотности (в проекте — массовые).

## Значение для проекта

**Прямая связь — запасной путь [[BUG-014]].** Вариант N (снятие нижней границы $S_g$ внутри Ньютона) из [[запасной путь с отрицательной насыщенностью и веткой скважины снимает порог шага на скачке p_wf вверх]] опирается на эту статью. Но вариант N — **не** согласованное продолжение в смысле (17):

| | Условия (17) в переводе на Black Oil | Вариант N в прототипе |
|---|---|---|
| мнимый газ: плотность, вязкость | нефти при фактическом $R_s$ | газа ($B_g$, $\mu_g$) |
| нефть: PVT | $B_o(p, R_s)$, $\mu_o(p, R_s)$ недонасыщенной нефти | $B_o$, $\mu_o$ при $R_{s,\text{нас}}(p)$ |
| $k_{rg}$ при $S_g < 0$ | $S_g$ (отрицательная) | 0 (зажим таблицы) |
| $k_{ro}$ при $S_g < 0$ | $1 - S_g$ (> 1) | $k_{ro}(0)$ |

Следствие: в варианте N состав запасов ячейки с $S_g < 0$ соответствует $R_s^{\text{экв}} = R_{s,\text{нас}} + S_g B_o/[B_g(1-S_g)]$, а поток несёт газ в отношении $R_{s,\text{нас}}$ — такое состояние не отвечает никакому однофазному. Это согласуется с выводом заметки BUG-014: $S_g < 0$ — только продолжение для итераций, принятое решение проходит через цикл набора фаз. При одном и том же дефиците $R_s$ отрицательная $S_g$ варианта N больше по модулю, чем согласованная $\widetilde S$, в $\rho_o/\rho_g$ раз (линеаризация: $S_g^N \approx -\Delta R_s B_g/B_o$, $\widetilde S \approx -\Delta R_s\rho_{g,\text{ст}}/(\rho_o B_o)$). Проверено расчётом на PVT примеров (`numerical_solver/examples/measure_negative_sg_scale.py`, 2026-09-30):

| PVT | $p$, МПа | $\rho_o/\rho_g$ | $S_g^N/\widetilde S$ при $\Delta R_s$ = 0.1 / 1 / 5 м³/м³ |
|---|---|---|---|
| пример 12, таблицы ($p_b = 15$ МПа) | 6 | 17.7 | 17.7 / 18.0 / 19.3 |
| | 14.94 | 6.9 | 6.9 / 7.0 / 7.1 |
| пример 03, Стендинг | 5 | 22.8 | 22.8 / 23.3 / 25.5 |
| | 20 | 5.1 | 5.1 / 5.1 / 5.2 |

Прежняя оценка «≈ 5 при 20 МПа» относится к давлению, при котором в обоих примерах нефть недонасыщена. В двухфазных зонах примеров множитель больше: в примере 12 ($p \le p_b = 15$ МПа) — от 7 до 18, в примере 03 ($p_b(R_{s0} = 50) = 9.43$ МПа, там $\rho_o/\rho_g = 11.7$) — от 12 до 23. С падением давления он растёт вместе с $B_g$. Абсолютный масштаб: $\Delta R_s = 1$ м³/м³ соответствует $\widetilde S \approx -10^{-3}$ во всех точках, $S_g^N$ — от $-4.5\cdot10^{-3}$ до $-2.3\cdot10^{-2}$. Граница прототипа $S_g \ge -0.05$ в варианте N отвечает дефициту $R_s$ всего 2–11 м³/м³.

**Набросок согласованного продолжения для Black Oil** (мой вывод, не проверен; только ветвь $\widetilde S < 0$ — сухой газ без $R_v$, пересыщенного газа в ПЗП нет). Массовая доля газового компонента в нефти $X(R_s) = R_s\rho_{g,\text{ст}}/(\rho_{o,\text{ст}} + R_s\rho_{g,\text{ст}})$; аналог (18):
$$\widetilde S_g = \frac{X(R_s) - X(R_{s,\text{нас}}(p))}{1 - X(R_{s,\text{нас}}(p))} < 0 .$$
Обе фазы несут $\rho_o(p, R_s)$, $\mu_o(p, R_s)$; мнимый газ — чистый газовый компонент; $k_{ro} = 1 - \widetilde S_g$, $k_{rg} = \widetilde S_g$. Тогда запасы $\phi\rho_o X$ и поток $\rho_o X k\nabla p/\mu_o$ точно однофазные. Для уравнения энергии добавляется условие $h_g^* \equiv h_o$: переход массы между неразличимыми фазами не несёт теплоты дегазации. Это воспроизводит $Q_{\text{deg}} = 0$ режима 2 ([[модули-energy-tridiag]]), но не $\dot m = 0$. Между мнимыми фазами масса переходит при любом изменении $p$, так как мнимая нефть несёт $R_{s,\text{нас}}(p)$. Поэтому в форме $Q_{\text{deg}} = -L\dot m$ условие означает $\hat L = 0$ при $\widetilde S_g < 0$ (или $\dot m$ по истинному $R_s$). Без него на PVT примера 03 ложный источник в 2–2.3 раза больше адиабатического члена — разбор в [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]].

**Открытые вопросы** (решений не предлагаю — это выбор пользователя):
- Нужна ли единая формулировка вместо переключения режимов 1/2 ([[P3-маппинг-состояния]])? Выигрыш — отказ от повторных решений шага при переключении фаз (в 13б — 392 переключения в 16 шагах запасного пути). Цена — зависимость PVT нефти от $\widetilde S_g$, линейное продолжение ОФП с изломом производной в 0, условие на энтальпию. Кроме того, излом якобиана на $p_b$ единая формулировка не снимает, а только переносит. При фиксированном $p$ однофазные и двухфазные состояния сходятся в точке насыщения под углом, и на PVT примеров наклон запасов газа там скачет в 1.6–21 раз ([[Panfilov Panfilova 2014 — отрицательные насыщенности для трёх фаз и многих компонентов]], «Значение для проекта»).
- Положение фронта разгазирования $r_b(t)$: в недонасыщенной зоне $\widetilde S_g$ — гладкая функция, пропорциональная превышению $p$ над $p_b(R_s)$, и пересекает 0 на фронте. Линейная интерполяция нуля $\widetilde S_g$ между ячейками даёт $r_b$ точнее признака режима ячейки.
- Вывод статьи о слабых разрывах (рис. 5): истинная $S_g$ на границе зон имеет излом, $\widetilde S_g$ гладкая. Для ПЗП без диффузии растворённого газа это не проверялось. Теоретический ответ — в [[Panfilov Rasoulzadeh 2010 — отрицательные насыщенности с диффузией и капиллярностью]] («Значение для проекта»): фронт разгазирования при истощении — равновесная поверхность исчезновения фазы, нефть подходит к нему точно при $p = p_b(R_{s0})$, поэтому $\widetilde S_g$ непрерывна и без диффузии. Механизм другой, чем в статье: не диффузия, а то, что переход вызван давлением, а не составом. Расчётом не проверено.

К алгебраическим моделям М.1–М.4 из `simplefied_approaches/cooling_models.tex` отношения не имеет; касается только численного решения PDE (М.5–М.6 и `numerical_solver/`).

Развитие метода: [[Panfilov Rasoulzadeh 2010 — отрицательные насыщенности с диффузией и капиллярностью]] (*TiPM* 83, 73–98; `Refs/panfilov2009.pdf`; диффузия там введена добавочным членом $\propto\nabla\widetilde S$, определённым в любой размерности, — снимает замечание 2; равновесная и неравновесная поверхности исчезновения фазы; фронт разгазирования ПЗП при истощении — равновесная); [[Panfilov Panfilova 2014 — отрицательные насыщенности для трёх фаз и многих компонентов]] (три фазы, $N$ компонентов, гравитация и диффузия; там же — неединственность плотностей мнимых фаз и альтернативный выбор продолжения для Black Oil). [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] (*TiPM* 91, 391–422; `Refs/salimi2011.pdf`) — **неизотермическая** постановка с появлением и исчезновением фаз, пример — закачка холодной смеси CO₂–вода в 1D геотермальный пласт. Условие для энергии там — (29) $\hat C_{pg} = \hat C_{pl} = C_{pl}$, то есть $h_g^* \equiv h_o$ из наброска выше; но скрытой теплоты в их модели нет, и для $Q_{\text{deg}}$ нужно отдельное условие (разобрано в обзоре).
