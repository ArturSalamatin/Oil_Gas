**Решения пользователя (2026-10-07):**
1. Объём — только строгий разбор строк (вариант 2). Проверки значений, как у XLSX-ридера ($B_g, \mu_g > 0$, $S_g \in [0, 1]$; вариант 3), вынесены в отдельную запись **DEBT-044**.
2. Заголовок сверяется по именам столбцов, а не только по их числу. Так ловится файл без заголовка (сейчас его первая строка данных молча съедается как заголовок) и перестановка столбцов.
3. Пустое поле в конце строки (`...,0.003,`) — ошибка: число полей должно равняться числу столбцов.

**Суть:** функция `_read_numeric_csv(csv_path, columns, kind)` в `factory.py` выдаёт `ValueError` с именем файла, номером строки и столбцом в случаях:
- заголовок не совпадает с ожидаемым (BOM и пробелы вокруг имён допустимы);
- файл пуст;
- число полей не равно числу столбцов;
- значение нечисловое или не конечное (`nan`, `inf`).

Пустые строки и строки из пустых полей пропускаются. Три ридера становятся обёртками, их сигнатуры не меняются. Столбцы ОФП собираются из целых строк, поэтому разойтись по длине не могут.
