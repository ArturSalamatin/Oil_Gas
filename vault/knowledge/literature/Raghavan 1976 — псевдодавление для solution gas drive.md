# Raghavan 1976 — псевдодавление для solution gas drive

**Полная ссылка.** Raghavan R. Well Test Analysis: Wells Producing by Solution Gas Drive. *Soc. Pet. Eng. J.*, Aug. 1976, **16**(4), 196–208. SPE 5588.

## Задача

Анализ поведения drawdown и buildup в однородном замкнутом цилиндрическом пласте, содержащем нефть с растворённым газом, при газонапорном режиме (solution gas drive). Скважина на постоянном поверхностном дебите нефти $q_o$, полностью вскрывает пласт. Гравитационные эффекты не учтены. Начальное давление $p_i = p_b = 1500$ psi, начальная $S_o = 1$, воды нет.

Основная цель: строго проверить применимость концепции псевдодавления ([[Al-Hussainy 1966 — псевдодавление для реальных газов|Al-Hussainy et al. 1966]]) к **двухфазному** потоку нефть–газ. Ранее Fetkovich (1973) предложил многофазное псевдодавление по аналогии с газовой $m(p)$, но не продемонстрировал способ вычисления интеграла и не верифицировал подход.

## Метод

### Двухфазное псевдодавление

Многофазная $m(p)$ определяется как (ур. 6):

$$m(p) = \int_{p_b}^{p} \frac{k_{ro}(S_o)}{\mu_o B_o}\,dp'$$

Для вычисления интеграла нужна связь $S_o(p)$. Raghavan показал, что GOR-уравнение (ур. 2):

$$R = R_s + \frac{k_{rg}}{k_{ro}}\,\frac{\mu_o B_o}{\mu_g B_g}$$

— можно использовать для определения этой связи, подставляя мгновенный GOR на забое скважины.

### Ключевое отличие: две разные $m(p)$

**Drawdown.** Связь $S_o(p)$ определяется по мгновенному GOR на забое из численного решения. GOR меняется со временем, поэтому теоретически $m(p)$ тоже зависит от истории. На практике влияние мало для ранних–средних времён.

**Buildup.** GOR фиксируется на значении в момент остановки скважины и считается постоянным для всех давлений. Обоснование: при buildup давление восстанавливается быстрее, чем перераспределяются насыщенности.

Необходимость двух разных $m(p)$ означает, что drawdown и buildup **не являются строго обратимыми процессами** — фундаментальное отступление от однофазной теории.

### Безразмерные переменные

Безразмерное давление (ур. 8):
$$p_{wD} = \frac{k h}{141.2\,q_o B_o \mu_o}\,[p_i - p_{wf}]$$

Безразмерное псевдодавление (ур. 9):
$$m_{wD} = \frac{k h}{141.2\,q_o}\,[m(p_i) - m(p_{wf})]$$

Безразмерное время (ур. 7):
$$t_D = \frac{0.000264\,k\,t}{\phi\,\mu_i\,c_{ti}\,r_w^2}$$

### Численная модель

Двухфазный конечно-разностный симулятор (Amoco Research Center) с имплицитными дебитами и ОФП. Верификация по аналитическим решениям для однофазной жидкости — совпадение до 4 значащих цифр.

Параметры пласта (Table 1): $\phi = 0.119$, $k = 6.16$ мд, $p_i = 1500$ psi, $\mu_{oi} = 1.7645$ сП, $\mu_{gi} = 0.0145$ сП. Три конфигурации: $r_e = 500, 214.39$ ft, $h = 25, 20$ ft, $q_o = 10, 25, 40$ STB/D.

## Результаты

### Drawdown

1. **Обычный анализ** ($p_{wD}$ vs $\log t_D$, Fig. 3): кривая drawdown при solution gas drive показывает увеличивающийся наклон из-за роста газовой насыщенности и снижения $k_{ro}$. Наклон зависит от дебита. Поздневременной псевдоустановившийся участок ($p_{wD}$ vs $t_{DA}$) **не имеет** наклона $2\pi$ (как для однофазной жидкости), что может привести к ошибкам в reservoir limit tests.

2. **Псевдодавление** ($m_{wD}$ vs $\log t_D$, Fig. 5): все данные коллапсируют на решение van Everdingen–Hurst для однофазной жидкости вплоть до начала boundary effects. Псевдодавление **устраняет зависимость от дебита** на ранних и средних временах. Это позволяет определить **абсолютную проницаемость** $k$ из наклона полулогарифмической прямой.

3. **Устранение «газового скина»**: при использовании $m(p)$ дополнительный скин-эффект от газовой насыщенности ($s'$ из ур. 4–5 Fetkovich) **не нужен**, т.к. $m_{wD}$ никогда не превышает $p_{wD}$ для однофазной жидкости.

### Buildup

1. **Horner-анализ через $m(p)$** (Fig. 9): абсолютная $kh$ определяется из наклона с приемлемой точностью: $kh = 144.8$ мд·ft при $t_p = 60$ дней, $kh = 161.3$ мд·ft при $t_p = 400$ дней (истинное $kh = 6.16 \times 25 = 154$ мд·ft). Погрешность $< 6\%$.

2. **Зависимость от $t_p$**: каждый buildup требует своей $m(p)$, рассчитанной по GOR на момент остановки. Для газовых пластов одна $m(p)$ — на все времена; для solution gas drive — нет.

### Скин-фактор

При наличии damage zone ($k_{\text{skin}} = k/10$, $r_{\text{skin}} = 1.7$ ft, $s = 11$): $m_{wD}$ с псевдодавлением снова совпадает с решением van Everdingen–Hurst для composit system (Fig. 10). Скин из buildup: $s \approx -0.64$ для примера из Appendix — отрицательный скин указывает на некорректность, т.к. газовый поток в скин-зоне не учтён в расчёте.

### Расширение результатов

Псевдодавление устраняет зависимость от конкретных PVT и ОФП, позволяя обобщить результаты через безразмерные группы на системы с другими $k$, $\phi$, $h$, $r_w$ (при тех же формах $B_o(p)$, $k_r(S)$). Отклонение на поздних временах от однофазной корреляции при разных ОФП (Fig. 11) показывает границы обобщения.

## Замечания

1. **Связь $S_o(p)$ через мгновенный GOR** — эмпирическая, не имеет строгого теоретического обоснования (автор это признаёт). Метод работает на уровне численных данных конкретного симулятора. Для практического применения требуется промысловый GOR, который известен грубо.

2. **Подход Perrine–Martin vs псевдодавление.** [[Perrine 1956 — PTA при многофазном потоке|Perrine (1956)]] и [[Martin 1959 — многофазный PTA|Martin (1959)]] предложили замену $k/\mu$ → $\lambda_t$, что даёт *эффективную* проницаемость фазы. Подход Raghavan через $m(p)$ даёт *абсолютную* проницаемость $k$, но требует знания ОФП и PVT. Perrine–Martin не требует ОФП, но теряет абсолютную $k$. Эти подходы комплементарны: Perrine–Martin — для быстрой оценки, Raghavan — для полного анализа.

3. **Необратимость drawdown/buildup.** Две разные $m(p)$ — симптом того, что суперпозиция неприменима строго. В однофазной теории линейность PDE гарантирует суперпозицию. В двухфазной задаче PDE нелинейны — суперпозиция нарушается. Это ограничение всех методов PTA для многофазного потока.

4. **Гравитация не учтена.** Для вертикальных скважин в толстых пластах с gas cap это может быть существенным (Cook, Fulton 1973 — SPE 4631).

5. **Изотермическая модель.** Температурные эффекты (JT, дегазация) отсутствуют. В нашей задаче ПЗП температура — неизвестная. Прямое применение $m(p)$ по Raghavan невозможно при $R_s = R_s(p, T)$.

6. **Единственный набор PVT и ОФП.** Обобщение через $m_{wD}$ справедливо только при тех же *формах* кривых. Для других коллекторов результаты нужно пересчитывать заново.

7. **Альтернативное замыкание $S(p)$ через автомодельность.** [[Boe 1989 — двухфазный анализ КПД|Boe et al. (1989)]] получили связь $S(p)$ из автомодельной переменной Больцмана $\eta = r^2/(4t)$, что строже GOR-подхода Raghavan: не требует знания мгновенного GOR, а выводится из структуры PDE. При этом результат — та же $m(p)$, но с иным замыканием и без привлечения данных симулятора.

## Значение для проекта

**Прямая связь с моделью ПЗП.** Работа Raghavan — первое строгое обоснование двухфазного псевдодавления для режима solution gas drive. Наша задача моделирует тот же процесс: фильтрация нефти с разгазированием при $p < p_b$.

**Что можно взять:**
- Формализм $m(p)$ через связь $S_o(p)$ из GOR — может использоваться для верификации численных решений модели ПЗП (method_of_moments).
- Идея «коллапса» безразмерных кривых на однофазное решение — проверка самосогласованности модели.
- Безразмерные группы (ур. 7–12) — непосредственно применимы.
- Эмпирический приём фиксации GOR при buildup получает теоретическое обоснование в [[Краснов — многофазное псевдодавление и функции источника|Краснов]], ур. 0.87: GOR = const на псевдоустановившемся режиме. Это усиливает подход Raghavan для поздних времён, но не для ранних (где $S(p)$ определяется из ур. 0.77).

**Что неприменимо:**
- Изотермическое допущение. В method_of_moments/two_phase_energy.tex температура определяется из уравнения энергии. $R_s(p, T)$ зависит от обеих переменных — $m(p)$ Raghavan необходимо обобщить до $m(p, T)$.
- Постоянный поверхностный дебит. В задаче ПЗП граничные условия могут быть иными (постоянное забойное давление).
- Отсутствие гравитации. Модель GORM (simplefied_approaches/) учитывает гравитационное расслоение.

**Открытые вопросы:**
- Как обобщить $m(p)$ на неизотермический случай? Если $R_s = R_s(p,T)$, связь $S_o(p)$ из GOR-уравнения не замкнута без знания $T(p)$.
- Справедлив ли «коллапс» $m_{wD}$ на однофазное решение при наличии температурных эффектов (JT, дегазация)?
- Как метод моментов (method_of_moments/moments_method.tex) соотносится с подходом Raghavan: момент $\langle p \rangle$ связан с $m_{wD}$?
