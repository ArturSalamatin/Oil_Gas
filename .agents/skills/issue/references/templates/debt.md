# Шаблоны для технического долга (DEBT)

## 1. Тело задачи (`01-issue-body.md`)

```markdown
## Описание
(что именно и почему требует улучшения)

## Текущее состояние
(как реализовано сейчас, недостатки решения)

## Целевое состояние
(как должно функционировать после доработки)

## Затронутые файлы
| Файл | Строки | Роль |
|---|---|---|
| `path/to/file.py` | L10–L20 | Описание |

## Анализ вариантов решения
(для каждого варианта: суть, изменения, достоинства и недостатки)

## План решения
1. **Подготовка** – базовый вариант (тесты, производительность, API)
2. **Реализация** – инкрементальные изменения
3. **Верификация** – все тесты зелёные, поведение не изменилось

## Ветка
`<имя ветки>`

## Связанные issues
(Related: #N)

## Связанные заметки в vault
(wiki-ссылки на заметки)
```

## 2. Комментарий «Контекст при открытии» (`02-comment-open.md`)

```markdown
### Контекст при открытии

- **Ветка:** `<имя ветки>`
- **Коммит:** `<короткий SHA>`
- **Мотивация:** <одно предложение>
- **Затронутые модули:** <список>
- **Оценка сложности:** <простой / средний / сложный>
```
