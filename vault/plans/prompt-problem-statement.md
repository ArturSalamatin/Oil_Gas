## Принцип

Документ разделяется на два слоя:

- **Основной текст** — компактная постановка: область, допущения, итоговая система уравнений (в рамках), определения коэффициентов, граничные и начальные условия. Достаточно для понимания задачи и написания кода. Начинается с окончательного набора уравнений — каждое с собственной новой меткой.
- **Приложения** — полные выводы с промежуточными шагами. Справочный материал для верификации формул. Сохраняют свои собственные метки (`\label`). Из основного текста на приложения **не ссылаться** — текст должен быть самодостаточен без них.

Разделы §2 и «Переходные режимы» — **без изменений**. Разделы §3–§4 (дискретизация, интегрирование по времени) — **без изменений** в этой итерации; их доработка — часть дальнейшей работы.

## Разделение меток (`\label`)

Основной текст и приложения содержат **независимые** наборы `\label`. Итоговые уравнения дублируются: в основном тексте — с **новыми** метками, в приложениях — с **исходными** метками (которые уже стоят в текущем файле). Это исключает конфликт дублированных `\label`.

**Конвенция именования:** новая метка = `main_` + исходное имя. Пример: `eq:energy_final` → `eq:main_energy_final`.

**Три категории уравнений:**

1. Уравнения, которые остаются **только** в основном тексте (Дарси, балансы масс, замыкающее, сжимаемость породы, ...) — сохраняют свои текущие `\label` без изменений.

2. Уравнения, которые **дублируются** (итоговые формулы, приведённые и в основном тексте, и в приложениях) — получают **новые** метки `main_*` в основном тексте; **исходные** метки остаются в приложениях. Полный список:

   | `eq:muJT_def` | `eq:main_muJT_def` | Прил. B |
