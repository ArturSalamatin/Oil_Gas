# План реализации фичи

Пользователь указал задачу: `$ARGUMENTS`

Формат аргумента: `FEAT-NNN` или описание фичи.

## Инструкции

### 1. Загрузи контекст

- Прочитай запись в `vault/roadmap/планируемые фичи.md`.
- Если `$ARGUMENTS` — описание, найди запись или создай через `/issue`.

### 2. Прочитай формулы

- Открой `moments_method.tex` на секциях, указанных в записи FEAT.
- Выпиши конкретные уравнения, которые будут реализованы.
- Проверь нотацию — соответствие с CLAUDE.md (секция «Обозначения и нотация»).

### 3. Определи зависимости

- Какие другие FEAT должны быть готовы? (например, FEAT-003 зависит от FEAT-001).
- Какие модули из `src/` уже существуют?
- Прочитай их интерфейсы (Grep по `def ` в нужном модуле).

### 4. Составь план

Записать в `vault/plans/FEAT-NNN <slug>.md`:

```markdown
---
tags: [plan, feature]
date: ГГГГ-ММ-ДД
issue: FEAT-NNN
status: черновик
---

# FEAT-NNN: Краткое описание

## Формулы
- \eqref{eq:...} — описание (moments_method.tex, §N)
- ...

## Зависимости
- FEAT-... — что нужно, готово ли

## План реализации

### Шаг 1: ...
- Файл: `src/module.py`
- Функция: `compute_something(p, T, Sg) -> float`
- Формула: \eqref{eq:...}
- Тест: `tests/test_module.py::test_something`

### Шаг 2: ...

## Тесты
- [ ] Unit: конкретные входы → ожидаемые выходы (из формул)
- [ ] Граничные: Sg=0, Sg→1−Sor, p→p_b, T→T_0
- [ ] Согласованность: сумма подвижностей, энергобаланс
- [ ] Интеграционный: solve_ivp с известным решением

## Связь формула → код
| Уравнение | Функция | Файл |
|---|---|---|
| \eqref{eq:...} | `func_name()` | `src/module.py` |
```

### 5. Обнови roadmap

Добавь ссылку на план. Статус → 🟡 В РАБОТЕ.

### 6. Спроси пользователя

Показать план. Приступать к реализации?
