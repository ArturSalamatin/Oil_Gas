# Palacio Blasingame 1993 — decline curve type curves для газа

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Palacio J.C., Blasingame T.A.** Decline-Curve Analysis Using Type Curves — Analysis of Gas Well Production Data. *SPE 25909*, Joint Rocky Mountain Regional and Low Permeability Reservoirs Symposium, Denver, CO, April 26–28, 1993.

## Аннотация
Расширение метода type curve decline analysis на газовые скважины с использованием псевдовремени и material balance time. Позволяет оценивать OGIP и продуктивность из кривых падения дебита при переменных свойствах газа.

## Потенциал для проекта
Вместе с Agarwal–Gardner 1999 и Fraim–Wattenbarger 1987 формирует методологическую базу decline/RTA для газовых пластов. Представляет интерес как отправная точка для обобщения на двухфазный Black Oil.
