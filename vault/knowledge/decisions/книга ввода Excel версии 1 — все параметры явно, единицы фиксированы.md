# Книга ввода Excel версии 1 — все параметры явно, единицы фиксированы

Инженер задаёт расчёт книгой `.xlsx`: **одна книга — один расчёт**. JSON-конфиг ([[P8-формат-ввода-json]]) остаётся каноническим форматом: книгу переводит в `config.json` и CSV таблиц перевод [[FEAT-035]], дальше — обычный `load_config`. Формат описан кодом — таблицей полей `numerical_solver/gpn_multiphase_solver/io/workbook_format.py`; шаблон пишет `gpn-solver template книга.xlsx` (`io/workbook_template.py`), книга генератора — `numerical_solver/configs/INPUT_TEMPLATE_v1.xlsx`. План и решения пользователя 1–63 — [[feat-033 workbook-input-format]].

## Листы

| Лист | Что | Защита |
|---|---|---|
| MODEL | версия формата, геометрия, порода, плотности при ст. у., начальные условия, скин — 14 строк | без пароля: Key, Unit, заголовки и постоянные значения заблокированы |
| THERMAL | скелет ($\rho_{ma}$, $c_{ma}$, $\lambda_{ma}$), теплопроводность и теплоёмкость фаз, $\mu_{JT}$, $L$ — 10 строк | то же |
| NUMERICS | все численные поля конфига, шаги — в часах — 11 строк; Jacobian mode = grouped и Linear solver = sparse — постоянные | то же |
| SCHEDULE | `Time, day`, `Control mode` (BHP / OIL_RATE), `BHP target, bar(a)`, `Oil-rate target, Sm3/day`, `Minimum BHP, bar(a)` | нет |
| OIL_PVT, GAS_PVT | таблицы прототипа (PVTO, газ), заголовки с единицами | нет |
| RELPERM | ОФП `Sg`, `kro`, `krg`; обязательные первая строка $S_g = 0$ с $k_{rg} = 0$ и последняя $S_g = 1$ с $k_{ro} = 0$ | без пароля: эти четыре ячейки заблокированы, вставка и удаление строк разрешены |
| COMMENTS | как получить шаблон и заполнить его; столбец B по-английски, C по-русски | нет |

Листы «параметр–значение» — столбцы **Key | Parameter | Value | Unit | Comment | Комментарии**. Key — путь поля конфига (`rock.permeability`) или ключ книги (`rock.p_ref`); строка ищется по ключу, подпись и комментарии правятся свободно. Подписи, единицы, заголовки — по-английски; комментарии — на двух языках, русский написан по-русски, не калькой. Единицы — ASCII в стиле прототипа (`bar(a)` — абсолютное давление в барах, `Sm3` и `rm3` — м³ при стандартных и пластовых условиях, `1/bar`, `J/(kg*K)`, `K/MPa`, `kJ/kg`, `h`, `Sm3/day`); сообщения программы — русские.

## Правила

- **Все параметры явно.** Каждая строка листов «параметр–значение» обязательна, у каждой — значение, даже равное умолчанию программы; строки не добавляются и не удаляются. Нет строки или пустая Value — отказ перевода. Слова «выключено» в книге нет: `time.dt_after_control_change` и `numerics.newton_cell_tol` — всегда числа > 0 ($h_0 \ge \Delta t$ отключает нарастание шага); `null` остаётся только в JSON. Постоянные строки (версия формата, `jacobian_mode` = grouped, `linear_solver` = sparse) перевод принимает только с этими значениями — здесь книга намеренно строже JSON. Умолчания `io/config.py` перевод не подставляет. Следствие: новое поле — новая версия формата (`format_version`), книга прежней версии получает отказ.
- **Единицы фиксированы** для каждой строки и столбца таблиц и сверяются точно. Перевод в СИ — `UNIT_TO_SI`; «на единицу» (1/bar, K/MPa, Sm3/day, cP) — делением на точный множитель.
- **SCHEDULE.** Строка $k$ — момент $t_k$ и режим на $[t_k, t_{k+1}]$; первая строка — $t = 0$, последняя — только момент завершения, её режим не читается. Каждая строка — момент записи. Строка BHP читает только BHP target, OIL_RATE — Oil-rate target и Minimum BHP; прочие заполненные ячейки молча пропускаются. Останов — OIL_RATE с дебитом 0 и Minimum BHP 1.01325 bar(a).
- **Шаги — в часах:** `dt_integration` и `dt_after_control_change` переводит программа ($h_0$ = 0.11 с — 3.05555555555556e-05 ч).
- **RELPERM** — от строки $S_g = 0$ ($k_{rg} = 0$) до строки $S_g = 1$ ($k_{ro} = 0$); перевод проверяет обе строки сам, защита листа без пароля снимается. В демо строка $S_g = 1$ повторяет $k_{rg}$ при 0.85 — выше последней строки фабрика берёт её значения, расчёт тот же.
- **Два поля конфига — из пар ячеек:** пористость при $p_0$ — $\varphi_0 = \varphi_{ref}\,e^{c_r(p_0 - p_{ref})}$ (пара «Reference porosity / Reference pressure», как ROCK в Eclipse/OPM); $(\rho c_p)_s = \rho_{ma} c_{ma}$ — определение под `eq:main_rhocpeff`. Свойства скелета — сплошной твёрдой фазы с весом $1-\varphi_0$ (`eq:main_rhocpeff`, `eq:lambda_eff`); `eq:lambda_eff` — верхняя оценка, $\lambda_{ma}$ подбирается под измеренную $\lambda_{eff}$ насыщенной породы.
- **Не из книги** (`NOT_FROM_WORKBOOK`): книга только табличная — Стендинг и Кори недоступны; имена CSV пишет перевод; секция `output` — умолчания, заголовок — имя книги ([[FEAT-036]]).

## Проверки Excel

У каждой числовой ячейки, кроме постоянных, — проверка данных Excel формулой (`=AND(ISNUMBER(C5),C5>0)`, целое — `C5=INT(C5)`, $r_e > r_w$ — ссылкой на ячейку); выпадающий список — Control mode. RELPERM: промежуточные точки добавляются и удаляются вставкой и удалением строк листа; промежуточные строки разблокированы целиком — строку с заблокированной ячейкой Excel на защищённом листе не удаляет. Строка, вставленная сразу под $S_g = 0$, наследует её заблокированные ячейки — проверить при приёмке в Excel. Пределы — как у программы (`_validate`, `_validate_interval`, пределы CSV фабрики); проверка книги не строже JSON — тест `test_excel_not_stricter_than_program`. Строже программы только постоянные строки (значение в книге не меняется); плотности при ст. у. (> 0) были исключением до [[DEBT-076]]: у программы предела не было. Вставка из буфера и очистка ячейки проверку Excel обходят — перевод проверяет всё заново. Условия таблиц целиком (ветви PVTO, $p_b$ растёт с $R_s$, $k_{rg} = 0$ в первой строке ОФП, $k_{ro} = 0$ в последней, недонасыщенный старт) — за фабрикой.

## Шаблон и книга генератора

`gpn-solver template книга.xlsx` пишет новый файл; существующий не перезаписывается — код 2, файл не меняется (книга собирается в памяти, файл создаётся `open(path, "xb")`). Книгу генератора при смене таблицы полей пересоздают, удалив прежнюю; тест `TestGeneratorBook` ловит отставшую книгу.

Демонстрационные значения: таблицы — `INPUT_TEMPLATE.xlsx` прототипа (совпадают с черновиком руководителя) и ветвь $R_s = 60$ из `regression/inputs/T08c.xlsx`; скелет — кварц: $\rho_{ma}$ = 2650 кг/м³, $c_{ma}$ = 820 Дж/(кг·К) (Шомейт NIST при 350 К; Гиматудинов, табл. II.5: породы нефтяных залежей 0.63–1.0 кДж/(кг·К)); $T_0$ = 350 К, $L$ = 230 кДж/кг. **Числа — с 15 значащими цифрами:** XlsxWriter пишет число с 16 цифрами (`{:.16G}`), 17-значное в книге сдвинулось бы до 5e-16; число с ≤ 16 цифрами запись не меняет, 15 — точность набранного в Excel числа. Тест-страж — `test_demo_numbers_have_15_digits`. Сценарий книги генератора (30 сут, $N$ = 100, ступени BHP 150 → 120 → 100 бар) считается за ~13 с без предупреждений (проба планирования FEAT-033).
