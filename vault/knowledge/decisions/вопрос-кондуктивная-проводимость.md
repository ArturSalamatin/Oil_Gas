# Вопрос: кондуктивная проводимость — двойной ln?

## Обнаружено при тестировании Grid (фаза 1)

### Формула из problem_statement.tex

Кондуктивный поток (eq. 25):
```
Q_{λ,j+1/2} = (2πh / ln(r_{j+1}/r_j)) · λ_eff^{j+1/2} · (T_j - T_{j+1})
```

Гармоническое среднее (eq. face_interp):
```
λ_eff^{j+1/2} = (ln(r_{j+1/2}/r_j)/λ_j + ln(r_{j+1}/r_{j+1/2})/λ_{j+1})^{-1}
```

### Проблема при однородном λ

При λ_j = λ_{j+1} = λ:
```
λ_face = λ / (ln(r_{j+1/2}/r_j) + ln(r_{j+1}/r_{j+1/2})) = λ / ln(r_{j+1}/r_j)
```

Подставляя в eq. 25:
```
Q = (2πh / ln(r_{j+1}/r_j)) · (λ / ln(r_{j+1}/r_j)) · ΔT = 2πhλ / ln²(r_{j+1}/r_j) · ΔT
```

### Аналитическое решение

Для стационарного кондуктивного потока через кольцевой слой при однородном λ:
```
Q = 2πhλ · ΔT / ln(r_{j+1}/r_j)
```

Один ln в знаменателе, не два.

### Возможные объяснения

1. **Ошибка в eq. 25:** лишний `1/ln(r_{j+1}/r_j)` в формуле. Правильно: `Q = 2πh · λ_face · ΔT` (без деления на ln).

2. **Ошибка в eq. face_interp:** веса должны быть нормированы. Вместо `ln(r_{face}/r_j)` нужно `ln(r_{face}/r_j) / ln(r_{j+1}/r_j)` — тогда w_L + w_R = 1, и λ_face = λ при однородном λ.

3. **r_{j+1} и r_j в eq. 25 — это грани, не центры.** Тогда `ln(r_{j+1}/r_j)` — другое число. Маловероятно: T_j и T_{j+1} — в центрах.

### Влияние

Ошибка (если есть) затрагивает **только EnergySolver** (фаза 5). Grid вычисляет log_weights корректно. Интерпретация весов — ответственность EnergySolver.

### Действие

Проверить при реализации EnergySolver. Варифицировать на стационарном кондуктивном профиле T(r) = A·ln(r) + B.
