# BUG-022: условие сходимости Ньютона по ячейке, отнесённое к её поровому объёму

## Кратко

- **Ошибка.** Ньютон прототипа останавливается по одному абсолютному критерию на всю сетку: $\|F\|_\infty \le$ atol + rtol·$\|F_0\|_\infty$, atol = 1e-11 м³ст/с, газовые строки поделены на `gas_residual_scale` = $\max(R_{s,ext}, 1)$. На логарифмической сетке поровый объём забойной ячейки в $\sim(R_{ext}/r_w)^2$ раз меньше, чем у внешней (пример 17: 4.96e-3 против 1.84e4 м³), и та же абсолютная невязка там — относительная ошибка в ~4e6 раз больше. У примера 17 на останове $R_s(r_w)$ блуждает на ±0.015 и убывает до −0.018 за сутки, хотя может только расти. Допуски зашиты в прототипе; поля `numerics.newton_*` фабрика не передаёт ([[DEBT-008]]).
- **Исправление** (решения пользователя 2026-10-10, раздел 0). У `RadialBlackOilModel` новый аргумент `cell_tol` (по умолчанию `None` — выключено). С ним решение Ньютона принимается, только если **кроме** абсолютного критерия в каждой ячейке $i$
  $$\max_c \frac{|F_{c,i}|\,\Delta t}{V_{p,i}} \le \varepsilon_{\text{cell}},$$
  где $F_c$ — та же невязка `residual()` (м³ст/с, газ поделён на `gas_residual_scale`), $V_{p,i}$ — поровый объём на начало шага. Иначе — отказ этого решения, шаг идёт на следующие ступени `advance` (жёсткая форма). Условие стоит в обоих Ньютонах: `_newton_fixed_active_set` (ступени 1–3) и `_newton_switching` (ступень 4). Фабрика GPN передаёт `cell_tol` из нового поля `numerics.newton_cell_tol` (по умолчанию 1e-8; `null` — выключить).
- **Почему именно так.** У недонасыщенной ячейки, которая ни на одной грани не стоит выше по потоку (забойная на останове), $R_s$ входит в накопление, но не в потоки, и условие даёт оценку ошибки $R_s$ за шаг $\varepsilon_{\text{cell}} B_o (s_g + R_s)$ (раздел 2.2, п. 4): у забоя примера 17 — 4.6e-6 при $\varepsilon_{\text{cell}}$ = 1e-8; с одним абсолютным критерием — 3.3e-3. Мягкие формы (принять решение, когда доводка упёрлась) замерены и отвергнуты: они принимают решения, недорешённые как раз в забойной ячейке (раздел 1.3).
- **Замерено при планировании** (код плана подменялся в памяти, пробы `vault/issues/bug-022/probes/`; базы `7b34a33` → `d0a8c05` → `d94f9e8` → `6324149` — код гидродинамики и энергии на них один и тот же: DEBT-046, DEBT-049, DEBT-052, DEBT-053 меняли тесты, README, vault, `_validate` и `Simulator(output_config=…)`; аудит применил текст плана к копии дерева на `6324149` — раздел 7):

### 1.3 Форма условия — жёсткая против мягких (пример 17, $\varepsilon_{\text{cell}}$ = 1e-8)

| форма | что делает после выполнения абсолютного критерия | наименьшее изменение $R_s(r_w)$ | убываний | якобианов | отказов шагов |

| `w` — доводка, $L_\infty$ | как `s`, но линейный поиск доводки — по мере ячеек $\max_i \|F_i\|\Delta t/V_{p,i}$ | −6.34e-3 | 8 | 13988 | 44 |

Почему мягкие не работают. У жёсткой формы на 17 решения ступеней 1–3, где абсолютный критерий выполнен, а условие ячейки — нет, кончаются отказом линейного поиска (86 раз) или исчерпанием лимита в 15 итераций (47). Две причины:
- функция качества линейного поиска ступеней 1–2 — $\|F\|_\infty$ по всем ячейкам — забойную ячейку не видит, а направление Ньютона — направление спуска для $\|DF\|_2$, но не для $L_\infty$-норм (`s`, `w` упираются в линейный поиск: 34 и 59 отказов поиска после абсолютного критерия);
- доводка не успевает за лимит итераций: у `q` линейный поиск по взвешенной $L_2$ шаги принимает, но 20 решений кончаются на 15-й итерации, и мягкая форма принимает их недорешёнными (−2.5e-3).

Жёсткая форма отдаёт такой шаг ступени 3 (линейный поиск по $\|F\|_2$, новые 15 итераций) или 4 (без линейного поиска, до 40 итераций), и они дорешивают: ступень 1 решает 513 шагов против 582 в базе, ступень 3 — 49 против 11, ступень 4 — 199 против 175; лимит ступени 4 при выполненном абсолютном критерии исчерпан 1 раз.

## 2. Анализ

### 2.1 Воспроизведение

- Тестом сейчас — никак: `TestShutInStrongCooling::test_gas_dissolves_at_well_and_ring_remains` (`numerical_solver/tests/test_examples.py:2711`) проверяет одну выборку $R_s(r_w)$ = 79.51 ± 0.01 и проходит случайно (база 79.5125).
- Пробой (из `numerical_solver`): `& $PY "$P\cell_tol.py" examples 0 17_shut_in_strong_cooling` — строка «min dR_s по записям 16..53 = -1.84e-02, убываний 6».
- Воспроизводящие тесты пишет шаг 1: монотонность $R_s(r_w)$ примера 17 на останове (красный: −1.84e-2) и модульные тесты условия (красные: аргумента `cell_tol` нет).

### 2.2 Цепочка причины

1. `RadialBlackOilModel.physical_residual` (`blackoil.py:221-223`) — баланс компонента в ячейке, м³ст/с: (запас нового − запас старого)/Δt + отток.
2. `residual` (`:224-225`) делит газовые строки на `gas_residual_scale` = $\max(R_{s,ext}, 1)$ (`:66`): у 17 это 300.
3. `_newton_fixed_active_set` (`:315-347`; ступени 1–3) и `_newton_switching` (`:489-544`; ступень 4) останавливаются при $\|f\|_\infty \le$ atol + rtol·$\max(\|f_0\|_\infty, 10^{-9})$, atol = 1e-11, rtol = 1e-8 (`:317`, `:327`, `:345-346`; `:507`, `:520-521`). Допуски — умолчания аргументов; `_advance_phases` их не передаёт (`:449`, `:452`); фабрика тоже (`factory.py:428-440`, [[DEBT-008]]).
4. Допуск по газу 3e-9 м³ст/с — за шаг 3600 с 1.08e-5 м³ст газа на ячейку. Забойная ячейка 17 содержит 4.1e-3 м³ст нефти ($V_p$ = 4.96e-3 м³, $B_o$ = 1.21 при $R_s$ = 79.5). На останове она ни на одной грани не стоит выше по потоку: её $R_s$ входит в накопление газа (и через $B_o$ — нефти), но не в потоки. Отсюда оценка ошибки $R_s$ за шаг $\Delta t\,(s_g|f_g| + R_s|f_o|)/o$: газовый член — 2.6e-3, с нефтяным — 3.3e-3 (вклад ошибки давления через потоки не учтён; это оценка, а не граница). У ячейки, стоящей выше по потоку, $R_s$ входит и в потоки, оценка к ней не относится.
5. На останове ошибки случайного знака копятся: за сутки $\sqrt{24}\cdot$2.6e-3 ≈ 0.013 — наблюдаемые ±0.015.
6. Проявляется в выходной величине: $R_s(r_w)$ немонотонен; тест `:2711` берёт одну выборку шума. [[DEBT-048]] сдвигает её на +0.055 — сдвиг от допуска, не от памяти.

### 2.3 Целевое состояние

- Решение Ньютона GPN принимается, только если выполнены абсолютный критерий и условие ячейки $\max_c \max_i |f_{c,i}|\Delta t/V_{p,i} \le 10^{-8}$.
- $R_s(r_w)$ примера 17 на останове не убывает больше чем на 1e-4 между записями (оценка ошибки 4.6e-6 за шаг, 24 шага в сутки — до 1.1e-4 в худшем случае; замер −2.0e-5).
- Прототип без аргумента считает побитово как прежде: его тесты и регрессия 17/17 PASS без пересъёма.
- `numerics.newton_cell_tol` задаёт порог, `null` выключает; неверное значение — `ValueError` с именем поля.
- Постановка (`problem_statement.tex`, раздел критериев сходимости) и P8 описывают действующие критерии.

### 2.4 Варианты

**Вариант A — глобально ужесточить atol (1e-14).** Правка: умолчание `atol_sm3s` у обоих Ньютонов. Плюс: одна строка; проба DEBT-048 — $R_s(r_w)$ монотонен. Минусы: критерий остаётся абсолютным — на более мелкой забойной ячейке шум вернётся; итерации оплачиваются во всех ячейках; предел округления: шум разности запасов крупной ячейки $\varepsilon_{маш} M/\Delta t$ на наименьшем подшаге Δt/512 ≈ 7 с — ~5e-13 м³ст/с, выше 1e-14 (оценка) — дроблёный шаг может не сойтись никогда; меняет и собственные расчёты прототипа. **Отклонён.**

**Вариант B — `gas_residual_scale` = 1.** Минусы: тот же абсолютный критерий; меняется и функция качества линейного поиска ступеней 1–3 (`:320`, `:342`) — другие принятые шаги; шум газового запаса в $R_s$ раз больше нефтяного. **Отклонён.**

**Вариант C — условие по ячейке, жёсткая форма (план).** Суть — раздел «Кратко». Изменения — шаги 2, 3. Плюсы: устраняет причину, а не случай 17; порог безразмерный — не зависит от Δt и размера ячейки; где условие на месте остановки уже выполнено, решение побитово прежнее (раздел 1.10); в прототипе выключено по умолчанию. Минусы: +13 % якобианов по примерам (+18 % у 17); у 14 один шаг дробится; предел округления $\varepsilon \gtrsim \varepsilon_{маш}(R_{ext}/r_w)^2$ (раздел 1.2) — у 1e-8 запас ~10× при $R_{ext}/r_w$ = 2000. Риск: новые отказы шагов там, где база сходилась (у 14 — один; у 17 отказов меньше: 41 против 47). Совместимость: истории 21 примера из 22 меняются, у 18 из них — на уровне округления.

**Вариант C′ — условие по ячейке, мягкие формы (`s`, `w`, `q`).** Новых отказов нет по построению, но пример 17 не исправляется (раздел 1.3). **Отклонён** (решение 1).

**Вариант D — провести допуски из конфига (DEBT-008) и ужесточить их в конфиге 17.** Обход: дефект остаётся во всех конфигах, где его не заметили; предел округления варианта A сохраняется. **Отклонён**; поле нового порога в конфиге входит в C (решение 4).

**Нормировка.** Поровый объём $V_{p,i}$ на начало шага (`rock.pore_volume_m3(grid.bulk_volumes_m3, p_old)`), как CNV в OPM Flow. Альтернатива — запас нефти ячейки $o_i$: в недонасыщенной ячейке это $V_p/B_o$, оценка ошибки $R_s$ та же с точностью до множителя $B_o$, но $o_i \to 0$ при $S_g \to 1$. Поровый объём не обращается в ноль и постоянен внутри шага. Порог CNV OPM по умолчанию не переносится: у OPM невязка умножается на $B$ фазы и меряется в долях порового объёма (по смыслу — насыщенность), а здесь нужна точность $R_s$.

"""BUG-022: условие сходимости Ньютона прототипа по ячейке (аргумент cell_tol).

Абсолютный критерий прототипа ||F||_inf <= atol + rtol*||F_0||_inf (м³ст/с) один на
все ячейки. На логарифмической сетке поровый объём забойной ячейки в ~(R_ext/r_w)^2 раз
меньше, чем у внешней, и та же невязка там — относительная ошибка в ~10^6 раз больше:
у примера 17 R_s(r_w) на останове блуждал на ±0.015 и убывал, хотя может только расти.
С cell_tol решение Ньютона принимается, только если ещё в каждой ячейке
max_c |F_c,i|*dt/PV_i <= cell_tol (PV — поровый объём на начало шага; газовые строки,
как и в абсолютном критерии, поделены на gas_residual_scale). Иначе — отказ решения,
шаг идёт на следующие ступени advance. По умолчанию выключено (собственные расчёты
прототипа и его эталон регрессии побитово прежние), фабрика GPN включает:
numerics.newton_cell_tol = 1e-8.

Модель Nabor_1b строится напрямую: пакет tests прототипа импортировать нельзя.
План: vault/plans/bug-022 newton-cell-relative-tolerance.md; числа —
vault/issues/bug-022/probes/unit_check.out.txt, unit_newton_direct.out.txt.

NABOR_1B = PROTO_ROOT / "tests" / "fixtures" / "Nabor_1b.xlsx"

DT_STAGE4 = 168.75       # шаг останова rs300, который решает только ступень 4 (BUG-020)


def _build(n, cell_tol=None):
    """Модель Nabor_1b на n ячейках (p_wf = 100 бар) и начальное состояние без газа (200 бар)."""
    inp = load_input(NABOR_1B)
    p = inp.params
    grid = RadialGrid(float(p["Well radius rw"]), float(p["Outer radius re"]),
                      float(p["Formation thickness h"]), n, float(p["Absolute permeability"]))
    rock = CompressibleRock(float(p["Reference porosity"]), float(p["Reference pressure"]),
                            float(p["Rock compressibility cr"]))
    model = RadialBlackOilModel(grid, rock, inp.pvt, inp.relperm, 100.0,
                                float(p["Outer-boundary pressure"]),
                                float(p["Initial dissolved gas Rs"]),
                                skin=float(p["Well skin"]), linear_solver="sparse",
                                cell_tol=cell_tol)
    state = BlackOilState.undersaturated(grid.n, 200.0, float(p["Initial dissolved gas Rs"]))
    return model, state


def _measure(model, s_old, s_new, dt):
    """Мера условия на решении: max_c |F_c,i|*dt/PV_i (газ — /gas_residual_scale, как в residual)."""
    f = model.residual(model.pack(s_new), s_old, dt, s_new.gas_active)
    w = dt / model.rock.pore_volume_m3(model.grid.bulk_volumes_m3, s_old.pressure_bar)
    n = model.grid.n
    return max(float(np.max(np.abs(f[:n]) * w)), float(np.max(np.abs(f[n:]) * w)))


def _newton(model, state):
    """Одно решение Ньютона ступени 1 на наборе фаз начального состояния: (z, отчёт)."""
    return model._newton_fixed_active_set(model.pack(state), state, DT, state.gas_active)

@pytest.fixture(scope="module")
def shutin():
    """Модель фабрики и состояние после 10 сут добычи сценария rs300 (~2 с), управление q_oil = 0.

    Замер плана: p(r_w) = 50.8965 бар, двухфазных 289, max S_g = 0.4483.
    """
    cfg = load_config(RS300)
    sim, init = SimulatorFactory.from_config(cfg)
    s = sim.run(init).states[-1]
    model = sim._hydro._model
    model.set_oil_rate_control(0.0, ATM_BAR)
    ps = BlackOilState(pressure_bar=s.p / BAR, rs_sm3_sm3=s.Rs.copy(),
                       sg=s.Sg.copy(), gas_active=(s.regime == 1))
    return model, ps


class TestSwitching:
    def test_switching_meets_cell_tol(self, shutin):
        """Шаг останова 168.75 с ступенью 4: без условия забой недорешён, с условием — нет.

        Замер плана: без условия — 20 итераций, мера 2.24e-8 > 1e-8; с условием — 21
        итерация, мера 1.15e-11, |dp| 2.14e-9 бар. Модель фабрики: cell_tol выключается
        на экземпляре и возвращается в finally (фикстура общая).
        Ловит: условие не стоит в _newton_switching.
        """
        model, ps = shutin
        assert model.cell_tol == CELL_TOL               # фабрика включила (шаг 3)
        try:
            model.cell_tol = None
            a, ra = model._newton_switching(ps, DT_STAGE4)
            assert ra.converged and _measure(model, ps, a, DT_STAGE4) > CELL_TOL
            model.cell_tol = CELL_TOL
            b, rb = model._newton_switching(ps, DT_STAGE4)
        finally:
            model.cell_tol = CELL_TOL
        assert rb.converged and rb.iterations > ra.iterations
        assert _measure(model, ps, b, DT_STAGE4) <= CELL_TOL
        assert np.max(np.abs(b.pressure_bar - a.pressure_bar)) < 1e-7
