# Краснов 2010 — идентификация параметров пласта

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Краснов В.А., Юдин Е.В., Лубнин А.А.** Модели работы скважины для решения задачи идентификации параметров пласта по данным эксплуатации. *Научно-технический вестник ОАО «НК Роснефть»*, 2010, №2, С. 34–38.

## Аннотация
Предложены модели работы скважины, используемые для идентификации параметров пласта по данным эксплуатации. Является предыдущей работой предположительного автора документа о многофазном псевдодавлении — в том документе упоминается: «подход уже был изложен ранее в статье [28]» (Gringarten) и ссылка [27] на данную работу.

## Потенциал для проекта
Методы идентификации параметров могут быть полезны на этапе верификации модели ПЗП по промысловым данным.
