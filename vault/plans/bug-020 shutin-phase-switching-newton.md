# BUG-020: четвёртая ступень `advance` — Ньютон с переключением набора фаз на итерациях

**Реестр:** [[известные баги и технический долг]] → BUG-020. **Issue:** [#63](https://github.com/ArturSalamatin/Oil_Gas/issues/63). **Ветка:** `fix/bug-020/shutin-gas-zone-convergence` от `numerical_scheme/implementation`.

## Кратко

**Симптом.** Останов скважины (или подъём $p_{wf}$) после добычи с развитой газовой зоной ($S_g \gtrsim 0.2$) не считается: `HydroSolver не сошёлся после 512 подшагов`. Конфиги 19, 20, 21 (и 14): 10 сут добычи, затем останов.

**Причина — два механизма в прототипе и одно свойство A-retry** (раздел 1):

- **М1, первый шаг останова.** Забойная ячейка 0 ($PV = 2.8\cdot10^{-3}$ м³) после закрытия скважины ни для одной грани не стоит выше по потоку: её $S_g$ входит только в её же запас. Коэффициент запаса газа по $S_g$, $1/B_g - R_s/B_o$, при 51 бар равен 7.4 м³ст/м³ пор: $1/B_g$ = 38.2 и $R_s/B_o$ = 30.7 почти сокращаются. При 200 бар он 38.9. Линеаризация в старом состоянии требует $|\Delta S_{g,0}| \approx 0.7\,\Delta t$ [с] (48 при 60 с, 435 при 600 с). Исходная ступень отвергает все пробные точки ($S_g < -0.05$). Запасной путь уводит $S_{g,0}$ в $-23 \ldots -1137$ (там $c_t < 0$) и стоит. Третья ступень масштабирует **всё** приращение на $0.2/|\Delta S_{g,0}|$, и давление ползёт по 0.2 бар за итерацию.
- **М2, следующие шаги.** В застойной однофазной зоне у забоя (ячейки 0–13, давление выровнено до $10^{-3}$ бар) на каждой итерации у 1–11 граней меняется ячейка выше по потоку. Якобиан разрывен, Ньютон сходится линейно: 26 итераций при лимите 15. Набор фаз и ветка скважины ни при чём.
- **Равномерное A-retry.** Адаптер дробит интервал `dt_integration` на $2^k$ равных подшагов, и сходиться обязан каждый. При `dt_integration` = 1 сут (14, 19, 20, 21) одного неудачного подшага из 512 хватает для отказа — даже с исправленным Ньютоном.

**Исправление** (решения пользователя — раздел 0):

1. Прототип: **четвёртая ступень `advance`** — только там, где три нынешние отказали. Это запасной путь BUG-014, в котором `_advance_phases` заменён новым `_newton_switching`. В нём набор фаз переключается после каждой итерации с сохранением отношения газ/нефть ячейки (а не после сходимости при замороженном наборе). Приращения ограничиваются поячеечно: $|\Delta p_i| \le 0.3\,p_i$, $|\Delta S_{g,i}| \le 0.2$ — вместо общего масштабирования. Линейного поиска нет (как в OPM Flow). Ячейка выше по потоку замораживается на гранях, где направление дважды сменилось; после сходимости — доводка без замораживания. Лимит 40 итераций, невязка после последней итерации проверяется.
2. Ступень включается флагом конструктора `phase_switching_stage` (по умолчанию `False`): прототип сам по себе и его эталон регрессии не меняются. Фабрика GPN передаёт `True`.
3. Документация: для останова и подъёма $p_{wf}$ после добычи с развитой газовой зоной `dt_integration` ≤ 3600 с. Это README 16, `examples/README.md` и текст ошибки адаптера.

**Эффект (замерено кодом плана, `probes/plan_code.py`).** Первый час останова: 19 — 1 подшаг вместо отказа; 21 — 16 вместо отказа; 20 — 64 вместо 256. 3 сут останова при `dt_integration` = 3600 с (замер до BUG-021; после него числа шагов и время сдвигаются, отказы без ступени 4 остаются): 19 — 438 с, 21 — 196 с (без ступени — отказ); 20 — 366 с против 512 с, шагов втрое меньше. Где три ступени сходятся, всё побитово. Изменится пример 16: шаг третьего часа останова, который раньше дробился 2 × 1800 с, — $|\Delta p| \le 0.44$ бар, $|\Delta T| \le 2.7$ мК. Пример 13b **не меняется**: BUG-021 вливается раньше (решение пользователя), и его шаг решает третья ступень. История 13b «BUG-021» против «BUG-021 + план» побитова (аудит, раунд 2). Без BUG-021 ступень 4 меняла бы и 13b — 392 Па, 0.6 мК (раздел 1.7). Эталон прототипа не затронут (флаг выключен; замер на T03, T04 с включённой ступенью — раздел 1.7).

### 1.1 М1 — первый шаг останова (конфиг 20)

|---|---|---|---|---|
| 50.9 | 38.17 | 30.74 | **7.43** | 0.849 |
| 150 | 112.47 | 88.42 | 24.05 | 0.683 |
| 200 | 149.97 | 111.05 | 38.92 | 0.608 |

Решения Ньютона (`trace_stages_20.out.txt`):

- **исходный алгоритм** (граница $S_g \ge -0.05$): все 12 пробных точек вне области, $\alpha \to 0$ за 2–4 итерации;
- **запасной путь, «закрыта»** (без границы): $\alpha = 0.5$ уводит $S_{g,0}$ в −23.5 (60 с), −65.4 (169 с), −216.9 (600 с), −1137 (3600 с); у 1–5 ячеек $c_t < 0$. На 60 с выходит и сходится за 15 итераций; на расширении $\min S_g = -0.229$ у 25 ячеек, $c_t > 0$ везде. С 169 с — лимит 15 или застой поиска;
- **запасной путь, «открыта»** (режим A): закачка при $p_{ext}$, $p_0 \to 1$ бар, поиск стоит;
- **третья ступень**: всё приращение умножается на $0.2/|\Delta S_{g,0}|$ ($4.6\cdot10^{-4}$ при 600 с); $p_0$ растёт 51 → 54 бар за 15 итераций.

Кандидат «$c_t < 0$ на расширении $S_g < 0$» из issue подтверждён лишь отчасти. Отрицательная сжимаемость появляется только в точках перелёта ($S_g \sim -20 \ldots -1000$), а не на решении 60 с. Это следствие перелёта, а не его причина.

### 2.2 Цепочка

1. Скважина закрывается (ветка «закрыта» или `q_oil = 0`): поток через забой обнуляется, ячейка 0 принимает приток от ячейки 1 и выше по потоку ни для кого не стоит.
2. Ньютон в старом состоянии (51 бар) видит малый газовый коэффициент запаса (7.4) и требует $|\Delta S_{g,0}| \approx 0.7\,\Delta t$: 48 при 60 с. Набор фаз внутри Ньютона заморожен (`_advance_phases`, на `6edc433` — `blackoil.py:400-422`). Ячейка не может стать однофазной, пока Ньютон не сойдётся в расширении $S_g < 0$.
3. Три ступени глобализации ломаются по-разному (1.1): граница −0.05 режет шаг до нуля; без границы — перелёт в область $c_t < 0$; общий ограничитель $|\Delta S_g| \le 0.2$ режет и давление. Ступень отказывает → A-retry делит интервал.
4. На следующих шагах фронт растворения уходит от забоя, а в однофазной зоне давление выравнивается. Смена ячейки выше по потоку на гранях с $|\Delta p| \sim 10^{-3}$ бар делает якобиан разрывным, Ньютону не хватает 15 итераций.
5. A-retry дробит интервал равномерно, и сходиться обязан каждый подшаг. У 20 первый час проходит лишь подшагами по 14 с (256 из предельных 512); у 19 и 21 он не проходит и при 7 с. При `dt_integration` = 1 сут для 20 понадобилось бы $\ge 2^{13}$ подшагов при пределе $2^9$ → `RuntimeError` (`prototype_adapter.py:182-198` на `6edc433`).

### 2.3 Целевое состояние

- Шаг, который ступени 1–3 не решают, проходит ступень 4, если её корень существует и Ньютон с переключением фаз его находит; иначе — как сейчас, отказ и A-retry.
- Решение ступени 4 — решение исходной схемы: та же невязка, исходный выбор ячейки выше по потоку (с доводкой), $S_g \ge 0$ у двухфазных, $R_s \le R_s^{sat}(p)$ у однофазных, баланс масс на уровне допуска Ньютона.
- Где ступени 1–3 сходятся, результат побитово прежний. Прототип без флага исполняет прежний код.
- Первый час останова после 10 сут добычи проходит: 19 — 1 подшаг, 21 — ≤ 16, 20 — ≤ 64. 3 сут останова при `dt_integration` = 3600 с проходят на 19, 20, 21.
- README и текст ошибки говорят: при останове после добычи с развитой газовой зоной нужен `dt_integration` ≤ 3600 с.

Инварианты (тесты): баланс масс шага, согласованность фаз, совпадение с корнем штатного алгоритма, сохранение отношения газ/нефть при переключении, побитовость без ступени, восстановление атрибутов после ступени (успех, отказ, исключение).

### 2.5 Выбор

Вариант А — единственный, что на замерах снимает оба механизма. Флаг — решение пользователя 1. Г — решение 2: документировать, а довод записать в DEBT-015.

Почему ступень — через `_fallback`, а не своя логика веток. Перебор веток скважины (сначала ветка старого состояния, при отказе или несогласованности — другая один раз) уже отлажен в BUG-014. Повторять его в новом методе — дублировать логику. Цена — лишние ~40 итераций на отказах ступени 4 в режиме BHP (вторая ветка). Зато в 13b именно вторая ветка решила шаг (1.7).

Почему без линейного поиска: 1.4, первая таблица — с поиском ступень не делает ни одной итерации. Защита от расхождения — ограничения приращений, лимит 40 итераций и отказ → A-retry, как в OPM Flow (`dpMaxRel`, `dsMax`; правило времени — дробление шага).

Почему доводка без замораживания. Решение с замороженной ячейкой выше по потоку решает другую схему, если направление разошлось с перепадом давления на решении. Доводка возвращает исходную схему, и результат — корень той же невязки, что у ступеней 1–3 (проверка 1.5, «Тот же корень»).

    def test_switch_preserves_gas_oil_ratio(self, shutin_start):
        """Переключение фаз ступени 4 сохраняет отношение газ/нефть ячейки (в обе стороны).

        Деактивация (S_g < 0): R_s = (S_o R_s^sat/B_o + S_g/B_g)/(S_o/B_o).
        Активация (R_s > R_s^sat): S_g «закрытого сосуда» — у двухфазного
        состояния то же отношение газ/нефть. Замер: ошибка <= 4e-16.
        """
        model, ps, _ = shutin_start
        pvt, n = model.pvt, model.grid.n
        p = ps.pressure_bar.copy()
        rs_sat = pvt.rs_sat(p)
        bo, bg = pvt.bo(p, rs_sat), pvt.bg(p)

        def ratio(sg):
            return ((1 - sg) * rs_sat / bo + sg / bg) / ((1 - sg) / bo)

        sg_neg = -np.linspace(0.01, 0.5, n)
        x, m, ns = model._switch_phases(p, sg_neg, np.ones(n, bool))
        ok = ratio(sg_neg) > 0          # где отношение < 0, R_s обрезается до 0
        assert ns == n and not m.any()
        assert np.allclose(x[ok], ratio(sg_neg)[ok], rtol=1e-12)

        rs_hi = rs_sat * 1.05 + 1.0
        x, m, ns = model._switch_phases(p, rs_hi, np.zeros(n, bool))
        assert ns == n and m.all()
        free = x < (model.sg_activation_cap or 2.0)   # ограничение BUG-018 не сработало
        assert np.allclose(ratio(x)[free], rs_hi[free], rtol=1e-12)

        """BUG-020: phase switch at a Newton iterate (p, x) of the fourth stage; returns (x, mask, switches)."""
        rs_sat=self.pvt.rs_sat(p); x=x.copy()
        deact=mask&(x<-self.sg_switch_tol); act=(~mask)&(x>rs_sat+self.rs_switch_tol)
        if np.any(deact):

            # (So*Rs_sat/Bo + Sg/Bg)/(So/Bo) = Rs_sat + Sg*Bo/((1-Sg)*Bg) -- the inverse
            # of the closed flash below; clipped at 0 where Sg is far below zero

        # Shut-in after production with a developed gas zone.  The well cell is upstream of no
        # face once the well is shut, and its gas storage per unit Sg, 1/Bg - Rs/Bo, is small at
        # low pressure (7.4 at 51 bar against 38.9 at 200 bar, example 20): the first Newton
        # direction asks |dSg| ~ 0.7*dt[s].  The bound -0.05 rejects every trial, no bound sends
        # Sg to -23...-1137 (c_t < 0 there), the third stage scales the whole update by
        # 0.2/|dSg| and the pressure crawls.  Here a cell leaves the two-phase set as soon as
        # an iterate takes its Sg below 0, and the limits act per cell (dpMaxRel, dsMax of OPM
        # Flow).  No line search: after the per-cell limit the update is not a descent
        # direction of ||F||, and the search stopped at the first iteration (plan BUG-020, 1.4).
        # Later steps: in the stagnant undersaturated zone near the shut well the pressure is
        # level to 1e-3 bar, the upstream cell of 1-11 faces flips every iteration and the
        # Newton converges linearly (26 iterations against 15); faces that flipped twice keep
        # their upstream cell until convergence, then a polish without holding returns the
        # original upwind scheme.
        state_old=state_old.copy(); n=self.grid.n; nf=max(n-1,0)
        mask=state_old.gas_active.copy(); z=self.pack(state_old,mask)
        scale=max(np.linalg.norm(self.residual(z,state_old,dt_s,mask),np.inf),1e-9); tol=atol_sm3s+rtol*scale
        switched=total=0; flips=np.zeros(nf,int); prev=None; polish=False
        self._upwind_frozen=np.zeros(nf,bool); self._upwind_left=np.zeros(nf,bool)
        try:
            # one pass more than max_iter: the residual after the last update is checked too
            for it in range(1,max_iter+2):
                p=z[:n]; left=(p[:-1]-p[1:])>=0
                if not polish:
                    # faces whose direction flipped flips_to_freeze times keep their upstream cell
                    if prev is not None: flips+=(left!=prev)&~self._upwind_frozen
                    fr=(~self._upwind_frozen)&(flips>=flips_to_freeze)
                    self._upwind_left=np.where(fr,left,self._upwind_left); self._upwind_frozen=self._upwind_frozen|fr
                prev=left
                J,f=self.finite_difference_jacobian(z,state_old,dt_s,mask); nrm=np.linalg.norm(f,np.inf)
                if nrm<=tol and switched==0:
                    fz=self._upwind_frozen
                    if fz is None or np.array_equal(self._upwind_left[fz],left[fz]):
                        new=self.unpack(z,mask); new.sg[mask&(new.sg<0)]=0.0
                        # same bound as _trial_is_reasonable: no root with Sg > 0.98
                        ok=not np.any(new.sg[mask]>0.98)
                        return new,BlackOilNewtonReport(ok,it-1,float(nrm),1,total)
                    # converged with a held upstream cell the solution contradicts: polish
                    # without holding, so the result solves the original upwind scheme
                    self._upwind_frozen=None; polish=True; continue
                if it>max_iter: break

                x=z[n:]; lim=dp_rel*np.maximum(p,1.0)
                pn=np.maximum(p+np.clip(dz[:n],-lim,lim),1.0+1e-6)
                xn=np.where(mask,x+np.clip(dz[n:],-ds_max,ds_max),np.maximum(x+dz[n:],0.0))
                if not (np.all(np.isfinite(pn)) and np.all(np.isfinite(xn))): break

            return self.unpack(z,mask),BlackOilNewtonReport(False,max_iter,float(np.linalg.norm(f,np.inf)),1,total)

## Local changes — GPN project (BUG-020): fourth stage of advance (off by default)
- Problem: shut-in (q_oil = 0, or BHP raised to the outer pressure) after production with a developed gas zone (Sg near the well 0.4, GPN examples 19-21) did not converge at any step split. - With the default `phase_switching_stage=False` the prototype runs exactly the former code: regression 17/17 PASS bitwise, golden outputs unchanged. With the stage on (the GPN factory), steps the first three stages solve stay bitwise.
- `BlackOilNewtonReport`: new field `phase_switching` (the fourth stage ran), default `False`.
- Physics, residual equations, tolerances and well semantics are unchanged. `PACKAGE_MANIFEST_SHA256.txt` is not updated.
