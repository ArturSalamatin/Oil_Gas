# Запасной путь с отрицательной насыщенностью и веткой скважины снимает порог шага на скачке p_wf вверх

Итог [[BUG-014]] (план [[bug-014 well-shutin-active-set]], issue #42).
Прототип (`radial_blackoil/blackoil.py`) не сходился на длинном шаге после
подъёма $p_{wf}$ выше давления в ячейке у забоя $p[0]$ — ни при каком
равномерном дроблении адаптера. Исправлено запасным путём в `advance`:
исходный алгоритм без изменений, при его отказе — повтор с веткой скважины
во внешнем цикле и без нижней границы $S_g$.

## Два механизма отказа

1. **Ветка скважины по текущей итерации.** $q = WI\,\lambda\max(p[0]-p_{wf},0)$
   считается в `_well_fluxes` на каждой оценке невязки. Стартовая итерация
   $p[0] < p_{wf}$ — ветка «закрыта», $\partial q/\partial p[0] = 0$; при
   длинном шаге на ней нет согласованного решения (правильный ответ —
   «открыта»: к концу шага $p[0] > p_{wf}$).
2. **Исчезновение газа внутри Ньютона.** Давление у забоя растёт, свободный
   газ растворяется во всей зоне, пробные точки получают $S_g < -0.05$ и
   отвергаются `_trial_is_reasonable`. Цикл набора фаз переводит ячейки в
   однофазный режим только **после** сходимости — до неё не доходит.
   Зеркально [[BUG-008]] (там — массовое появление газа).

Один механизм 1 не лечит: 13б падает на втором скачке (t = 3 сут) — там
работает механизм 2. Ни `max_newton` 15 → 40, ни граница −1 вместо −0.05
не помогают.

## Что проверено для механизма 2

| Метод | Суть | Результат |
|---|---|---|
| C | ограничение приращения (Appleyard): $\lvert\Delta S_g\rvert \le 0.2$, $\lvert\Delta p\rvert \le 0.3p$ | ✗ при всех dt |
| S | переключение переменных на каждой итерации | скачки ✓, но зацикливание на фронте из начального состояния (ячейка 21 ↔ 22) |
| **N** | **без нижней границы $S_g$ двухфазной ячейки; фазы — после сходимости** | ✓ |

Почему N допустим — только как приём для итераций, а не как модель: при
$S_g < 0$ уравнения ячейки гладко продолжены (запасы линейны по $S_g$, PVT от
$S_g$ не зависят, `TabulatedRelPerm` — `np.interp` с зажимом на краю
таблицы), и Ньютон может пройти через эту область; цикл набора фаз после
сходимости переводит такую ячейку в однофазный режим и решает шаг заново —
принятое решение физично. Идея — из метода отрицательных насыщенностей
[[Abadpour Panfilov 2009 — метод отрицательных насыщенностей]]
(`Refs/abadpour2008.pdf`, ссылка сверена), но N — **не** согласованное
продолжение в смысле статьи: там $k_{rg} = S_g < 0$, $k_{ro} = 1 - S_g$, мнимый
газ со свойствами нефти, PVT нефти при фактическом $R_s$; в N — $k_{rg} = 0$,
$k_{ro} = k_{ro}(0)$, мнимый газ со свойствами газа, $B_o$, $\mu_o$ при
$R_{s,\text{нас}}(p)$. Поэтому состояние N с $S_g < 0$ не отвечает никакой
однофазной нефти и принято быть не может. Масштаб: при одном дефиците $R_s$
$|S_g|$ варианта N в 7–23 раза больше согласованной $\widetilde S_g$; граница
−0.05 соответствует дефициту $R_s$ всего 2–11 м³/м³ — разбор в заметке-обзоре.
Обобщение метода — [[Panfilov Panfilova 2014 — отрицательные насыщенности для трёх фаз и многих компонентов]].
Там есть два довода в пользу того, что N годится только как запасной путь.
Во-первых, приближённый вариант статьи (§4.3: истинные свойства,
отрицательная насыщенность заменяется нулём) по рис. 3–4 даёт неверные
скорости фронтов и значения на плато. Во-вторых, излом якобиана на $p_b$
неустраним и при согласованном продолжении: на PVT примеров наклон запасов
газа скачет в 1.6–21 раз. Второй неустранимый излом — по потокам в
$\widetilde S_g = 0$: условия согласования задают $k_{rg} = \widetilde S_g$
(наклон 1), а при критической газонасыщенности $k_{rg}'(0^+) = 0$
([[Panfilov Rasoulzadeh 2010 — отрицательные насыщенности с диффузией и капиллярностью]],
рис. 5 — излом композиционной доли потока).
Неизотермический вариант метода —
[[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]].
Для запасного пути N он важен одним выводом: если $Q_{\text{deg}}$ считать по
$R_s$ нефтяной фазы при $S_g < 0$, в недонасыщенной зоне появляется ложная
теплота дегазации. Шаг N на итерациях её не создаёт, пока принятое решение
проходит через цикл набора фаз и энергия считается по принятому состоянию.

## Начальная ветка

Дешёвая матрица `Nabor_1b` (80 скачков), все стратегии — с методом N:
«всегда открыта» — 12 отказов (ветка «открыта» при $p[0] \ll p_{wf}$ —
огромная закачка, Ньютон на ней не сходится); **по старому состоянию
($p[0] \le p_{wf}$ → «закрыта»), при отказе Ньютона или несогласованности —
другая ветка, не более двух решений (PB)** — 0 отказов.

## Почему запасной путь, а не N «всегда»

Аудит плана: N на каждом шаге ухудшает глубокую депрессию. Пример 03,
$N = 150$, минимальный `max_retries` при $p_{wf}$ = 2 / 0.5 МПа: исходный
9 / 9, N «всегда» 12 / 11 — при штатном лимите 9 такие расчёты упали бы.
Граница −0.05 служит страховкой при массовом **появлении** газа. Вариант F:
граница снимается только там, где исходный алгоритм уже отказал, — по
построению не хуже исходного, а где исходный сходится, ответ побитово тот же.

## Где бывает отрицательная S_g (замер 2026-09-30)

Граница в поиске по направлению — страховка сходимости, а не физическое
ограничение. Физичность ответа обеспечивает цикл набора фаз
(`_advance_phases`), он не менялся: шаг принимается только без переключений,
двухфазная ячейка с $S_g < -10^{-9}$ переводится в однофазный режим
(неизвестная $R_s$) и шаг решается заново, остаток из $[-10^{-9}, 0)$
обнуляется. Решение с $S_g < 0$ не принимается и по существу: $S_g < 0$
указывает на недонасыщенную ячейку, но само состояние N не отвечает никакой
однофазной нефти (несогласованное продолжение — см. выше «Что проверено для
механизма 2»).

Замер — обёртки на экземпляре модели: `finite_difference_jacobian` видит каждую
итерацию Ньютона, `advance` — каждое принятое состояние.

| Случай | $S_g$ итераций, исходный путь | $S_g$ итераций, запасной путь | итоговая точка Ньютона запасного пути (до переключения фаз) | принятые состояния |
|---|---|---|---|---|
| тест 1: `Nabor_1b`, 150 бар, 3600 с | ≥ −0.0499 | ≥ −0.447 | ≥ −0.049 | $S_g \in [0, 0.031]$; двухфазных 5 → 4 |
| тест 2: 195 бар, 3600 с | ≥ −0.0499 | ≥ −0.447 | ≥ −0.049 | $[0, 0.014]$; 5 → 3 |
| 13б 30 сут: 978 принятых подшагов, из них 16 — запасным путём | ≥ −0.050 (5038 итераций) | **≥ −240.9** (1054 итерации, 699 — с $S_g < 0$) | ≥ −9.28; 111 из 158 сошедшихся решений — с $S_g < 0$ | $[0, 0.085]$; у однофазных ячеек $S_g = 0$ ровно; 392 переключения фаз в 16 шагах |

- Итерация $S_g = -241$ — ячейка 45 из 17 двухфазных, $p = 14.94$ МПа при
  $p_b = 15$ МПа, то есть на фронте разгазирования, на скачках вверх 25, 27,
  29 сут, ветка «закрыта». Ньютон оттуда **сходится** (итоговая точка
  $S_g = -0.176$), затем ячейка переключается. Почему шаг Ньютона по $S_g$ так
  велик именно у фронта — не разбиралось; уравнения по $S_g$ линейны, ничего не
  расходится, $p$ и $R_s$ проверяются прежними границами.
- Вывод: отрицательная $S_g$ живёт только внутри Ньютона, в принятых
  состояниях её нет. Путь итераций запасного пути бывает очень «широким» —
  ограничения приращения $S_g$ в нём нет. На других конфигурациях это стоит
  держать в уме, если запасной путь начнёт отказывать.
- Тесты: `test_prototype_well_branch.py::TestFallbackInvariants::test_negative_iterates_not_accepted`
  (итерации за −0.05, принятое $S_g \ge 0$, переключения фаз),
  проверка $0 \le S_g < 1$ в тестах 1, 2 и адаптерных 10, 11.

## Попутное: у примера 03 дробление первого шага давала граница S_g

Первый шаг примера 03 (20 → 8 МПа, Standing) раньше дробился на 512
подшагов; [[DEBT-007]] объяснял это нелинейностью $B_g$. С запасным путём
шаг сходится при 3600 с (пороги при $N = 150$: 8…5 МПа — 0, 4 МПа — 1,
2 и 0.5 МПа — 9). Значит, ограничивала и граница $S_g \ge -0.05$.

Побочное наблюдение: величины «уровня округления» в README 03 изменились
(|GOR − $R_{s,0}$| на забое $2.1\cdot10^{-7} \to 2.5\cdot10^{-9}$,
разброс потоков по граням $10^{-9} \to 10^{-11}$). Причина — критерий
остановки Ньютона: в стационаре невязка стартовой точки уже ниже допуска,
Ньютон делает 0 итераций, и состояние **застывает**. Раньше гидродинамика
застывала с 1-го часа (512 подшагов успевали выйти на стационар) — остаток
переходного процесса держался все 72 ч. Теперь первый час — один неявный шаг
(GOR на 1 ч = 49.9907, на 2 ч — отклонение $6\cdot10^{-6}$), и застывание
наступает с 3-го часа ближе к стационару. Это не точность решения, а
история итераций.
