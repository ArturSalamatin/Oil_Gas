# Модуль логирования

## Два режима логирования

### Пользовательский (user)

Для человека, запускающего расчёт. Показывает прогресс и ключевые характеристики.

Что логируется:
- Начало расчёта: параметры задачи (N, dt, число интервалов)
- Начало каждого интервала истории: номер, p_wf, длительность, число подшагов
- Конец каждого интервала: t, p_well, T_well, Sg_well, дебит q_o, GOR
- Окончание расчёта: полное время, число шагов

Формат — компактный, одна строка на интервал:
```
[INFO] Start: N=100, dt=3600s, 50 intervals
[INFO] Interval  1/50: p_wf=1.50e+07 Pa, dt_hist=86400s, 24 substeps
[INFO]   → t=8.64e+04 s, p_w=1.52e+07, T_w=350.1 K, Sg_w=0.032, q_o=1.5e-03 m³st/s
[INFO] Interval  2/50: p_wf=1.20e+07 Pa, dt_hist=172800s, 48 substeps
[INFO]   → t=2.59e+05 s, p_w=1.23e+07, T_w=347.8 K, Sg_w=0.089, q_o=2.1e-03 m³st/s
...
[INFO] Done: 50 intervals, 1200 steps, elapsed 12.3 s
```

### Разработческий (developer)

Для отладки библиотеки. Показывает внутреннее состояние модулей.

Что логируется:
- Каждый подшаг интегрирования: номер, dt, t
- PVT-вычисления: min/max Bo, Bg, mu_o, mu_g, Rs_eq
- Потоки через грани: min/max G_o, Q_o
- EnergySolver: min/max коэффициентов a, b, c, d; диагональное преобладание
- Невязки Ньютона (когда появится): итерация, max|F_oil|, max|F_gas|, число переключений режимов
- Физические ограничения: min(p), max(Sg), min(T)
- Предупреждения: Sg близок к 1−S_or, Rs близок к Rs_eq, T сильно изменилась за шаг

Формат — подробный:
```
[DEBUG] Step 12/24, dt=3600.0 s, t=4.32e+04 s
[DEBUG]   PVT: Bo=[1.12, 1.35], Bg=[0.004, 0.012], mu_o=[2.1e-3, 3.8e-3]
[DEBUG]   Fluxes: G_o=[-2.1e-3, -1.8e-3], Q_o=[-1.9e-3, -1.5e-3]
[DEBUG]   Energy: T=[347.2, 353.0], Q_jt=[-12.3, -0.1], Q_deg=[-5.2, 0.0]
[DEBUG]   Constraints: min(p)=1.2e+07, max(Sg)=0.15, min(T)=347.2
```

## Реализация

Используем стандартный `logging` модуль Python. Два логгера:

```python
import logging

# Пользовательский логгер
user_logger = logging.getLogger("numerical_solver")

# Разработческий логгер
dev_logger = logging.getLogger("numerical_solver.dev")
```

Иерархия: `numerical_solver.dev` наследует от `numerical_solver`. При установке уровня `numerical_solver` в INFO — пользовательские сообщения видны, разработческие (DEBUG) — нет. При DEBUG — оба.

### Настройка

Через JSON-конфиг:
```json
"output": {
    "log_level": "INFO"
}
```

Или программно:
```python
import logging
logging.getLogger("numerical_solver").setLevel(logging.DEBUG)
```

Уровни:
- `WARNING` — только ошибки и предупреждения (молчаливый режим)
- `INFO` — пользовательский (прогресс, итоги интервалов)
- `DEBUG` — разработческий (каждый подшаг, PVT, потоки)

### Модуль `gpn_multiphase_solver/log.py`

```python
"""Настройка логирования для numerical_solver."""

import logging

def setup_logging(level: str = "INFO"):
    """Настроить логирование. Вызывается в SimulatorFactory."""
    log_level = getattr(logging, level.upper(), logging.INFO)
    
    logger = logging.getLogger("numerical_solver")
    logger.setLevel(log_level)
    
    if not logger.handlers:
        handler = logging.StreamHandler()
        formatter = logging.Formatter(
            "[%(levelname)s] %(message)s")
        handler.setFormatter(formatter)
        logger.addHandler(handler)

# Удобные ссылки для модулей
user_log = logging.getLogger("numerical_solver")
dev_log = logging.getLogger("numerical_solver.dev")
```

### Использование в модулях

```python
from numerical_solver.log import user_log, dev_log

class Simulator:
    def run(self):
        user_log.info(f"Start: N={self.grid.N}, {len(self.schedule.history)} intervals")
        
        for k, interval in enumerate(self.schedule.history):
            n_sub, dt = self.schedule.substeps(k)
            user_log.info(
                f"Interval {k+1}/{len(self.schedule.history)}: "
                f"p_wf={interval.p_wf:.2e} Pa, dt_hist={interval.dt:.0f}s, "
                f"{n_sub} substeps")
            
            for step in range(n_sub):
                dev_log.debug(f"  Step {step+1}/{n_sub}, dt={dt:.1f} s")
                ...
            
            user_log.info(
                f"  → t={state.t:.2e} s, T_w={state.T[0]:.1f} K, "
                f"q_o={well_data.q_o_std:.2e} m³st/s")
```

## Предупреждения

Отдельная категория — `WARNING` — для ситуаций, не являющихся ошибкой, но требующих внимания:

```python
if np.any(state.Sg > 0.9 * (1 - S_or)):
    user_log.warning(f"Sg approaching 1-S_or at cells {np.where(...)}")

if np.any(state.T < 273):
    user_log.warning(f"Temperature below 0°C at cells {np.where(...)}")

if np.max(np.abs(T_new - T_old)) > 10:
    dev_log.warning(f"Large T change: max|ΔT| = {np.max(np.abs(T_new - T_old)):.1f} K")
```
