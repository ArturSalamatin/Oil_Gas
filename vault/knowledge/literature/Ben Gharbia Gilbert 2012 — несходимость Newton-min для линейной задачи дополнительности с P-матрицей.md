# Ben Gharbia Gilbert 2012 — несходимость Newton-min для линейной задачи дополнительности с P-матрицей

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Ben Gharbia I., Gilbert J.Ch. Nonconvergence of the plain Newton-min algorithm for linear complementarity problems with a P-matrix. *Mathematical Programming*, 2012, 134, 349–364. DOI 10.1007/s10107-010-0439-6.

## Аннотация

В [[Ben Gharbia Jaffré 2014 — полугладкий Ньютон для появления и исчезновения газовой фазы]] цитируется дважды. Во введении — как одна из работ активного направления оптимизации, где решаются задачи дополнительности. В §3.2, вместе с [4], — как источник названия «Newton-min» (полугладкий метод Ньютона с функцией $\min$). По названию: показано, что «чистый» Newton-min, без глобализации, может не сходиться даже для линейной задачи дополнительности с P-матрицей. В статье 2014 г. это следствие для решателя не обсуждается.
