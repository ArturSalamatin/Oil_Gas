# Fujita 1951 — метод моментов для нелинейной диффузии

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Fujita H.** *Mem. Coll. Agr. Kyoto Univ.*, 1951, Vol. 59, p. 31.

## Аннотация
Одно из первых применений метода моментов к нелинейному уравнению диффузии с зависящей от температуры теплопроводностью $k(T)$. Fujita (со ссылкой на Yamada 1947) использует весовые функции $w_j = x^j$ (ур. 205 в Goodman 1964) для линейной зависимости $k \propto T$. Применяет нулевой и первый моменты, получая два уравнения для двух параметров (глубина проникновения и форма профиля). Численный фактор поверхностного теплового потока: 0.576 при кубическом профиле — совпадает с точным значением. Goodman (1964, §VII.A.2) отмечает, что потеря точности при переходе от квадратичного к кубическому профилю, наблюдаемая в обычном HBIM, **не возникает** в методе моментов.

## Потенциал для проекта
Прямой предшественник метода моментов Баренблатта для нелинейных задач. Подтверждает, что нулевой + первый момент достаточны для хорошей точности даже при нелинейных коэффициентах. Crank (49) воспроизводит полный анализ Fujita — доступный источник.
