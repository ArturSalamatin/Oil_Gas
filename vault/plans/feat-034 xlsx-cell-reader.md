9. **Книга с пометкой «пересчитать при открытии» (`fullCalcOnLoad`) — значений формул нет** (2026-10-17). Пометку ставит XlsxWriter (проверено: книга генератора) и, по документации, openpyxl (в окружении его нет — не проверено). XlsxWriter у формулы без переданного значения пишет `<v>0</v>` (проба `xlsxwriter_xml.out.txt`, ячейка A1) — нуль неотличим от настоящего. Признак книги — `Workbook.recalc_on_open`: им FEAT-035 может пояснить причину.
   **Допущение решения — Excel при сохранении пометку снимает** (так ведут себя книги, сохранённые Excel: у 22 книг IMEX `calcPr` без неё). Подтверждения именно для книги XlsxWriter в проекте нет: книги, которую Excel сохранил бы поверх книги XlsxWriter, на диске нет (аудит 1). Если Excel пометку сохраняет, каждая книга инженера из `gpn-solver template` останется помеченной — и все её формулы получат отказ, вопреки решению 5. Проверка — шаг 3, часть Б (книга генератора, сохранённая Excel); не подтвердилось — стоп, решение пользователя.
10. **Свой модуль подтверждён** (2026-10-17): `gpn_multiphase_solver/io/xlsx_reader.py`. `radial_blackoil.xlsxio` не меняется; пример 18 (`examples/18_prototype_input/prototype_input.py`) читает книгу через него по-прежнему (FEAT-035, решение 7).

12. **Признак даты** (умолчание плана): встроенные форматы 14–22, 45–47 и восточноазиатские 27–36, 50–58 — даты; код формата из `styles.xml` — дата, если в его первом разделе (до «;») после удаления текста в кавычках, символа после `\`, `_`, `*` и скобок `[…]` (кроме прошедшего времени `[h]`, `[mm]`, `[ss]`) осталась буква d, m, y, h или s в любом регистре. Код в книге важнее встроенного номера. Признак — только у чисел и у `t="d"`. Следствие: формат 164 книг IMEX `\y\y\y\y\-\m\m\m\-…` — не дата: все буквы экранированы, Excel выводит их как текст. Так же решают `openpyxl` и сам Excel; правило «любая буква, даже экранированная» дало бы ложные отказы на числах с подписью `0.0\ \m`.
13. **Отказы чтения** (умолчание плана): нет файла — `FileNotFoundError`, как у `open` (FEAT-036 ловит оба); составной файл OLE (`.xls` и книга с паролем на открытие начинаются одинаково) — одно сообщение про оба случая; не zip; zip без книги Excel (`.ods`, `.docx`); `.xlsb`; строгий формат Open XML (Strict) — отказ, а не поддержка: проверить его на настоящих книгах Excel нечем; повреждённый XML или архив — с именем части; испорченная ячейка — с листом и адресом; испорченный служебный атрибут (номер строки `r`, стиль `s`, `numFmtId`) — с частью или адресом (аудит 2). Каждое сообщение — с путём файла и подсказкой «Сохраните книгу в Excel как «Книга Excel (*.xlsx)»». `.xlsm` читается как `.xlsx` (та же разметка, макросы не исполняются).
   **Контракт исключений для вызывающих** (FEAT-035, FEAT-036, его решение 9 «ошибки книги — код возврата 2»): любой отказ из-за содержимого файла — только `WorkbookError` (подкласс `ValueError`); ошибки файловой системы — `OSError` как есть (`FileNotFoundError`, `PermissionError`). Иное исключение из `read_workbook` — ошибка кода разбора. Подкоманда `run` сейчас ловит только `CaseConfigError` и `CaseRunError`, прочее печатает с трассировкой как ошибку кода (`cli.py`, `main`) — голый `ValueError` из `int()` испорченной книги попал бы туда же.
14. **Стилизованная пустая ячейка не хранится** (умолчание плана): `<c r="A16" s="1"/>` равна отсутствующей; `Sheet.max_row` — по ячейкам со значением или формулой. В черновике руководителя таких 80 (THERMAL 7, SCHEDULE 16, COMMENTS 57).
15. **Строки — как в книге** (умолчание плана): пробелы не срезаются, «1,5» — строка (толкует FEAT-035); `_xHHHH_` раскодируется (ECMA-376: так записываются управляющие символы, `_x005F_` — сам «_»); фонетика `<rPh>` не читается.
16. **`<v></v>` без типа — значения нет** (умолчание плана): так XlsxWriter пишет формулу со значением `""`.
17. **Цель связи «xl/…» от корня архива** (умолчание плана) читается, если от каталога части такой части нет: так читает `xlsxio`.
18. **`tests/_xlsx.py` остаётся** (умолчание плана): он читает стили, защиту и проверки данных генератора FEAT-033 — этого разбор не делает. Значения книги генератора сверяются с ним тестом.
19. **Приёмка в Excel пользователем** (умолчание плана, шаг 3): книга-ловушка, сохранённая Excel с русскими настройками, — фикстура в git `numerical_solver/tests/data/feat034_excel/`. Без неё всё проверено только на книгах XlsxWriter и правках XML; главная ловушка («1.5» → 1 мая) — свойство самого Excel. Если пользователь откажется — шаг 3 пропускается, отметка в реестре.

## 2. Контекст

### 2.1. Почему не `radial_blackoil.xlsxio`

`numerical_solver/HydroSolverPrototype/Prototype_1.0.3/radial_blackoil/xlsxio.py`, `read_workbook_tables` (строки 15–55, только стандартная библиотека) возвращает листы как списки строк значений:

- ячейка без `t` с `<v>` → `float`; формат ячейки (`s`, `styles.xml`) не читается — **дата приходит числом** (Excel превращает «1.5» в 1 мая → 46143.0);
- `t="b"` → `float` 1.0 — **логическое значение неотличимо от числа**;
- `<f>` без `<v>` → `None` — **формула без сохранённого значения неотличима от пустой ячейки**;
- `t="e"` → строка `'#DIV/0!'` — различимо;
- адресов нет; строки без ячеек пропускаются (номера строк сдвигаются); стилизованные пустые — `None`.

Им пользуется `radial_blackoil/input_reader.py` (строка 27) и пример 18 (`examples/18_prototype_input/prototype_input.py`, `_read_book`, строки 73–76).

## 7. API (итог)

```python
# numerical_solver/gpn_multiphase_solver/io/xlsx_reader.py
NUMBER, STRING, BOOL, ERROR, EMPTY = "number", "string", "bool", "error", "empty"

class WorkbookError(ValueError): ...            # отказ чтения; сообщение — что не так и как пересохранить

@dataclass(frozen=True)
class Cell:
    sheet: str
    row: int                                     # с 1
    col: int                                     # с 1: A = 1
    kind: str = EMPTY
    value: float | str | bool | None = None      # float — все числа Excel
    is_date: bool = False
    formula: str | None = None                   # без «=»; "" — ячейка общей формулы
    address -> "C5";  ref -> "MODEL!C5";  formula_without_value -> bool

@dataclass(frozen=True)
class Sheet:
    name: str
    cells: dict                                  # (row, col) → Cell: только со значением или формулой
    cell(row, col) -> Cell                       # отсутствующая — Cell(kind=EMPTY)
    max_row -> int                               # 0 — лист пуст

@dataclass(frozen=True)
class Workbook:
    path: Path
    sheets: dict                                 # имя → Sheet, порядок книги
    recalc_on_open: bool                         # fullCalcOnLoad (решение 9)

def read_workbook(path) -> Workbook
def is_date_format(code: str) -> bool            # решение 12
def column_letters(col: int) -> str              # 1 → A, 16384 → XFD
```

Сообщения отказов (полный текст — в коде плана): «не книга .xlsx — это файл .xls или книга с паролем на открытие … Пароль на открытие не ставится.»; «не книга .xlsx — файл не zip-архив»; «в архиве нет книги Excel — возможно, это .ods, .docx или другой zip-архив»; «двоичная книга Excel (.xlsb) — разбор её не читает»; «книга сохранена в строгом формате Open XML (Strict) — разбор его не читает»; «книга повреждена — нет части …» / «— <часть>: <ошибка XML>» / «— <часть> не распаковывается»; «ячейка T!C21: значение 'abc' не число» (и: нет общей строки, логическое значение, неизвестный тип). Все — с путём файла и «Сохраните книгу в Excel как «Книга Excel (*.xlsx)»». Испорченный служебный атрибут — «книга повреждена — лист T: номер строки: 'x' не целое» / «ячейка T!C21: стиль: 'x' не целое» / «xl/styles.xml: numFmtId: None не целое».

**Исключения `read_workbook`** (контракт для FEAT-035 и FEAT-036, решение 13): `WorkbookError` — любой отказ из-за содержимого файла; `OSError` (`FileNotFoundError`, `PermissionError`) — файловая система, как у `open`. Иное — ошибка кода разбора.
