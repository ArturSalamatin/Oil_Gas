## Описание

Гидродинамика (прототип) считает пористость зависящей от давления, $\varphi(p) = \varphi_0\,e^{c_r(p - p_0)}$, а энергетический блок — постоянной, $\varphi_0$ = `rock.porosity`. При $c_r \ne 0$ два блока одного шага работают с разным поровым объёмом: баланс массы — с $\varphi(p)$, эффективная теплоёмкость, теплопроводность, адиабатический член и временная часть дегазации — с $\varphi_0$. Расхождение — множитель $e^{c_r(p - p_0)}$.

Вторая часть задачи — постановка. Непрерывное `eq:main_Qad_muJT` содержит член $c_r\,(p + (\rho c_p)_s T)$, которого нет ни в дискретном `eq:Qad_disc` (записано «при $c_r = 0$»), ни в коде. Часть этого члена с $T$, по всей видимости, артефакт вывода (разбор ниже) — её надо не реализовать, а убрать из постановки.

**Существующие проверки расхождения не видят:**
- невязка баланса энергии ([DEBT-043](https://github.com/ArturSalamatin/Oil_Gas/issues/70)) суммирует ровно те члены, что ставит решатель, — проверяет согласованность дискретизации с самой собой, а не с гидродинамикой;
- баланс массы ([DEBT-039](https://github.com/ArturSalamatin/Oil_Gas/issues/65)) считает прототип по $\varphi(p)$ — тоже согласован сам с собой;
- эталон сверки матрицы энергии повторяет $\varphi_0$.

**Физика члена $c_r(\rho c_p)_s T$** (разбор при открытии, проверить при планировании). Член рождается в `eq:rock_dt`: $\partial_t[(1-\varphi)(\rho c_p)_s T]$ при $(\rho c_p)_s = \mathrm{const}$ и неподвижном скелете. Он пропорционален абсолютной $T$. Если отсчитывать энергию скелета от $T_{ref}$, $u_s = c_s(T - T_{ref})$, член меняется на $\varphi\,c_r(\rho c_p)_s T_{ref}\,\partial_t p$ — решение зависит от выбора нуля энтальпии. Так бывает, только когда масса не сохраняется: уходящий из ячейки скелет уносит энергию $u_s$. При сохранении массы скелета, $\partial_t[(1-\varphi)\rho_s] + \mathrm{div}[(1-\varphi)\rho_s \mathbf v_s] = 0$, вклад сокращается до $(1-\varphi)\rho_s c_s\,D_s T/Dt$. Вывод: член с $T$ не реализовывать, `eq:main_Qad_muJT` и `eq:rock_dt` исправить. Оценка реестра «0.20 против 0.36» показывает только, что артефакт был бы велик.

Член $c_r\,p$ — работа против изменения порового объёма — от отсчёта не зависит. На примере 18: $c_r p \approx 4.5\cdot10^{-10}\cdot2\cdot10^{7} = 0.009$ против $1 + S_o\rho_o c_{p,o}\mu_{JT,o} \approx 0.3$, то есть ≈3 % $Q_{ad}$. Работа деформации скелета не учтена ни в постановке, ни в коде; без неё учёт $c_r p$ тоже спорен.

**Критерий закрытия в реестре не работает.** Запись предлагает закрыть, «если эффект ниже допусков сверки VAL-005». Но `TOL_PROTOTYPE` (`tests/test_examples.py:3037-3053`) — допуски по $p$, $S_g$, $R_s$, $q$; внешнего эталона по $T$ у примера 18 нет (README 18, строки 21–22). Критерий для $T$ выбрать при планировании — например, сравнить $\Delta T(r_w, t)$ с погрешностью шага 3600 с на том же примере или с амплитудой $T(r_w) - T_0$ из таблицы README 18.

## Целевое состояние

- Энергия и гидродинамика одного шага используют один поровый объём — либо принято и записано решение оставить $\varphi_0$ с количественной оценкой ошибки по $T$.
- Постановка согласована с кодом: член с $T$ из `eq:main_Qad_muJT` и `eq:rock_dt` убран с обоснованием; `eq:Qad_disc`, `eq:mdot_disc`, `eq:main_rhocpeff` записаны для $\varphi(p)$ — либо явно для $c_r = 0$ с оговоркой, что пример 18 выходит за допущение.
- Эталон сверки матрицы энергии берёт ту же $\varphi$, что и решатель.
- Конфиги с $c_r = 0$ (21 пример) — истории побитово.

## Анализ вариантов решения

**Вариант 0 — замер и документ, код не меняется.**
- Суть: проба на примере 18 с подменой $\varphi_0 \to \varphi(p^{n+1})$ в трёх местах; записать $\max|\Delta T(r_w, t)|$ и по полю, закрыть с оценкой. Постановку исправить (член с $T$ — артефакт; оговорка про пример 18).
- Плюсы: истории всех примеров побитово, работа малая.
- Минусы: расхождение остаётся; на будущих конфигах с бо́льшим $c_r\Delta p$ оно не контролируется ничем.

**Вариант 1 — $\varphi(p)$ в энергии.**
- Суть: энергия получает закон $\varphi(p) = \varphi_0\,e^{c_r(p - p_0)}$ с $p_0$ — начальным давлением, как в фабрике, и считает $\varphi^{n+1}$ в трёх местах; эталон теста — так же.
- Изменения: `tridiag.py` (3 места), `factory.py:70` (передать $p_0$ или функцию $\varphi$), функция $\varphi(p)$ в пакете (например, рядом с `RockConfig`), `test_energy_matrix_examples.py` (3 места); постановка.
- Плюсы: блоки согласованы. При $c_r = 0$ множитель $e^0 = 1.0$ — умножение точное, 21 пример побитово.
- Минусы: формула $\varphi(p)$ в двух пакетах — нужен тест совпадения с `CompressibleRock.porosity`. История 18 меняется — перемер README 18 и тестов 18. Решить, на каком слое $\varphi$ в ёмкости: неконсервативная форма $(\rho c_p)_{eff}\,\partial_t T$ требует $\varphi^{n+1}$; консервативная $\partial_t[(\rho c_p)_{eff} T]$ вернула бы член $(\varphi^{n+1} - \varphi^n)$ — тот самый артефакт.

**Вариант 2 — вариант 1 + член $\varphi\,c_r\,p\,\partial_t p$ в $Q_{ad}$** (член с $T$ не добавляется).
- Плюсы: код соответствует исправленной `eq:main_Qad_muJT`.
- Минусы: без работы деформации скелета физичность спорна; вклад ~3 % $Q_{ad}$ на примере 18; новая статья баланса энергии.

**Вариант 3 — предупреждение фабрики при $c_r \ne 0$** («энергия считает с постоянной пористостью»).
- Плюсы: дёшево, пользователь знает об ограничении.
- Минусы: проблема не решается; пример 18 выдаёт предупреждение на каждом запуске.

**Рекомендация:** вариант 0 как первый шаг (замер), по его итогу — вариант 1 (если $\Delta T$ сравнима с погрешностью шага) или 0 + 3. Исправление постановки по члену с $T$ — в любом случае. Член $c_r p$ (вариант 2) — решение пользователя после замера.

## План решения

1. **Подготовка.** Базовый замер: число тестов, отпечаток истории 18, $T(r_w, t)$ примера 18. Проба с подменой $\varphi$ (отдельно — с членом $c_r p$): $\max|\Delta T(r_w, t)|$, $\max|\Delta T|$ по полю, невязка баланса энергии; сравнение с погрешностью шага 3600 с. Проверка разбора члена с $T$: вывод с сохранением массы скелета, сверка с литературой из `Refs/` (как записана энергия породы при $c_r \ne 0$).
2. **Решение пользователя:** вариант и критерий для $T$.
3. **Реализация (инкрементально):** постановка (`eq:rock_dt`, `eq:main_Qad_muJT`, допущения, `eq:Qad_disc`, `eq:mdot_disc`) → код энергии и фабрики → эталон теста → тесты: при $c_r = 0$ — побитово; при $c_r \ne 0$ — $\varphi$ энергии равна $\varphi$ прототипа в ячейках; временная часть $\dot m$ согласована с изменением растворённого газа в запасах гидродинамики.
4. **Верификация:** быстрый уровень после каждого шага, полный в конце; отпечатки 21 примера с $c_r = 0$ — без изменений; пример 18 — перемер README и тестов; невязка баланса энергии ≤ $10^{-12}$ (порог DEBT-043); сверка VAL-005 по гидродинамике — без изменений (энергия на гидродинамику не влияет).
