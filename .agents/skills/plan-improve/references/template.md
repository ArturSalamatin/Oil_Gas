# Содержание плана DEBT

Frontmatter должен позволять следующим этапам определить ID, номер issue при наличии, `branch`, `base`, `worktree`, статус и дату. Не требуй нового поля от исторического плана без определения его значения. План содержит исходную задачу и её источники, проверенное текущее состояние, целевое поведение, границы, решения и открытые вопросы, зависимости, последовательность шагов и критерии завершения.

Для каждого шага запиши цель, пути от корня, проверяемый контекст, действия и зависимости. Добавь команду и каталог запуска, исходные данные, ожидаемый результат и профиль регрессии. Если правка неоднозначна, приведи актуальные фрагменты «было» и «стало». Для чисел укажи источник или команду. Сохрани отдельно прогнозируемые результаты и подтверждённые измерения. Заверши план инструкцией передачи работы в `audit-plan`. Ветку создаёт `implement`.
