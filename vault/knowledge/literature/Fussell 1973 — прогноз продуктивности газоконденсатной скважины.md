# Fussell 1973 — прогноз продуктивности газоконденсатной скважины

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Fussell D.D. Single-Well Performance Predictions For Gas Condensate Reservoir. *Journal of Petroleum Technology*, 1973, 25(7), 860–870.

## Аннотация
Развитие двухзонной модели O'Dell–Miller (1966) для прогноза продуктивности газоконденсатных скважин. Описание профиля насыщенности жидкости внутри пласта как двух зон: однофазная ($p > p_{dew}$) и двухфазная (конденсат + газ). Используется для построения pseudopressure-функции.

## Потенциал для проекта
Двухзонная модель Fussell — прямой предшественник трёхзонной модели [[Fevang Whitson 1996 — газоконденсат трёхзонная модель|Fevang–Whitson 1996]]. Концепция «двух зон» (с/без фазового перехода) — базовая для всех приближённых моделей ПЗП с разгазированием.
