# Mitchell Myers 2010 — HBIM и RIM для задач Стефана

**Полная ссылка.** Mitchell S.L., Myers T.G. Application of Standard and Refined Heat Balance Integral Methods to One-Dimensional Stefan Problems. *SIAM Review*, 2010, Vol. 52, No. 1, pp. 57–86.

## Задача

Одномерные задачи Стефана (плавление/затвердевание с подвижной границей фазового перехода). Уравнение теплопроводности в двух фазах (жидкость и твёрдое тело) с условием Стефана на межфазной границе $x = s(t)$:

$$\beta \frac{\mathrm{d}s}{\mathrm{d}t} = k\frac{\partial v}{\partial x} - \frac{\partial u}{\partial x}, \quad u = v = 0 \text{ при } x = s,$$

где $\beta = \rho L_m \kappa_l / (k_l \Delta u) = 1/\text{St}$ — обратное число Стефана (ур. 2.12). Рассматриваются граничные условия: (i) постоянная температура $u(0,t) = 1$; (ii) условие Робина $\partial u / \partial x = -\gamma_1 + \gamma_2(u-1)$ при $x = 0$.

## Метод

Систематическое сравнение трёх вариантов интегрального метода:

**1. HBIM (Heat Balance Integral Method, Goodman 1958 [13]).**
Однократное интегрирование PDE по $x$ от 0 до $s(t)$ даёт (ур. 3.5):
$$\left.\frac{\partial u}{\partial x}\right|_{x=s} - \left.\frac{\partial u}{\partial x}\right|_{x=0} = \frac{\mathrm{d}}{\mathrm{d}t}\int_0^s u\,\mathrm{d}x.$$

**2. RIM (Refined Integral Method, Sadoun 2006 [38]).**
Двукратное интегрирование PDE по $x$ даёт первый момент (ур. 4.3):
$$\frac{\mathrm{d}}{\mathrm{d}t}\int_0^s xu\,\mathrm{d}x = u|_{x=0} - \beta s\frac{\mathrm{d}s}{\mathrm{d}t}.$$

**3. ARIM (Alternative RIM, предложен авторами).**
Используется непосредственно ур. (4.2) вместо комбинации с условием Стефана. Удобнее при условии Робина, когда $\partial u / \partial x$ задан на границе.

Для каждого метода исследуются три типа аппроксимирующей функции:
- **Квадратичная** (Goodman): $u = a(1 - x/s) + (1-a)(1 - x/s)^2$ (ур. 3.10)
- **Кубическая** (Myers et al. [35]): $u = a(1 - x/s) + b(1 - x/s)^2 + c(1 - x/s)^3$ (ур. 3.18–3.19)
- **Экспоненциальная** (Mosally et al. [27]): $u = 1 - (x/s)e^{c(1-x^2/s^2)}$ (ур. 3.23)

Для квадратичной аппроксимации авторы показывают, что существует 6 различных формулировок (Wood [43]), дающих 4 различных значения коэффициента $a$ (и, соответственно, $\alpha$ в $s(t) = 2\alpha\sqrt{t}$). Точность зависит от $\beta$.

## Результаты

### Однофазное плавление (§3, §5)

**Постоянная температура (Table 5.1):**
- Квадратичная HBIM: ошибка $\|s\|_\infty \sim 10^{-2}$ — худший результат.
- Кубическая HBIM: на порядок лучше ($\sim 10^{-3}$).
- Экспоненциальная HBIM: ещё немного лучше кубической.
- RIM улучшает все профили на порядок по сравнению с HBIM (Table 5.1).
- При $\beta \geq 1$ (реалистичные значения для воды/льда) кубическая и экспоненциальная аппроксимации на порядок точнее квадратичной.

**Условие Робина (Table 5.2):**
- Кубическая HBIM — наиболее точная для $\beta < 5$.
- RIM не даёт улучшения для квадратичного профиля при условии Робина.
- ARIM — наиболее точная при задании потока ($\partial u / \partial x$) на границе.

### Двухфазное плавление (§6)

Подкладка ниже температуры плавления. Две подвижные границы: фронт плавления $s(t)$ и глубина теплового проникновения $\delta(t)$.
- Для $\beta < 2$: кубическая HBIM наиболее точна (Table 6.1).
- Для $\beta > 2$: квадратичная RIM наиболее точна.
- При условии Робина: стадия предплавления (premelting) — кубическая ARIM лучше всех (Table 6.4, ошибка 0.51–3.8%).
- Ошибки в положении фронта $s(t)$: 2–5% для лучших формулировок (Fig. 6.1).

### Абляция (§7)

Три стадии: нагрев → абляция → полное разрушение. Для Stage 1 (нагрев):
- Кубическая аппроксимация: ошибка в $t_1$ = 0.27% (против 15.1% для квадратичной HBIM).
- Оптимальный показатель формы $n$: для HBIM $n = \pi/(4-\pi) \approx 3.66$, для RIM $n \approx 3.87$ (нецелые!).
- Braga & Mantelli [4,5] подбирают $n$ из точного решения — но это работает только при известном решении.
- Mitchell & Myers [24] показали ограничение: при переключении показателя с $n$ на $m > n$ во время абляции нарушается баланс массы.

## Замечания

1. **Зависимость оптимальной формулировки от ГУ.** Нет универсально лучшего метода: при $u|_{x=0}$ задан — лучше кубическая RIM; при $\partial u / \partial x|_{x=0}$ задан — лучше кубическая HBIM или ARIM. Это принципиально: в задаче фильтрации граничное условие тоже меняет оптимальный выбор.

2. **RIM = первый момент уравнения.** Формально RIM — это использование первого момента $\int xu\,\mathrm{d}x$ вместо нулевого $\int u\,\mathrm{d}x$. Прямая аналогия с методом моментов Баренблатта: нулевой момент → масса/энергия в зоне, первый момент → «центр масс» распределения.

3. **Нецелые оптимальные показатели.** Для абляции $n_{\mathrm{opt}} \approx 3.66$ (HBIM), $3.87$ (RIM). Это означает, что фиксация целого показателя $\beta$ в проекте (как в $S_g \sim (1-\eta)^\beta$) — компромисс, и чувствительность к $\beta$ подлежит исследованию.

4. **Ограничение при переключении показателя.** Если показатель формы меняется во времени (разные стадии задачи), возможно нарушение баланса массы (Mitchell & Myers [24]). Это предупреждение для FEAT-010 ($\beta(t)$ как переменный показатель).

5. **Проблема time-dependent ГУ.** Если граничная температура стремится к дальнему полю ($u(0,t) \to 0$), HBIM/RIM предсказывают $u \equiv 0$ всюду — полная потеря решения (§7.5). В задаче ПЗП аналог: если $\Delta p_w \to 0$ (скважина останавливается), параметризация $\Phi(\eta)$ вырождается.

6. **Все задачи — линейные.** PDE $u_t = u_{xx}$ с постоянными коэффициентами. Нелинейность возникает только через подвижную границу (условие Стефана). В задаче ПЗП коэффициенты сами зависят от решения — существенно более сложная ситуация.

## Значение для проекта

**Прямая аналогия:** фронт разгазирования $r_b(t)$ ↔ фронт плавления $s(t)$; профиль $S_g(r) = S_{g,w}(1-\eta)^\beta$ ↔ профиль $u = a(1-x/s)^n$; теплота дегазации $L$ ↔ скрытая теплота $L_m$; условие Стефана $\rho L_m \dot{s} = [k \partial T / \partial x]$ ↔ баланс потоков на $r_b$.

**Что взять:**
1. Кубическая аппроксимация почти всегда точнее квадратичной (на порядок). В проекте профиль давления $\Phi(\eta) = 1 - (1 - \eta)^{n_\Phi}$ фиксирует $n_\Phi$ из условия на $r_b$. Стоит проверить: достаточно ли линейного + квадратичного члена, или нужен кубический.
2. RIM (первый момент) даёт дополнительное уравнение для показателя формы. В проекте это реализовано: §5 moments_method.tex использует первые моменты для определения $\beta$. Mitchell & Myers подтверждают, что это существенно повышает точность.
3. Оптимальный показатель — нецелый и зависит от $\beta$ (числа Стефана). Чувствительность решения ODE к значению $\beta$ — открытый вопрос проекта (§8.3 moments_method.tex).
4. Предупреждение об ошибке при переменном показателе (FEAT-010).

**Что неприменимо:**
- Все результаты — для линейного PDE с постоянными коэффициентами. В задаче ПЗП коэффициенты (ОФП, PVT) нелинейны → нет аналитических точных решений для сравнения.
- Экспоненциальная аппроксимация (Mosally) вряд ли полезна: физический профиль $S_g(r)$ монотонно убывает со степенным поведением у фронта, не экспоненциальным.
