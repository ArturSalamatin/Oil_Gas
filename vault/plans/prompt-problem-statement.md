# Промпт для генерации problem_statement.tex

Промпт предназначен для генерации файла `numerical_solver/doc/problem_statement.tex` — самодостаточного документа с постановкой задачи и описанием численной схемы. Документ ляжет в основу программной реализации алгоритма решения системы дифференциальных уравнений в частных производных.

## Контекст

Проект: математическая модель призабойной зоны пласта (ПЗП) в окрестности нефтедобывающей скважины. Двухфазная фильтрация (нефть с растворённым газом + свободный газ) в рамках подхода Black Oil с уравнением энергии. Водная фаза отсутствует.

Исходный документ с выводами уравнений: `method_of_moments/two_phase_energy.tex`. Из него нужно взять уравнения, обозначения и промежуточные выводы. **Не ссылаться** на этот файл — копировать нужный материал. Новый документ должен быть полностью самодостаточным: читатель не должен обращаться к другим файлам проекта.

## Общие требования

- Язык: русский.
- Формат: LaTeX, UTF-8, пакеты inputenc, fontenc (T2A), babel (russian), amsmath, amssymb.
- Документ должен быть подробным — компактность не требуется.
- Ключевые итоговые формулы — в `\boxed{}`.
- Нумерация **всех** уравнений, перекрёстные ссылки через `\eqref{}`.
- Каждый раздел самодостаточен: обозначения вводятся там, где впервые используются.
- Единицы измерения: СИ. Указывать размерность при введении каждой величины.
- Документ должен содержать **сводную таблицу обозначений** в начале (после введения, перед §1), аналогичную §2 (Обозначения) из `two_phase_energy.tex`. Таблица группирует символы по категориям: координаты, давление/температура, насыщенности, PVT-свойства, сжимаемости, пористая среда, термодинамика.
- Документ должен начинаться с **краткого введения** (0.5–1 страница): что моделируется, зачем, какова структура документа. Введение — не раздел с номером, а ненумерованный текст перед §1.
- Нотационная согласованность: один и тот же символ не может обозначать разные величины в разных разделах. Индекс α ∈ {o, g} — всегда фаза. Индекс i — всегда номер ячейки сетки. Верхний индекс n — всегда номер временного шага. Нижний индекс ст — всегда стандартные условия.

## Структура и содержание по разделам

### §1 Физическая постановка

**§1.1 Область и допущения.**
- Горизонтальный пласт постоянной мощности h, вскрытый вертикальной скважиной радиуса r_w. Контур питания R_ext. Привести схему расчётной области (словесное описание для LaTeX: осевое сечение пласта, скважина слева, контур питания справа, координата r).
- Область: r ∈ [r_w, R_ext], t ≥ 0.
- Задача одномерная: все величины зависят от r и t. Оператор дивергенции в цилиндрических координатах при осевой симметрии: (1/r)·∂(r·(...)) /∂r.
- Модель Black Oil: нефтяная фаза (тяжёлый нефтяной + растворённый газовый компонент) и газовая фаза (свободный газ). Пояснить: в модели Black Oil различают **компоненты** (нефтяной, газовый — химические вещества) и **фазы** (нефтяная, газовая — агрегатные состояния). Компонент может присутствовать в разных фазах.
- Водной фазы нет. Испарения нефтяного компонента в газовую фазу нет (газовая фаза содержит только газовый компонент).
- Полный список допущений:
  1. **Мгновенное локальное фазовое равновесие.** При p < p_b(T) газ выделяется из нефти мгновенно; газосодержание R_s(p,T) определяется текущими p и T. Нет кинетики фазового перехода.
  2. **Единое давление фаз.** Капиллярное давление не учитывается: p_o = p_g ≡ p. Пояснить: допустимо при высокой проницаемости и умеренных насыщенностях.
  3. **Температурная зависимость PVT-свойств.** Все свойства фаз (R_s, B_o, B_g, ρ, μ, c_p, α) зависят как от давления, так и от температуры. Указать: в гидродинамической подзадаче эта зависимость упрощается (см. §2).
  4. **Локальное термодинамическое равновесие порода–флюид.** T_s = T_f = T. Пояснить: справедливо при малых скоростях фильтрации (числа Пекле ≪ 1 на масштабе зёрен).
  5. **Постоянная пористость:** φ = const (сжимаемость породы c_r = 0). В §1.2 формулы записываются в общем виде с c_r для полноты; при реализации (§2) c_r = 0.
  6. **Отсутствие гравитации.** Пласт горизонтальный, одномерная задача по r.
  7. **Отсутствие теплообмена с кровлей и подошвой.** Адиабатные границы по вертикали. Пояснить: допустимо на ранних стадиях (пока тепловой фронт не дошёл до кровли/подошвы).
  8. **Пренебрежение вязкой диссипацией и кинетической энергией.** Числа Рейнольдса ≪ 1 при фильтрации, скорости малы.
- Неизвестные: p(r,t), T(r,t), S_g(r,t).

**§1.2 Система уравнений.**

Указание: этот подраздел — самый объёмный в документе. Каждое уравнение записать в развёрнутой форме. После каждой формулы — абзац с пояснением физического смысла **каждого** слагаемого. Промежуточные выводы приводить полностью (не «после подстановки получаем», а показать подстановку).

**Важно:** формулы в §1.2 записываются в **общем виде** — с c_r, β_o, β_g, C_T и т.д. Это полная физическая постановка. Упрощения (c_r = 0, C_T = 0, T = const в гидродинамике) применяются **только в §2** при подготовке к дискретизации. Такая структура позволяет читателю увидеть полную модель и понять, что именно отбрасывается.

**Закон Дарси** (записать первым, так как скорости входят во все последующие уравнения):
- u_α = −(k·k_{rα}/μ_α)·∂p/∂r, α ∈ {o, g}.
- Пояснить знак: давление убывает к скважине (∂p/∂r > 0), поэтому u_α < 0 (поток к скважине).
- Определить подвижность фазы: λ_α = k·k_{rα}/μ_α.

**Сжимаемость породы:**
- Определение c_r = (1/φ)·dφ/dp.
- Следствие: ∂φ/∂t = φ·c_r·∂p/∂t и ∂φ/∂r = φ·c_r·∂p/∂r.
- Пояснить: эти формулы используются при раскрытии производных от произведений, содержащих φ.

**Баланс массы нефтяного компонента:**
- Нефтяной компонент присутствует **только** в нефтяной фазе.
- Масса нефтяного компонента в единице объёма пористой среды: φ·(S_o/B_o)·ρ_o^ст. Множитель ρ_o^ст постоянен и сокращается. Ввести ξ_o = S_o/B_o — объём нефтяного компонента (при ст. условиях) на единицу порового объёма.
- Записать закон сохранения в объёмных единицах ст. условий: уравнение (eq:mass_oil).
- Пояснить каждое слагаемое: накопление vs дивергенция потока. Пояснить форму оператора дивергенции (1/r)·∂(r·(...))/∂r в цилиндрических координатах.

**Баланс массы газового компонента:**
- Газовый компонент в **двух** фазах: растворённый в нефти (объём при ст. условиях: R_s·ξ_o) и свободный (объём при ст. условиях: S_g/B_g).
- Записать закон сохранения: уравнение (eq:mass_gas).
- Пояснить: конвективный поток состоит из двух частей — растворённый газ переносится нефтяной фазой (R_s·u_o/B_o), свободный газ — газовой фазой (u_g/B_g).

**Раскрытие баланса нефтяного компонента:**
- Раскрыть ∂(φ·ξ_o)/∂t по правилу произведения.
- Вычислить ∂ξ_o/∂t через ∂S_g/∂t и ∂B_o/∂t.
- Раскрыть (1/B_o)·∂B_o/∂t через c_o, β_o, ∂B_o/∂R_s.
- **Ключевой момент:** ввести «полные» коэффициенты вдоль кривой насыщения:
  - c_o^sat = c_o − (1/B_o)·(∂B_o/∂R_s)|_{p,T} · (∂R_s/∂p)|_T
  - β_o^sat = β_o + (1/B_o)·(∂B_o/∂R_s)|_{p,T} · (∂R_s/∂T)|_p
- Пояснить знак c_o^sat: при увеличении p нефть поглощает газ и набухает, поэтому c_o^sat < c_o.
- Пояснить различие: c_o, β_o — при **фиксированном** составе (используются в ур-и энергии); c_o^sat, β_o^sat — вдоль **кривой насыщения** (используются в балансах масс). Это различие критически важно для корректности.
- Записать раскрытую форму баланса нефтяного компонента: уравнение (eq:mass_oil_expanded).
- Пояснить каждое из четырёх слагаемых.

**Раскрытие баланса газового компонента:**
- Ввести ξ_g = R_s·ξ_o + S_g/B_g — полный запас газового компонента.
- Раскрыть ∂ξ_g/∂t, используя ∂R_s/∂t и ∂B_g/∂t.
- Записать раскрытую форму: уравнение (eq:mass_gas_expanded).
- Привести **подробный** вывод коэффициента при ∂p/∂t (четыре вклада, как в two_phase_energy.tex, §5.2).

**Уравнение давления:**
- Получается исключением ∂S_g/∂t: выразить ∂S_g/∂t из раскрытого баланса нефтяного компонента (eq:dSg_dt) и подставить в раскрытый баланс газового компонента.
- Привести подробности подстановки: какой член с ∂S_g/∂t в газовом балансе, что даёт пространственный вклад, как сокращаются члены с R_s.
- Записать итоговое уравнение давления: C_p·∂p/∂t + C_T·∂T/∂t + D = 0.
- Определить каждый коэффициент отдельным уравнением с номером:
  - C_p — формула с пояснением каждого слагаемого (вклад нефтяной фазы через 1/B_g − R_s/B_o, вклад газосодержания, вклад свободного газа).
  - C_T — аналогично.
  - D — пространственный оператор. Раскрыть: D = (B_o/B_g)·div(u_o/B_o) + (u_o/B_o)·∂R_s/∂r + div(u_g/B_g), где div означает (1/r)·∂(r·(...))/∂r.

**Эволюция газонасыщенности:**
- Записать ∂S_g/∂t = S_o·(c_r + c_o^sat)·∂p/∂t − S_o·β_o^sat·∂T/∂t + (B_o/φ)·div(u_o/B_o).
- Пояснить: это не независимое уравнение, а следствие баланса нефтяного компонента. В §1 оно записывается в общем виде; при дискретизации (§3) оно входит в **совместную систему** с уравнением давления и решается методом Ньютона.
- Указать: в однофазной зоне (p > p_b(T)) газонасыщенность S_g = 0 тождественно, состав фиксирован (R_s = R_s^0 = const), и c_o^sat = c_o, β_o^sat = β_o.

**Темп выделения свободного газа:**
- Вывести явно: вычесть из баланса газового компонента произведение R_s на баланс нефтяного компонента.
- Показать, что временная часть даёт φ·ξ_o·∂R_s/∂t, конвективная — (u_o/B_o)·∂R_s/∂r.
- Записать массовый темп ṁ: формула (eq:mdot).
- Пояснить знак: при ṁ > 0 газ выделяется, при ṁ < 0 — растворяется.

**Уравнение энергии — полный вывод:**

Вывод включить целиком, разбив на подразделы:

(a) *Первое начало для открытой системы.* Записать уравнение (eq:first_law_open). Пояснить: почему e (внутренняя энергия) в члене накопления и h (энтальпия) в конвективном потоке. Показать механизм: работа проталкивания (flow work) pv превращает e + pv = h. Без этого объяснения структура уравнения выглядит произвольной.

(b) *Формализация для одной фазы в пористой среде.* Конвективный перенос энергии фазой α: ρ_α·h_α·u_α. Других форм работы нет (вязкая диссипация и кинетическая энергия пренебрежимо малы).

(c) *Консервативная форма для многофазной системы.* Записать уравнение в виде ∂E/∂t + div(F) = div(λ_eff·∂T/∂r), определив E (полная внутренняя энергия: порода + флюиды − φp) и F (поток энтальпии). Пояснить, откуда берётся член −φp в E.

(d) *Энтальпия многокомпонентной нефтяной фазы.* Разложить через парциальные энтальпии: h_{oo} (нефтяной компонент в нефти) и h_{go} (газовый компонент в нефти). Привести формулу плотности нефти: ρ_o = (ρ_o^ст + R_s·ρ_g^ст)/B_o.

(e) *Перегруппировка по компонентам.* Перегруппировать энтальпию флюидов из «по фазам» в «по компонентам» — это позволяет выделить член фазового перехода. Записать E и F в компонентной форме.

(f) *Выделение теплоты дегазации.* Собрать члены с h_{go} как множителем → по определению темпа дегазации выражение в скобках = −ṁ. Аналогично для h_g → выражение = +ṁ. Сумма: (h_g − h_{go})·ṁ = L·ṁ, где L(p,T) = h_g − h_{go} — удельная теплота дегазации. Пояснить: L > 0 (свободный газ имеет большую энтальпию, чем растворённый); при ṁ > 0 система охлаждается. Указать: L — это **не** теплота фазового перехода по Клапейрону–Клаузиусу (та — для однокомпонентной системы); здесь — разность парциальных энтальпий компонента в разных фазах.

(g) *Гладкие члены.* После выделения члена дегазации остаются производные энтальпий при фиксированном составе. Записать термодинамические тождества: dh_o|_{R_s} = c_{p,o}·dT + v_o·(1−α_o·T)·dp и dh_g = c_{p,g}·dT + v_g·(1−α_g·T)·dp. Пояснить: первый член — изобарный нагрев, второй — изотермическое сжатие. Показать, что ρ_α·v_α = 1, и давленческие члены упрощаются.

(h) *Вклад породы.* Раскрыть ∂[(1−φ)·(ρc_p)_s·T]/∂t. Показать появление членов с ∂T/∂t и ∂p/∂t (через ∂φ/∂t).

(i) *Член −φp.* Раскрыть −∂(φp)/∂t = −φ·(1+p·c_r)·∂p/∂t.

(j) *Сборка.* Собрать все вклады. Сгруппировать:
  - Члены с ∂T/∂t → определить (ρc_p)_eff.
  - Члены с ∂T/∂r → определить (ρc_p·u)_conv.
  - Члены с ∂p/∂t → перенести в правую часть → Q_ad.
  - Члены с ∂p/∂r → перенести в правую часть → Q_JT.
  - Член дегазации → Q_deg.

(k) *Итоговое уравнение энергии:*
  - (ρc_p)_eff·∂T/∂t + (ρc_p·u)_conv·∂T/∂r = div(λ_eff·∂T/∂r) + Q_JT + Q_ad + Q_deg.
  - Определить каждый коэффициент и источник отдельным пронумерованным уравнением:
    - (ρc_p)_eff = (1−φ)·(ρc_p)_s + φ·(S_o·ρ_o·c_{p,o} + S_g·ρ_g·c_{p,g}).
    - (ρc_p·u)_conv = ρ_o·c_{p,o}·u_o + ρ_g·c_{p,g}·u_g.
    - Q_JT = −Σ_α u_α·(1−α_α·T)·∂p/∂r. Проверка знака: для нефти (α_o·T < 1 при типичных условиях) → Q_JT > 0, нагрев при дросселировании. Для газа (идеальный газ: α_g·T = 1) → вклад = 0. Пояснить: наблюдаемое **охлаждение** при добыче обусловлено дегазацией (Q_deg < 0), а не JT-эффектом жидкости.
    - Q_ad = φ·[T·Σ_α S_α·α_α + c_r·(p + (ρc_p)_s·T)]·∂p/∂t. Пояснить каждое слагаемое: вклад теплового расширения флюидов и вклад сжимаемости породы (два подвклада: p·c_r — работа деформации; (ρc_p)_s·T·c_r — изменение эффективной теплоёмкости).
    - Q_deg = −L(p,T)·ṁ. Указать: через ṁ содержит ∂T/∂t и ∂T/∂r, что при подстановке модифицирует (ρc_p)_eff и (ρc_p·u)_conv. **Обработка при дискретизации:** Q_deg < 0 (охлаждение при дегазации, ṁ > 0) → вычисляется **неявно** (на уровне T^{n+1}), вклад добавляется в диагональ матрицы → **усиливает** диагональное преобладание; Q_deg > 0 (нагрев при растворении газа, ṁ < 0) → вычисляется **явно** (на уровне T^n), вклад — в правую часть → не ослабляет диагональное преобладание. Критерий выбора: **диагональное преобладание** матрицы СЛАУ. Ориентир — однородные разностные схемы.

**§1.3 Замыкающие соотношения.**

Записать полный список замыкающих соотношений с определениями и размерностями.

*PVT-корреляции (функции p и T):*
- R_s(p,T) — газосодержание, м³ст/м³ст. Пояснить: объём растворённого газа при ст. условиях на единицу объёма нефтяного компонента при ст. условиях. При p ≥ p_b(T): R_s = R_s^0 = const.
- B_o(p,T) — объёмный коэффициент нефти, м³пл/м³ст. Пояснить: отношение объёма нефтяной фазы при пластовых условиях к объёму нефтяного компонента при стандартных.
- B_g(p,T) — объёмный коэффициент газа, м³пл/м³ст.
- ρ_o(p,T), ρ_g(p,T) — плотности фаз при пластовых условиях, кг/м³.
- ρ_o^ст, ρ_g^ст — плотности компонентов при стандартных условиях (постоянные), кг/м³.
- μ_o(p,T), μ_g(p,T) — динамические вязкости, Па·с.
- c_{p,o}(p,T), c_{p,g}(p,T) — удельные изобарные теплоёмкости, Дж/(кг·К).
- α_o(p,T), α_g(p,T) — коэффициенты объёмного теплового расширения **при фиксированном составе**: α_α = −(1/ρ_α)·∂ρ_α/∂T|_{p,R_s}. Подчеркнуть: для нефтяной фазы производная берётся при фиксированном R_s.
- L(p,T) — удельная теплота дегазации, Дж/кг газа.

*Сжимаемости и коэффициенты расширения объёмных факторов (при фиксированном составе):*
- c_o = −(1/B_o)·∂B_o/∂p|_{T,R_s}, c_g = −(1/B_g)·∂B_g/∂p|_T — сжимаемости, Па⁻¹.
- β_o = (1/B_o)·∂B_o/∂T|_{p,R_s}, β_g = (1/B_g)·∂B_g/∂T|_p — температурные коэффициенты, К⁻¹.
- Указать: условие R_s = const принципиально для нефтяной фазы. Полная производная по T при фиксированном p включает вклад изменения состава: ∂B_o/∂T|_p = ∂B_o/∂T|_{p,R_s} + (∂B_o/∂R_s)·(∂R_s/∂T). В уравнении энергии используется первое слагаемое; вклад состава учтён через Q_deg.

*Полные коэффициенты вдоль кривой насыщения (для балансов масс):*
- c_o^sat, β_o^sat — записать определения (повторить из §1.2 для полноты).

*Относительные фазовые проницаемости:*
- k_{ro}(S_o), k_{rg}(S_g). Модель Кори с параметрами: S_or, S_gc, n_o, n_g, k_{ro,max}, k_{rg,max}. Нормализованная насыщенность: S* = (S_g − S_gc)/(1 − S_or − S_gc). Формулы: k_{ro} = k_{ro,max}·(1−S*)^{n_o}, k_{rg} = k_{rg,max}·(S*)^{n_g}.

*Свойства породы:*
- φ — пористость, **постоянная** (не зависит от давления). Сжимаемость породы c_r = 0 в данной модели.
- k — абсолютная проницаемость (постоянная), м².
- c_r — сжимаемость порового пространства, Па⁻¹. В данной модели c_r = 0 (φ = const).
- (ρc_p)_s — объёмная теплоёмкость скелета породы, Дж/(м³·К).
- λ_eff — эффективная теплопроводность (порода + флюиды), Вт/(м·К). **Параллельная (объёмно-взвешенная) модель** (как в проекте Injector, `SomeCollector.hpp`): λ_eff = (1−φ)·λ_s + φ·(S_o·λ_o + S_g·λ_g). Пояснить: λ_eff изменяется по пласту вместе с S_g. Параметры λ_s, λ_o, λ_g — постоянные, задаются в конфиге.

*Вспомогательные:*
- ξ_o = S_o/B_o = (1 − S_g)/B_o.
- ρ_o = (ρ_o^ст + R_s·ρ_g^ст)/B_o.
- p_b(T) — давление насыщения, Па.

**§1.4 Граничные и начальные условия.**

*Начальные условия (t = 0):*
- p(r,0) = p_0 = const — однородное давление.
- T(r,0) = T_0 = const — однородная температура.
- S_g(r,0) = 0 — газ полностью растворён.
- Указать: p_0 > p_b(T_0) — начальное давление выше давления насыщения, свободная газовая фаза отсутствует.

*Граничные условия по давлению:*
- На забое (r = r_w): p(r_w, t) = p_wf(t) — условие Дирихле. Забойное давление задано как функция времени. Пояснить: p_wf < p_b при типичных условиях, поэтому вблизи скважины образуется двухфазная зона.
- На контуре питания (r = R_ext): p(R_ext, t) = p_0 = const — условие Дирихле. Пояснить: контур питания поддерживает постоянное давление; через него жидкость поступает в пласт.

*Граничные условия по температуре:*
- На контуре питания (r = R_ext): T(R_ext, t) = T_0 — условие Дирихле. Пояснить: приток с контура имеет пластовую температуру.
- На забое (r = r_w): ∂T/∂r|_{r=r_w} = 0 — условие Неймана (нулевой кондуктивный поток). Пояснить: это условие свободного выхода — температура у скважины определяется конвекцией, а не теплопроводностью. Кондуктивный поток в скважину отсутствует.

*Граничные условия по насыщенности:*
- Явных граничных условий для S_g не задаётся: S_g определяется из эволюционного уравнения (eq:Sg_ode). На границах значения потоков u_o/B_o определяются upstream-аппроксимацией по направлению фильтрации (к скважине).

### §2 Разделение задачи

**§2.1 Допущение независимости гидродинамики от температуры.**
- Формулировка: все PVT-свойства в уравнениях давления и насыщенности считаются зависящими **только от давления** при фиксированной температуре T = T_0 = const. Формально: R_s(p, T_0), B_o(p, T_0), B_g(p, T_0), μ_o(p, T_0), μ_g(p, T_0).
- Следствия:
  - ∂R_s/∂T = 0, ∂B_o/∂T = 0, ∂B_g/∂T = 0 в гидродинамических уравнениях.
  - β_o = 0, β_g = 0, β_o^sat = 0 в гидродинамических уравнениях.
  - Коэффициент C_T ≡ 0 в уравнении давления.
  - Уравнение давления содержит только ∂p/∂t и пространственные производные — **параболическое** по p.
  - Уравнение S_g: член с ∂T/∂t выпадает.
- Обоснование: слабая зависимость PVT от T по сравнению с зависимостью от p при типичных пластовых условиях (перепад давления ~5–10 МПа, перепад температуры ~1–5 К). Допущение стандартно в коммерческих симуляторах (изотермический режим гидродинамики).
- Указать: это допущение является решением, принятым с заказчиком.
- **Важно:** в уравнении энергии PVT-свойства сохраняют полную зависимость от p и T (c_{p,α}(p,T), α_α(p,T), L(p,T) и т.д.). Упрощение касается **только** гидродинамической подзадачи.

**§2.2 Упрощение коэффициентов.**

Записать упрощённые формулы в \boxed{} — **это те формулы, которые непосредственно реализуются в коде.**

Для каждого упрощения: (1) выписать исходную формулу из §1.2, (2) указать, какие члены обнуляются при T = const и почему, (3) записать упрощённый результат. Не просто «β_o^sat = 0, поэтому выпадает» — показать, какие именно слагаемые пропадают из формулы C_p.

*Уравнение давления при T = const:*
- C_p упрощается: при T = const имеем ∂R_s/∂T = 0, ∂B_o/∂R_s · ∂R_s/∂T = 0, поэтому β_o^sat = β_o + 0 = β_o; но β_o = (1/B_o)·∂B_o/∂T|_{p,R_s} тоже не вычисляется, поскольку T фиксирована. В C_p: члены, содержавшие β_o^sat, выпадают. Записать упрощённую формулу C_p. Указать, какие слагаемые остаются.
- C_T = 0 (выпадает полностью, так как ∂T/∂t = 0 в гидродинамике).

*Уравнение газонасыщенности при T = const:*
- ∂S_g/∂t = S_o·(c_r + c_o^sat)·∂p/∂t + (B_o/φ)·div(u_o/B_o). Член с ∂T/∂t выпадает. Записать в \boxed{}.
- Указать: c_o^sat при T = const отличается от c_o^sat при полной системе. При T = const: ∂R_s/∂T = 0, поэтому β_o^sat = β_o, и c_o^sat = c_o − (1/B_o)·(∂B_o/∂R_s)·(∂R_s/∂p). Формула c_o^sat **не упрощается** до c_o — вклад изменения состава через давление сохраняется.

*Уравнение энергии на известных полях:*
- В уравнении энергии p(r,t), u_o(r,t), u_g(r,t), S_g(r,t) — **известные** функции, вычисленные на предыдущем шаге.
- При фиксированных p, u, S_g уравнение энергии — **линейное** по T^{n+1}. Коэффициенты A(r), B(r), λ_eff(r), f(r) зависят от p^{n+1}, S_g^{n+1}, u^{n+1} (уже известны) и от T^n (замораживание). После дискретизации — **трёхдиагональная СЛАУ**, решаемая прогонкой без итераций. Записать структуру: A(r)·∂T/∂t + B(r)·∂T/∂r = div(λ·∂T/∂r) + f(r).
- **Важно**: Q_deg через ṁ содержит ∂T/∂t и ∂T/∂r. Обработка при дискретизации: Q_deg < 0 (охлаждение, дегазация) вычисляется **неявно** → добавляет вклад в коэффициенты A(r) и B(r); Q_deg > 0 (нагрев, растворение) вычисляется **явно** (при T^n) → переходит в f(r). Критерий разделения — сохранение диагонального преобладания матрицы (см. §1.2, пункт k, Q_deg).

**§2.3 Порядок решения.**

На каждом временном шаге t^n → t^{n+1}:

1. **Гидродинамика (изотермическая):**
   - Вычислить PVT-свойства при p^n и T = T_0.
   - Решить уравнение давления → p^{n+1}.
   - Вычислить скорости Дарси u_o^{n+1}, u_g^{n+1} из p^{n+1}.
   - Обновить S_g^{n+1}.

2. **Теплоперенос:**
   - Вычислить PVT-свойства для уравнения энергии при p^{n+1} и T^n.
   - Вычислить коэффициенты (ρc_p)_eff, (ρc_p·u)_conv, Q_JT, Q_ad, Q_deg, используя p^{n+1}, u^{n+1}, S_g^{n+1}.
   - Решить уравнение энергии → T^{n+1}.

Обратная связь T → гидродинамика **отсутствует**. Температура — пассивный скаляр, переносимый на известном поле скоростей. Нелинейность уравнения энергии проявляется только через зависимость коэффициентов от T (слабая), которая обрабатывается замораживанием на T^n.

**§3.1 Радиальная сетка.**

Сетка строится по тем же принципам, что и в проекте Injector (`d:\Lessons\Grants\2025\GPN\Injector\Injector\Grids\CoordinateTypes.h`, класс `R_CylCoord`; `d:\Lessons\Grants\2025\GPN\Injector\reports\gp_formulation.tex`, §4.1).

- Расстояние между центрами: Δr_{j+1/2} = r_{j+1} − r_j (для радиальной задачи используется не напрямую — см. потоки).

- Указать: параметры сетки (r_w, R_ext, N или шаги) задаются пользователем в конфигурационном файле.

**§3.2 Уравнение давления.**

Дискретизация оператора D. Интегрируем уравнение давления по объёму ячейки V_i.

Начать с записи интегральной формы: проинтегрировать C_p·∂p/∂t + D = 0 по объёму ячейки V_i и применить теорему Гаусса к дивергенциям.

Ввести понятие **трансмиссибильности** (transmissibility) на грани. В логарифмической радиальной сетке поток через грань имеет вид (аналогично `gp_formulation.tex`, формула (eq:flux_gp)):

G_{j+1/2} = (2π·h / ln(r_{j+1}/r_j)) · A_{j+1/2} · (p_{j+1} − p_j),

где делитель — **ln(r_{j+1}/r_j)**, а не Δr. Это следствие точного решения для радиального потока в кольцевом слое.

Трансмиссибильность грани: T_{j+1/2} = (2π·h / ln(r_{j+1}/r_j)) · A_{j+1/2}.

Интерполяция свойств A на грань — **гармоническое среднее с логарифмическими весами** (как в `R_CylCoord::face_interpolator`):
A_{j+1/2} = 1 / (ln(r_{j+1/2}/r_j)/A_j + ln(r_{j+1}/r_{j+1/2})/A_{j+1}).
Пояснить: логарифмические веса корректны для радиальной геометрии (аналогия с последовательными сопротивлениями в кольцевых слоях).

Для двухфазного случая: подвижность каждой фазы λ_α = k·k_{rα}/μ_α на грани — **upstream** по направлению потока фазы α (берётся из ячейки, откуда течёт фаза). Пояснить: upstream обеспечивает монотонность и подавляет осцилляции при двухфазном течении.

Раскрыть каждый из трёх членов D:
- div(u_o/B_o): поток через грани. На грани j+1/2 поток F_{o,j+1/2} = −T_{o,j+1/2} · (p_{j+1} − p_j), где T_{o,j+1/2} = (2π·h / ln(r_{j+1}/r_j)) · (λ_o/B_o)_{j+1/2}.
- Член (u_o/B_o)·∂R_s/∂r: при T = const имеем ∂R_s/∂r = (∂R_s/∂p)·∂p/∂r. Подставить: этот член **поглощается** в дивергенцию нефтяного потока через модификацию трансмиссибильности. Показать, как именно.
- div(u_g/B_g): аналогично первому члену с газовой подвижностью.

Полностью неявная схема: все PVT-коэффициенты и потоки вычисляются при p^{n+1}. Система **нелинейна** — решается **методом Ньютона** (как в `gp_formulation.tex`, §4.2).

**Совместная система для p и S_g.** Уравнения давления и насыщенности решаются **совместно** методом Ньютона. Вектор неизвестных в каждой ячейке — пара (p_j, S_{g,j}). Полный вектор неизвестных размера 2N:

U = (p_1, S_{g,1}, p_2, S_{g,2}, ..., p_N, S_{g,N})^T.

**Невязка.** Для ячейки j записать два уравнения невязки:
- F^p_j — невязка уравнения давления: V_j · C_{p,j} · (p_j^{n+1} − p_j^n)/Δt + D_j = 0.
- F^S_j — невязка уравнения насыщенности: S_{g,j}^{n+1} − S_{g,j}^n − Δt · RHS_j = 0, где RHS_j — дискретизованная правая часть (eq:Sg_ode).

Оба уравнения нелинейны: C_p, D, RHS зависят от p и S_g (через PVT и ОФП).

**Матрица Якоби.** Блочно-трёхдиагональная с блоками 2×2. Для ячейки j блок на диагонали:

J_{j,j} = | ∂F^p_j/∂p_j    ∂F^p_j/∂S_{g,j}  |
          | ∂F^S_j/∂p_j    ∂F^S_j/∂S_{g,j}  |

Внедиагональные блоки J_{j,j±1} — аналогично, производные по p_{j±1} и S_{g,j±1}.

Записать **явные** выражения для всех четырёх элементов диагонального блока. Указать, какие производные нужны:
- По p: ∂C_p/∂p, ∂(1/B_o)/∂p, ∂(1/B_g)/∂p, ∂R_s/∂p, ∂μ_o/∂p, ∂μ_g/∂p.
- По S_g: ∂C_p/∂S_g (через S_o = 1 − S_g), ∂k_{ro}/∂S_g, ∂k_{rg}/∂S_g (из модели ОФП).

**Итерационная процедура** (аналог `gp_formulation.tex`, §4.2, но для системы 2N):
1. Начальное приближение: (p^{(0)}, S_g^{(0)}) = (p^n, S_g^n).
2. Вычислить PVT и ОФП при (p^{(k)}, S_g^{(k)}).
3. Вычислить невязку F(p^{(k)}, S_g^{(k)}).
4. Собрать блочно-трёхдиагональную матрицу Якоби J.
5. Решить СЛАУ: J·δU = −F (блочной прогонкой, O(N) с блоками 2×2).
6. Обновить: U^{(k+1)} = U^{(k)} + δU.
7. Итерировать, пока ||F(U^{(k+1)})|| > ε.

Указать: блочная прогонка — обобщение скалярной прогонки Томаса на блочные системы. Каждый шаг прогонки — обращение блока 2×2 (аналитически). Сложность O(N).

Сходимость Ньютона квадратичная; типично 2–4 итерации на шаг.

**§3.3 Уравнение насыщенности.**

Уравнение насыщенности входит в **совместную систему** с уравнением давления (см. §3.2). S_g — полноправная неизвестная наравне с p.

- Дискретная форма невязки F^S_j: записать дискретизацию уравнения (eq:Sg_ode). Все члены — на уровне n+1.
- ∂p/∂t ≈ (p_j^{n+1} − p_j^n)/Δt.
- div(u_o/B_o): потоки на гранях, **upstream** по направлению потока нефти.
- Невязка F^S_j зависит от p_j (через PVT) и S_{g,j} (через ОФП и S_o = 1 − S_g). Это обеспечивает связь в блочном якобиане.
- Записать производные ∂F^S_j/∂p_j и ∂F^S_j/∂S_{g,j} для якобиана.
- Физическая проверка после каждой итерации Ньютона: 0 ≤ S_g ≤ 1 − S_or. Если нарушено — уменьшить Δt и повторить шаг (damping не используется).

**§3.4 Уравнение энергии.**

- Интегрирование по объёму ячейки V_i.
- Временная часть: V_i · (ρc_p)_{eff,i} · (T_i^{n+1} − T_i^n)/Δt.
- Конвективный член: **upstream отдельно по каждой фазе**. Конвективный поток энергии через грань j+1/2 — сумма вкладов двух фаз:
  - Нефтяная фаза: (ρ_o·c_{p,o}·u_o)_{j+1/2} · T_{j+1/2}^{upw,o}, где T^{upw,o} берётся из ячейки, откуда течёт нефтяная фаза.
  - Газовая фаза: (ρ_g·c_{p,g}·u_g)_{j+1/2} · T_{j+1/2}^{upw,g}, аналогично для газа.
  - Формально фазы могут течь в разные стороны (контрпоток), поэтому upstream определяется **раздельно** для каждой фазы.
  - Записать через ṁ⁺ и ṁ⁻ (как в `gp_formulation.tex`, §4.4): ṁ_α·T = ṁ_α⁺·T_j + ṁ_α⁻·T_{j+1}, где ṁ_α = ρ_α·c_{p,α}·u_α.
- Диффузионный член (теплопроводность): в радиальной геометрии — тот же вид, что и для давления (как в `gp_formulation.tex`, §4.4): Q_λ = (2π·h / ln(r_{j+1}/r_j)) · λ_{eff,j+1/2} · (T_{j+1} − T_j). Делитель — **ln(r_{j+1}/r_j)**, не Δr. Интерполяция λ_eff на грань — гармоническое среднее с логарифмическими весами (как для подвижности в §3.2).
- Источниковые члены Q_{JT}, Q_{ad}, Q_{deg}: вычисляются в центрах ячеек по **известным** p^{n+1}, u^{n+1}, S_g^{n+1}. Это скалярные значения, не требующие пространственной аппроксимации.
- Неявная схема: T в конвективном и диффузионном членах берётся на уровне n+1; коэффициенты замораживаются на n.
- Результат: **трёхдиагональная** система для T_i^{n+1}. Записать коэффициенты.
- Решается методом прогонки.

**§3.5 Граничные условия (дискретная форма).**

Ghost cell **не используется**. Граничные условия реализуются **модификацией коэффициентов матрицы** — тот же подход, что и в проекте Injector (`BoundaryConditions.hpp`, `EquationView.hpp`; `gp_formulation.tex`, §4.3).

Центры граничных ячеек сдвинуты к границам области (r_0 ≈ r_w, r_{N-1} ≈ R_ext), поэтому граничное условие задаётся непосредственно в граничной ячейке.

*Давление:*
- r = r_w (ячейка j = 0): условие I рода, p_0 = p_wf. Строку j = 0 в матрице заменяем на: b_0 = 1, c_0 = 0, d_0 = p_wf. Все соседние коэффициенты обнуляются.
- r = R_ext (ячейка j = N−1): условие I рода, p_{N-1} = p_0. Аналогично: a_{N-1} = 0, b_{N-1} = 1, d_{N-1} = p_0.

*Температура:*
- r = R_ext: условие I рода, T_{N-1} = T_0. Замена строки: b_{N-1} = 1, a_{N-1} = 0, d_{N-1} = T_0.
- r = r_w: ∂T/∂r = 0. Нулевой кондуктивный поток: q_{1/2} = 0 → в дискретной форме: убрать диффузионный поток через левую грань ячейки i = 1. Конвективный поток: T_{1/2} = T_1 (upstream при u < 0 не вносит потока слева).

*Насыщенность:*
- На контуре питания (r = R_ext): S_g = 0 — условие I рода. Пояснить: на контуре питания нефть однофазная (p = p_0 > p_b), свободного газа нет. Строку S_g в блочном якобиане для ячейки j = N−1 заменяем на S_{g,N-1} = 0 (аналогично замене строки давления для BC I рода).
- На забое (r = r_w): граничное условие для S_g **не задаётся**. Строка S_g для ячейки j = 0 остаётся без изменений — S_g определяется из уравнения (eq:Sg_ode). Пояснить: давление на забое задано (p = p_wf), это фиксирует строку давления; S_g на забое — свободная переменная, определяемая динамикой дегазации.

### §4 Интегрирование по времени

**§4.1 Схема по времени.**

Все уравнения решаются по **абсолютно неявной** схеме. Конвективные члены аппроксимируются **схемой против потока** (upwind). Схема имеет первый порядок точности по времени и пространству, но безусловно устойчива и консервативна — это ключевое требование.

Для каждого уравнения:

- **Уравнения давления и насыщенности — совместная полностью неявная система, метод Ньютона.** Неизвестные (p, S_g) определяются одновременно на уровне n+1. Формулируются невязки обоих уравнений, собирается блочно-трёхдиагональная матрица Якоби (блоки 2×2), итерируется до сходимости. PVT и ОФП обновляются на каждой итерации.
- **Уравнение энергии — неявная по T.** Коэффициенты вычислены по p^{n+1}, u^{n+1}, S_g^{n+1} и заморожены. Конвекция — upstream. СЛАУ линейна на каждом шаге.

Указание: в документе явно обсудить, почему выбрана схема пониженного порядка точности. Аргумент: устойчивость и консервативность важнее порядка для задач с разгазированием (резкое изменение свойств на фронте), а повышение порядка (Crank–Nicolson, TVD) может быть добавлено позже.

**§4.2 Алгоритм одного шага.**

Записать в виде нумерованного списка (псевдокод):

Алгоритм аналогичен `gp_formulation.tex`, §5 (Алгоритм решения на каждом временном шаге):

```
Вход: p^n, S_g^n, T^n, Δt

ШАГИ ГИДРОДИНАМИКИ (при T = T_0):
1. Определить p_wf из истории: найти интервал, содержащий t^n.
2. Начальное приближение: (p^{(0)}, S_g^{(0)}) = (p^n, S_g^n).
3. Цикл Ньютона (k = 0, 1, ...):
   3a. Вычислить PVT(p^{(k)}, T_0) и их производные по p.
   3b. Вычислить ОФП(S_g^{(k)}) и их производные по S_g.
   3c. Вычислить невязки F^p и F^S для каждой ячейки.
   3d. Собрать блочно-трёхдиагональную матрицу Якоби J (блоки 2×2).
   3e. Применить граничные условия (модификация коэффициентов).
   3f. Решить СЛАУ: J·δU = −F (блочная прогонка, O(N)).
   3g. Обновить: (p^{(k+1)}, S_g^{(k+1)}) = (p^{(k)}, S_g^{(k)}) + δU.
   3h. Контроль физичности: если S_g ∉ [0, 1−S_or] → уменьшить Δt, начать шаг заново.
   3i. Проверить сходимость покомпонентно: для каждой ячейки |F^p_j| < ε_p^abs ИЛИ |F^p_j|/|F^p_j,0| < ε_p^rel (аналогично для F^S). Если выполнено для всех ячеек → выход.
4. Вычислить скорости Дарси: u_o^{n+1}, u_g^{n+1} из p^{n+1}.

ШАГИ ТЕПЛОПЕРЕНОСА:
10. Вычислить PVT(p^{n+1}, T^n): ρ_o, ρ_g, c_{p,o}, c_{p,g}, α_o, α_g, L, λ_eff.
11. Вычислить коэффициенты: (ρc_p)_eff, (ρc_p·u)_conv, Q_JT, Q_ad.
12. Вычислить Q_deg: положительную часть (охлаждение) — неявно (в матрицу),
    отрицательную (нагрев) — явно (в правую часть). Критерий: диагональное преобладание.
13. Собрать трёхдиагональную матрицу уравнения энергии.
14. Применить граничные условия.
15. Решить СЛАУ → T^{n+1}.

КОНТРОЛЬ ШАГА:
16. Вычислить max|p^{n+1} − p^n| и max|S_g^{n+1} − S_g^n|.
17. Если изменения > tolerance → уменьшить Δt и повторить.
18. Если изменения малы → увеличить Δt (до максимального).

Выход: p^{n+1}, S_g^{n+1}, T^{n+1}, Δt_next
```

**§4.3 Критерии устойчивости и сходимости.**

- **CFL-ограничение отсутствует:** схема полностью неявная, безусловно устойчива. Шаг по времени ограничивается только точностью, не устойчивостью.
- **Адаптация шага по времени** в документе постановки не описывается — стратегия определяется при реализации в коде.
- **Нелинейные итерации:** система (p, S_g) решается методом Ньютона (типично 2–4 итерации на шаг). Критерий сходимости — **покомпонентный**, для каждой ячейки j должно выполняться хотя бы одно из двух условий:
  - Абсолютное: |F^p_j| < ε_p^abs и |F^S_j| < ε_S^abs.
  - Относительное: |F^p_j| / |F^p_j,0| < ε_p^rel и |F^S_j| / |F^S_j,0| < ε_S^rel, где F_0 — невязка на первой итерации.
  Пределы погрешности ε_p^abs, ε_p^rel, ε_S^abs, ε_S^rel задаются пользователем в конфиге. Уравнение энергии — линейная СЛАУ (коэффициенты заморожены), итерации не нужны.
- **Контроль физичности:**
  - 0 ≤ S_g ≤ 1 − S_or (не может быть отрицательной или превышать 1 минус остаточная нефть).
  - p > 0 (давление положительно).
  - T > 0 (температура положительна).
  - R_s(p) ≤ R_s^0 (нельзя растворить больше газа, чем было начально).
  Нарушение любого — Δt уменьшается вдвое, шаг повторяется.

## Особые случаи и переходные режимы

В документе обязательно описать следующие ситуации:

**Переключение однофазная → двухфазная зона.**
- В ячейке j: если p_j > p_b → однофазная зона. S_g,j = 0, R_s = R_s^0 = const, k_{rg} = 0, газовая подвижность = 0. Уравнение давления упрощается до однофазного (члены с газом обнуляются).
- Если p_j < p_b → двухфазная зона. Полная система.
- Переключение **поячеечное**: в каждой ячейке независимо проверяется условие p_j ≶ p_b. Фронт разгазирования r_b(t) явно не отслеживается.
- В якобиане: при S_g = 0 члены с ∂k_{rg}/∂S_g формально ненулевые (модель Кори: k_{rg} ∝ S*^{n_g}, производная конечна). Указать, как это обрабатывается. При S_g < S_gc (критическая газонасыщенность): k_{rg} = 0 тождественно, газ неподвижен.

**Появление газовой фазы.**
- При переходе p через p_b в ячейке впервые появляется S_g > 0. Начальное значение S_g в этой ячейке определяется из уравнения (eq:Sg_ode): на первом шаге ∂p/∂t < 0, поэтому ∂S_g/∂t > 0.
- Указать: нет скачка — S_g нарастает непрерывно от нуля.

**p_wf(t) — режим работы скважины.**
- Забойное давление задаётся **историей**: набор пар (интервал времени, значение давления). На каждом интервале p_wf = const, между интервалами — скачок. Это кусочно-постоянная функция.
- В документе записать p_wf(t) как кусочно-постоянную функцию: p_wf(t) = p_wf^{(k)} при t ∈ [t_k, t_{k+1}). Привести пример: один интервал (p_wf = const на всё время) и два интервала (снижение давления в заданный момент).
- Указать: солвер на каждом временном шаге использует значение p_wf, соответствующее текущему моменту t^n.
