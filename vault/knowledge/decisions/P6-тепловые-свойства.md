# P6. Тепловые свойства — отсутствуют в прототипе

## Суть

Прототип коллеги решает только гидродинамику. Тепловых свойств (c_p, μ_JT, L) в нём нет. Это ожидаемо — температурная задача целиком наша ответственность.

## Решение (через P5)

`TableFullPVT` = `PrototypePVTAdapter` (табличные гидро) + скалярные тепловые свойства:

```python
full_pvt = TableFullPVT(
    proto_pvt_adapter,          # гидро: Bo, Bg, μ_o, μ_g, Rs_sat из BlackOilPVT
    c_p_oil=1880.0,             # Дж/(кг·К)
    c_p_gas=2800.0,             # Дж/(кг·К)
    mu_JT_oil=4.0e-7,           # К/Па
    mu_JT_gas=-4.0e-6,          # К/Па
    L_degas=168000.0,           # Дж/кг
)
```

Значения из JSON (секция `thermal`) или из baseline-параметров (Шарафутдинов 2019).

## Что не входит в PVT

**λ_eff (теплопроводность среды)** — не PVT-свойство. Зависит от породы и насыщенности:

```
λ_eff[j] = (1-φ)·λ_solid + φ·(So[j]·λ_oil + Sg[j]·λ_gas)
```

λ_solid, λ_oil, λ_gas — постоянные из JSON (секция `rock`). Вычисляется в EnergySolver на каждом шаге (зависит от Sg).

## Расширяемость

Сейчас тепловые свойства — постоянные скаляры. ABC FullPVT принимает (p, T) как аргументы. При необходимости зависимости от p, T — реализовать новый подкласс FullPVT с табличными или корреляционными тепловыми свойствами. Остальной код (EnergySolver) не меняется.
