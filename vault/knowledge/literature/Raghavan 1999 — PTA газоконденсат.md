# Raghavan 1999 — PTA газоконденсат

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Raghavan R., Chu W.C., Jones J.R.** Practical Consideration in the Analysis of Gas-Condensate Well Tests. *SPE Res Eval & Eng*, 1999, 2(3), 288–295. SPE-56837-PA.

## Аннотация

Практические аспекты анализа ГДИС для газоконденсатных скважин. В контексте Kamal & Pan (2011) упоминается как пример многофазного потока (газоконденсат ниже давления росы), выходящего за рамки рассмотренных двухфазных систем (нефть–газ, нефть–вода, газ–вода).

## Потенциал для проекта

Газоконденсатная задача — смежная с разгазированием нефти в ПЗП: в обоих случаях фазовый переход создаёт двухфазную зону вблизи скважины с переменной насыщенностью. Опыт PTA для газоконденсата может подсказать подходы к верификации модели ПЗП через данные ГДИС.
