# 09 — Разгазирование: адиабатический эффект + скрытая теплота дегазации

## Описание

Пример [07](../07_degassing_adiabatic_only/) с включённой скрытой теплотой
дегазации $L = 168000$ Дж/кг газа. Джоуль–Томсон выключен ($\mu_{JT} = 0$).

Физика: выделение газа из раствора — фазовый переход, на который тратится
энергия. Тепло отбирается у флюида и породы, что охлаждает пласт в зоне
разгазирования.

Разница между 09 и 07 — **чистый вклад скрытой теплоты**.

## Комбинация модулей (B: Table + Table)

Та же, что в 07. Изменена одна строка:

```json
"thermal": {
    "c_p_oil": 2000.0,
    "c_p_gas": 1000.0,
    "mu_JT_oil": 0.0,
    "mu_JT_gas": 0.0,
    "L_degas": 168000.0      ← было 0.0
}
```

| Модуль | Класс |
|---|---|
| PVT (гидро) | `TableFullPVT` |
| ОФП | `PrototypeRPAdapter` |
| Гидродинамика | `PrototypeHydroAdapter` |
| Энергия | `TridiagEnergySolver` |

## Ожидаемое поведение

| Величина | Значение |
|---|---|
| $T(r_w)$ финал | **351.083 К** |
| вклад дегазации ($T_{09} - T_{07}$) | **$-1.687$ К** |
| $S_g^{max}$ | 0.0147 (как в 07) |
| $R_s^{min}$ | 9.5 (как в 07) |
| $q_o$ финал | $5.876 \times 10^{-3}$ м³ст/с (как в 07) |

Вклад скрытой теплоты в 2.5 раза слабее, чем JT (пример 08: $-4.212$ К).
Причина — малое количество выделившегося газа: $S_g^{max}$ всего 1.5 %.
При более подвижной газовой фазе (см. раздел ниже) вклад вырос бы.

Зона охлаждения **пространственно совпадает с зоной разгазирования**
($r < r_b = 2.39$ м) — в отличие от JT, который работает всюду, где есть
градиент давления. Это видно при сравнении `temperature_profiles.png`
из 08 и 09.

## Место в семействе 07–09

| Сценарий | $\mu_{JT}$ | $L$ | $T(r_w)$, К | вклад относительно 07 |
|---|---|---|---|---|
| [07](../07_degassing_adiabatic_only/) | 0 | 0 | 352.770 | — (опора) |
| [08](../08_degassing_jt/) | > 0 | 0 | 348.558 | $-4.212$ К |
| **09** (этот) | 0 | > 0 | 351.083 | **$-1.687$ К** |
| [04](../04_table_table/) | > 0 | > 0 | 346.871 | $-5.899$ К |

Суперпозиция: $(-4.212) + (-1.687) = -5.899$ К — точно равно полному эффекту
(невязка $4 \times 10^{-13}$ К, машинная точность). Эффекты линейно
складываются, что позволяет оценивать их по отдельности.

**Гидродинамика идентична 07 побитово** ($S_g$, $p$, $R_s$, $q_o$;
`np.array_equal` → `True`) — следствие расщепления.

## Как увеличить газонасыщенность

$S_g^{max} = 1.5\,\%$ — свойство демонстрационной таблицы ОФП.
Для этого сценария рычаг вдвойне полезен: больше газа → сильнее вклад
скрытой теплоты. Заменить `relperm` на модель Кори с крутой кривой:

```json
"relperm": {"model": "corey", "S_or": 0.2, "S_gc": 0.05,
            "n_o": 2.0, "n_g": 3.0, "kro_max": 1.0, "krg_max": 0.3}
```

даст $S_g^{max} = 0.165$ вместо 0.015. Подробный разбор с числами —
в README примера [04](../04_table_table/). Увеличение длительности расчёта
и расширение $R_e$ не помогают: стационар наступает за 8–12 ч.

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| $L$ | `thermal.L_degas` | прямо пропорционально усиливает охлаждение |
| $c_{p,o}$, $c_{p,g}$ | `thermal` | тепловая инерция флюида |
| $R_{s,0}$ | `initial_conditions.Rs0` | больше газа выделится → сильнее эффект (макс. 30 для этой таблицы) |
| $R_e$ | `geometry.R_ext` | шире область; фронт $r_b$ растёт |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[].dt` | ⚠️ стационар за 8–12 ч |
| `save_every` | `output.save_every` | 1 → 73 шага (0.22 МБ), 6 → 13, 24 → 4 |

### Что требует осторожности — $p_{wf}$

**Сверху:** при $p_{wf} > p_b = 15$ МПа разгазирования не будет вообще —
и вместе с ним исчезнет весь эффект этого сценария ($T$ станет как в 07).
**Снизу:** табличный PVT устойчив в диапазоне 14…3 МПа; при отказе
Newton помогает `"dt_integration": 600` (DEBT-007).

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.
