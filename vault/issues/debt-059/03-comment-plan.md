### План готов

План: `vault/plans/debt-059 installable-prototype-package.md`. Ветка: `refactor/debt-059/installable-prototype-package`. Шагов: 7 (0–6).

**Решения пользователя (2026-10-10):**
- два дистрибутива в одном репозитории: у прототипа свой `pyproject.toml` (`radial-blackoil`), GPN объявляет его в `dependencies`; импорты ядра не меняются;
- тесты GPN берут прототип по `pythonpath` в `[tool.pytest.ini_options]` вместо вставки в `tests/conftest.py`: общий venv указывал бы на основной каталог, а тесты worktree должны проверять свой код;
- версия `1.0.3+gpn.1` только у дистрибутива (`radial_blackoil.__version__`). `build_info.VERSION` и `BUILD_ID` не меняются: `run_regression.py:72` сверяет их в `run_summary.json` с эталонами. GPN требует ровно `radial-blackoil==1.0.3+gpn.1`; версию с локальной меткой PyPI не примет, так что подменить зависимость чужим пакетом нельзя;
- `PACKAGE_MANIFEST_SHA256.txt` остаётся записью поставки 2026-08-25.

**Шаги:** 0 — базовый вариант (тесты, регрессия прототипа, отпечаток примеров 03/04/05, `pip freeze` общего venv) → 1 — `pyproject.toml` прототипа и версия → 2 — зависимость GPN, `pythonpath`, `tests/test_packaging.py` (7 тестов) → 3 — 14 вставок пути из примеров, сторож вставок (+1 тест) → 4 — документы, команды `.claude/`, vault → 5 — приёмка в чистом окружении (колёса без PyPI и `pip install -e`, отпечаток побитово) → 6 — полный прогон, тесты и регрессия `--quick` прототипа.

**Проверено пробами при планировании** (`vault/issues/debt-059/probes/`):
- `setuptools` читает версию без импорта пакета;
- в колесе прототипа только `radial_blackoil`;
- `pip --no-index` находит прототип как зависимость;
- `pip check` чистый;
- отпечаток примеров в чистом окружении побитово равен текущему;
- проба приёмки на макете дерева — 9 × «ОК».

**Найдено при планировании:** `04/04a grid_convergence.py` импортируют `example_runner` «ради прототипа», но заодно переключают консоль на UTF-8 (печатают `м³ст/с`). Импорт остаётся. Число тестов прототипа в шапках команд `.claude/` устарело (80 → 97), правится попутно.

**После влития — однократно:** `pip install -e HydroSolverPrototype\Prototype_1.0.3 -e ".[dev]"` в общий venv из основного каталога. Иначе примеры падают с `ModuleNotFoundError`, тесты — нет.
