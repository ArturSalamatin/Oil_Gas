# Bourdet 2002 — монография ГДИС

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Bourdet D. Well-Test Analysis: The Use of Advanced Interpretation Models. *Elsevier Science*, 2002.

## Аннотация
Монография по современным методам интерпретации ГДИС. Среди прочего: radial composite модель (формулировка скина, Eq. 8 в Hamdi 2013), ограничения преобразования $m(p)$ при больших изменениях сжимаемости газа, применение производной давления (Bourdet derivative) для диагностики моделей.

## Потенциал для проекта
Справочник по radial composite модели и интерпретации derivative curves — полезен для верификации приближённых аналитических решений ПЗП.
