# He 1997 — sensitivity coefficients для обратных задач ГДИС

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** He N. Three Dimensional Reservoir Description by Inverse Theory Using Well-Test Pressure and Geostatistical Data. *PhD thesis*, University of Tulsa, 1997.

## Аннотация
Разработан метод расчёта коэффициентов чувствительности (time-dependent sensitivity coefficients, TDSCs), показывающих чувствительность забойного давления к изменению проницаемости в произвольной ячейке модели в произвольный момент времени. TDSCs используются для 3D-описания пласта по данным ГДИС совместно с геостатистической информацией (обратная задача).

## Потенциал для проекта
TDSC-подход объясняет, почему drawdown чувствителен к ПЗП на поздних временах (когда конденсат/свободный газ нарастает). Может быть использован для оценки информативности ГДИС при наличии зоны разгазирования.
