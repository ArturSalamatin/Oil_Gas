# Xu Lee 1999 — однофазная аналогия для газоконденсата

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Xu S., Lee J. Gas Condensate Well Test Analysis Using a Single Phase Analogy. *SPE Western Regional Meeting*, 1999. SPE 55992.

## Аннотация
Показано, что однофазная функция псевдодавления $m(p) = 2\int p/(\mu z)\,dp$ при достаточно глубокой конденсатной банке и длительном shut-in адекватна для анализа нестационарных данных давления газоконденсатных скважин. Однофазная $m(p)$ даёт radial composite сигнатуру (два полулогарифмических прямолинейных участка). Формулировка суммарного скина (Eq. 7): $S_t = S_m/k_{rg} + S_{2p}$.

## Потенциал для проекта
Обоснование применимости однофазной $m(p)$ к двухфазным задачам — потенциально полезно для упрощённой интерпретации ГДИС при разгазировании нефти.
