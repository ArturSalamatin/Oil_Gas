# Словарь: код ↔ физика ↔ уравнения

Каждая переменная программы однозначно соответствует физической величине из problem_statement.tex. Этот словарь — единственный источник истины при реализации. Ссылки на уравнения — метками `problem_statement.tex` (DEBT-010); номера уравнений сдвигаются при правках документа.

## 1. Сетка (Grid)

### Индексация

Ячейки нумеруются j = 0, 1, ..., N-1. Грани нумеруются f = 0, 1, ..., N.

```
грань 0     ячейка 0     грань 1     ячейка 1     ...     ячейка N-1     грань N
(забой)                                                                   (контур)
r_w ─────── r_centers[0] ─────── r_centers[1] ─── ... ─── r_centers[N-1] ─── R_ext
r_faces[0]               r_faces[1]              ...                      r_faces[N]
```

### Соответствие кода и документа

| Код | Документ (problem_statement.tex) | Уравнение | Размер |
|---|---|---|---|
| `r_faces[f]` | r_{f+1/2} при нумерации ячеек с 1; r_faces[0]=r_w, r_faces[N]=R_ext | `eq:log_grid` | [N+1] |
| `r_centers[j]` | r_j = √(r_{j-1/2}·r_{j+1/2}) — середина ячейки по ln r, как у прототипа | `eq:cell_center` | [N] |
| `volumes[j]` | V_j = π·h·(r_faces[j+1]² − r_faces[j]²) | `eq:volume` | [N] |
| `trans_internal[f]` | T_{f+1} = 2πhk / ln(r_centers[f+1]/r_centers[f]), f=0..N-2 | `eq:transmissibility` | [N-1] |
| `trans_well` | T_{1/2} = 2πhk / ln(r_centers[0]/r_w) | формула без номера над `eq:bc_flux_well` | скаляр |
| `trans_ext` | T_{N+1/2} = 2πhk / ln(R_ext/r_centers[N-1]) | формула без номера над `eq:bc_flux_well` | скаляр |

### Правило: грань f расположена **между ячейкой f-1 и ячейкой f**

- Грань f=0: между забоем и ячейкой 0 (левая граничная)
- Грань f=1..N-1: между ячейками f-1 и f (внутренние)
- Грань f=N: между ячейкой N-1 и контуром (правая граничная)

Проводимость `trans_internal[f]` соответствует грани f+1 (между ячейками f и f+1), f=0..N-2. Альтернативная интерпретация: проводимость грани между ячейками f и f+1.

## 2a. SimulationHistory — контейнер результатов

```python
@dataclass
class SimulationHistory:
    times: list[float]                 # [K] — моменты времени сохранённых шагов, с
    states: list[SimulationState]      # [K] — состояния
    hydro_results: list[HydroResult]   # [K] — потоки
    well_data: list[WellData]          # [K] — скважинные данные
```

K = число интервалов `time.history` + 1: запись делается на конце каждого интервала плюс начальное состояние (DEBT-013). Подшаги интегрирования в историю не попадают — они задают точность схемы, а не частоту вывода.

Simulator.run() → SimulationHistory. I/O-модуль принимает SimulationHistory для записи CSV/NPZ и визуализации.

## 3. Потоки через грани (HydroResult)

### 3.1 Потоки компонентов (для балансов масс и ṁ)

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `G_o[f]` | G^o_{f} | м³ст/с | `eq:flux_oil` | [N+1] |
| `G_g[f]` | G^g_{f} | м³ст/с | `eq:flux_gas` | [N+1] |
| `G_free_gas[f]` | G^{fg}_{f} | м³ст/с | второе слагаемое `eq:flux_gas` | [N+1] |

**Определение:** поток нефтяного (газового) **компонента** при стандартных условиях через грань f.

Баланс массы компонентов (DEBT-039):

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `HydroResult.int_G_o_well`, `int_G_g_well` | $\int G^{o,g}_0\,dt$ за шаг | м³ст | сумма `eq:residual_oil`, `eq:residual_gas` | скаляр |
| `HydroResult.int_G_o_ext`, `int_G_g_ext` | $\int G^{o,g}_N\,dt$ за шаг | м³ст | то же | скаляр |
| `HydroSolver.component_inventories(state)` | $M_o = \sum \phi V S_o/B_o$, $M_g = \sum \phi V (S_o R_s/B_o + S_g/B_g)$ | м³ст | то же | 2 скаляра |

Интегралы — по всем внутренним подшагам решателя, знак как у $G$ (при добыче `int_G_*_well` < 0, при притоке с контура `int_G_*_ext` < 0). Невязка: $\Delta M + \int G_N\,dt - \int G_0\,dt$.

**Формулы (конвенция: G > 0 = от скважины):**
```
Внутренние грани (f = 1..N-1):
G_o[f] = trans_internal[f-1] · (kro/(μo·Bo))_up · (p[f-1] - p[f])
G_g[f] = trans_internal[f-1] · [Rs_up·(kro/(μo·Bo))_up + (krg/(μg·Bg))_up] · (p[f-1] - p[f])

Граничная грань забоя (f = 0):
G_o[0] = trans_well · (kro/(μo·Bo))_0 · (p_wf - p[0])
G_g[0] = trans_well · [Rs_0·(kro/(μo·Bo))_0 + (krg/(μg·Bg))_0] · (p_wf - p[0])

Граничная грань контура (f = N):
G_o[N] = trans_ext · (kro/(μo·Bo))_{N-1} · (p[N-1] - p_ext)
G_g[N] = trans_ext · Rs0·(kro/(μo·Bo))_{N-1} · (p[N-1] - p_ext)
         // krg=0 на контуре (Sg=0)
```

При типичном потоке: все G < 0 (к скважине).

**Давление на забойной грани `p_wf`** — в формулах выше это `HydroResult.p_wf`
(скаляр, Па; FEAT-020, 2026-09-30): фактическое давление шага, которое
возвращает гидродинамика. При управлении по давлению — уставка (при закрытии
скважины, $p[0] \le$ уставки, — $p[0]$); при управлении по дебиту нефти
$q_{o,\text{ст}}$ оно выражается из уравнения притока (`eq:bc_rate_pwf`):
`p_wf = p[0] − q_o,ст / (trans_well · (kro/(μo·Bo))_0)`, `G_o[0] = −q_o,ст`.
Энергия и `WellData.p_wf` берут $p_{wf}$ только отсюда.

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `HydroResult.p_wf` | $p_{wf}$ | Па | `eq:bc_p_well` / `eq:bc_rate_pwf` | скаляр |
| `RateControl.q_oil` | $q_{o,\text{ст}}$ | м³ст/с | `eq:bc_rate_well` | скаляр |
| `RateControl.min_bhp` | $p_{\min}$ | Па | `eq:bc_rate_well` | скаляр |

### 3.2 Конвенция знака потоков

**Положительное направление — от скважины (рост r).** См. [[конвенции-знаков]].

```
G_o[f] > 0  ⟹  поток от скважины (в сторону роста r)
G_o[f] < 0  ⟹  поток к скважине (в сторону убывания r) — ТИПИЧНЫЙ СЛУЧАЙ
```

Формула: `G_o[f] = T_f · mob_up · (p[f-1] − p[f])`.

Проверка: на забое p_wf < p[0] → (p_wf − p[0]) < 0 → G_o[0] < 0 → поток к скважине. ✓
На контуре p[N-1] < p_ext → (p[N-1] − p_ext) < 0 → G_o[N] < 0 → поток к скважине (приток в область). ✓

Дебит: `q_o_std = −G_o[0] > 0`.

### 3.3 Upstream-правило

Upstream = ячейка с бо́льшим давлением (откуда течёт жидкость).

Для грани f между ячейками f-1 и f:
```
Если p[f-1] > p[f]  (G > 0, поток от скважины, нетипично):
    upstream = ячейка f-1

Если p[f-1] < p[f]  (G < 0, поток к скважине, типично):
    upstream = ячейка f
```

### 3.4 Расходы фаз (для уравнения энергии)

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `Q_o[f]` | Q_{o,f} | м³пл/с | `eq:phase_flux` | [N+1] |
| `Q_g[f]` | Q_{g,f} | м³пл/с | `eq:phase_flux` | [N+1] |

**Отличие от G:** расход фазы в **пластовых** условиях, без деления на Bo.

```
Q_o[f] = trans[f] · (kro/μo)_up · Δp    // без 1/Bo!
Q_g[f] = trans[f] · (krg/μg)_up · Δp    // без 1/Bg!
```

Связи (точные):
```
G_o = Q_o / Bo_up                        (нефтяной компонент)
G_free_gas = Q_g / Bg_up                 (свободный газовый компонент)
G_g = Rs_up · G_o + G_free_gas           (ПОЛНЫЙ газовый компонент)
```

Обратные:
```
Q_o = G_o · Bo_up                        (расход нефтяной фазы)
Q_g = (G_g − Rs_up · G_o) · Bg_up       (расход газовой фазы)
    = G_free_gas · Bg_up
```

G_g ≠ Q_g / Bg. G_g содержит растворённый газ (Rs·G_o), который не занимает объём газовой фазы.

**Где вычисляется:** EnergySolver вычисляет Q_o, Q_g самостоятельно из p, grid.trans, PVT, ОФП, или из G_o, G_free_gas и Bo, Bg (upstream).

### 3.5 Скорости Дарси

| Код | Документ | Единицы | Уравнение | Размер |
|---|---|---|---|---|
| `u_o[f]` | u_{o,f} | м/с | `eq:darcy` | [N+1] |
| `u_g[f]` | u_{g,f} | м/с | `eq:darcy` | [N+1] |

```
u_α[f] = Q_α[f] / (2π·h·r_faces[f])
```

Единая конвенция: **u > 0 → от скважины**. При типичном потоке u < 0. Совпадает с непрерывным определением u = −Λ·∂p/∂r.

## 4. Невязки гидродинамики (3 штуки на ячейку)

### 4.1 Невязка баланса нефтяного компонента

| Код | Документ | Уравнение |
|---|---|---|
| `F_oil[j]` | F_j^{oil} | `eq:residual_oil` |

```
F_oil[j] = V[j]·φ · ((1-Sg[j])/Bo[j] - (1-Sg_prev[j])/Bo_prev[j]) / dt
           + G_o[j+1] - G_o[j]
```

Единицы: м³ст/с (объёмный расход нефтяного компонента при ст. условиях).

Слагаемые:
- **Накопление**: V·φ · Δ(So/Bo) / dt — изменение запаса нефтяного компонента в ячейке за dt
- **Потоки**: G_o[j+1] − G_o[j] — отток через правую грань минус приток через левую грань

При стационаре: accum = 0, G_o[j+1] = G_o[j] = const < 0 → F = 0. ✓
Баланс масс: изменение запаса + чистый отток = 0.

### 4.2 Невязка баланса газового компонента

| Код | Документ | Уравнение |
|---|---|---|
| `F_gas[j]` | F_j^{gas} | `eq:residual_gas` |

```
F_gas[j] = V[j]·φ · ((Rs[j]·(1-Sg[j])/Bo[j] + Sg[j]/Bg[j])
                     - (Rs_prev[j]·(1-Sg_prev[j])/Bo_prev[j] + Sg_prev[j]/Bg_prev[j])) / dt
           + G_g[j+1] - G_g[j]
```

Единицы: м³ст/с (объёмный расход газового компонента при ст. условиях).

### 4.3 Невязка замыкающего уравнения

| Код | Документ | Уравнение |
|---|---|---|
| `F_eq[j]` | F_j^{eq} | `eq:residual_eq_r1` (режим 1), `eq:residual_eq_r2` (режим 2) |

```
Режим 1 (Sg > 0):  F_eq[j] = Rs[j] - Rs_eq(p[j])
Режим 2 (Sg = 0):  F_eq[j] = Sg[j]
```

Единицы: м³ст/м³ст (режим 1), безразмерное (режим 2).

### 4.4 Источниковые члены

В балансах масс (`eq:residual_oil`, `eq:residual_gas`) **нет** явных источниковых членов. Дегазация учтена неявно через Rs и замыкающее уравнение. Все источники — в уравнении энергии.

## 5. Уравнение энергии (1 уравнение на ячейку)

Форма — **адвективная** (BUG-012): конвекция, JT и перенос $R_s$ собираются как вклады граней с **разностью** переносимой величины; теплопроводность остаётся дивергентной. Код — `gpn_multiphase_solver/energy/tridiag.py` (`TridiagEnergySolver`), шапка модуля объясняет, почему не дивергентная: разность потоков через грани дискретизирует $\operatorname{div}(\Phi T)$ вместо $\Phi\,\partial T/\partial r$ и даёт лишний член $T_j D_j$, $D_j = \Phi_{j+1/2} - \Phi_{j-1/2}$, — работу расширения газа второй раз (она уже в $Q_{ad}$ и JT).

### 5.1 Дискретное уравнение (`eq:energy_disc_full`)

```
V[j]·(ρcp)_eff[j] · (T[j] − T_prev[j]) / dt + F_j
    = −(Q_λ[j+1] − Q_λ[j]) + J_jt[j] + V[j]·(Q_ad[j] + Q_deg[j])
```

`F_j` — конвективный член (`eq:energy_conv_face`); отдельным массивом в коде не хранится, входит в коэффициенты `a`, `b`, `c` через `Phi_plus`, `Phi_minus`. `Q_λ[f] > 0` — поток тепла от скважины.

В трёхдиагональную СЛАУ (`eq:energy_tridiag`): `a[j]·T[j−1] + b[j]·T[j] + c[j]·T[j+1] = d[j]`.

### 5.2 Слагаемые уравнения энергии

| Код | Документ | Единицы | Уравнение | Описание |
|---|---|---|---|---|
| `props['rho_cp_eff'][j]` (`compute_cell_properties`) | (ρc_p)_{eff,j} | Дж/(м³·К) | `eq:main_rhocpeff` | Эффективная теплоёмкость |
| `props['lambda_eff'][j]` | λ_{eff,j} | Вт/(м·К) | `eq:lambda_eff` | Эффективная теплопроводность |
| `Phi_o[f]`, `Phi_g[f]` (`compute_convective_coefficients`) | Φ_{α,f} | Вт/К | определение под `eq:energy_conv_face` | Конвективный коэффициент фазы |
| `Phi_plus[f]`, `Phi_minus[f]` | Φ^±_f = Σ_α max/min(Φ_{α,f}, 0) | Вт/К | там же | Расщепление по знаку, раздельно по фазам |
| `Q_T[f]` (`compute_conductive_transmissibility`) | Q^T_f | Вт/К | `eq:heat_cond_disc` | Кондуктивная проводимость грани; [N+1], `Q_T[0] = 0` (Нейман), `Q_T[N]` — контур (DEBT-020) |

### 5.3 Конвекция (`eq:energy_conv_face`)

```
F_j = Σ_α [ Φ⁺_α[j]·(T[j] − T[j−1]) + Φ⁻_α[j+1]·(T[j+1] − T[j]) ]
```

`Φ_α[f] = ρ_α^up · c_{p,α}^up · Q_α[f]` — свойства из ячейки выше по потоку, **раздельно по каждой фазе** (по знаку `Q_α`); на контурной грани при притоке — при условиях контура (`eq:bc_props_ext`). `Φ⁺ = max(Φ, 0)`, `Φ⁻ = min(Φ, 0)`. Раздельно по фазам — потому что при противотоке фаз `Φ_o` и `Φ_g` на одной грани разных знаков.

Забойная грань (f = 0) конвективного вклада не даёт: слева ячейки нет, разность T нулевая (условие Неймана).

### 5.4 Теплопроводность (`eq:heat_cond_disc`, дивергентная форма)

```
Q_λ[f] = Q^T_f · (T[f−1] − T[f]),     Q^T_f = 2πh / (w_L/λ_L + w_R/λ_R)
w_L = ln(r_faces[f] / r_centers[f−1]),  w_R = ln(r_centers[f] / r_faces[f])
```

Последовательные кольцевые сопротивления. При однородном λ: `Q^T_f = 2πhλ / ln(r_centers[f]/r_centers[f−1])` — один логарифм (BUG-002). Контур: `Q_T[N] = 2πh·λ_eff[N−1] / ln(R_ext/r_centers[N−1])`. Забой: `Q_T[0] = 0` (Нейман).

Документ после [[BUG-027]]: `eq:heat_cond_disc` со средним `eq:face_interp` — $\lambda^{j+1/2} = (w_L + w_R)/(w_L/\lambda_L + w_R/\lambda_R)$, веса нормированы; подстановка даёт ту же формулу последовательных сопротивлений. До BUG-027 `.tex` записывал среднее без множителя $(w_L + w_R)$ — двойной ln BUG-002 в постановке.

### 5.5 Джоуль–Томсон (`eq:QJT_disc`)

```
J_jt[j] = Σ_α [ μ_JT,α[j]·Φ⁺_α[j]·(p[j] − p[j−1]) + μ_JT,α[j+1]·Φ⁻_α[j+1]·(p[j+1] − p[j]) ]   [Вт]
```

Здесь `μ_JT,α[f]` — значение **на грани** f (в коде `mu_o_face`, `mu_g_face`): из ячейки выше по потоку (тот же выбор, что для `Φ_α`; на забойной грани — ячейка 0), на контуре при притоке — при условиях контура. Давление «за гранью»: на забое — `p_wf` шага (`HydroResult.p_wf`), на контуре — `p_ext`. Забойная грань входит с весом `Φ⁺`: при добыче (`Φ < 0`) её вклад нулевой. При однородном p член обращается в нуль тождественно.

### 5.6 Адиабатический эффект (`eq:Qad_disc`)

```
Q_ad[j] = φ · Σ_α S_α[j]·(1 + ρ_α[j]·c_{p,α}[j]·μ_JT,α[j]) · (p[j] − p_prev[j]) / dt
```

Совпадает с `eq:Qad_disc` (там единица вне суммы; равны, так как S_o + S_g = 1). Это форма при $c_r = 0$: непрерывная `eq:main_Qad_muJT` содержит ещё член $c_r\,(p + (\rho c_p)_s T)$ — см. DEBT-057. Единицы: Вт/м³.

### 5.7 Теплота дегазации (`eq:Qdeg_disc`, `eq:mdot_disc`, `eq:mdot_conv_face`)

```
Q_deg[j] = −L · mdot[j]
V[j]·mdot[j] = −ρ_g,ст · [ V[j]·φ·(1 − Sg[j])/Bo[j] · (Rs[j] − Rs_prev[j])/dt + R_adv[j] ]
R_adv[j] = G_o⁺[j]·(Rs[j] − Rs[j−1]) + G_o⁻[j+1]·(Rs[j+1] − Rs[j])
```

Расщепление — по знаку `G_o` (потока нефтяного **компонента**), как для `Φ` и `J_jt`. Слева от ячейки 0 соседом считается она сама (разность нулевая при любом знаке потока); справа от ячейки N−1 — состав притока `Rs_ext` (`eq:bc_Sg_ext`), не `Rs[N−1]` (DEBT-009). Множитель 1/B_o пространственного члена сидит внутри `G_o` и снесён по потоку, временного — из ячейки: так воспроизводится дискретное правило Лейбница гидродинамики (невязка ~1e-15).

При однородном Rs (режим 2, Rs = Rs0): `R_adv = 0`, `ΔRs/dt = 0` → `mdot = 0`, `Q_deg = 0` — тождественно.

## 6. Коэффициенты трёхдиагональной СЛАУ (`eq:tridiag_a` … `eq:tridiag_d`)

Все ячейки j = 0..N−1 (`assemble_tridiag`, операции над массивами граней; срез `[:-1]` — левые грани, `[1:]` — правые); `cap[j] = V[j]·(ρcp)_eff[j]/dt`:

| Код | Документ | Формула |
|---|---|---|
| `a[j]` | a_j, `eq:tridiag_a` | −Q^T_{j−1/2} − Φ⁺_{j−1/2} = `−Q_T[j] − Phi_plus[j]` (≤ 0) |
| `c[j]` | c_j, `eq:tridiag_c` | −Q^T_{j+1/2} + Φ⁻_{j+1/2} = `−Q_T[j+1] + Phi_minus[j+1]` (≤ 0) |
| `b[j]` | b_j, `eq:tridiag_b` | cap + Q^T_{j−1/2} + Q^T_{j+1/2} + Φ⁺_{j−1/2} − Φ⁻_{j+1/2} = `cap[j] + Q_T[j] + Q_T[j+1] + Phi_plus[j] − Phi_minus[j+1]` (> 0) |
| `d[j]` | d_j, `eq:tridiag_d` | `cap[j]·T^n[j] + J_jt[j] + V[j]·(Q_ad[j] + Q_deg[j])` |

`Φ⁺` и `Φ⁻` в `b_j` — с тех же граней, что в `a_j` и `c_j`. Дивергентная форма брала противоположные (`Φ⁺_{j+1/2} − Φ⁻_{j−1/2}`); разность двух версий `b_j` равна ровно $D_j$ (BUG-012).

Граничные условия — поправки к общим формулам:
- **j = 0** (забой, Нейман): `Q_T[0] = 0`; `a[0] = 0`; `Phi_plus[0]` в `b[0]` не входит (грань 0 конвективного вклада не даёт). Итог: `c[0] = −Q_T[1] + Phi_minus[1]`, `b[0] = cap[0] + Q_T[1] − Phi_minus[1]`.
- **j = N−1** (контур, Дирихле `T = T_ext`): `c[N−1] = 0`; `b[N−1]` — по общей формуле (`cap + Q_T[N−1] + Q_T[N] + Phi_plus[N−1] − Phi_minus[N]`); к `d[N−1]` добавляется `(Q_T[N] − Phi_minus[N])·T_ext`.
- **N = 1** — отдельной ветви нет (DEBT-020): обе поправки относятся к строке 0 и не затирают друг друга.

Здесь `Q^T_f` — кондуктивная проводимость грани (> 0, раздел 5.4); `Φ⁺_f = Σ_α max(Φ_{α,f}, 0) ≥ 0`, `Φ⁻_f = Σ_α min(Φ_{α,f}, 0) ≤ 0`; `J_jt`, `Q_ad`, `Q_deg` — известные числа (из p^{n+1}, T^n).

СЛАУ решается в отклонениях θ = T − T_ext (DEBT-043): матрица та же, правая часть собирается от T^n − T_ext.

Диагональное преобладание: `b_j − |a_j| − |c_j| = cap[j] > 0` (`eq:diag_dominance`) — обеспечено конструкцией.

## 7. PVT-функции

Допущение splitting: в гидродинамике PVT зависят от p и Rs, но **не от T** (T = T0 = const). В энергетике тепловые свойства (c_p, μ_JT, L) принимают (p, T) для расширяемости, но в текущей реализации — скаляры.

pb = pb(Rs) — функция газосодержания (при T = const). В общем случае pb = pb(Rs, T).
