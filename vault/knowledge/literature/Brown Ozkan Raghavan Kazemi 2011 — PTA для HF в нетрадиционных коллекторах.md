# Brown Ozkan Raghavan Kazemi 2011 — PTA для HF в нетрадиционных коллекторах

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Brown M., Ozkan E., Raghavan R., Kazemi H.** Practical Solutions for Pressure-Transient Responses of Fractured Horizontal Wells in Unconventional Shale Reservoirs. *SPE Reservoir Evaluation & Engineering*, 2011, 14(6), pp. 663–676.

## Аннотация
Аналитическое решение в пространстве Лапласа для давления в горизонтальной скважине с множественным ГРП. Модель SRV/USRV с двойной пористостью. Является базовой моделью давления в Al-Rbeawi 2018 (Eq. 32), куда встроены многофазные поправки.

## Потенциал для проекта
Ключевая модель для геометрии с ГРП, но не для радиальной ПЗП нашего проекта. Аналитический подход (Лаплас + Стефест) методологически близок.
