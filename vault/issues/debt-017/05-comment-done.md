**Ядро:**
- `energy/tridiag.py` — приватный `_ext_properties(bc)`: свойства фаз при условиях контура, единый источник для обоих методов. `compute_convective_coefficients` и `compute_jt` разбирают знак Q_α на грани N: отток → ячейка N−1, приток → ГУ. В `compute_jt` контурным берётся и давление в ⟨Φ·p⟩.

**Тесты:**

### Обнаружено при реализации

**`test_convergence_order_ge_1` (VAL-002) переписан на метод Рунге.** Тест мерил порядок против эталона `N_REF = 400`. Такая ошибка содержит паразитный вклад — погрешность самого эталона. После правки ошибка схемы упала в 27 раз (RMS 4.8e-3 → 1.7e-4) и стала сопоставима с ним: при N = 100 ошибка 6.7e-3 против 9.4e-4 у эталона, всего в 7 раз больше. Наклон исказился, тест давал 0.85 при фактическом первом порядке.

Метод Рунге не требует точного решения: `p = log2(|T_a − T_b| / |T_b − T_c|)` на сетках с отношением 2. Замер на том же коде: 1.081 / 1.043 / 1.022 / 1.011 на тройках 25-100 / 50-200 / 100-400 / 200-800. Порог ≥ 1.0 сохранён, тест не ослаблен.

Границы применимости проверены инъекциями: тест ловит появление в решении члена меньшего порядка (добавка B·√h даёт p = 0.497), но не ошибку в значении коэффициента — её ловит эталон DEBT-016, что проверено на той же инъекции.

Разбор: `vault/inbox/порядок-сходимости-val002-измеряется-против-недостаточно-мелкого-эталона.md`
