# Перенос диагностики в пакет не изменил вывод примеров — 23 примера побайтно

[[DEBT-011]] (#91) перенёс проверки расчёта из `numerical_solver/examples/` в пакет `gpn_multiphase_solver` для поставки заказчику: подпакет `diagnostics/` (замкнутое решение, двухфазный стационар, $R_s$, асимптотика $T$), ряды балансов — к накопителям (`energy/balance.py`, `mass_balance.py`), рисунки балансов и ОФП и узлы таблиц — в `io/output.py`; объекты задачи — свойства `Simulator.grid/pvt/relperm` и публичные `create_pvt`, `create_relperm`. План — [[debt-011 diagnostics-into-package]].

## Как проверено

Перенос — без изменения чисел, поэтому критерий — побайтное совпадение всего вывода примеров до и после. Проба `vault/issues/debt-011/probes/snapshot_examples.py` запускает 23 `main.py` отдельными процессами с `PYTHONPATH` на проверяемое дерево (печатает путь пакета — страж «снят не тот код»), EMF выключен, и сохраняет печать (путь дерева заменён на `<TREE>`, строка «Время расчёта» отброшена) и SHA-256 каждого файла `output/`.

| | до (база `87eb55f`) | после (ветка, `f0ad91a`) |
|---|---|---|
| примеров, код 0 | 23 | 23 |
| печать | — | совпадает у всех 23 |
| файлов `output/` | 291 | 291: 287 побайтно; 4 — время выполнения |

Четыре файла выхода прототипа у примера 18 (`prototype/results.xlsx`, `run_summary.json`, `run_summary.txt`, `summary.json`) содержат `wall_seconds` — время прогона. Два прогона одного и того же кода дают в них разные байты; проба отмечает их отдельно (`TIME_FILES`). PNG всех рисунков — в том числе `energy_balance.png`, `mass_balance.png`, `relperm.png`, где рисование разделено на функцию пакета и обёртку с записью файла, — побайтно прежние.

## Что ещё проверено

- Тесты: 1741 → 1799 (+12 в `test_public_api.py`, +46 — страж приватного доступа по каждому скрипту `examples/`), полный прогон зелёный.
- Колесо `pip wheel . --no-deps` содержит `gpn_multiphase_solver/diagnostics/` (до задачи — только `energy`, `grid`, `hydro`, `io`, `pvt`).
- Пробные запуски CLI `energy_balance.py 01`, `mass_balance.py 01`, `two_phase_analytics.py 03`, `temperature_asymptotics.py 02` — код 0.
- Стражи (разбор AST): `test_no_private_solver_access` — скрипты `examples/` не обращаются к приватным полям чужих объектов; `test_package_does_not_depend_on_examples` — пакет не импортирует модули `examples/` и не трогает `sys.path` (негативная проверка: подложенный `import closed_form` — красный).
- Страж DEBT-046 (`test_script_names_resolve`) поймал вызывающего, которого план пропустил: `04_table_table/grid_convergence.py` брал `SG_EPS` из `two_phase_analytics`.

## Значение

Проверки расчёта доступны пользователю установленного пакета без репозитория; в `examples/` остались печать, наложения на профили и запись рисунков — их переносит [[FEAT-030]].
