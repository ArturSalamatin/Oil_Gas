# Шаблоны для дефектов (BUG)

## 1. Тело задачи (`01-issue-body.md`)

```markdown
## Описание
(что происходит, критичность)

## Симптомы
(наблюдаемое поведение)

## Корневая причина
(подтверждённая причина или явно обозначенная гипотеза)

## Воспроизведение
(pytest-тест, команда запуска)

## Затронутые файлы
| Файл | Строки | Роль |
|---|---|---|
| `path/to/file.py` | L10–L20 | Описание |
(⚠️ пометки для файлов, которые не найдены или строки сдвинуты)

## Анализ вариантов решения
(для каждого варианта: суть, изменения, достоинства и недостатки)

## План решения
(укрупнённые этапы исправления и проверки по существу задачи)

## Ветка
`<имя ветки>`

## Связанные issues
(Related: #N)

## Связанные заметки в vault
(wiki-ссылки на заметки)
```

## 2. Комментарий «Контекст при открытии» (`02-comment-open.md`)

```markdown
### Контекст при открытии

- **Обнаружено:** <дата>
- **Ветка:** `<имя ветки>`
- **Коммит:** `<короткий SHA>`
- **Корневая причина:** <одно предложение>
- **Рекомендуемый вариант:** <номер варианта из анализа>
- **Оценка сложности:** <простой / средний / сложный>
```
