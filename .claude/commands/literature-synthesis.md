# Синтез литературных обзоров

Пользователь указал тему или раздел: `$ARGUMENTS`

Если `$ARGUMENTS` пуст — охватить все расширенные обзоры из `vault/knowledge/literature/`.

## Инструкции

### 1. Собери обзоры

- Прочитай `vault/knowledge/literature/index-literature.md` — определи тематические разделы.
- Проверь также legacy-заметки в `vault/` (корень): `ref_spe202436.md`, `ref_moments_method.md` и другие файлы `ref_*.md`.
- Если указана тема — отбери заметки по этому разделу.
- Прочитай frontmatter и секции «Метод», «Замечания», «Значение для проекта» каждой расширенной заметки.
- Краткие заметки (status: краткая) учитывай только если они группируют ≥3 ссылок по одной теме.

### 2. Построй сводную таблицу

Формат:

```markdown
| Работа | Год | Метод | Фазы | Геометрия | Температура | Применимость к ПЗП |
|---|---|---|---|---|---|---|
| [[Автор Год — тема]] | ГГГГ | описание | нефть+газ / газ / ... | радиальная / 1D / ... | да/нет/JT/... | высокая / частичная / нет |
```

Столбцы адаптируй под реальный набор работ. Обязательные параметры сравнения:
- Число фаз и компонентов
- Учёт температуры (какие эффекты)
- Тип геометрии (радиальная, 1D, 2D, 3D)
- Аналитический / численный / полуаналитический
- Применимость к задаче ПЗП (обоснуй)

### 3. Выяви группы и пробелы

- Какие подходы представлены хорошо (≥3 работ)?
- Какие подходы пропущены (упоминаются в одной работе, но не покрыты отдельными обзорами)?
- Есть ли противоречия между обзорами (метод назван ограниченным в одном и достаточным в другом)?

### 4. Составь черновик раздела «Обзор литературы»

Структура:
1. **Группировка по подходам** (не хронологическая, а тематическая).
2. **Связь с проектом** — для каждой группы: что взято, что не подходит, почему.
3. **Обоснование выбора** — почему метод моментов Баренблатта (или другой текущий подход) предпочтительнее.

Формат: LaTeX-фрагмент (без `\begin{document}`), готовый к вставке в Draft.

Стиль:
- Русский.
- `\cite{}` для ссылок (ключи вида `автор_год`).
- Критический тон: сравнение, не перечисление.
- Указывать конкретные ограничения каждого подхода.

### 5. Обнови vault

- Создай/обнови тематическую сборную заметку: `vault/knowledge/literature/ключевые работы по <тема>.md`
- Если выявлены пробелы — добавь TODO в сборную заметку.

### 6. Покажи результат

Выведи:
1. Сводную таблицу.
2. Список пробелов (работы для поиска/обзора).
3. Черновик LaTeX-фрагмента.

Спроси: куда вставить фрагмент (какой Draft), какие пробелы приоритетны для закрытия.
