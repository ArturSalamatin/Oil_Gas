# Andra 2008 — бенчмарк Couplex-gaz

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Andra.** Couplex-gaz. http://www.andra.fr/interne.php3?id_article=913&id_rubrique=76, 2008.

## Аннотация

Категория B. Бенчмарк французского национального агентства по обращению с радиоактивными отходами (Andra) по миграции газа (водорода) в хранилище. По [[Bourgeat Jurak Smaï 2009 — двухфазная фильтрация с растворением газа в хранилище отходов]], ни один из штатных кодов этой области не смог адекватно смоделировать появление и/или исчезновение одной из фаз. Тесты статьи построены «по мотивам» бенчмарка; решение самого бенчмарка авторы обещают в следующей работе.

## Потенциал для проекта

Промышленный пример задачи, на которой стандартные двухфазные формулировки дают сбой при исчезновении фазы. Физика другая: газ появляется от накопления компонента при почти постоянном давлении, а в ПЗП — от падения давления. Как тест единой формулировки (если до неё дойдёт) — второстепенный; для ПЗП нужнее собственные кейсы со скачками $p_{wf}$ ([[BUG-014]]).
