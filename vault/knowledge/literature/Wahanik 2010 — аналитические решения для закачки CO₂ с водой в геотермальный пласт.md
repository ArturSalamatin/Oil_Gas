# Wahanik 2010 — аналитические решения для закачки CO₂ с водой в геотермальный пласт

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Wahanik H., Eftekhari A.A., Bruining J., Marchesin D.** Analytical solutions for mixed CO₂–water injection in geothermal reservoirs. Paper SPE 138154, Canadian Unconventional Resources and International Petroleum Conference, Calgary, 19–21 October 2010.

## Аннотация
Категория A. Эталон для проверки в [[Salimi Wolf Bruining 2012 — отрицательные насыщенности для неизотермической фильтрации]] (рис. 1). Решение методом волновых кривых — расширения теории дробного потока — для неизотермической закачки холодной смеси CO₂–вода: 100 бар, 358 К, $T_{\text{зак}} = 298$ К, $z_{\text{CO}_2} = 0.29$, $k_{rg} = 0.95S_g^2$, $k_{rl} = 0.5(1-S_g)^2$. Последовательность волн: скачок Бакли–Леверетта, тепловая волна, волна разрежения Бакли–Леверетта, композиционный скачок. Здесь же описана термодинамическая модель, которую используют Salimi et al.: уравнение состояния Пенга–Робинсона–Стрыжека–Веры, правило смешения Хурона–Видаля второго порядка с NRTL, поправка объёма.
