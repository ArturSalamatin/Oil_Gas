# Gringarten Ramey Raghavan 1974 — типовые кривые для вертикальной трещины

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Gringarten A.C., Ramey H.J. Jr., Raghavan R.** Unsteady-State Pressure Distribution Created by a Well With a Single Infinite-Conductivity Vertical Fracture. *Soc. Pet. Eng. J.*, August 1974, 347–360; Trans. AIME, 257.

## Аннотация

Аналитическое решение для нестационарного распределения давления вокруг скважины с единственной вертикальной трещиной бесконечной проводимости. Построены drawdown type curves (Fig. 1 в Agarwal 1979), используемые как базовые для type curve matching в жидкостных и газовых системах.
