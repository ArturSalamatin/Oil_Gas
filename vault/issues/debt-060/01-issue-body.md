## Описание

Центр ячейки радиальной сетки во всех документах и докстрингах назван «центром масс кольцевого слоя». Формула `eq:cell_center` (`doc/problem_statement.tex`) даёт другую точку — среднее геометрическое радиуса по площади слоя, $r_j = \exp\langle\ln r\rangle$. Сама формула для метода конечных объёмов обоснована; неверно только название. Читатель, который проверит «центр масс» напрямую, получит расхождение 2–3 % и решит, что ошибочна формула.

Приоритет низкий: на расчёт не влияет, правятся только тексты.

## Текущее состояние

`eq:cell_center`:

$$r_j = r_{j+1/2}\sqrt{\exp\Bigl(-\frac{x\ln x}{1-x} - 1\Bigr)},\qquad x = \Bigl(\frac{r_{j-1/2}}{r_{j+1/2}}\Bigr)^2.$$

Это в точности

$$\ln r_j = \frac{\int_{r_{j-1/2}}^{r_{j+1/2}} r\ln r\,dr}{\int_{r_{j-1/2}}^{r_{j+1/2}} r\,dr} = \frac{r_{j+1/2}^2\ln r_{j+1/2} - r_{j-1/2}^2\ln r_{j-1/2}}{r_{j+1/2}^2 - r_{j-1/2}^2} - \frac12,$$

то есть среднее $\ln r$ по площади слоя. Физический смысл: в точке $r_j$ логарифмический профиль $p = A + B\ln r$ равен своему среднему по ячейке — накопление (среднее по объёму) и потоки (значения в центрах) согласованы на стационарном профиле.

Центр масс кольца — другая величина: $\langle r\rangle = \tfrac23\,(r_{j+1/2}^3 - r_{j-1/2}^3)/(r_{j+1/2}^2 - r_{j-1/2}^2)$.

Проверка (`_cell_centers_mass` на `b3ffaac`):

| Ячейка | $\exp\langle\ln r\rangle$ (код) | $\langle r\rangle$ (центр масс) | $\sqrt{r_{j-1/2}r_{j+1/2}}$ (прототип) |
|---|---|---|---|
| кольцо 1–2 м | 1.5284 | 1.5556 | 1.4142 |
| $r_w = 0.1$, $R = 500$, $N = 10$ | — | больше на 2.54 % во всех ячейках | — |

Неточны и смежные формулировки:

- `problem_statement.tex:938` — «логарифмически взвешенное среднее граней». Формула не является взвешенным средним $\ln r_{j\pm1/2}$: веса $r_{j+1/2}^2/(r_{j+1/2}^2 - r_{j-1/2}^2)$ и $-r_{j-1/2}^2/(\ldots)$, один отрицательный, плюс постоянная $-1/2$.
- `tests/test_grid.py:191`, докстринг `test_flux_exact_for_any_N`: «Центр масс кольца точен для логарифмического профиля при любом N». Точность потока у забоя от выбора центра **не зависит**: при $T_w = 2\pi kh/\ln(r_0/r_w)$ и $p(r_0)$ с точного логарифмического профиля поток равен дебиту Дюпюи при любом $r_0 > r_w$. Тест проверяет двухточечную схему с логарифмической проводимостью грани, а не центр ячейки.
- `tests/test_grid.py:308`, класс `TestCenterMassVerification` — проверяет как раз $\langle\ln r\rangle = \ln r_j$ (верно), но назван «центр масс».

## Целевое состояние

Одно корректное название центра ячейки во всех местах: `.tex`, докстринги, комментарии тестов, заметки vault. Формула и числа не меняются, истории примеров побитово те же. В `problem_statement.tex` рядом с `eq:cell_center` — одна строка вывода ($\ln r_j = \int r\ln r\,dr/\int r\,dr$) и физический смысл, чтобы читатель мог проверить формулу сам.

### Вариант A — заменить только название (рекомендуется)

Название — по согласованию с пользователем. Кандидаты:

| Название | Плюсы | Минусы |
|---|---|---|
| **среднее геометрическое радиуса по площади слоя** | точно: $\exp\langle\ln r\rangle_S$ — взвешенное по площади среднее геометрическое; естественно противопоставляется $\sqrt{r_{j-1/2}r_{j+1/2}}$ прототипа (среднее геометрическое граней) | длинно; в коде нужна короткая форма |
| точка среднего давления | физический смысл | формула геометрическая — то же свойство у любой величины, линейной по $\ln r$ (температура при теплопроводности); привязка к давлению сужает |
| ~~среднелогарифмический радиус~~ | — | **не годится**: «среднелогарифмическое» в русской технической литературе — $(b-a)/\ln(b/a)$, другая величина; создаст новую путаницу |
