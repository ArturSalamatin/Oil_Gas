# Хасанов 2010 — приток при разгазировании

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Хасанов М.М., Мукминов И.Р., Бачин С.И.** К расчету притока жидкости к скважинам, работающим в условиях локального разгазирования. Источник [12] в документе Краснова.

## Аннотация
Рассматривается приток жидкости к скважинам при локальном разгазировании в призабойной зоне. Работа непосредственно связана с моделированием двухфазной фильтрации при $p < p_b$ — центральная задача нашего проекта.

## Потенциал для проекта
Прямо релевантна: приток при разгазировании в ПЗП — ключевой процесс для моделей М.3–М.6.
