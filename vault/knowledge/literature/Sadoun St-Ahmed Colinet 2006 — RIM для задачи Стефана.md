# Sadoun St-Ahmed Colinet 2006 — RIM для задачи Стефана

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Sadoun N., St-Ahmed E.-K., Colinet P.** On the refined integral method for the one-phase Stefan problem with time-dependent boundary conditions. *Appl. Math. Modelling*, 2006, Vol. 30, pp. 531–544.

## Аннотация
Предложен Refined Integral Method (RIM) — усовершенствование HBIM через двукратное интегрирование PDE, что даёт первый пространственный момент $\int_0^s xu\,\mathrm{d}x$ (ур. 4.3 в Mitchell & Myers 2010). RIM повышает точность на порядок по сравнению со стандартным HBIM для квадратичного профиля при фиксированной температуре на границе. Mitchell & Myers (2010) показывают, что RIM — наиболее точный при задании $u$ на границе, но не при задании $\partial u / \partial x$.

## Потенциал для проекта
RIM = первый момент в терминологии Баренблатта. В проекте ПЗП первый момент используется для определения показателей формы $\beta$, $\sigma$ (§5 moments_method.tex). Sadoun — первоисточник этой идеи в контексте задач Стефана.
