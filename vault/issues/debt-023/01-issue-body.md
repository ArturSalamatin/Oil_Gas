## Описание

В восьми примерах — 03, 04, 04a, 05, 06, 07, 08, 09 — теплопроводность скелета и флюидов обнулена: `lambda_solid = lambda_oil = lambda_gas = 0`. Исходное обоснование (применимость ОДУ-аналитики температуры) исчезло вместе с самой аналитикой в DEBT-022 (#37). Нулевая теплопроводность физически невозможна. Кондуктивный член в ядре реализован и покрыт модульными тестами, но в восьми из двадцати одного штатного сценария не работает вовсе. Примеры входят в поставку заказчику, поэтому нефизичный режим в них — не только вопрос покрытия.

Задача: вернуть физические значения λ в примеры 03–09 и согласовать с этим README примеров, сводный README и тесты.

## Что проверить при планировании

1. **Суперпозиция (`test_thermal_superposition`).** Тест требует (T08 − T07) + (T09 − T07) = T04 − T07; сейчас невязка ~4e-13 К. При замороженной гидродинамике уравнение энергии линейно по T, а λ_eff зависит от S_g, не от T — суперпозиция должна остаться точной, **если λ одинаковы у 04, 07, 08 и 09**. Это прямое ограничение на «выборочный» вариант. Подтвердить замером.
2. **Однофазная асимптотика T = T_ext + μ_JT,o (p − p_0).** Довод README 03 «λ = 0 оставляет её применимой» по оценке слабее, чем выглядит. В координате ξ = ln r стационар однофазной зоны: Φ (dT/dξ − μ_JT dp/dξ) = 2πh λ d²T/dξ². При p, линейном по ξ (Дюпюи), асимптота тоже линейна по ξ, и кондуктивный член на ней равен нулю. Отклонения дают нелинейность p(ξ) из-за B_o(p), μ_o(p) и пограничный слой шириной ~1/Pe по ξ у границы двухфазной зоны. **Оценка не проверена** — замерить `err_1ph` из `report_asymptotics` до и после. В 10–21 эта проверка уже печатается при λ ≠ 0.
3. **Зависит ли гидродинамика от T.** Для табличного PVT (04, 04a, 06–09) — нет: это фиксирует `test_thermal_does_not_affect_hydro` (побитовое равенство 07/08/09). Для Стендинга (03, 05) R_s = R_s(p, T) — выяснить, видит ли гидродинамика текущую T. Если видит, сдвинутся p, S_g и дебиты 03/05.
4. **Сходимость по Δt (`test_dt_convergence`, пример 07).** Перепроверить монотонность ошибки по Δt при λ ≠ 0, поправить комментарий.
5. **Закреплённые числа в тестах.** Абсолютных значений T для 03–09 в `test_examples.py` нет (просмотрено 2026-10-11 по `approx`). У 04a закреплены только S_g(r_w) = 0.70 и q_o — гидродинамика табличного PVT, от λ не зависит.
6. **Порядок величины эффекта.** README 04: 0.002 К за 3 сут. Реестр (замер при разборе BUG-012, до DEBT-017 и BUG-013): 0.0002 К на забое, максимум 0.0029 К в примере 03. Перемерить на текущем коде.
