# Osorio Stewart Danesh 2005 — долгосрочная продуктивность газоконденсата из PTA

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Авторы.** Osorio R., Stewart G., Danesh A. et al. Estimating of Long Term Gas Condensate Well Productivity Using Pressure Transient Data. *SPE Europec/EAGE*, 2005. SPE 94065.

## Аннотация
Предложена методика оценки долгосрочной продуктивности газоконденсатных скважин по данным PTA. Используется двухзонная модель флюида (O'Dell–Miller 1966, Fussell 1973) для оценки псевдодавления: конденсатный скин уже включён в двухфазный интеграл.

## Потенциал для проекта
Методика прогноза продуктивности при двухзонной структуре — переносима на нефтяную скважину с зоной разгазирования для оценки потерь IPR.
