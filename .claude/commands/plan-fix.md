# План исправления бага

Пользователь указал задачу: `$ARGUMENTS`

Формат аргумента: `BUG-NNN` или описание бага.

## Инструкции

### 1. Загрузи контекст

- Прочитай запись в `vault/roadmap/известные баги и технический долг.md`.
- Если `$ARGUMENTS` — описание, а не ID, найди соответствующую запись или создай через `/issue`.
- Прочитай указанный файл и строку.

### 2. Воспроизведи

- Найди или напиши минимальный pytest-тест, который падает на баге.
- Запусти: `cd method_of_moments && python -m pytest tests/ -k "test_name" -v`.
- Если тест уже есть — укажи его.

### 3. Определи причину

- Цепочка от симптома к корневой причине.
- Конкретные строки кода.
- Связь с формулами из `.tex` — где расхождение между формулой и кодом?

### 4. Составь план

Записать в `vault/plans/BUG-NNN <slug>.md`:

```markdown
---
tags: [plan, bug-fix]
date: ГГГГ-ММ-ДД
issue: BUG-NNN
status: черновик
---

# BUG-NNN: Краткое описание

## Симптом
## Причина
## План исправления

### Шаг 1: ...
- Файл: `src/module.py:строка`
- Действие: ...
- Формула: \eqref{eq:...} из moments_method.tex

### Шаг 2: ...

## Верификация
- [ ] Тест `test_name` проходит
- [ ] pytest полный прогон без регрессий
- [ ] Физическая корректность: ...

## Подводные камни
- ...
```

### 5. Обнови roadmap

Добавь ссылку на план в запись BUG-NNN.

### 6. Спроси пользователя

Показать план. Приступать к реализации?
