# Oil_Gas — навигационный хаб vault

## Проект

Математическая модель призабойной зоны пласта (ПЗП): двухфазная фильтрация Black Oil + уравнение энергии.

  - [[bug-010 table-pvt-dt-anomaly]] — A-retry отдаёт поток последнего подшага вместо среднего за шаг; скачок $T$ на 0.48 К при отдельных $\Delta t$

## Команды

### Литература

| Команда | Назначение |
|---|---|
| `/review-paper <файл>` | Обзор статьи → расширенная заметка + краткие + индексы |
| `/review-after [автор год]` | Пост-обработка: полнота, ссылки, покрытие библиографии |
| `/review-book <файл> [глава N]` | Обзор книги/монографии по главам |
| `/literature-synthesis [тема]` | Синтез обзоров → сводная таблица + LaTeX-фрагмент |
| `/card <описание>` | Быстрая карточка: факт, решение, наблюдение |

### Разработка

| Команда | Назначение |
|---|---|
| `/issue <описание>` | Создание задачи (BUG/DEBT/FEAT/VAL) → GitHub issue + vault + комментарий |
| `/plan-fix <BUG-NNN>` | План исправления бага |
| `/plan-improve <DEBT-NNN>` | План рефакторинга / миграции / улучшения |
| `/plan-feature <FEAT-NNN>` | План фичи: формулы → код → тесты |
| `/plan-validate <VAL-NNN>` | План верификации: эталон, сценарий, tolerance |
| `/audit-plan <ID>` | Аудит плана по 7 измерениям перед /implement |
| `/implement <ID>` | Реализация плана из vault |
| `/run [config]` | Запуск решателя + визуализация |
