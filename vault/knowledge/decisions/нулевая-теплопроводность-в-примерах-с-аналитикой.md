# Теплопроводности обнуляются в примерах, где проверяется аналитика T

## Решение

В `config.json` примеров 04 и 05: `lambda_solid = lambda_oil = lambda_gas = 0`.
В примере 03 они ненулевые (1.5 / 0.14 / 0.04 Вт/(м·К)).

## Почему

Обе аналитические конструкции для температуры выведены **при λ = 0**:

1. **Телескопическая формула** (`temperature_asymptotics.stationary_face_temperature`)
   суммирует конвективные и источниковые члены вдоль радиуса:

   ```
   T_f = [Φ_N T_ext - J_N + J_f - L ρ_g,ст (R_N - R_f)] / Φ_f
   ```

   Кондуктивный поток в это суммирование не входит. При λ ≠ 0 остаётся
   необъяснённая поправка (в примере 03 — около 0.003 К).

2. **ОДУ-аналитика** (`temperature_ode`) — уравнение первого порядка.
   Теплопроводность добавила бы вторую производную и сделала задачу краевой.

При λ = 0 кондуктивная проводимость `Q_T = 2πh/(w_L/λ_L + w_R/λ_R)`
обращается в ноль тождественно, и аналитика описывает ровно ту задачу,
которую решает решатель.

## Что это даёт

Расхождение аналитики со схемой становится диагностическим: оно указывает
либо на ошибку сборки уравнения, либо на незавершённую релаксацию — но не
на отброшенную физику. Проверено в примере 05
(`check_stationary_T.py`): при выходе на стационар расхождение падает
до 7·10⁻¹¹ К и дальше не меняется.

| Длительность | max\|T_форм − T_числ\|, К |
|---|---|
| 3 сут | 3.9·10⁻¹ |
| 100 сут | 1.2·10⁻³ |
| 400 сут | 7.3·10⁻¹¹ |

## Что теряется

Немного: в примере 03 показано, что вклад кондукции здесь меньше сотых
долей кельвина (Pe = |Φ|/Q_T ~ 16, конвекция доминирует). Физика ПЗП
при добыче конвективная.

## Побочный эффект

При λ = 0 в `energy/tridiag.py:167` возникает `RuntimeWarning: divide by
zero` — деление `w/λ` даёт inf, затем `2πh/inf = 0`. Результат корректен
(Q_T = 0, кондукции нет), но предупреждение печатается на каждом шаге.
