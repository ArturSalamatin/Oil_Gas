# Первый час останова одним шагом занижает подъём температуры у забоя на 15 процентов — p сходится с первым порядком, T и R_s помнят первые шаги

Схема по времени (`problem_statement.tex`, `ssec:time_scheme`: неявная гидродинамика, энергия на замороженных $p^{n+1}$, $S_g^{n+1}$ — `eq:Qad_disc`, `eq:mdot_disc`, `eq:energy_disc_full`) на самом жёстком переходном процессе проекта — первом часе останова после добычи с развитой газовой зоной — сходится с **первым порядком**. Два разных пути сгущения ведут к **одному пределу**: по $p(r_w)$ — до 2.5e-4 бар, по $T(r_w)$ — до 4e-5 К. Локальное дробление шага ([[DEBT-015]]) на реальном решателе побитово равно явным подшагам.

Практика примеров 16 и 17 — первый час останова одним шагом 3600 с — занижает подъём за час: $p(r_w)$ на 8.85 бар (5.7 %), $T(r_w)$ на 0.230 К (15 %), рост $R_s(r_w)$ на 6.4 (23 %). Внешнего эталона нет ([[VAL-003]]); проверка внутренняя — сходимость по $\Delta t$.

## Сценарий и способ сгущения

`numerical_solver/tests/data/bug020_rs150/config.json` — замороженный сценарий [[BUG-020]]: $N$ = 350, $r_w$ = 0.1 м, $R_{ext}$ = 200 м, Стендинг, $R_{s0}$ = 150, $p_0$ = 24.7 МПа, $T_0$ = 400 К. 10 сут добычи при $p_{wf}$ = 3 МПа (интервал 1 сут — один шаг), затем $q_{oil} = 0$. На конец добычи $p(r_w)$ = 30.78 бар, $T(r_w)$ = 396.44 К, $R_s(r_w)$ = 13.26, двухфазных 332 из 350.

Шаг останова задаётся **длиной интервалов истории**, а не `dt_integration`: при `dt_integration` = 1 сут каждый короткий интервал — ровно один шаг. Добыча при этом не меняется, и состояние на конец добычи побитово одно во всех прогонах. Если менять `dt_integration`, в разность попала бы погрешность фазы добычи.

Серии:
- **равномерная** — $h = 3600/2^k$, $k$ = 0…12 (до 0.88 с);
- **нарастающая** — первый час из 10 шагов $3600/2^9, 3600/2^9, 3600/2^8, \dots, 1800$ с, каждый поделён на $2^k$; отношение шагов соседних прогонов — ровно 2 на каждом шаге.

Номинальный шаг ≠ фактический: первый шаг останова сходится немонотонно по длине — при 3600, 56.25, 7.03 с и мельче сходится, при 1800…112.5, 28 и 14 с не сходится и дробится. Поэтому в оценку порядка идут только прогоны **без отказов** гидродинамики.

## Результаты: первый час

Предел — Ричардсон по равномерному сгущению $k$ = 11, 12 при $q$ = 1: $p^*$ = 185.4611262 бар, $T^*$ = 398.0232431 К.

| величина | порядок (равномерно, $k$ = 10..12) | порядок (нарастающие, $k$ = 4..6) | предел нарастающих − предел равномерных |
|---|---|---|---|
| $p(r_w)$ | 0.9995 | 0.9942 | +2.51e-4 бар |
| $T(r_w)$ | 0.9535 (выход на 1 снизу: 0.29 → 0.95 при шаге 56 → 0.88 с) | 0.9981 | +4.11e-5 К |
| профиль $p$, $T$, $S_g$ (max-норма) | 1.00, 0.95, 0.94 | 0.994, 0.998, 1.012 | — |

| шаги первого часа | $p(r_w)$, бар | $T(r_w)$, К | $R_s(r_w)$ |
|---|---|---|---|
| один шаг 3600 с (практика) | −8.85 (5.7 % подъёма) | −0.230 (15 % подъёма) | −6.4 (23 % роста) |
| равномерно 56 с | −0.104 | −0.118 | −6.5 |
| равномерно 7 с | −0.013 | −0.025 | −8.6 |

## Механизм

- $p(r_w)$ квазистационарна: ошибку задаёт текущий шаг. Нарастающие шаги с наибольшим 112.5 с ошибаются по $p$ больше, чем равномерные 7 с.
- $T(r_w)$ и $R_s(r_w)$ **помнят первые секунды** останова. Время установления забойной ячейки ~$\phi\mu c_t\Delta r^2/(k k_r)$ — 0.01–0.1 с ($\Delta r_0$ = 2.2 мм). Нарастающие шаги от 0.44 с дают по $T$ ошибку −0.005 К при наибольшем шаге 112.5 с; равномерные 7 с — −0.025 К.
- $R_s(r_w)$ задаёт почти только **первый** шаг: прогоны с одинаковым первым шагом дают одно $R_s(r_w)$ при разных остальных шагах (32.70 при 7.03 с, 31.12 при 3.52 с, 34.13 при 1.76 с, 37.17 при 0.88 с — немонотонно), сходится только при первом шаге ≲ 0.5 с (порядок 0.90, предел ≈ 41.2). Ошибка не затухает: через сутки $R_s(r_w)$ тот же, что через час. Это [[BUG-026]]; гипотеза — подвижность газа на конце неявного шага.
- Газ к 1 ч растворился в ячейках 0–77 ($r \le 0.54$ м).

## Сутки останова

Тройка без отказов (первый час нарастающими шагами от $3600/2^{12+k}$, дальше по 56.25 / 28.125 / 14.06 с при $k$ = 1, 2, 3):

| на 24 ч | $q$ | предел | ошибка практики (`dt_integration` = 3600 с) |
|---|---|---|---|
| $p(r_w)$ | 1.000 | 224.7315 бар | −0.051 бар (0.03 % подъёма) |
| $T(r_w)$ | 0.947 | 399.0195 К | −0.064 К (2.5 % подъёма 2.58 К) |
| $R_s(r_w)$ | — | ≈ 41.2 | −6.4 (не затухает) |

$p$ к суткам ошибку первого часа «забывает»; ошибка $T$ — почти вся унаследована от первого часа (−0.23 → −0.064 К).

## Ограничения

- Шаг короче ~0.1 с на старте останова не сходится ([[BUG-025]]) — сгущение ограничено снизу; наименьший шаг теста 0.11 с.
- Один сценарий; конфиги 19–21 и примеры 16, 17 не сгущались (README примеров не менялись — решение пользователя: примеры самостоятельны, без контрольных прогонов).
- Внешнего эталона нет ([[VAL-003]]): проверены согласованность и предел дискретной схемы, а не физика.

## Тест

`numerical_solver/tests/test_val004.py`, метка `slow`, 9 тестов, ~75 с. Нарастающие шаги, $k$ = 4, 5, 6:
- `test_series_preconditions` — отказов нет, записи и время конца как заданы, добыча побитово одна;
- `test_wellbore_first_order[p|T]`, `test_profile_first_order[p|T|Sg]` — порядок по Рунге в [0.9, 1.1] (метод — как в [[VAL-002]]: без эталона);
- `test_limit_matches_uniform_refinement[p|T]` — $|2u_6 - u_5 - u_{ref}|$ ≤ 1e-3 бар / 5e-4 К, эталон — предел равномерного сгущения;
- `test_local_subdivision_equals_finer_series` — серия 4 с принудительным отказом первой попытки каждого интервала побитово равна серии 5.

Чувствительность проверена инъекциями (`vault/issues/val-004/probes/injections.out.txt`):

| инъекция | что падает |
|---|---|
| И1: адиабатический член с $dt \times 1.1$ (схема согласована с другим уравнением) | только предел $T$: −2.51e-2 К; порядок остаётся ~1 |
| И2: +1e-6 К к $T$ на каждом шаге (член, не исчезающий при $\Delta t \to 0$) | порядок $T$ (0.742) у забоя и по профилю, предел $T$ (+1.01e-3) |
| И3: энергия на подшаге дробления получает длину шага ([[BUG-010]]) | только тест дробления: $T$ max\|Δ\| = 0.165 К |

Не ловит: ошибку, общую для эталона и серии (если эталон пересчитан на ошибочном коде), ошибки пространственной дискретизации, физику.

## Следствия

- [[FEAT-032]] — после смены управления скважиной начинать с малого шага и удваивать. Для $T$ и $R_s$ нужен начальный шаг ≲ 0.5 с, но не меньше ~0.2 с ([[BUG-025]]); старт с 1 мин, как у прототипа, $R_s$ не исправляет.
- Шаг выбирается только по сходимости Ньютона — погрешность по времени не контролируется (наблюдение [[DEBT-029]]).
