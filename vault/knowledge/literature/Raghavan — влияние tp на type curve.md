# Raghavan — влияние tp на type curve

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Raghavan R.** The Effect of Producing Time on Type Curve Analysis. Submitted to SPE of AIME (Ref. 7 в Agarwal 1979).

## Аннотация

Исследование влияния продолжительности работы скважины $t_p$ до остановки на интерпретацию buildup-данных методом type curve matching. Показано, что при коротком $t_p$ drawdown type curves неприменимы для buildup-данных. Результаты использованы в Agarwal 1979 (Fig. 3) как обоснование ограничения $(t_p + \Delta t)/\Delta t \approx 1$.
