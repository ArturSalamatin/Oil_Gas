# Tabatabaie Pooladi-Darvish 2017 — многофазный линейный поток в tight oil

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Tabatabaie S.H., Pooladi-Darvish M.** Multiphase Linear Flow in Tight Oil Reservoirs. *SPE Reservoir Evaluation & Engineering*, 2017, 20(01), pp. 184–196.

## Аннотация
Модель насыщенности нефти $S_o(p)$ для двухфазного потока (нефть + газ), не зависящая от относительных фазовых проницаемостей (Eq. 17 в Al-Rbeawi 2018). Применяется к линейному потоку в tight oil. Ключевая идея: $S_o$ определяется из материального баланса и PVT-свойств без знания кривых ОФП.

## Потенциал для проекта
Модель $S_o(p)$ без ОФП может быть полезна для замыкания упрощённых моделей ПЗП (M.1–M.3), где пространственное распределение насыщенности заменяется средним значением.
