# Polubarinova-Kochina 1962 — движение грунтовых вод

> [!warning] Заметка составлена по контексту цитирования, не по первоисточнику.

**Полубаринова-Кочина П.Я.** Theory of Ground Water Movement. *Princeton U. Press*, 1962.

## Аннотация

Монография по теории движения грунтовых вод. Al-Hussainy 1966 (стр. 624) отмечает, что точное аналитическое решение Kidder (1957) для потока газа в полубесконечной среде (преобразование Больцмана) является частным случаем более общего решения Полубариновой-Кочиной. Работа также цитируется (стр. 631) в контексте суперпозиции и немонотонных свойств при инъекции.

## Потенциал для проекта

Классический источник по безнапорной фильтрации — прямая связь с GORM_2/trapped_gas.tex (уравнение Буссинеска). Преобразование Больцмана для нелинейной диффузии может быть полезно при поиске автомодельных решений для двухфазной задачи.
