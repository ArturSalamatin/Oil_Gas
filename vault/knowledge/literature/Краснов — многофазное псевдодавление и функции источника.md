# Краснов — многофазное псевдодавление и функции источника

**Полная ссылка.** Краснов В.А. (предположительно). Текущий (flowing) материальный баланс для многофазной фильтрации. Подход к моделированию скважин сложного заканчивания в реальном пространстве. Внутренний методический документ, без даты.

> [!info] Авторство установлено косвенно по ссылке [27] (Краснов В.А., Юдин Е.В., Лубнин А.А., 2010) и ссылкам [28] «уже был изложен ранее в статье [28]». Документ содержит красные рукописные пометки, характерные для рабочего конспекта.

## Задача

Документ решает две независимые задачи:

**Часть 1 (стр. 1–28).** Обобщение функции псевдодавления Аль-Хуссейни на случай многофазной фильтрации (газ–нефть–вода) в рамках модели Black Oil. Цель — свести нелинейное уравнение многофазной фильтрации к виду, аналогичному однофазному, через введение:
- многофазной функции псевдодавления $m^k(p)$,
- функции псевдовремени $t_{ao}$.

**Часть 2 (стр. 29–46).** Аналитическое моделирование производительности скважин сложного заканчивания (наклонные, горизонтальные, многозабойные) методом произведения Ньюмана с функциями мгновенного точечного источника в прямоугольном пласте.

## Метод

### Часть 1: Многофазное псевдодавление

**Определение.** Функция псевдодавления для $k$-ой фазы (ур. 0.1):
$$m^k(p) = \mu_i^k B_i^k \int_{p_{ref}}^{p} \frac{k_r^k(p)\,dp}{\mu^k(p)\,B^k(p)}.$$

Множитель $\mu_i^k B_i^k$ вынесен для нормировки; зависимость $k_r^k$ от давления — через связь насыщенности с давлением.

**Текущий материальный баланс (Flowing Material Balance, FMB).** Основное уравнение (ур. 0.2, 0.6):
$$\frac{q_k}{m^k(\overline{p_i}) - m^k(p_w)} = \frac{1}{b_{pss}} - \frac{1}{OFIP^k \cdot b_{pss}} \left[\frac{m^k(\overline{p_i}) - m^k(\overline{p})}{m^k(\overline{p_i}) - m^k(p_w)} OFIP^k\right],$$
где $b_{pss}$ — геометрический параметр, не зависящий от свойств флюида, $OFIP^k$ — запасы $k$-ой фазы.

**Вариант псевдодавления для нефти с учётом взаимных превращений** (ур. 0.13):
$$m_o = \mu_{oi} B_{oi} \int_{p_{ref}}^{p} \left(\frac{k_o(S_o)}{B_o(p)\mu_o(p)} + R_v \frac{k_g(S_g)}{B_g(p)\mu_g(p)}\right) dp.$$
Здесь $R_v$ — нефтесодержание газа. Интеграл учитывает перенос нефти в обеих фазах.

**Линеаризация.** Уравнение фильтрации (ур. 0.12) приводится к виду (ур. 0.23):
$$\mu_{oi} C_{ti} \varphi \frac{\partial m_o}{\partial t_{ao}} = \mathrm{div}(k \nabla m_o),$$
через введение псевдовремени (ур. 0.22):
$$t_{ao} = \mu_{oi} C_{ti} \varphi \int_0^t \frac{\left(\frac{k_o}{B_o\mu_o} + R_v \frac{k_g}{B_g\mu_g}\right)}{A(S_g, S_o, p)}\,d\tau.$$

**Ключевое ограничение:** функция $m^k(p)$ в общем случае *не является* однозначной функцией давления — зависит от истории процесса (различается для КПД и КВД при одном давлении).

**Условие GOR = const** (ур. 0.33–0.36). Упрощающее предположение: постоянство газового фактора позволяет связать $S_o(p)$ и построить однозначные функции псевдодавления.

**Автомодельное решение** (ур. 0.46–0.53). Переменная $y = \varphi r^2/(4kt)$ сводит радиальную задачу к ОДУ, аналогичному однофазному (ур. 0.53):
$$\frac{d}{dy}\left(y\frac{dm_o}{dy}\right) = -y\left(\frac{C}{\lambda}\right)^* \frac{dm_o}{dy},$$
где $(C/\lambda)^*$ — обобщённое отношение сжимаемости к подвижности двухфазной системы.

**Связь давления и насыщенности** (ур. 0.70):
$$\frac{dS}{dp} = -\frac{\frac{N}{y}(a\alpha'-\alpha a') + (a\beta'-\alpha b')}{\frac{N}{y}(a\dot{\alpha}-\alpha\dot{a}) + (a\dot{\beta}-\alpha\dot{b})}.$$

Важный вывод (ур. 0.87): на псевдоустановившемся режиме ($y \to 0$) газовый фактор $R = a/\alpha$ не зависит от давления и времени — его полная производная $dR/dp = 0$.

**Общая сжимаемость системы** (ур. 0.80–0.81):
$$C_t = S_o C_o + S_g C_g + C_{R_s},$$
где $C_{R_s} = S_o R_s' B_g/B_o$ — вклад фазового перехода (дегазации).

**Материальный баланс (tank model)** (ур. 0.89–0.118). Трёхфазный материальный баланс с введением коэффициентов $B_{to}$, $B_{tg}$ (ур. 0.104) и нормированных вкладов $\Phi_o$, $\Phi_g$, $\Phi_w$ (ур. 0.112):
$$\Phi_o \frac{N_p}{N} + \Phi_g \frac{G_p}{G} + \Phi_w \frac{W_{ps}}{W} = 1.$$
Отмечена ошибка в формуле D-9 работы SPE 185052.

### Часть 2: Функции источника для скважин сложного заканчивания

**Функция мгновенного точечного источника** (ур. 0.120–0.122) строится методом произведения Ньюмана в прямоугольном пласте. Для одномерных источников приводятся четыре типа решений (ips1–ips4) для разных граничных условий: заданный поток, заданное давление, смешанные (таблица стр. 30).

**Моделирование наклонных скважин** — параметризация сегмента (ур. 0.134), разбиение траектории на линейные сегменты, интегрирование функции точечного источника вдоль каждого.

**Регуляризация сингулярности.** При вычислении забойного давления подынтегральное выражение имеет сингулярность вблизи источника. Решение (ур. 0.149–0.151): вычесть установившееся решение $\Delta p = q\mu/(4\pi r k)$, интеграл от которого берётся аналитически, и прибавить его обратно.

**Численные поправки для ускорения счёта.** Разделение на малые и большие времена:
- большие: $ips1 \to 1$, тройное произведение тривиально (ур. 0.140–0.141);
- малые: переход к решению для бесконечного пласта через erfc (ур. 0.145, 0.149).

## Результаты

1. **Рис. 1** — совпадение профилей насыщенности (аналитическая зависимость vs. численная гидродинамическая модель) для КПД и КВД. Ссылка [115] (Fekete Harmony FMB Theory).
2. **Рис. 2** — апробация многофазного FMB (ссылка [114], Shahamat & Clarkson, SPE 185052) для случая многоскважинной трёхфазной задачи: нормированный дебит vs. нормированная накопленная добыча для нефти и газа.
3. **Рис. 4** — сравнение расчёта распределения депрессии вдоль оси скважины конечного вскрытия: без регуляризации (осцилляции) и с регуляризацией (гладкое решение).

## Замечания

1. **Не опубликованный документ.** Это рабочий конспект, а не рецензированная статья. Отсутствуют: автор на титульной странице, дата, журнал, нумерация уравнений начинается с (0.1). Содержит красные рукописные пометки («Арпс — какие a и b когда используются — Fekete + Baker + Материалы Петрашова», «Новая книга», «Далее анализ при активном аквифере»).

2. **Однозначность $m^k(p)$.** Сам автор подчёркивает, что многофазная функция псевдодавления в общем случае *не* однозначна — зависит от истории. Это фундаментальное ограничение подхода, особенно при наличии аквифера или закачки. Подход работает «чисто» только при истощении без закачки.

3. **Условие GOR = const.** Доказательство постоянства GOR на псевдоустановившемся режиме (ур. 0.87) — математически корректное, но оно справедливо только на больших временах и без влияния границ. На ранних временах связь $S(p)$ определяется из (0.77), а не из постоянства GOR.

4. **Нестыковка двух частей.** Первая часть (многофазное псевдодавление) и вторая (функции источника) — фактически независимые разделы, объединённые в одном документе. Связь только в том, что обе используют однофазные аналогии (линеаризованное уравнение) для многофазной задачи.

5. **Ошибки в тексте.** Стр. 25 — «Error! Reference source not found» (битые ссылки в Word/PDF). Стр. 31 — замечание «в статье [59] потерян множитель $2\pi$» (расхождение с Economides et al., SPE 27980).

6. **Расхождения в нотации с проектом.** Документ использует $R_v$ (нефтесодержание газа) — в нашем проекте этот параметр не фигурирует, т.к. рассматривается система нефть + растворённый газ без обратной конденсации. Функция псевдодавления обозначена $m^k(p)$, что не конфликтует с нотацией проекта.

## Значение для проекта

### Что применимо

1. **Общая сжимаемость двухфазной системы** $C_t = S_o C_o + S_g C_g + S_o R_s' B_g/B_o$ (ур. 0.80–0.81) — непосредственно используется в нашей модели ПЗП. Член $C_{R_s}$ отвечает за скачок сжимаемости при разгазировании — это тот же физический эффект, который даёт «аномальное» охлаждение в моделях М.1–М.6 (Draft/cooling_models.tex).

2. **Связь $dS/dp$ через автомодельную переменную** (ур. 0.70, 0.74, 0.77) может быть полезна как замыкающее соотношение для метода моментов (Draft4/moments_method.tex): вместо решения полной задачи на насыщенность, использовать алгебраическое выражение $dS/dp$ из условия малых или больших времён.

3. **Условие GOR = const на стационаре** (ур. 0.87) — обоснование для упрощения, которое мы фактически используем в стационарных оценках (модель М.3 в Draft/cooling_models.tex).

4. **Формализм FMB** (ур. 0.2) — потенциально полезен для верификации моделей ПЗП: построив график нормированного дебита vs. нормированной накопленной добычи, можно сравнить с аналитическим решением.

### Что неприменимо

1. Вторая часть (функции источника) не связана с нашей задачей — мы рассматриваем радиальную геометрию с одной вертикальной скважиной, а не сложное заканчивание.

2. Подход «всё сводим к однофазному» принципиально не учитывает температуру — наш проект строит модель именно с уравнением энергии (Draft4/two_phase_energy.tex).

3. Трёхфазный материальный баланс (нефть + газ + вода) избыточен — в нашей модели воды нет.
