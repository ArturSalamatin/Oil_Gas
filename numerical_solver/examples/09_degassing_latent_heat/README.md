# 09 — Разгазирование: адиабатический эффект + скрытая теплота дегазации

## Описание

Двухфазный сценарий с разгазированием: табличные PVT и ОФП,
$R_{s,0} = 30$, $p_{wf} = 8$ МПа. Включены адиабатический эффект и
скрытая теплота дегазации $L = 168000$ Дж/кг газа; Джоуль–Томсон
выключен ($\mu_{JT} = 0$).

Физика: выделение газа из раствора — фазовый переход, на который тратится
энергия. Тепло отбирается у флюида и породы, что охлаждает пласт в зоне
разгазирования.

## Комбинация модулей (B: Table + Table)

```json
"thermal": {
    "c_p_oil": 2000.0,
    "c_p_gas": 1000.0,
    "mu_JT_oil": 0.0,
    "mu_JT_gas": 0.0,
    "L_degas": 168000.0
}
```

| Модуль | Класс |
|---|---|
| PVT (гидро) | `TableFullPVT` |
| ОФП | `PrototypeRPAdapter` |
| Гидродинамика | `PrototypeHydroAdapter` |
| Энергия | `TridiagEnergySolver` |

Теплопроводность обнулена ($\lambda_s = \lambda_o = \lambda_g = 0$).

## Ожидаемое поведение

| Величина | Значение |
|---|---|
| $T(r_w)$ финал | **347.847 К** — охлаждение на 2.2 К |
| $S_g^{max}$ | 0.0147 |
| $R_s^{min}$ | 9.5 м³ст/м³ст |
| $q_o$ финал | $5.876 \times 10^{-3}$ м³ст/с |
| фронт $r_b$ | 2.63 м |

Баланс энергии за 3 сут:

| Компонент | Значение, Дж |
|---|---|
| адиабатика | $-1.348\times10^{10}$ |
| скрытая теплота | $-4.478\times10^{9}$ |
| конвекция | $+6.017\times10^{9}$ |
| $\Delta E$ (накопление) | $-1.194\times10^{10}$ |
| относительная невязка | $2.7\times10^{-16}$ |

Скрытая теплота забирает втрое меньше энергии, чем адиабатическое
расширение: газа выделяется мало, $S_g^{max}$ всего 1.5 %. При более
подвижной газовой фазе (см. раздел ниже) вклад вырос бы.

Зона охлаждения от дегазации **пространственно совпадает с зоной
разгазирования** ($r < r_b = 2.63$ м): член $-L\,\dot m$ отличен от нуля
только там, где газ выделяется.

Гидродинамика от тепловых параметров не зависит — следствие расщепления.

## Как увеличить газонасыщенность

$S_g^{max} = 1.5\,\%$ — свойство демонстрационной таблицы ОФП:
`relperm.csv` даёт $k_{rg} = 0.01$ уже при $S_g = 0.1$, газ подвижен и
выносится потоком. Для этого сценария рычаг вдвойне полезен: больше газа →
сильнее вклад скрытой теплоты. Заменить `relperm` на модель Кори с крутой
кривой:

```json
"relperm": {"model": "corey", "S_or": 0.2, "S_gc": 0.05,
            "n_o": 2.0, "n_g": 3.0, "kro_max": 1.0, "krg_max": 0.3}
```

даст $S_g^{max} = 0.165$ вместо 0.015. Увеличение длительности расчёта и
расширение $R_e$ не помогают: стационар наступает за 8–12 ч.

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| $L$ | `thermal.L_degas` | прямо пропорционально усиливает охлаждение |
| $c_{p,o}$, $c_{p,g}$ | `thermal` | тепловая инерция флюида |
| $R_{s,0}$ | `initial_conditions.Rs0` | больше газа выделится → сильнее эффект (макс. 30 для этой таблицы) |
| $R_e$ | `geometry.R_ext` | шире область; фронт $r_b$ растёт |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[0].duration` | ⚠️ стационар за 8–12 ч |
| частота записи | `time.history[0].dt_out` | запись раз в `dt_out` на этапе `duration`: 259 200 / 3600 → 72 интервала, 73 шага; `duration` должна делиться на `dt_out` |

### Что требует осторожности — $p_{wf}$

**Сверху:** при $p_{wf} > p_b = 15$ МПа разгазирования не будет вообще —
останется только адиабатический эффект.
**Снизу:** табличный PVT устойчив в диапазоне 14…3 МПа; при отказе
Newton помогает увеличение `"max_retries"` в секции `numerics`
(по умолчанию 9).

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.
