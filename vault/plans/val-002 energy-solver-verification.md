## Мотивация

`TridiagEnergySolver` — единственный модуль `gpn_multiphase_solver`, написанный с нуля (гидродинамика делегирована Prototype 1.0.3 через `PrototypeHydroAdapter`). Модуль содержит 7 подшагов сборки СЛАУ, каждый — потенциальный источник ошибки. Существующие unit-тесты (`test_energy.py`, ~35 тестов) изолируют слагаемые поодиночке на синтетических данных. VAL-002 проверяет **совместную** работу слагаемых на реальной радиальной сетке с физически согласованными потоками.

## Уравнение энергии (eq:energy_final)

```
ρ_cp_eff · ∂T/∂t + ρ_cp_conv · ∂T/∂r = div(λ_eff · ∂T/∂r) + Q_JT + Q_ad + Q_deg
```

Здесь:
- ρ_cp_eff = (1−φ)·(ρcₚ)_s + φ·(S_o·ρ_o·cₚ_o + S_g·ρ_g·cₚ_g) — объёмная теплоёмкость
- ρ_cp_conv · ∂T/∂r — конвекция (через Φ_α = ρ_α · cₚ_α · Q_α)
- div(λ_eff · ∂T/∂r) — теплопроводность
- Q_JT — эффект Джоуля-Томсона
- Q_ad — адиабатический эффект (∂p/∂t)
- Q_deg — скрытая теплота дегазации

ГУ:
- Забой (r = r_w): ∂T/∂r = 0 (Нейман — нулевой кондуктивный поток)
- Контур (r = R_ext): T = T_ext (Дирихле)

Дискретизация: неявная по T (eq:energy_tridiag). Коэффициенты a_j, b_j, c_j, d_j — eq. 33–36 problem_statement.tex. Решение — прогонка Томаса (LAPACK dgbsv).

## Общая стратегия

4 валидационных кейса (A–D), каждый изолирует определённую комбинацию слагаемых. Во всех кейсах — **однофазная** фильтрация (Sg=0, L=0), чтобы убрать дегазацию и получить аналитическое решение. Это корректно: при Sg=0 кейс C покрывает основной физический эффект (JT-охлаждение при притоке), а дегазация уже проверена в unit-тестах поодиночке.

## Шаг 2: Кейс D — нестационарная теплопроводность (Q=0)

**Цель:** проверить накопительный член и кондуктивные коэффициенты без влияния конвекции.

**Файлы:**
- `numerical_solver/tests/test_val002.py`

**Контекст:**
Скважина закрыта (Q=0), начальная ступенька T₀ ≠ T_ext. Чистая диффузия тепла в радиальной геометрии. Это проверяет:
- Подшаг 1–2: ρ_cp_eff (при Q=0 конвекция не участвует)
- Подшаг 4: кондуктивная проводимость Q_T
- Подшаг 6: сборка СЛАУ (накопление + кондукция)
- ГУ: Нейман на забое, Дирихле на контуре

Уравнение:
```
ρ_cp_eff · ∂T/∂t = (1/r) · ∂/∂r (r · λ_eff · ∂T/∂r)
```

ГУ: T(R_ext, t) = T_ext, ∂T/∂r|_{r_w} = 0.
IC: T(r, 0) = T₀ ≠ T_ext.

**Эталон:**

Точное аналитическое решение этой задачи в конечном кольце r_w < r < R_ext с ГУ Нейман + Дирихле — ряд Фурье-Бесселя. Сходимость ряда медленная, и реализация функций Бесселя для конечной области громоздка.

Альтернативный подход: **проверка свойств решения** вместо точного числа.

1. **Асимптотика t → ∞:** T(r) → T_ext (единственный стационар при Q=0).
   Метрика: max|T(r) − T_ext| < ε после достаточного числа шагов.

2. **Баланс энергии:** на каждом шаге:
   ```
   Σ_j V_j · ρ_cp_eff · (T_j^{n+1} − T_j^n) = −dt · Q_T_ext · (T_{N-1}^{n+1} − T_ext)
   ```
   (единственный кондуктивный поток — через контур, забой = Нейман → 0)
   Невязка баланса < 1e-12.

3. **Принцип максимума:** min(T₀, T_ext) ≤ T(r,t) ≤ max(T₀, T_ext) на каждом шаге.

4. **Монотонность по времени:** если T₀ < T_ext, то T(r,t) монотонно растёт при каждом r.

5. **Характерное время диффузии:**
   ```
   τ = ρ_cp_eff · (R_ext − r_w)² / λ_eff
   ```
   При t ≫ τ отклонение от T_ext должно быть экспоненциально мало.

**Параметры:**

| Параметр | Значение | Обоснование |
|---|---|---|
| T₀ | 330.0 К | ΔT = 20 К от T_ext=350 К — достаточно для метрик |
| μ_JT_o, μ_JT_g | 0.0 | изолируем теплопроводность |
| L | 0.0 | без дегазации |
| λ_solid | 1.5 Вт/(м·К) | типичное |
| λ_oil | 0.14 Вт/(м·К) | типичное |
| λ_gas | 0.04 Вт/(м·К) | не используется (Sg=0) |
| N | 50 | достаточно для 2% точности |
| dt | 3600 с (1 ч) | |
| n_steps | 2000 | t_end = 7.2e6 с ≈ 83 дня |

Оценка λ_eff при Sg=0:
```
λ_eff = (1−φ)·λ_solid + φ·(S_o·λ_oil + S_g·λ_gas)
      = 0.8 · 1.5 + 0.2 · 1.0 · 0.14 = 1.228 Вт/(м·К)
```

Оценка ρ_cp_eff при Sg=0, ρ_o ≈ 728 кг/м³:
```
ρ_cp_eff = (1−φ)·(ρcₚ)_s + φ·ρ_o·cₚ_o
         = 0.8 · 1.25e6 + 0.2 · 728 · 2000 ≈ 1.291e6 Дж/(м³·К)
```

Характерное время:
```
τ = ρ_cp_eff · L² / λ_eff, L = R_ext − r_w = 49.9 м
  = 1.291e6 · 49.9² / 1.228 ≈ 2.62e9 с ≈ 83 года
```

Это огромное время — диффузия в пласте очень медленная. За 2000 шагов (83 дня) T сдвинется незначительно от T₀. Тогда проверки:

- Принцип максимума: T ∈ [T₀, T_ext] = [330, 350] на каждом шаге — **да**.
- Монотонность: T растёт — **да**.
- Баланс энергии: невязка < 1e-12 — **да**.
- Асимптотика: за 83 дня T сдвинется мало. Проверяем: T_final ∈ (T₀, T_ext) — **да**.
  Для полной сходимости к T_ext нужно ~τ, но это нереально по времени. Проверять: T(r_w) > T₀ (что прогресс есть) и T(R_ext−) < T_ext (ещё не дошло).

**Что сделать:**

1. Создать фикстуру: grid, pvt (mu_JT=0, L=0), rock (стандартные λ), solver.
2. IC: p = p_ext (uniform, нет градиента → нет потоков), T = T₀ = 330 К.
3. HydroResult: нулевые потоки (Q=0), state.p = p_ext (нет dp → нет Q_ad).
4. Цикл: n_steps шагов `solver.solve(hydro, state_prev, dt, T_ext)`, обновляя T в state_prev.

## Шаг 3: Кейс B — чистый JT, стационар

**Цель:** проверить JT-источник на реальном профиле давления.

**Файлы:**
- `numerical_solver/tests/test_val002.py`

**Контекст:**
Однофазный стационарный приток, λ_eff ≈ 0 (очень маленькое λ, чтобы доминировала конвекция), L=0. Конвекция переносит T с контура, JT-эффект меняет T. В стационаре без теплопроводности уравнение вырождается:

```
Φ · dT/dr = J_JT
```

где Φ = ρ_o · cₚ_o · Q_o — конвективный коэффициент (const при стационарном потоке и однофазной нефти с постоянными свойствами), J_JT — JT-источник.

**Вывод аналитического решения:**

Стационарное уравнение энергии в радиальной геометрии при Q_o = const, μ_JT = const, cₚ = const, λ_eff = 0, L = 0:

```
ρ_o · cₚ_o · Q_o · dT/dr = ρ_o · cₚ_o · μ_JT · Q_o · dp/dr
```

Сокращая ρ_o · cₚ_o · Q_o ≠ 0:

```
dT/dr = μ_JT · dp/dr
```

Интегрируя от R_ext (где T = T_ext, p = p_ext):

```
T(r) = T_ext + μ_JT · (p(r) − p_ext)
```

Подставляя p(r) Дюпюи:

```
T(r) = T_ext + μ_JT · (p_wf − p_ext) · ln(r/r_w) / ln(R_ext/r_w)
     = T_ext − μ_JT · Δp · (1 − ln(r/r_w) / ln(R_ext/r_w))
```

где Δp = p_ext − p_wf = 5 МПа. При μ_JT = −3e-7 К/Па:

```
ΔT_w = T(r_w) − T_ext = μ_JT · (p_wf − p_ext) = (−3e-7) · (−5e6) = 1.5 К
```

Забойный нагрев — 1.5 К (при μ_JT < 0 расширение нагревает). Для охлаждения нужен μ_JT > 0 (типичный для лёгких нефтей). Профиль T(r) — логарифмический, как p(r).

**Важно:** формула `T(r) = T_ext + μ_JT · (p(r) − p_ext)` верна **только** когда конвекция и JT сбалансированы, а теплопроводность отсутствует. При λ_eff > 0 теплопроводность сглаживает профиль.

**Нюанс реализации:** в `TridiagEnergySolver` полностью нулевое λ_eff невозможно (деление на ноль в `compute_conductive_transmissibility` через `1.0 / (w_L / lam_L + w_R / lam_R)`). Нужно задать λ_eff достаточно маленьким, чтобы число Пекле Pe ≫ 1:

```
Pe = ρ_o · cₚ_o · |Q_o| / (2πh · λ_eff)
   = 728 · 2000 · 4.57e-5 / (2π · 10 · λ_eff)
   = 66.5 / λ_eff
```

При λ_eff = 0.001 Вт/(м·К): Pe ≈ 66500 — теплопроводность пренебрежимо мала.

Задать: λ_solid = 0.001, λ_oil = 0.001, λ_gas = 0.001.
Тогда: λ_eff = (1−0.2)·0.001 + 0.2·0.001 = 0.001 Вт/(м·К).

**Параметры:**

| Параметр | Значение | Обоснование |
|---|---|---|
| μ_JT_o | −3e-7 К/Па | типичный JT для нефти |
| μ_JT_g | 0.0 | однофазная нефть |
| L | 0.0 | без дегазации |
| λ_solid | 0.001 | ≈ 0, Pe ≫ 1 |
| λ_oil | 0.001 | ≈ 0 |
| λ_gas | 0.001 | не используется |
| N | 50 | |
| dt | 1e7 с (~116 дней) | большой шаг для ускорения выхода на стационар неявной схемы |
| n_steps | 200 | достаточно при большом dt (cap/|Φ| ≈ 60 при dt=1e7, exp(−200/60) ≈ 0.04) |

**Обоснование выбора dt:**
При dt = 3600 с стационар не достигается за разумное число шагов (cap/|Φ| ~ 16800 для внешних ячеек). Увеличение dt до 1e7 с снижает cap/|Φ| до ~60, позволяя достичь стационара за ~200 шагов. Неявная схема безусловно устойчива, большой dt не вызывает проблем.

Альтернативно: вместо фиксированного n_steps использовать критерий сходимости: `max|T^{n+1} − T^n| / |ΔT_w| < 1e-4` (стационар до 0.01% от JT-охлаждения).

**Что сделать:**

1. Фикстура: grid, pvt (mu_JT_o=−3e-7, L=0), rock (λ≈0), solver.
2. IC: стационарный p(r), T(r,0) = T_ext (uniform).
3. HydroResult: стационарные потоки из compute_fluxes (шаг 1).
4. Многошаговый прогон: solver.solve() в цикле, p и потоки фиксированы (стационарный приток), обновляется только T. Остановка по критерию сходимости или по n_steps (что раньше).
5. После стационара — сравнить T(r) с аналитикой.

Эталонная формула:
```python
T_exact = T_ext + mu_JT * (p_profile - p_ext)
```

```python
        """T(r) монотонна по r. При μ_JT < 0: T убывает от r_w к R_ext (забой теплее).
        При μ_JT > 0: T растёт от r_w к R_ext (забой холоднее)."""

    def test_maximum_principle(self):
        """T ∈ [min(T_ext, T_ext+μ_JT·(p_wf−p_ext)), max(T_ext, T_ext+μ_JT·(p_wf−p_ext))]."""
```

**Метрика:** max|T_num − T_exact| / |μ_JT · Δp| < 1%.

При μ_JT·Δp = 1.5 К, tolerance 1% → допуск 0.015 К.

**Подводные камни:**

## Шаг 4: Кейс C — конвекция + JT, стационар

**Цель:** проверить баланс конвективного переноса и JT-источника — основной физический режим охлаждения ПЗП.

**Файлы:**
- `numerical_solver/tests/test_val002.py`

**Контекст:**

Этот кейс **совпадает** с кейсом B при постоянных свойствах! Вывод:

Стационарное уравнение при Q_o = const, μ_JT = const, cₚ = const, λ_eff = 0:

```
ρ_o · cₚ_o · Q_o · dT/dr = ρ_o · cₚ_o · μ_JT · Q_o · dp/dr
```

→ `dT/dr = μ_JT · dp/dr` → `T(r) = T_ext + μ_JT · (p(r) − p_ext)`.

В issue указано решение `T(r) = T_ext + (μ_JT / cₚ) · (p(r) − p_ext)` — это **неверно** при данной реализации JT. Пересмотрим.

В `TridiagEnergySolver` JT-источник (подшаг 5a, compute_jt) реализован как:

```
J_face[f] = μ_JT_up · (Φ⁺ · p[f-1] + Φ⁻ · p[f])
J_jt[j] = J_face[j+1] − J_face[j]
```

где Φ = ρ_o · cₚ_o · Q_o. Это значит, что JT-поток **уже содержит** множитель ρ_o·cₚ_o. Стационарный баланс ячейки:

```
(Φ · T)_{j+1/2} − (Φ · T)_{j-1/2} = (μ_JT · Φ · p)_{j+1/2} − (μ_JT · Φ · p)_{j-1/2}
```

При постоянных Φ и μ_JT:

```
Φ · (T_{j+1/2} − T_{j-1/2}) = μ_JT · Φ · (p_{j+1/2} − p_{j-1/2})
```

→ `T(r) = T_ext + μ_JT · (p(r) − p_ext)`.

**Заключение:** кейсы B и C при постоянных свойствах дают **одну и ту же** формулу. Разница возникла бы при переменном μ_JT(p,T) или при ненулевом λ_eff. 

**Решение:** объединить B и C в один кейс B, а кейс C переформулировать как **конвекция + JT + умеренная теплопроводность** (Pe ~ O(1)), чтобы проверить взаимодействие всех трёх слагаемых.

При Pe ~ O(1) аналитическое решение ODE:

```
Φ · dT/dr = d/dr(r · λ_eff · dT/dr) / r + μ_JT · Φ · dp/dr
```

Замена u(r) = T(r) − μ_JT · p(r):

```
Φ · du/dr = d/dr(r · λ_eff · du/dr) / r + λ_eff · μ_JT · d/dr(r · dp/dr) / r
```

Последний член = 0 при стационарном притоке (div(r·dp/dr) = 0 — уравнение Лапласа). Тогда:

```
Φ · du/dr = (1/r) · d/dr(r · λ_eff · du/dr)
```

ГУ: u(R_ext) = T_ext − μ_JT · p_ext = 0 (точнее, u(R_ext) = 0 если T_ext = T_ext и p(R_ext)=p_ext).
ГУ забой: du/dr|_{r_w} = −μ_JT · dp/dr|_{r_w} ≠ 0 (не Нейман для u!).

Забойное ГУ для T: dT/dr|_{r_w} = 0, а dp/dr|_{r_w} ≠ 0, значит du/dr|_{r_w} = −μ_JT · dp/dr|_{r_w}.

Это ODE для u(r) = T − μ_JT·p в кольце с конвекцией и теплопроводностью, неоднородное ГУ на забое. Решение выражается через функции Бесселя (или, при постоянном Q/r, через степенные функции).

Заменим переменную: r → ξ = ln(r/r_w), ξ ∈ [0, L̃], L̃ = ln(R_ext/r_w).

При постоянных λ_eff и Φ = ρ_o·cₚ_o·Q_o (Q_o = const·r — нет! Q_o [м³пл/с] на грани = const при стационаре, но это объёмный расход, а не скорость):

```
Q_o = 2πrh · u_o = const (стационар)
```

Подставляя Φ = ρ_o · cₚ_o · Q_o (const), уравнение конвекции-диффузии в координатах:

```
Φ · dT/dr = (1/r) d/dr (r · λ_eff · dT/dr) + μ_JT · Φ · dp/dr
```

Замена переменной ξ = ln(r/r_w), dr = r·dξ:

```
Φ/r · dT/dξ = (1/r²) d/dξ (λ_eff · dT/dξ) + μ_JT · Φ/r · dp/dξ
```

Учтём, что dp/dξ = (p_ext − p_wf)/L̃ = const (логарифмический профиль → dp/d(lnr) = const).

Умножим на r²/λ_eff:

```
(Φ·r/λ_eff) · dT/dξ = d²T/dξ² + μ_JT · (Φ·r/λ_eff) · dp/dξ
```

Проблема: r = r_w · exp(ξ) — переменный коэффициент. ODE с переменными коэффициентами — аналитическое решение через функции Бесселя, что громоздко.

**Упрощение:** вместо аналитического решения с конечным λ — использовать **проверку сходимости по сетке** для кейса C.

**Переформулированный кейс C:**

Кейс C: конвекция + JT + теплопроводность, Pe ~ O(1). Проверка: **mesh refinement** — убедиться, что ошибка уменьшается с порядком ≥ 2 при измельчении сетки. Эталон — решение на самой мелкой сетке (N=400).

**Параметры:**

Pe при λ_eff = 1.228:
```
Pe = 728 · 2000 · 4.57e-5 / (2π · 10 · 1.228) ≈ 0.86
```

Pe ~ 1 — конвекция и теплопроводность сопоставимы. Идеальный режим для проверки взаимодействия.

## Шаг 5: Кейс A — конвекция + теплопроводность (без JT)

**Цель:** проверить конвекцию + теплопроводность совместно, без JT-источника.

**Файлы:**
- `numerical_solver/tests/test_val002.py`

**Контекст:**
Стационарный приток, μ_JT = 0, L = 0. Уравнение:

```
Φ · dT/dr = (1/r) d/dr (r · λ_eff · dT/dr)
```

ГУ: T(R_ext) = T_ext, dT/dr|_{r_w} = 0.

Это **однородное** уравнение конвекции-диффузии. Стационарное решение при ГУ Нейман + Дирихле:

Если IC = T₀ ≠ T_ext и μ_JT = 0, то в стационаре T(r) = T_ext (ток от контура при T_ext, нет источников → всё приходит к T_ext).

Это тривиальный стационар. Нетривиальный результат: **скорость** выхода на стационар зависит от Pe. При Pe ≫ 1 — конвекция быстро выравнивает T. При Pe ≪ 1 — теплопроводность медленно выравнивает T.

Проверка: при Pe = 0.86 (наши параметры) — выход на стационар за ~τ_conv = V/(|Q_o|·ρ_o·cₚ_o/ρ_cp_eff) ≈ ...

Полный объём пласта:
```
V = π · h · (R_ext² − r_w²) ≈ π · 10 · 2500 ≈ 78540 м³
```

Тепловой расход:
```
|Φ| = ρ_o · cₚ_o · |Q_o| = 728 · 2000 · 4.57e-5 ≈ 66.5 Вт/К
```

Время опустошения по теплу:
```
τ_conv = V · ρ_cp_eff / |Φ| ≈ 78540 · 1.291e6 / 66.5 ≈ 1.52e9 с ≈ 48 лет
```

Это слишком долго для теста. Альтернатива: **увеличить расход** (уменьшить μ_o или увеличить Δp). Или сделать малый R_ext.

Вариант: R_ext = 5.0 м (вместо 50), тогда V уменьшается в ~100 раз, τ ~ 0.5 года. Всё ещё долго.

**Решение:** кейс A — **вырожденный** (стационар T = T_ext). Физически интересный вопрос — скорость выхода на стационар — требует нестационарных аналитических решений (Фурье-Бессель).

Переформулируем: **кейс A проверяет, что при μ_JT=0 решение приходит к T=T_ext**, а не к какому-то другому профилю. Это более слабый, но полезный тест — ловит ошибки знака в конвективных коэффициентах.

3. Проверить: T(r) ближе к T_ext, чем T₀ (направление сходимости правильное).

```
V_j · ρ_cp_eff_j · (T_j^{n+1} − T_j^n) / dt + (F_{j+1/2} − F_{j-1/2}) = −(Q_{T,j+1/2}·(T_j − T_{j+1}) − Q_{T,j-1/2}·(T_{j-1} − T_j)) + J_jt[j] + V_j·(Q_ad[j] + Q_deg[j])
```
