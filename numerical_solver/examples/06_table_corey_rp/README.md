# 06 — Смешанная комбинация: табличные PVT + ОФП Кори (комбинация D)

**Ситуация:** лабораторное исследование PVT есть, а керновых кривых ОФП нет —
используется аналитическая модель Кори с оценочными параметрами.

## Описание

Двухфазный сценарий с разгазированием: $R_{s,0} = 30$, $p_b = 15$ МПа,
$p_{wf} = 8$ МПа, полная термика. PVT задан таблицами, ОФП — аналитической
моделью Кори. Библиотека не требует согласованности «источника» данных:
модули PVT и ОФП комбинируются в любом сочетании.

## Комбинация модулей (D: Table PVT + Corey ОФП)

| Модуль | Класс | Ключ конфига | Внешние файлы |
|---|---|---|---|
| Сетка | `LogRadialGrid` | `grid.N = 50` | — |
| PVT (гидро) | `TableFullPVT` | `pvt.model = "table"` | **`oil_pvt.csv`, `gas_pvt.csv`** |
| ОФП | `CoreyRP` | `relperm.model = "corey"` | **нет** |
| Гидродинамика | `PrototypeHydroAdapter` | (единственный) | — |
| Энергия | `TridiagEnergySolver` | (единственный) | — |
| Управление | `PressureControl` | `control = "pressure"` | — |

Как это задаётся:

```json
"pvt": {"model": "table", "rho_o_std": 850.0, "rho_g_std": 0.85,
        "oil_pvt_file": "oil_pvt.csv", "gas_pvt_file": "gas_pvt.csv"},
"relperm": {"model": "corey", "S_or": 0.2, "S_gc": 0.05,
            "n_o": 2.0, "n_g": 2.0, "kro_max": 1.0, "krg_max": 0.8}
```

В папке лежат **только `oil_pvt.csv` и `gas_pvt.csv`**.
Файл `relperm.csv` не нужен — ОФП считаются по формулам Кори:
$k_{ro} = k_{ro}^{max} \left(\frac{S_o - S_{or}}{1 - S_{or} - S_{gc}}\right)^{n_o}$,
$k_{rg} = k_{rg}^{max} \left(\frac{S_g - S_{gc}}{1 - S_{or} - S_{gc}}\right)^{n_g}$.

## Ключевые параметры

| Параметр | Значение | Смысл |
|---|---|---|
| $R_{s,0}$ | 30 м³ст/м³ст | ограничен таблицей PVTO |
| $p_b$ | 15 МПа | из `oil_pvt.csv` |
| $p_0$ / $p_{wf}$ | 20 / 8 МПа | |
| $S_{or}$ / $S_{gc}$ | 0.2 / 0.05 | остаточные насыщенности Кори |
| $n_o$ / $n_g$ | 2.0 / 2.0 | показатели степени |
| $k_{ro}^{max}$ / $k_{rg}^{max}$ | 1.0 / 0.8 | |
| $\lambda_s$ / $\lambda_o$ / $\lambda_g$ | 0 / 0 / 0 | теплопроводность обнулена |

## Ожидаемое поведение

| Величина | Значение |
|---|---|
| $S_g^{max}$ | 0.0811 |
| $R_s^{min}$ | 9.5 м³ст/м³ст |
| $T(r_w)$ финал | 351.511 К (нагрев на 1.5 К) |
| $q_o$ финал | $5.763 \times 10^{-3}$ м³ст/с |
| фронт разгазирования $r_b$ | 2.49 м |

Насыщенность задаёт условие GOR $= R_{s,0}$: оно фиксирует отношение
$k_{rg}/k_{ro}$, а ОФП определяет лишь, при какой $S_g$ это отношение
достигается. Тепловая задача видит только потоки, поэтому от параметров
Кори температура и дебит зависят слабо, а насыщенность — сильно. Смотреть
надо `saturation_profiles.png`.

## Как увеличить газонасыщенность

$S_g^{max} = 0.081$ — около 8 %. Главный рычаг — параметры Кори в этом же
конфиге:

| $n_g$ | $k_{rg}^{max}$ | $S_{gc}$ | $S_g^{max}$ |
|---|---|---|---|
| 2.0 | 0.8 | 0.05 | 0.081 (текущий) |
| 3.0 | 0.3 | 0.05 | **0.165** |
| 4.0 | 0.1 | 0.10 | **0.306** |

Логика: чем **менее** подвижен газ (больше $n_g$, меньше $k_{rg}^{max}$),
тем бо́льшая насыщенность нужна, чтобы вынести то же количество газа.
В стационаре GOR всегда равен $R_{s,0}$ — весь поступающий с контура газ
уходит в скважину, накопления нет.

Что **не** помогает: увеличение длительности расчёта (стационар наступает
за 8–12 ч), расширение $R_e$ (двигает фронт, не насыщенность).

При отказе `RuntimeError: HydroSolver не сошёлся при дроблении шага до dt/N …`
увеличить `"max_retries"` в секции `numerics` (по умолчанию 9).

## Как модифицировать

### Что менять безопасно

| Параметр | Секция JSON | Эффект |
|---|---|---|
| параметры Кори | `relperm` | сильно влияет на $S_g$, слабо — на $T$ и дебит |
| содержимое CSV PVT | `oil_pvt.csv`, `gas_pvt.csv` | своя лаборатория |
| $R_e$ | `geometry.R_ext` | шире область; фронт $r_b$ растёт |
| $h$, $k$, $\varphi$ | `geometry`, `rock` | дебит |
| $N$ | `grid.N` | детальность профилей |
| длительность | `time.history[0].duration` | ⚠️ стационар за 8–12 ч |
| частота записи | `time.history[0].dt_out` | запись раз в `dt_out` на этапе `duration`: 259 200 / 3600 → 72 интервала, 73 шага; `duration` должна делиться на `dt_out` |
| тепловые скаляры | `thermal` | только $T$ (расщепление) |

### Что требует осторожности — $p_{wf}$

**Сверху:** при $p_{wf} > p_b = 15$ МПа разгазирования не будет.

**Снизу:** табличный PVT устойчив в диапазоне 14…3 МПа.

### Не трогать

`grid.type` и `output.format` — объявлены в `io/config.py`, но не читаются.
